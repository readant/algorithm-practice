# 训练记录 · 第二个真值源

> **`真实比赛/` 覆盖低频高信号的赛场；本目录覆盖高频的日常训练。**
> 两者共用同一套「真值源 → 生成器 → 数据出口」管线，一起进仪表盘。
>
> 本目录只装**真实训练事实**。AI 生成的题解、讲义一律不算——那是学习材料，见 `题解归档/`、`学习模块/`。

---

## 为什么要有它

`题解归档/洛谷` 里的 40 题*看起来*像训练数据，其实记录的是"这道题的正解长什么样"，**不是**"你当时做出来没有、卡在哪、有没有看题解"。两者的区别就是**能不能证明成长**。

所以本目录只收三类事实：

| 内容 | 说明 |
| :-- | :-- |
| **平台判定** | AC / WA / TLE / RE —— 平台给的，不是自己说的 |
| **你原始提交的代码** | 哪怕是丑的、错的（放 `原始代码/`）。不是事后让 AI 重写的正解 |
| **独立完成度** | 独立 / 卡住后自己过 / 看题解后过 —— **核心防伪字段** |

## 证据分级（硬约定，写入每条记录）

| 等级 | 定义 | 能否用于能力结论 |
| :-- | :-- | :-- |
| **强** | 平台判定 + 原始提交代码（可信来源：平台提交记录） | ✅ 可以 |
| **中** | 你的自述 + 可核对截图（放 `证据/`） | ⚠️ 可以，但需标注 |
| **弱** | 只有题号/题单记载，无代码、无截图、无完成度标注 | ❌ **不可用于能力结论**，只能算"做过" |

> 弱证据不是没用——它证明"这段时间在练"。但它**不能**支撑"我独立做出来了"这类结论。

## 独立完成度（`independent`）

这是整个训练层最重要的字段。AC 数字可以刷（抄一遍也算 AC），只有它区分真实成长与伪装。

| 取值 | 含义 |
| :-- | :-- |
| `独立` | 没看任何提示、没搜、没问 AI，自己想出来并 AC |
| `卡住后自己过` | 卡了一段时间，但靠自己调通/想通 |
| `看题解后过` | 看了题解或问过 AI 之后才写出来 |
| `null` | 没记录（弱证据常见） |

**指标口径**：`独立 AC 率 = 独立题数 / 有完成度标注的题数`。**`null` 的题不参与这个比率**——否则弱证据会污染指标。所以录入时宁可留 `null`，不要为了凑数乱填。

## 目录

```
训练记录/
├── schema.json        数据契约（JSON Schema draft-07）
├── 日志/              ← 唯一输入。一天一个文件：YYYY-MM-DD_平台.json
│   └── _模板.json
├── 原始代码/           你真实提交的代码（强证据的载体）
└── 证据/              截图（排行榜/提交记录/题面），按日期建子目录
```

## 录入 SOP

**你不用碰下面的 JSON。** 在根目录 [`../随手记.md`](../随手记.md) 里一行一题写清「日期 / 平台 / 题号 / 结果 / **是否独立** / 用时」，然后跟 AI 说一句「整理随手记」即可。

AI 侧的动作（供参考）：

```
① 解析 随手记.md → 生成 训练记录/日志/YYYY-MM-DD_平台.json（可复制 日志/_模板.json）
② 原始代码若已放进 训练记录/原始代码/<日期>/，把相对路径填进 code_file
③ 跑 python 可视化/build.py   （校验 + 导出 + 出图）
```

## 与别的目录的边界

| 东西 | 放哪 | 性质 |
| :-- | :-- | :-- |
| 你赛场上提交的代码 | `真实比赛/赛内代码/` | 真值（比赛） |
| 你训练时提交的代码 | `训练记录/原始代码/` | 真值（训练） |
| 赛后/练后写的正解、变体 | `题解归档/` | 学习产物，**非证据** |
| AI 整理的题解与讲义 | `题解归档/`、`学习模块/` | 学习材料，**非证据** |
| 比赛成绩 | `真实比赛/比赛记录/` | 真值（比赛） |
| 训练流水 | `训练记录/日志/` | 真值（训练） |

## 诚实规则（生成器已落地，别绕过）

- **弱证据题不参与独立 AC 率**，只单独计数。
- **训练日 < 4 不画趋势线**（`constraints[]` 会告诉你当前能不能画）。
- 没有 `independent` 标注的题，**永远不要**在分析里当成"独立做出来的"。
- `attempts` / `minutes` 记不清就写 `null`，**不要估**——估出来的数字比没有更糟。
