## 一句话

| 比赛 | 更像什么 | 本仓库态度 |
| :-- | :-- | :-- |
| **蓝桥杯** | 个人赛，算法应用 + 熟练度，和洛谷入门/省赛题接近 | **现在的主战场** |
| **校赛 / ACM 类** | 更偏限时综合解题；有的校赛是选拔，有的是兴趣赛 | 门槛轨目标：能看懂、能切常见题型 |
| **ICPC / 区域赛** | 团队 3 人 5 小时，题量与强度更高 | **不是现阶段目标**；开轨后仍只是「更远的可能」 |

「够到 ACM 门槛」在本仓库的意思是：

> 系统完成 Level 2 阶梯后，能独立看懂校赛题解，能在时限内做出普及+～弱省选常见模型题，  
> 而不是「已经具备打区域赛的实力」。

## 和蓝桥杯训练差在哪

| 维度 | 蓝桥（当前） | ACM 类（门槛轨） |
| :-- | :-- | :-- |
| 题型 | 模拟、字符串、STL、前缀和、搜索等，覆盖面杂 | 在此之上更强调 DP、图论、数论与结构 |
| 节奏 | 按块学 + 真题 | 专题深挖 + 限时套题 + 赛后补题 |
| 平台 | 洛谷入门/蓝桥真题 | 洛谷专题、校赛题、Codeforces Div.4/3 起 |
| 题解仓库落点 | `题解归档/蓝桥杯/`、`洛谷/` | `题解归档/校赛与CF/` |

## 训练方式差别（预告，开轨后再执行）

1. **专题**：一段时间只攻一类（如背包、最短路），不是每天随机切题。  
2. **限时**：套题或单题设时限，练速度与取舍。  
3. **补题**：赛时没做出来的，赛后必须补到能独立重写。  
4. **模板**：仍用 C++；比蓝桥更依赖自己默写过的模板。

## LeetCode 是不是竞赛党主路径？

不是本仓库的**主路径**。

- LC 偏面试/周赛题风，与蓝桥、校赛重合度不稳定。  
- 可作**副路径**：某专题学完后加练，或以后求职用。  
- 竞赛主路径：洛谷（按块）+ 蓝桥真题 +（开轨后）校赛/CF。

落点：[题解归档/LeetCode/](../../题解归档/LeetCode/) — 保留，不进竞赛进度表。
