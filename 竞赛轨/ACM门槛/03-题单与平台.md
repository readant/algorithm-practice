# ACM 门槛轨 · 03 题单与平台

> 开轨后按阶段选用。原则：**少而必做**，不是题海。  
> 阶段定义见 [02-能力阶梯.md](02-能力阶梯.md)。

---

## 平台怎么选

| 平台 | 用途 | 建议 |
| :-- | :-- | :-- |
| **洛谷** | 主练习场；专题题单、真题、校赛题 | 优先，沿用现有题解规范 |
| **Codeforces** | 赛制感、时限、题面英文 | 开轨后从 **Div.4 / Div.3** 起，每周 0～2 场 |
| **AtCoder** | 题面短、质量高 | 可选，ABC 起 |
| **牛客 / AcWing** | 已有目录占位 | 有需要再归档，不强制 |
| **LeetCode** | 副路径 | 不列入本门槛必做；语言同样以 C++ 为主 |

语言：竞赛提交与练习默认 **C++**；Python 仅个别题对照；Java 不在考虑。

题解目录：做完 CF/校赛题 → [题解归档/校赛与CF/](../../题解归档/校赛与CF/README.md)

## 各阶段必做（起步清单）

数量刻意压低：做完验收，不够再从洛谷专题补充。

### 阶段 A · 结构

| 来源方向 | 做什么 | 数量 |
| :-- | :-- | :-- |
| 洛谷 | 并查集模板题 + 1 道应用（如连通块） | 2 |
| 洛谷 | 单调栈/队列入门各 1 | 2 |
| 洛谷 | 树状数组模板 + 1 道区间 | 2 |
| 仓库 | 重写 A2/相关篇篇末例题中未做过的 | 1–2 |

### 阶段 B · DP

| 来源方向 | 做什么 | 数量 |
| :-- | :-- | :-- |
| 洛谷 | 线性 DP 入门（如数字三角形 P1216） | 2 |
| 洛谷 | 0/1 背包 + 完全背包模板题 | 2 |
| 洛谷 | 1 道简单区间或状态 DP | 1 |
| 仓库 | [经典DP模型](../../学习模块/02-学习层/01-C++/04-进阶算法体系/02-经典DP模型（背包-线性DP-区间DP）.md) 篇末索引 | 按索引补 |

### 阶段 C · 图

| 来源方向 | 做什么 | 数量 |
| :-- | :-- | :-- |
| 洛谷 | 存图 + 遍历 | 2 |
| 洛谷 | 无权最短路 / 0-1 BFS 或朴素 Dijkstra | 2 |
| 洛谷 | 并查集应用 1 题 | 1 |

### 阶段 D · 数论

| 来源方向 | 做什么 | 数量 |
| :-- | :-- | :-- |
| 洛谷/真题 | 快速幂、筛法、GCD 综合 | 3–4 |
| 蓝桥真题 | 数论相关未勾题（#1–3、#14 等） | 若仍未做优先 |

### 阶段 E · 赛制

| 来源方向 | 做什么 | 数量 |
| :-- | :-- | :-- |
| Codeforces | Div.4 或 Div.3 整场（能做几题做几题） | 4 场起 |
| 校赛 | 本校或友好校近年题 | 1–2 套 |
| 补题 | 每场赛后补到「能独立重写」 | 必须 |

## 洛谷专题入口（开轨后检索用）

在洛谷题单/题库按标签选，本仓库不复制整份题单：

- 并查集 / 树状数组 / 单调栈  
- 动态规划（背包、线性）  
- 图论（最短路、遍历）  
- 数论（快速幂、筛法）

蓝桥已有路径继续用：[竞赛轨/蓝桥杯/主线.md](../蓝桥杯/主线.md)
