## 与删除的区别

| 处理 | 适用 | 例子 |
| :-- | :-- | :-- |
| **直接删除** | 既无证据价值也无使用价值 | 空壳占位目录、编译产物 `.exe` |
| **进冷宫** | 无证据价值，但复习时或他人可能想看 | 大批 AI 生成的模板讲义、重复度极高的题解 |
| **保留原位 + 标注** | 有使用价值、且在导航中被引用 | 速查卡、真实个人笔记 |

## 为什么要有它

`学习模块/` 与 `题解归档/洛谷/` 里的 AI 生成内容对**学习过程**仍有用（复习、查模板），
但**不能当作能力证据**。一刀切全删会损失使用价值，全部保留又会让仓库显得还在"堆内容"。
冷宫提供一个可回退的中间态：**移出去、不再出现在导航里、但随时能捞回来。**

## 入选标准

- 批量生成、结构高度模板化、无个人痕迹（如 `02-学习层` 的 40+ 篇讲义）。
- 与已有内容重复度极高（如同一题的多个仅换模板的版本）。
- 纯管理/元文档（如 AI 生成的"目录整理方案"）。

> 移动前先 `git add` 一次当前状态，确保可回退。
