## 今天做什么

**只有一件事：做完题，在 [随手记.md](随手记.md) 里写一行。**

```text
10-14 洛谷 P1614 爱与愁的心痛 AC 独立 15分钟
```

写完跟 AI 说一句「**整理随手记**」——解析、JSON、校验、图表、归档全部由 AI 完成。

| 我想…… | 就…… | 去哪 |
| :-- | :-- | :-- |
| 记一笔今天做的题 | 写一行（一行一题，随便写） | **[随手记.md](随手记.md)** |
| 不知道今天该练什么 | 看当前块与今日指令 | [COMPETE.md](COMPETE.md) |
| 看自己练得怎么样 | 打开成长仪表盘 | [可视化/dashboard.html](可视化/dashboard.html) |
| 回忆某道题的解法 | 翻题解 | [题解归档/](题解归档/README.md) |

> **你不用做**：跑命令、写 JSON、写题解、整理归档。
> **你只需要做**：做题 → 写一行 → 说「整理随手记」。

## 仓库怎么分

| 层 | 目录 | 是什么 | 证据等级 |
| :-- | :-- | :-- | :-- |
| **你的输入** | [随手记.md](随手记.md) | 唯一需要手写的地方（自由格式） | — |
| **真值源 ①** | [真实比赛/](真实比赛/README.md) | 赛场成绩 + 赛内原始代码 | **强证据** |
| **真值源 ②** | [训练记录/](训练记录/README.md) | 日常训练 + **独立完成度** | 强 / 中 / 弱 分级 |
| 数据出口 | [成长数据/](成长数据/接口说明.md) | 机器可读快照 + 给 AI 的摘要 | 生成物 |
| 看图 | [可视化/](可视化/README.md) | 成长仪表盘（离线单文件 HTML） | 生成物 |
| 训练体系 | [竞赛轨/](竞赛轨/README.md) · [学习模块/](学习模块/README.md) · [题解归档/](题解归档/README.md) | 主线 / 讲义 / 题解 | **非证据** |

> **能力证据只看两个真值源。** AI 生成的讲义与题解一律不算——它们证明"读过"，不证明"会做"。

## 仓库结构

```
algorithm-practice/
├── 随手记.md               ← ★ 你唯一要写的地方（一行一题，随便写）
├── COMPETE.md              ← 每日竞赛总控
│
├── 真实比赛/               ← ★ 真值源①：赛场（强证据）
│   ├── 比赛记录/           ← 每场一个 JSON
│   ├── 原始证据/           ← 排行榜/题面截图
│   └── 赛内代码/           ← 赛场上真正提交的代码
├── 训练记录/               ← ★ 真值源②：日常训练（含独立完成度）
│   ├── 日志/               ← 一天一个 JSON，逐题记
│   ├── 原始代码/           ← 你训练时真正提交的代码
│   └── 证据/               ← 提交记录/题面截图
├── 成长数据/               ← ★ 唯一数据出口（AI 可读）
│   ├── 接口说明.md         ← 接口契约（读/写规则）
│   ├── snapshot.json       ← 全量机器可读快照
│   └── brief.md            ← 给 AI 的精简摘要
├── 可视化/                 ← ★ 由真值源生成
│   ├── build.py            ← 唯一入口（AI 用：校验+导出+出图一条命令）
│   ├── growth_core.py      ← 计算内核
│   └── dashboard.html      ← 成长仪表盘（勿手改）
│
├── 竞赛轨/
│   ├── 蓝桥杯/            ← Level 1 主路径（主线 + 进度）
│   └── ACM门槛/           ← Level 2 门禁与阶梯（默认未开轨）
│
├── 学习模块/               ← 参考（讲义由 AI 生成，非能力证据）
│   ├── 01-参考层/         ← 速查卡
│   ├── 02-学习层/         ← 讲义（备赛块 / 深造轨）
│   └── 03-实战层/         ← 模板 + 踩坑
│
├── 题解归档/               ← 参考（赛后正解与 AI 题解，非能力证据）
│   ├── 洛谷/ · 牛客网/ · 蓝桥杯/
│
└── README.md
```

### 学习层（服务竞赛块）

├── 01-C++基础语法/   ← 语法底座（欠账再补）

| **C** | 对照 | 按需 | 从 C++ 思路调整，不单独成线 |
| **Java** | **不在考虑** | 不再新增 | 历史存档可留；参考层 `04-Java` 不再导航 |

## 每题文件规范

### 标准命名

| 文件 | 说明 |
| :----- | :----- |
| `题解.md` | 题目描述 + 解题笔记 + 易错点 + 算法总结 |
| `solution.cpp` | **主解法（竞赛默认，C++）** |
| `solution.py` | 可选副语言对照（Python） |
| `solution.c` | 可选，按 C++ 思路对照 |
| ~~`solution.java`~~ | **不再新增**（历史存档可留） |
| `drafts/` | 草稿文件夹（个人尝试，本地为主） |

### 多解法命名

| 类型 | 命名规则 | 说明 |
|:-----|:---------|:-----|
| 主解法 | `solution.cpp` | 推荐解法，竞赛与教学默认 |
| 副语言 | `solution.py` / `solution.c` | 对照用；C 从 C++ 调整 |
| 其他解法 | `暴力枚举.cpp` / `贪心法.cpp` 等 | 解法特征命名，C++ |

```
P3741_小果的键盘/
├── solution.cpp       ← 主解法
├── 暴力枚举.cpp       ← 其他解法
└── 题解.md
```

竞赛题解落点：

- 蓝桥真题 → `题解归档/蓝桥杯/真题强化24/`
- 洛谷 → `题解归档/洛谷/`
- 校赛/CF（开轨后）→ `题解归档/校赛与CF/`
