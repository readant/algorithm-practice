# Algorithm Practice

> 算法学习与刷题记录，按洛谷题单系统学习，支持 C++ / C / Python / Java 多语言实现。

## 关于本仓库

算法学习没有捷径，唯有日积月累。这个仓库记录了我从零开始的学习过程——有写对的喜悦，也有调试到深夜的迷茫。

**给每一位正在刷题的你：** 每一道 AC 的背后，都是无数次 WA 和 TLE 的积累。不要害怕犯错，每一次错误都是成长的阶梯。坚持下去，量变终会引发质变。

**说明：** 我并非算法高手，代码中难免有不够优雅的地方，笔记中也可能有理解偏差。如果你发现了错误或更好的解法，欢迎指正交流。学习的路上，我们都是同行者。
