## 仓库结构

```
algorithm-practice/
├── 随手记.md               ← ★ 你唯一要写的地方（一行一题，随便写）
├── COMPETE.md              ← 今天练什么
├── 记录.html               ← 你的练习记录（网页，勿手改）
├── 竞赛轨/                 ← 主线 / 进度
├── 学习模块/               ← 讲义
├── 题解归档/               ← 题解
│
└── .ai/                    ← AI 的机器层，你不用看
    ├── 真实比赛/           ← 赛场成绩、赛内代码、截图
    ├── 训练记录/           ← 日常训练、是否独立做出来
    ├── 输出/               ← brief.md（摘要）、snapshot.json（逐题明细）
    └── build.py            ← 汇总脚本
```

### 学习层（服务竞赛块）

```
02-学习层/01-C++/
├── 01-C++基础语法/   ← 语法底座（欠账再补）
├── 02-数据结构/      ← 备赛：A1 STL 工具箱；深造：教材轨
├── 03-基础算法体系/  ← 暴力/排序/二分/贪心/搜索 + 技巧 + 高精度
└── 04-进阶算法体系/  ← DP、图论、数论（ACM 轨 A–D 对应）
```

### 语言策略

| 语言 | 定位 | 新题解 | 说明 |
| :-- | :-- | :-- | :-- |
| **C++** | **主语言** | 默认必须 | 讲义 / 模板 / 竞赛提交 |
| **Python** | 副语言 | 可选对照 | 不作竞赛主提交 |
| **C** | 对照 | 按需 | 从 C++ 思路调整，不单独成线 |
| **Java** | **不在考虑** | 不再新增 | 历史存档可留；参考层 `04-Java` 不再导航 |

```
01-参考层/
├── 00-通用规范/
├── 01-C++/      ← 主
├── 02-Python/   ← 副
└── 03-C/        ← 对照
```

## 每题文件规范

### 标准命名

| 文件 | 说明 |
| :----- | :----- |
| `题解.md` | 题目描述 + 解题笔记 + 易错点 + 算法总结 |
| `solution.cpp` | **主解法（竞赛默认，C++）** |
| `solution.py` | 可选副语言对照（Python） |
| `solution.c` | 可选，按 C++ 思路对照 |
| ~~`solution.java`~~ | **不再新增**（历史存档可留） |
| `drafts/` | 草稿文件夹（个人尝试，本地为主） |

### 多解法命名

| 类型 | 命名规则 | 说明 |
|:-----|:---------|:-----|
| 主解法 | `solution.cpp` | 推荐解法，竞赛与教学默认 |
| 副语言 | `solution.py` / `solution.c` | 对照用；C 从 C++ 调整 |
| 其他解法 | `暴力枚举.cpp` / `贪心法.cpp` 等 | 解法特征命名，C++ |

```
P3741_小果的键盘/
├── solution.cpp       ← 主解法
├── 暴力枚举.cpp       ← 其他解法
└── 题解.md
```

竞赛题解落点：

- 蓝桥真题 → `题解归档/蓝桥杯/真题强化24/`
- 洛谷 → `题解归档/洛谷/`
- 校赛/CF（开轨后）→ `题解归档/校赛与CF/`
