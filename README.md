# 算法练习仓

> 一个自用的算法练习仓库：**备赛 + 学习 + 题解**。C++ 为主。

---

## 这是什么

我在准备蓝桥杯，同时按 ACM 的门槛补基础。仓库装三样东西：

| 目录 | 内容 |
| :-- | :-- |
| [`竞赛轨/`](竞赛轨/README.md) | 备赛主线与进度。蓝桥杯为主路径；ACM 门槛轨未开 |
| [`学习模块/`](学习模块/README.md) | 讲义、速查卡、实战模板，按用途分三层 |
| [`题解归档/`](题解归档/README.md) | 做过的题，按平台分：洛谷 / 牛客 / 蓝桥杯 |

**当前进度** → [`竞赛轨/蓝桥杯/进度.md`](竞赛轨/蓝桥杯/进度.md)（本 README 不复制进度数字）

> 另有 `随手记.md`、`记录.html`、`.ai/`，是我自己的练习记录与本机工具，不是仓库主体，可以忽略。

## 仓库结构

```
algorithm-practice/
├── README.md
├── COMPETE.md              ← 训练总控（自用）
├── 随手记.md               ← 练习流水（自用）
├── 记录.html               ← 练习记录网页（自用，生成物）
│
├── 竞赛轨/                 ← 备赛
│   ├── 蓝桥杯/             ← 主路径：主线 + 进度
│   └── ACM门槛/            ← 未开轨：门禁与阶梯
├── 学习模块/               ← 知识沉淀（三层，见下）
├── 题解归档/               ← 题解
│   ├── 洛谷/ · 牛客网/ · 蓝桥杯/
│
└── .ai/                    ← 记录与脚本（自用，机器层）
```

### 学习模块的三层

| 层 | 用途 |
| :-- | :-- |
| `01-参考层/` | 遇到问题时快速查阅：STL、`algorithm`、IO、常用函数 |
| `02-学习层/` | 按块读的讲义，不要求通读 |
| `03-实战层/` | 做题时复制粘贴：算法模板、踩坑记录 |

`02-学习层/01-C++/` 下分四块：

```
01-C++基础语法/   ← 语法底座
02-数据结构/      ← STL 工具箱（备赛） / 教材轨（深造）
03-基础算法体系/  ← 暴力、排序、二分、贪心、搜索、前缀和、双指针…
04-进阶算法体系/  ← DP、图论、数论（ACM 开轨后）
```

## 语言与约定

| 语言 | 定位 |
| :-- | :-- |
| **C++** | 主语言。竞赛提交、讲义、模板默认用它 |
| Python | 副语言。写脚本、对小数据、可选的解法对照 |
| C | 按需对照，不单独成线 |
| Java | 不在考虑 |

两条硬规则：

- **禁止万能头文件**——不使用 `#include <bits/stdc++.h>`，按实际用到的显式列出标准头文件
- **题解必须验证**——`g++` 编译通过，且与暴力解在小数据上对拍一致，才归档

## 题解规范

| 文件 | 说明 |
| :-- | :-- |
| `题解.md` | 题目描述 + 思路拆解 + 易错点 + 算法总结 |
| `solution.cpp` | 主解法（C++） |
| `solution.py` / `solution.c` | 可选的语言对照 |
| `<解法名>.cpp` | 多解法，按解法特征命名，如 `暴力枚举.cpp`、`贪心法.cpp` |

落点：洛谷题 → [`题解归档/洛谷/`](题解归档/洛谷/)；蓝桥真题 → [`题解归档/蓝桥杯/真题强化24/`](题解归档/蓝桥杯/真题强化24/README.md)

## Commit 规范

| 前缀 | 说明 |
| :-- | :-- |
| `feat:` | 新增题目解法 |
| `fix:` | 修复代码或补充边界处理 |
| `docs:` | 更新题解、讲义、竞赛轨 |
| `refactor:` | 重构代码实现 |
