## 仓库结构

```
algorithm-practice/
├── 学习模块/
│   ├── 02-学习层/       ← 系统学习（从零开始，顺序阅读）
│   ├── 01-参考层/       ← 速查卡（遇到语法问题时翻阅）
│   └── 03-实战层/       ← 算法模板 + 踩坑记录（做题直接复制）
│
├── 洛谷题单/
│   ├── 入门1_顺序结构/  ←  1 题
│   ├── 入门4_数组/      ← 19 题
│   └── 入门5_字符串/    ←  2 题
│
└── README.md
```

### 三层知识库

```
02-学习层/01-C++/
├── 01-基础学习/     → 第一个程序、cin/cout
├── 02-核心语法/     → 变量、控制结构、函数、指针、STL
├── 03-基础数据结构/  → 数组、链表、栈、队列、哈希表、树
├── 04-排序算法/     → 冒泡、选择、插入、归并、快排、堆排
├── 05-搜索算法/     → 线性搜索、二分搜索
└── 06-基础算法思想/  → 暴力法、分治法、贪心算法
```

## 每题文件规范

| 文件 | 说明 |
|:-----|:-----|
| `题解.md` | 题目描述 + 解题笔记 + 易错点 + 算法总结 |
| `solution.cpp` | C++ AC 解法 |
| `solution.c` / `.py` / `.java` | 其他语言实现（部分题目） |
| `drafts/` | 草稿文件夹（不提交） |
