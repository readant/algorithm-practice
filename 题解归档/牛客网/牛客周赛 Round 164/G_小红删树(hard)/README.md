## 1. 题面要点

与 F 完全相同的过程（反复删叶子至剩 1 节点），但 `q` 次询问（`2 ≤ q ≤ n`），每次问"最后一次删除必须删第 `x_i` 条边"的方案数（模 `998244353`）。`n, q ≤ 2e5`。

---

## 2. 思路（赛后整理）

### 2.1 复用 F 的公式

每条边 `x=(a,b)` 的答案仍为 `W(a,b) + W(b,a)`，公式与推导见 [F 的 2.2 / 2.3 节](../F_小红删树(easy)/README.md)。

### 2.2 hard 的难点：对每条边 O(1) 回答

F 只问一条边，可 `O(n)` 现算；G 要回答 `q` 条边，必须预处理。

做法是**换根 DP**：
1. 以 1 为根 `dfs` 一次，求出 `size / f / chF / chSZ`；
2. 第二次 `dfs` **沿边走边换根**：从 `u` 移到孩子 `v` 时，更新 `size(u) = n − size(v)`、`size(v) = n`，并按公式增删 `chF / chSZ / f`（去掉旧因子用逆元相乘、再加新因子）。
3. 这样每个**有向边** `(u,v)` 恰好被访问一次，直接把 `W(u,v)` 累加到该边的答案里；全程 `O(n)`，之后每个询问 `O(1)`。

> **实现易错点（本次实际踩到）**：计算 `W(u,v)` 时必须对**所有邻居**都算一次（含父方向 `v == p`），父方向只是**不再递归**；若写成"遇到父节点直接 `continue`"，每条边只会被统计到一个方向，答案直接**减半**。

---

## 3. 复杂度

预处理 O(n)；每次询问 O(1)。整体 **O(n + q)**。

---

## 4. 易错点

1. **沿用 F 的"每次现算"** ⇒ `O(nq)` 超时，必须换根预处理。
2. **换根时 `f_u'` 算错**：要正确"除以 `v` 子树贡献并补回剩余合并系数"，易漏乘组合数项。
3. **模逆元在乘积链上的处理**：预处理阶乘逆元 + 子树乘积的逆元，缺一不可。

---

## 5. 举一反三

- **套路本质**：F 的"树上操作序列计数" + 「多询问 ⇒ 换根/前缀积预处理」的经典组合。识别信号：**同一条树的多个边/点询问，且每次答案可沿树边分解**。
- **同类题**：
  - 洛谷/CF 树形 DP + 换根（如 "换根 DP 求每个点为根的答案"）
  - AtCoder ARC 树上计数 + 多查询
- **变体**：把"末边约束"换成"给定根/给定最后剩哪个点"等，分解方法一致。
- **训练切入点**：先吃透 F（单询问）→ 再练换根 DP 模板 → 最后合成 G。
