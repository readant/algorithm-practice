## 1. 题面要点

给一棵 `n` 个节点的树。每次操作：选一个**叶子**删掉它及其连边，直到只剩 1 个节点。

`q=1` 次询问，给定 `x`：问**最后一次删除必须删掉第 `x` 条边**的前提下，有多少种不同的删法？对 `998244353` 取模。两种删法不同 ⇔ 存在某一步选的叶子不同。

`2 ≤ n ≤ 2e5`。

---

## 2. 思路（赛后整理）

### 2.1 这是什么类别

"反复删叶子直到剩一个节点"的**操作序列计数**，是经典的**树上拓扑序/剥叶子计数**。一个节点能作为叶子被删 ⇔ 它所有"更远离幸存点"的分支都已删完。

### 2.2 固定幸存点，先解决"无末边约束"的计数

设最后剩下的节点为 `s`，把树**以 `s` 为根**。则约束是：每个非根节点必须在它的**所有儿子**都被删之后才能删（自底向上）。

记 `size[v]` 为以 `s` 为根时 `v` 的子树大小。把各孩子子树的删除序列交错合并（多重组合数），可得：

```
以 s 为幸存点的合法序列数 = (n−1)! / ∏_{v≠s} size[v]
```

### 2.3 末边约束：最后一次删的必是幸存点的某个孩子

只剩 2 个节点时，它们必是 `s` 与它的一个邻居 `u`，中间的边就是最后要删的边。所以：

> 边 `x=(a,b)` 作为**最后一次删除** ⇔ 幸存点 `s ∈ {a,b}`，且最后被删的是另一个端点。

于是 `ans(x) = W(a,b) + W(b,a)`（两种幸存方向各算一次），其中 `W(s,u)`（`s` 幸存、`u` 最后删、`u` 是 `s` 的孩子）为：

```
W(s,u) = (n−2)! × chF(s) × chF(u) × size(u)! / ( chSZ(s) × chSZ(u) × f(u) )
```

（全部模 `998244353`，除法用逆元；）
- `chF(v) = ∏_{c 为 v 的孩子} f(c)`
- `chSZ(v) = ∏_{c 为 v 的孩子} size(c)!`
- `f(v) = (size(v)−1)! × chF(v) / chSZ(v)`（`v` 作为被删节点时，`v` 子树内部的合法序列数）

直觉：把 `u` 从 `s` 的孩子里摘掉后，`s` 的其余孩子子树、以及 `u` 的每个孩子子树都成了"独立块"，用多重组合数交错归并，最后归一化掉 `u` 自身那一块，再放 `u` 在末位。

> easy 版 `q=1`：对给定 `x` 算一次 `W(a,b)+W(b,a)` 即可（下方代码通用，q=1 直接可用）。

## 3. 复杂度（easy）

预处理阶乘/逆元 O(n)；一次 dfs 求子树大小与 `f(r)` O(n)；回答单询问 O(1)。整体 **O(n)**。

---

## 4. 易错点

1. **模运算忘取模/忘逆元**：组合数必须用费马小定理逆元，不能整除。
2. **把"删叶子序列"当成任意拓扑序**：叶子约束比一般 DAG 拓扑序更特殊，子树内部必须严格"自底向上"。
3. **末边约束理解反**：是"最后一次删的是边 x"，不是"第一次"。

---

## 5. 举一反三

- **套路本质**：「树上操作序列的合法计数」= 偏序 + 线性扩展计数；带"末态约束"时按约束边把树切开分解。
- **同类题**：
  - 洛谷 P 系列树形 DP 计数（树上拓扑序、树的删点序）
  - AtCoder ARC 常见 "count ways to do operations on tree"
  - Prüfer 序列（树的编码，与"删叶子"同族）
- **变体**：`q` 很大（G 题）→ 需对每条边 O(1) 回答，必须用**换根/前缀积**预处理任意边分割的两子树计数。
- **训练切入点**：先独立练「模逆元 + 组合数」→「树形 DP 基础」→「树上计数题」；本题放在 阶段 E 进阶。
