## 3. 题目描述

**问题描述**
小红认为一个正整数 $x$ 是一个好数，当且仅当 $x$ 的个位与 $x^2$ 的个位相同。

给定整数 $n$，请你找到一个 $n$ 位的好数。

**输入格式**
第一行输入一个整数 $n$ $(1 \le n \le 8)$。

**输出格式**
输出一个整数，代表你所找到的 $n$ 位好数。
多解时输出任意一个都正确。

**数据范围**
$1 \le n \le 8$

**样例**
输入：

```
3
```

输出：

```
100
```

## 4. 解题思路

### 审题过程

- 好数：数字的个位，等于它平方后的个位。
- 输出**n位**正整数，答案任选其一。

### 主解法选择说明

直接构造法，最简单，不用循环枚举数字。

### 主解法核心思路

观察：个位是0的数，平方后个位依旧是0。
构造形如 `100…0` 的n位数，首位是1，后面n-1个0，一定满足条件。

### 其他解法思路

本题解法较为固定，以下主要介绍最优解。

### 主解法伪代码设计

```
读入n
生成字符串：'1' + n-1个'0'
输出字符串
```

## 5. 代码实现

### 主解法逐步讲解（带注释版本）

```
#include <iostream>
#include <string>
using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    string ans = '1' + string(n - 1, '0');
    cout << ans << '\n';
    return 0;
}
```

第1步：头文件

- `<iostream>`：`cin`、`cout` 输入输出。
- `<string>`：字符串类型，`string(k, c)` 快速生成k个相同字符。

第2步：`ios::sync_with_stdio(false); cin.tie(nullptr);`
加速cin/cout，竞赛常用。

第3步：读入n，构造字符串。
`string(n-1,'0')` 生成n-1个0，前面加'1'，得到n位的100...0。

>
> 用字符串而不是数字，避免大数溢出。

第4步：输出，`'\n'`代替`endl`，不强制刷新缓冲区，速度更快。

本题主解法已覆盖全部情况，无额外实现。

## 6. 易错点

- 直接用数字保存：n=8时，int存不下，会溢出，优先用字符串。
- 输出前导0：如`001`不是3位数，首位必须是1。
- 误用`endl`：频繁刷新，影响IO性能。
- 多余枚举：题目只要求任意一个解，不需要遍历判断所有数字。
