### C · 小红的gcd构造 —— 35/150 ⚠️ 【本场最大技术收获】

**你写的核心代码：**

```cpp
ll g = gcd(x, y);
ll a = g, b = x * y / g;   // 保证 a*b == x*y
```

**这个写法为什么不是最优解：**

`a = gcd(x,y)`、`b = x*y/gcd(x,y)` 确实保证了 `a*b == x*y`，但**完全没有让 gcd 变大**。它只在恰好 `x`、`y` 的质因数分布本来就对称时才碰巧最优。

**最小反例（已用脚本枚举确认）：**

```
x = 1, y = 4
你的写法：a=1, b=4  → gcd = 1
最优解：  a=2, b=2  → gcd = 2   ← 直接差一倍
```

**实测你的写法恰好最优的概率：47.3%**（20000 组随机 x,y）。这正好解释了 35/150 的部分分——**一半的测试点过了，一半没过**。这不是"运气好"，是"方法只在半数情况下正确"，属于最危险的状态。

**正解：质因数均分。**

把 `x*y` 分解质因数 `x*y = Π p_i^{e_i}`，然后**把每个质因子的指数一分为二**：

```
a = Π p_i^{⌈e_i/2⌉}
b = Π p_i^{⌊e_i/2⌋}
```

这样 `a*b == x*y` 恒成立，且 `gcd(a,b) = Π p_i^{⌊e_i/2⌋}`，即**理论最大值**（因为 `gcd² | x*y` 决定了 gcd 不可能超过这个值）。

**已验证：** 该构造与暴力枚举在 4000 组小范围数据上 **100% 一致**。

**但本题真正的坑在这里 —— 已实测确认：**

`x,y ≤ 10^9` ⇒ `x*y` 可达 `10^18` ⇒ 均分后的 `a` 或 `b` **经常超过 `10^9` 上界**。实测 20000 组随机数据，**19999 组越界**。

所以本题的完整难点是：**在 `1 ≤ a,b ≤ 10^9` 的硬约束下，让 gcd 尽可能大**。这解释了为什么它 150 分、通过率只有 63.1%——它是一道真正的数论构造题，不是套 gcd 公式。

**完整正解（已补，无需 Pollard-Rho）：**

因为 `x,y ≤ 1e9`，各自试除到 `√1e9 ≈ 31623` 就能完全分解，**不需要 Pollard-Rho**。做法是：枚举 `N = x*y` 的所有因子 `a`，在合法区间 `[⌈N/1e9⌉, 1e9]` 内取使 `gcd(a, N/a)` 最大的那组即可。

**定位判断：** 这题属于 ACM 门槛轨 **阶段 D（数论与组合）** 的范畴，当前主路径（块5 STL）尚未涉及。**本场做不出来是正常的**，但方法错误的信号必须记住。

题解已归档（含正解）：[C_小红的gcd构造](C_小红的gcd构造/README.md)

## 五、逐题举一反三

> 每条给出：套路本质 / 同类题 / 变体方向 / 训练切入点 / 本场警示。

### A · 签到构造（输出大数）
- **套路本质**：把"满足某性质的数"转化成"构造一个长数字串"——本质是**输出构造 + 末位规律**。
- **同类**：洛谷入门组「输出 10 的 n 次方 / 输出特定数字串」类；本质是"不要硬算，用字符串"。
- **变体**：要求平方末两位固定、或末 k 位固定 → 同理用 `1` 后接 `n-1` 个 `0` 的推广。
- **切入**：练"看到大数输出先想字符串，别想 `long long`"（n 一大必爆）。
- **警示**：A 不是难点，**36 分钟是纯流程损耗**，下场 5 分钟封顶。

### B · 暴力枚举 + 模拟
- **套路本质**：状态空间极小（3×3）→ **枚举所有候选 + 合法性检查**，是回溯的极简形态。
- **同类**：LeetCode 1275「Find Winner on a Tic-Tac-Toe Game」；洛谷 P2668 斗地主（回溯+剪枝进阶）。
- **变体**：N×N 棋盘、多子落子、需要"最少步数取胜" → 仍是枚举+检查，规模变大就上 DFS/博弈。
- **切入**：先练"枚举候选→试操作→撤销（回溯）"的固定框架。
- **警示**：44 分钟偏长（逻辑 10 分钟可写完）；代码里 `'1'` 硬编码、`is_win` 语义不完整，属"能过但不稳"。

### C · 数论构造（质因数 + gcd）⭐最有技术价值
- **套路本质**：`a*b=N` 且 `gcd(a,b)` 最大 → **质因数指数均分**；上界约束下转为"在合法区间内取最优因子"。
- **关键修正**：`x,y ≤ 1e9` ⇒ 各自试除到 `√1e9≈31623` 即可完全分解，**不需要 Pollard-Rho**；正解是"枚举 `N=x*y` 的所有因子，在 `[⌈N/1e9⌉, 1e9]` 内取 `gcd(a,N/a)` 最大"。
- **同类**：洛谷 P1075 质因数分解、P1029 最大公约数与最小公倍数问题；CF 常见「构造 a,b 使 gcd/lcm 满足某条件」。
- **变体**：把 `a*b=N` 改成 `gcd(a,b)=给定值` / `lcm(a,b)=给定值` → 同一套素数指数操控。
- **切入**：数论三板斧——**试除分解、素数指数操控、gcd/lcm 关系**——独立练一版模板。
- **警示**：你那版 `a=gcd(x,y), b=x*y/gcd` **只在约 47% 情况正确**却过了样例，是最危险状态——"正确率是个百分比"=方法错。

### D · 多约束贪心选择 ⭐期望分第 2
- **套路本质**：「多资源约束下最大化收益」——把 `b_i∈{0,1}` 的两类顾客分开，组内按价值降序贪心，组间用**枚举一类数量**覆盖。
- **同类**：洛谷 P1803 线段覆盖（单约束贪心）、P2095 美食（背包变形）；CF「两种资源 + 选子集最大化」。
- **变体**：`b_i` 不止 0/1 → 枚举"篮子用量"或双指针；成本与价值强相关 → 改按性价比排。
- **切入**：先单约束贪心，再练"分组 + 一维枚举"处理第二约束。
- **警示**：你 0 分只是**没读题**——这类贪心你完全能写。

### E · 排列逆向构造 ⭐期望分第 1（最大遗憾）
- **套路本质**：「过程模拟题逆向构造」——正向难构造就**逆向插入**：把"第 i 步删值 i"倒过来变成"插入值 i"，把约束变成"插在哪个位置"。
- **关键观察**：最后一步 `i=n` 必然得分 ⇒ `k` 合法范围 `1≤k≤⌈n/2⌉`；用 treap/平衡树按位置插入，O(n log n)。
- **同类**：AtCoder ABC/ARC 排列构造题、CF "construct permutation with given property"。
- **变体**：把"删值 i / 查中间"换成"删最小 / 查端点"等 → 套路一致，先想清正向每步再倒推插入规则。
- **切入**：先练正向模拟建立直觉，再练逆向构造；treap「按位置插入」值得单独存一版模板。
- **警示**：期望分全场第一却 0 分，**不是不会，是没看**——下次 E/D 必须先扫题面。

### F / G · 树上操作序列计数（超纲，正确弃）
- **套路本质**：「树上剥叶子序列计数」= 偏序 + 线性扩展计数；带末边约束时**按约束边把树切开分解**；多询问（G）则**换根/前缀积预处理**做到 O(1) 回答。
- **同类**：洛谷 树形DP计数、AtCoder ARC 树上计数；Prüfer 序列（同族）。
- **变体**：末态约束换成"给定根/给定最后剩哪个点" → 分解法一致。
- **切入**：先单独练「模逆元+组合数」→「树形DP基础」→「树上计数」→ 最后才碰换根。
- **警示**：通过率 13%/12.8%、期望分全场垫底——**分高≠该做**，判据永远是 `通过率×分值`。

## 八、下次赛前策略与硬规则

> 下次赛前 10 分钟读一遍本条。

1. **开场先算期望分，按 `通过率×满分` 定顺序。** 本场正确序：E(120.8) → D(116.8) → C(94.7) → B(91.7) → A(49.8) → G(44.8) → F(39.0)。牛客分值递增，"按分值从大到小做"是错的，必须两者相乘。
2. **前两题总耗时 ≤ 20 分钟。** A+B 都是"读题就写"级别，超过 20 分钟就是流程出了问题。省下的 60 分钟够攻 E 或 D。
3. **单题止损线：25 分钟。** 卡住 25 分钟且没有任何可提交进展 → 立刻跳走。C 题卡了 28 分钟且方法从一开始就是错的——再给 30 分钟也还是 35 分。止损判据是"**我是否还有新想法**"，不是"我是否快要想到"。
4. **E/D 两题至少扫一眼题面。** 本场漏掉的正是期望分前二的两题，不是不会，是没看。
5. **样例过了但心里没底 → 当方法错处理。** 先小数据验证或止损。C 的 47% 正确率是前车之鉴。
6. **做完即归档，半归档 = 没归档。** 做题和归档是同一动作的两半。
7. **首次参赛的额外流程成本下场归零。** 本场 A 题多花约 30 分钟基本是"第一次打周赛"的流程损耗（熟悉提交界面、确认评测状态、切题节奏），下场这部分成本应消失。

## 九、结论

**185 分、327 名不是能力问题，是时间分配问题。**

- 做到的：A、B 满分，说明"读题就写"这一档已经站稳。
- 丢掉的：E（期望分第一）、D（期望分第二）两道高期望分题，共 400+ 分的潜在区间。
- 卡住的：C 题方法性错误（写出了 47.3% 正确率的代码却不自知），这是最需要警惕的一类问题。
- 正确放弃的：F/G 分值陷阱，期望分全场垫底，弃之有理。

**一句话记法：先算期望分，再定顺序；前两题 20 分钟，单题 25 分钟止损；E/D 必扫题面。**
