## 1. 题面要点

小红进货：桃子 `x` 元/个，篮子 `y` 元/个；共有 `s` 元、进货商最多 `m` 个桃子。每位顾客固定买 `k` 个桃子。

有 `n` 个顾客，第 `i` 位愿出 `a_i` 元买 `k` 个桃子、并需要 `b_i` 个篮子（`b_i ∈ {0,1}`）。**保证 `k·x + b_i·y < a_i`**——即每位顾客都是"稳赚不赔"的。

目标：**选择服务哪些顾客，使今天获得的钱数（不扣除支出）最大**。

约束：`1 ≤ x,y,s,m,k ≤ 1e9`，`1 ≤ n ≤ 2e5`，`a_i ≤ 1e9`。

### 直觉

- 每位顾客都赚钱（净收益为正），所以"服务得越多、且挑出价高的，总收入越大"。
- 但有两道硬约束：**桃子总数 `m`**（每位顾客吃 `k` 个）、**预算 `s`**（进货总花费）。
- 篮子是个"额外开关"：要篮子的顾客（`b_i=1`）每位多花 `y` 元预算，但不多吃桃子。

---

## 2. 解题思路

### 核心转化

服务集合 `S` 的总花费 = `|S|·k·x`（桃子，统一） + `(S 中 b_i=1 的人数)·y`（篮子）。

两道约束写成：

```
桃子： |S| · k            ≤ m        ⇒  |S| ≤ M_peach = ⌊m/k⌋
预算： |S|·k·x + b_cnt·y   ≤ s
```

目标：在以上约束下，最大化 `Σ_{i∈S} a_i`。

### 为什么是"贪心 + 枚举一类"而非裸背包

`b_i` 只有 0/1 两种，把顾客按 `b_i` 分成两组：

- **type0**（`b_i=0`）：每位花费 `k·x`
- **type1**（`b_i=1`）：每位花费 `k·x + y`

两组内部，要最大化 `Σa_i`，显然**优先挑 `a_i` 大的**（因为只考虑收益、成本固定）。于是：

1. 两组分别按 `a_i` **降序排序**，求前缀和 `ps0`、`ps1`。
2. **枚举选 `t` 个 type1 顾客**（`t = 0,1,2,…`）：
   - 这部分花费 `t·(k·x + y)`，超预算就停。
   - 剩下的预算还能买 `⌊(s − 花费)/(k·x)⌋` 个 type0。
   - 总服务人数还不能超过 `M_peach`，也不能超过实际 type0 数量。
   - 取 `p = min(剩余可买 type0 数, M_peach − t, type0 总数)`，收益 `= ps1[t] + ps0[p]`。
3. 所有 `t` 取最大收益。

枚举 `t` 是 O(n)，排序 O(n log n)，整体 **O(n log n)**。

### 样例验证（x=2,y=3,s=20,m=10,k=2）

- type0（b=0）：a=[9,7]；type1（b=1）：a=[10,8]
- M_peach = ⌊10/2⌋ = 5
- t=0：p=min(⌊20/4⌋=5, 5, 2)=2 → 收益 0+16=16
- t=1：花费 7，剩 13，p=min(3, 4, 2)=2 → 收益 10+16=26
- t=2：花费 14，剩 6，p=min(1, 3, 2)=1 → 收益 18+9=**27**
- 答案 **27** ✓（与官方样例一致）

## 3. 代码实现（C++）

```cpp
#include <iostream>   // cin / cout
#include <vector>     // vector
#include <algorithm>  // sort
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    ll x, y, s, m, k; cin >> x >> y >> s >> m >> k;
    int n; cin >> n;
    vector<ll> a(n); for (int i = 0; i < n; i++) cin >> a[i];
    vector<int> b(n); for (int i = 0; i < n; i++) cin >> b[i];

    vector<ll> t0, t1;                       // b==0 / b==1
    for (int i = 0; i < n; i++)
        (b[i] ? t1 : t0).push_back(a[i]);
    sort(t0.rbegin(), t0.rend());
    sort(t1.rbegin(), t1.rend());

    vector<ll> ps0(t0.size() + 1, 0), ps1(t1.size() + 1, 0);
    for (size_t i = 0; i < t0.size(); i++) ps0[i + 1] = ps0[i] + t0[i];
    for (size_t i = 0; i < t1.size(); i++) ps1[i + 1] = ps1[i] + t1[i];

    ll peachCost  = k * x;          // 每位顾客固定桃子花费
    ll basketCost = y;              // 每位 type1 额外篮子花费
    ll Mpeach = m / k;              // 最多服务顾客数（桃子上限）

    ll ans = 0;
    for (int t = 0; t <= (int)t1.size(); t++) {
        if (t > Mpeach) continue;                       // 桃子不够
        ll money = (ll)t * (peachCost + basketCost);
        if (money > s) break;                           // 预算不够
        ll rem = s - money;
        ll p = rem / peachCost;                         // 还能买的 type0 数
        p = min({p, Mpeach - t, (ll)t0.size()});
        if (p < 0) p = 0;
        ans = max(ans, ps1[t] + ps0[p]);
    }
    cout << ans << "\n";
    return 0;
}
```

## 5. 易错点

1. **忘记桃子上限** `M_peach = m/k`：只卡预算会多选顾客导致桃子不够。
2. **把"不扣支出"误解为"不卡预算"**：预算 `s` 限制的是进货花费，不是目标；但花费确实约束能服务多少人。
3. **type1 的篮子只增加预算、不增加桃子**：混为一谈会算错约束。
4. **贪心正确性**：组内按 `a_i` 降序取前缀是显然最优（成本固定、收益越大越好）；跨组用枚举 `t` 覆盖，无需背包 DP。

## 6. 举一反三

- **套路本质**：「多资源约束下的最大收益选择」——成本结构分组后，每组内部贪心，组间用一维枚举覆盖。
- **同类题**：
  - 洛谷 P1803 线段覆盖（按价值/成本贪心）
  - 洛谷 P2095 美食（背包变形）
  - 牛客/Codeforces 常见「两种资源 + 选子集最大化」题
- **变体方向**：若 `b_i` 不止 0/1（多种篮子），可改为枚举"篮子用量"或排序后双指针；若 `a_i` 与成本强相关，可转按"性价比"排序。
- **训练切入点**：先练「单约束贪心」→ 再练「双约束拆组枚举」。本题是双约束拆组的干净范例。
