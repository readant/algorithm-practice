## 1. 题意

价值 $a$ 枚金币的物品由 $b$ 人平摊，$1$ 枚金币 $=10^k$ 粒碎银。老板对**每个人**抹去不足 1 粒碎银的零头。问每人应付多少金币、多少碎银（能凑整金币的都用金币）。

## 2. 解法

先把每人的份额统一化成碎银，再往下拆：

```
每人碎银 = floor(a * 10^k / b)
金币     = 每人碎银 / 10^k
碎银     = 每人碎银 % 10^k
```

赛内写法在数学上等价（也是对的）：

```cpp
int one = a / b;                 // 金币整除部分
double yu = a % b;               // 金币余数
int sui = yu * pow(10,k)/b + 1e-8;
```

因为 $a = \lfloor a/b \rfloor b + (a \bmod b)$，两边同乘 $10^k$ 再除以 $b$ 就得到上面的拆分。

## 3. 易错点

1. **顺序不能反**：必须先乘 $10^k$ 再除以 $b$，先除会把零头丢掉。
2. **溢出边界**：$a \le 10^4$、$10^k \le 10^5$，$a \cdot 10^k \le 10^9$，int 刚好；写成 `long long` 更稳。
3. **不要用浮点算整数除法**。本场用 `pow` + `1e-8` 补误差，靠数据范围才没翻车；换成 $10^{18}$ 量级就会错。
