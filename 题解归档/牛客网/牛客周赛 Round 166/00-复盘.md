## 四、逐题复盘

### A · 小月的增减 —— AC 50/50 ✅

一次遍历，奇数减一、偶数加一，$O(n)$。4.25 分钟，比上场慢 1.75 分钟，仍在合理区间。

改进点：`a[101]` 可以直接省掉，边读边算。

### B · 小月的集市 —— AC 100/100 ✅【本场最大的进步】

```cpp
int one = a / b;                       // 金币整除部分
double yu = a % b;                     // 金币余数
int sui = yu * pow(10,k)/b + 1e-8;     // 余数换算成碎银
```

等价于"先算每人碎银再拆"，**结论正确**。9.87 分钟，比上场的 20.5 分钟快一倍。

遗留风险（不影响本场，但要记）：

| 隐患 | 说明 |
| :-- | :-- |
| `pow` 走 double | 靠 `+1e-8` 兜误差；本题 $a \cdot 10^k \le 10^9 < 2^{53}$ 才安全 |
| `yu` 声明成 double | 它是 `a % b` 的整数余数，没必要转浮点 |

### C · 小月的长廊 —— 26.25/150 ⚠️【本场最贵的一课】

**你的判据**：

```cpp
if (r - l + 1 > p) cnt++;    // 判的是区间长度
```

**题面要的是**：$|d(l_i) - d(r_i)| \ge p$，其中 $d(x)$ 是**覆盖位置 $x$ 的结界数量**。

两者毫无关系：`r - l + 1` 是"这个区间有多长"，`d(l_i)` 是"有多少个区间盖住了这个左端点"。

**为什么没被拦住**——样例 1（$n=5, p=2$）用错式子算出来恰好也是 4：

| 区间 | 长度 | $d(l_i)$ | $d(r_i)$ | 真差 | 你的判据 |
| :-- | --: | --: | --: | --: | :-- |
| [1,5] | 5 | 1 | 5 | 4 ✅ | 5>2 ✅ |
| [2,5] | 4 | 2 | 5 | 3 ✅ | 4>2 ✅ |
| [5,8] | 4 | 5 | 1 | 4 ✅ | 4>2 ✅ |
| [3,7] | 5 | 3 | 2 | 1 ❌ | 5>2 ✅ |
| [5,6] | 2 | 5 | 3 | 2 ✅ | 2>2 ❌ |

两类错误刚好抵消，总数都等于 4。**这不是运气差，是判据从头到尾没被检验过。**

正解（离散化 + 差分，$O(n\log n)$）见 [C_小月的长廊.cpp](C_小月的长廊/C_小月的长廊.cpp)，样例全过、对拍 300/300。

> 定位：扫描线入门题——"数轴上被多少个区间覆盖"的标准解法就是端点差分。挂块 7 的号。

### D · 小月的回声 —— 60/200 ⚠️

**你的写法**：枚举 $l$ → 枚举 $r$ → 再扫一遍中间求和，$O(n^3)$。

$n \le 2\times10^5$ 时是 $8\times10^{15}$ 量级。60 分来自最小一档测试点。

**这与上场 C 题是同一个病**：上场是 $O(n^2)$ 跑 $n=2\times10^5$，本场是 $O(n^3)$ 跑同一个 $n$。复杂度换算连续两场没做。

**正解的关键不是算法，而是看数据范围：**

- $a_i \ge 1 \Rightarrow$ 中间和 $S \ge r-l-1$；
- $a_i \le 30 \Rightarrow a_l \cdot a_r \le 900$；
- 于是 $S > 900$ 立刻 break。

每个左端点最多扫 901 步，$O(900n)$。$n=2\times10^5$ 实测 0.5–0.7 s。

> 题目的设计意图就是考"用 $a_i \le 30$ 这个上界把枚举压成常数"——**数据范围不是背景信息，是解法的一部分**。

榜面显示 0 且无提交时间戳，按**未提交**处理。

终版通过率（E 54.4%、F 28.7%）看似"不难"，但这组数字含补题、分母又是自选提交者，**不能作为"该不该做"的依据**。缺封榜数据，本场不对这两题下判断。

### 6.2 专项训练

| 专项 | 具体动作 | 为什么 |
| :-- | :-- | :-- |
| **读题复述** | 读完每题写一句"我要算的量"及其定义域 | C 题的直接解药 |
| **复杂度换算** | 读完先写 $n$ 上限 ⇒ 允许复杂度（$2\times10^5$ ⇒ $O(n)$ / $O(n\log n)$） | D 题的直接解药 |

### 6.3 行为训练

1. **交卷前用样例手算关键量**——不是"跑一下看输出对不对"，而是"我知道它为什么等于 4"。
2. **止损后必须有下一个动作**：跳题 → 立刻打开下一题并计时；不跳 → 写下"这题放弃，改补哪题"。
3. **尾段 30 分钟无进展 → 切换到整理/补题/看榜**，不要干坐。
