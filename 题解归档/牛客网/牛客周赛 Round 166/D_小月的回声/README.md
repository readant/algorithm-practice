## 1. 题意

统计满足两个条件的区间 $[l,r]$ 数量：

- 长度至少 3，即 $r - l + 1 \ge 3$；
- $a_l \times a_r = \sum_{t=l+1}^{r-1} a_t$（首尾乘积 = 中间元素之和）。

$n \le 2\times10^5$，$1 \le a_i \le 30$。

## 2. 赛内写法错在哪

三重循环：枚举 $l$、枚举 $r$、再扫一遍中间求和，$O(n^3)$。

$n = 2\times10^5$ 时是 $8\times10^{15}$ 量级，必然超时。60 分对应只过了最小一档测试点——**这是复杂度没换算的典型结果**，与上场 C 题（$O(n^2)$ 跑 $n=2\times10^5$）是同一个病。

## 3. 正解

关键是**把 $r$ 的枚举范围压到常数**：

- 因为 $a_i \ge 1$，中间和 $S \ge r - l - 1$；
- 又因为 $a_i \le 30$，$a_l \times a_r \le 900$；
- 所以一旦 $S > 900$，往后加元素只会更大，**直接 break**。

每个左端点最多向右扫 901 个位置，总复杂度 $O(900n)$。

```cpp
for (int l = 1; l <= n; l++) {
    long long s = 0;
    for (int r = l + 2; r <= n; r++) {
        s += a[r - 1];
        if (s > 900) break;                  // 上界剪枝
        if (s == (long long)a[l] * a[r]) cnt++;
    }
}
```

实测 $n = 2\times10^5$：全 1、全 30、随机、以及"30 后接 899 个 1"的最坏构造，均在 0.5–0.7 s。

## 4. 易错点

1. **剪枝的前提是 $a_i \ge 1$**。题面写的是 $1 \le a_i$，没有 0；若有 0，$S$ 不单调，剪枝失效。
2. 长度条件等价于 $r \ge l + 2$，循环从 `l + 2` 起。
3. 累加 $S$ 时在 `r` 移动后加 `a[r-1]`，别写成 `a[r]`。
4. 用 `long long` 存 $S$ 和乘积，避免边界误判。
