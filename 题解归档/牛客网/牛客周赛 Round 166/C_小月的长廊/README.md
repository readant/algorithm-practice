## 1. 题意

数轴上有 $n$ 个闭区间 $[l_i, r_i]$。对任意位置 $x$，$d(x)$ 定义为**覆盖该位置的区间个数**（含端点；多个完全相同的区间分别计数）。

求有多少个 $i$ 满足 $|d(l_i) - d(r_i)| \ge p$。

## 2. 赛内写法错在哪

```cpp
if (r - l + 1 > p) cnt++;      // 判的是「区间长度」
```

题面要的是 **$d(l_i)$ 与 $d(r_i)$ 的差**，也就是"左端点被几个区间盖住、右端点被几个区间盖住"。上面判断的是区间自己有多长，和 $d$ 没有关系。

**为什么没被发现**：样例 1（$n=5,p=2$）用这个错式子算出来恰好也是 4。样例过 ≠ 对，这是本场最贵的一次误判。

## 3. 正解

$d(x)$ 只在端点处变化，所以**只需知道 2n 个端点上的 $d$ 值**，数轴长度 $10^9$ 不用管：

1. 收集全部 $l_i, r_i$，排序去重得 `xs`；
2. 对每个区间，在 `xs` 里二分出左右端点的下标 `a`、`b`，做差分 `diff[a] += 1; diff[b+1] -= 1`；
3. 前缀和得到每个端点的覆盖数；
4. 逐区间比较 `|d(a) - d(b)| >= p`。

复杂度 $O(n \log n)$。

验证：样例 1 的端点覆盖数为 $d(1)=1, d(2)=2, d(3)=3, d(5)=5, d(6)=3, d(7)=2, d(8)=1$，
五个区间的端点差依次为 4、3、4、1、2，只有第 4 个不满足，答案 4 ✅。

## 4. 易错点

1. **$d$ 的定义含区间自身**：$l_i$ 至少被第 $i$ 个区间覆盖一次，所以 $d(l_i) \ge 1$。
2. **$p = 0$ 时答案恒为 $n$**（绝对值 ≥ 0 恒成立），别写反成 `> p`。
3. 坐标 $10^9$，**不能开数组**，必须离散化。
4. 差分的右端点是 `b + 1` 处减一，`b+1` 可能等于 `m`（数组要开 `m+1`）。
