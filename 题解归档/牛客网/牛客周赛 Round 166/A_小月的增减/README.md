## 1. 题意

计数器初值为 $x$，从左到右处理长度为 $n$ 的数组：元素是奇数则 $x$ 减 1，是偶数则 $x$ 加 1。输出处理完的 $x$。

## 2. 解法

一次遍历，边读边改，O(n)。不需要存数组，甚至不需要 `a[101]`。

## 3. 易错点

1. **0 是偶数**——样例 2（`3 0 / 1 0 3`）就是专门考这一点。
2. 处理过程中 $x$ 可以为负，不要加 `max(x, 0)` 之类的保护。
