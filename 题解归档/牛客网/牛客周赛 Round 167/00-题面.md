## A. 小红的单复数

- 时间限制：C/C++/Rust/Pascal 1 秒，其他语言 2 秒
- 空间限制：C/C++/Rust/Pascal 256 M，其他语言 512 M
- 64bit IO Format: `%lld`

**题目描述**

给定一个仅包含小写字母的字符串 $s$，小红希望把它“变为单数”，具体的：
- 如果其最后两个字母恰好是 `es`，请你把 `es` 去掉后将其输出；
- 否则，如果其最后一个字母恰好是 `s`，请你把 `s` 去掉后将其输出；
- 否则，直接输出 $s$。

**输入描述**

第一行输入一个字符串 $s\ (3 \le \operatorname{len}(s) \le 10)$，保证其仅包含小写字母。

**输出描述**

输出一个字符串，代表“变为单数”后的字符串 $s$。

**示例**

```
输入：boxes      输出：box
输入：cats       输出：cat
输入：apple      输出：apple
```

## B. qcjj的演唱会

- 时间限制：C/C++/Rust/Pascal 1 秒，其他语言 2 秒
- 空间限制：C/C++/Rust/Pascal 256 M，其他语言 512 M
- Special Judge, 64bit IO Format: `%lld`

**题目描述**

清楚姐姐要连续看三场演唱会，每场都有 $n$ 首歌。给定三个长为 $n$ 的字符串数组，分别代表第一场、第二场、第三场演唱会包含歌的名字。清楚想知道有哪些歌在三场演唱会都出现过，请你帮她计算。

**输入描述**

第一行输入一个整数 $n\ (1 \le n \le 10^5)$。

第二行输入 $n$ 个字符串 $s_1,s_2,\dots,s_n\ (1 \le \operatorname{len}(s_i) \le 5)$，保证仅含小写字母，且互不相同。

第三行输入 $n$ 个字符串 $s'_1,s'_2,\dots,s'_n\ (1 \le \operatorname{len}(s'_i) \le 5)$，保证仅含小写字母，且互不相同。

第四行输入 $n$ 个字符串 $s''_1,s''_2,\dots,s''_n\ (1 \le \operatorname{len}(s''_i) \le 5)$，保证仅含小写字母，且互不相同。

**输出描述**

第一行输出一个整数 $k$，代表在三场演唱会都出现过的歌的数量；

第二行输出 $k$ 个字符串，代表三场都出现过的歌。特殊地，如果 $k=0$，则不用输出这一行。

多个解可任意输出一个（Special Judge 自动判定）。

**示例**

```
输入：
5
moon star rain wind dream
rain moon cloud dream light
dream rain fire moon sky
输出：
3
moon rain dream

输入：
3
spring summer autumn
cloud rain snow
red blue green
输出：
0
```

## C. 小红的区间

- 时间限制：C/C++/Rust/Pascal 1 秒，其他语言 2 秒
- 空间限制：C/C++/Rust/Pascal 256 M，其他语言 512 M
- Special Judge, 64bit IO Format: `%lld`

**题目描述**

给定一个正整数 $x$，请你找到一个长度不小于 $3$ 的区间 $[l,r]$，满足 $\gcd\!\left(\sum_{i=l}^{r} i,\ x\right) = 1$。如果不存在这样的区间，请输出 $-1$。

【名词解释】$\gcd$：最大公约数，指两个或多个整数共有约数中最大的一个。例如 $12$ 和 $30$ 的公约数有 $1,2,3,6$，最大的是 $6$，记作 $\gcd(12,30)=6$。特别地，单个整数的 $\gcd$ 定义为其自身。

> 注：题面原文公式渲染在截图里曾被误读为“连乘积”，但样例 $x=6 \to [1,13]$ 仅当取**区间和** $\sum_{i=l}^r i$ 时成立（$\gcd(91,6)=1$；若取连乘积则 $\gcd(13!,6)=6\neq1$）。故此处为**区间和**。

**输入描述**

第一行输入一个整数 $x\ (1 \le x \le 10^9)$。

**输出描述**

如果不存在这样的区间，请输出 $-1$；否则输出两个整数 $l,r\ (1 \le l < r \le 10^{18})$，代表你所找到的区间。多个解可任意输出一个。

**示例**

```
输入：6
输出：1 13
```

## D. 小红的排列构造

- 时间限制：C/C++/Rust/Pascal 1 秒，其他语言 2 秒
- 空间限制：C/C++/Rust/Pascal 256 M，其他语言 512 M
- Special Judge, 64bit IO Format: `%lld`

**题目描述**

给定一个长度为 $n$、仅由字符 `a`、`b`、`c` 组成的字符串 $s=s_1s_2\dots s_n$。请你构造一个长度为 $n$ 的排列 $p$，使得下列三个和的奇偶性相同：
- 所有满足 $s_i=\texttt{a}$ 的位置 $i$ 对应的 $p_i$ 之和；
- 所有满足 $s_i=\texttt{b}$ 的位置 $i$ 对应的 $p_i$ 之和；
- 所有满足 $s_i=\texttt{c}$ 的位置 $i$ 对应的 $p_i$ 之和。

【名词解释】长度为 $n$ 的排列：由 $1,2,\dots,n$ 这 $n$ 个整数按任意顺序组成的数组（每个整数均恰好出现一次）。例如 $\{2,3,1,5,4\}$ 是一个长度为 $5$ 的排列，而 $\{1,2,2\}$ 和 $\{1,3,4\}$ 都不是排列，因为前者存在重复元素，后者包含了超出范围的数。

**输入描述**

第一行输入一个整数 $n\ (1 \le n \le 2\times 10^5)$，表示字符串的长度。

第二行输入一个长度为 $n$ 的字符串 $s$，保证其仅由字符 `a`、`b`、`c` 组成。

**输出描述**

如果不存在满足条件的排列，请输出 $-1$；否则输出 $n$ 个整数 $p_1,p_2,\dots,p_n$，表示你所构造的排列。多个解可任意输出一个。

**示例**

```
输入：
6
abcabc
输出：
1 2 3 4 5 6
（说明：a/b/c 三组位置之和分别为 1+4=5、2+5=7、3+6=9，均为奇数）

输入：
3
aab
输出：
1 3 2
（说明：a 位 1+3=4 偶，b 位 2 偶，c 位空和为 0 偶）

输入：
3
abc
输出：
-1
（说明：1,2,3 中只有一个偶数，无法让 a/b/c 三组同奇偶）
```

## E. 小红的根（easy）

- 时间限制：C/C++/Rust/Pascal 2 秒，其他语言 4 秒
- 空间限制：C/C++/Rust/Pascal 256 M，其他语言 512 M
- 64bit IO Format: `%lld`

**题目描述**

**本题为《F. 小红的根（hard）》的简单版本，两题的区别在于：本题中 $k=1$。**

给定一棵包含 $n$ 个节点的树，小红对其有两种共 $k$ 个断言：
- 种类 1：给定两个整数 $a,b\ (a\neq b)$，代表节点 $a$ 是节点 $b$ 的祖先节点；
- 种类 2：给定两个整数 $a,b\ (a\neq b)$，代表节点 $a$ 与节点 $b$ 没有祖先关系。

请你计算，共有多少个 $i\in[1,n]$ 满足：将节点 $i$ 选为树的根后，能够满足所有的断言。

【名词解释】祖先节点：在一棵以 $u$ 为根的树中，若点 $x$ 在 $u$ 到 $v$ 的简单路径上，且 $x\neq v$，则称 $x$ 是 $v$ 的祖先节点。根节点没有祖先节点。简单路径：树上任意两个节点之间的路径，不经过重复的点和边。

**输入描述**

第一行输入两个整数 $n,k\ (2 \le n \le 2\times 10^5;\ k = 1)$。

之后的 $n-1$ 行，第 $i$ 行输入两个整数 $u_i,v_i\ (1 \le u_i, v_i \le n;\ u_i \neq v_i)$ 表示树上第 $i$ 条边连接节点 $u_i$ 和 $v_i$。保证树连通。

之后的 $k$ 行，第 $i$ 行输入三个整数 $op_i,a_i,b_i\ (op_i\in\{1,2\};\ 1\le a_i,b_i\le n;\ a_i\neq b_i)$，代表第 $i$ 个断言的种类是 $op_i$，参数为 $a_i,b_i$。

**输出描述**

输出一个整数，代表符合条件的节点数量。

**示例**

```
输入：
5 1
1 2
2 3
2 4
4 5
1 2 5
输出：3
（说明：选节点 1,2,3 作为根时均满足断言）
```

**输出描述**

输出一个整数，代表符合条件的节点数量。

**示例**

```
输入：
5 2
```

## G. qcjj抢票

- 时间限制：C/C++/Rust/Pascal 1 秒，其他语言 2 秒
- 空间限制：C/C++/Rust/Pascal 256 M，其他语言 512 M
- 64bit IO Format: `%lld`

**题目描述**

清楚姐姐正在抢票。一共有 $n$ 个出票口，用长为 $n$ 的数组 $a_1,a_2,\dots,a_n$ 表示，第 $i$ 个出票口初始还剩 $a_i$ 张票。清楚姐姐会不断进行“抢票”操作。每次操作前，她可以选择任意一个余票数量大于 $0$ 的出票口进行抢票。每次抢票成功的概率都为 $\frac{p}{q}$。如果抢票成功，清楚姐姐抢到一张票。清楚姐姐每次进行抢票操作后，其他人都会在 $n$ 个出票口各抢到一张票。

设本次操作前第 $i$ 个出票口的余票数量为 $b_i$，清楚姐姐选择了出票口 $k$。操作结束后：
- 如果本次抢票成功，则出票口 $k$ 的余票数量变为 $\max(0,b_k-1)$；
- 对于所有 $i$，出票口 $i$ 的余票数量再减少 $1$，变为 $\max(0,b_i-1)$。因此，如果清楚姐姐抢票成功，那么第 $k$ 个出票口的余票数量最终会变为 $\max(0,b_k-2)$。

当所有出票口的余票数量均变为 $0$ 时，抢票过程结束。清楚姐姐可以根据此前每次抢票的结果决定下一次选择哪个出票口。

请你求出在最优策略下，清楚姐姐最终抢到的票数的最大期望。可以证明答案可以表示为一个不可约分数 $\frac{p}{q}$，请直接输出整数 $\left(p \times q^{-1} \bmod M\right)$ 作为答案，其中 $M = 998\,244\,353$，$q^{-1}$ 是满足 $q\times q^{-1}\equiv 1\pmod M$ 的整数。

**输入描述**

第一行输入三个整数 $n,p,q\ (1 \le n \le 100;\ 1 \le p \le q < 998\,244\,353)$，表示出票口的数量、单次抢票成功概率的分子、分母。

第二行输入 $n$ 个整数 $a_1,a_2,\dots,a_n\ (1 \le a_i \le 100)$，表示每个出票口初始的余票数量。

**输出描述**

输出一个整数，代表答案对 $998\,244\,353$ 取模后的值。

**示例**

```
输入：
2 1 2
1 1
输出：499122177

输入：
5 11 45
14 19 19 8 10
输出：924245124
```
