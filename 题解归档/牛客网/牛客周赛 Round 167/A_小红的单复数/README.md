## 1. 题意

把字符串 $s$ 变“单数”：末尾若是 `es` 则去掉 `es`；否则末尾若是 `s` 则去掉 `s`；否则原样输出。保证 $\operatorname{len}(s)\ge 3$，所以取末两位不会越界。

## 2. 解法

一次判断即可：`s.substr(size-2,2)=="es"` → 截掉末 2 位；`else s.back()=='s'` → `pop_back()`；否则不动。

## 3. 易错点

1. **顺序**：先判 `es` 再判 `s`，不能反过来（否则 `es` 会被先当 `s` 处理只剩 `e`）。
2. 边界由题面 $\operatorname{len}(s)\ge 3$ 保证，无需特判长度。
