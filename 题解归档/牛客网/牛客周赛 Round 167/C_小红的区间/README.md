## 1. 题意

给定 $x$，找一个长度 $\ge 3$ 的区间 $[l,r]$，满足 $\gcd\!\left(\sum_{i=l}^{r} i,\ x\right)=1$；不存在则输出 $-1$。

> 注：题面公式是**区间和** $\sum_{i=l}^r i$（不是连乘积）。样例 $x=6\to[1,13]$ 中 $\sum=91$、$\gcd(91,6)=1$；若取连乘积 $\gcd(13!,6)=6\neq1$，矛盾，故确定为区间和。

## 2. 解法（正解思路）

区间和 $S(l,r)=\dfrac{(l+r)(r-l+1)}{2}$。令长度 $k=r-l+1\ge 3$，则 $S = \dfrac{k(2l+k-1)}{2}$。

1. 取**最小**的 $k\ge 3$ 使 $\gcd(k,x)=1$（一定存在，例如某个不整除 $x$ 的素数 $k$）。
2. 此时只需让 $\dfrac{2l+k-1}{2}$ 与 $x$ 互质。令 $m=\dfrac{2l+k-1}{2}=l+\dfrac{k-1}{2}$，取最小的 $m\ge \dfrac{k+1}{2}$ 且 $\gcd(m,x)=1$，则 $l=m-\dfrac{k-1}{2}\ge 1$。
3. 因 $\gcd(k,x)=1$ 且 $\gcd(m,x)=1$，有 $\gcd(k\cdot m,x)=1$，即 $\gcd(S,x)=1$。
4. 输出 $l,\ r=l+k-1$（保证 $r\le 10^{18}$ 只需 $l$ 别取太大）。

**必然有解**：对任意 $x$ 都能找到这样的 $k,m$（自由度很大）。
