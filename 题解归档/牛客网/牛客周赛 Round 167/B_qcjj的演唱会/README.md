## 1. 题意

三场演唱会各 $n$ 首不重复的歌，求**三场都出现**的歌的集合（Special Judge，顺序任意）。

## 2. 解法

把后两场的歌分别排序，对第一场的每首歌用 `binary_search` 判断是否在二、三场都出现。`n\le 10^5$，字符串长度 $\le 5$，排序 + 二分 $O(n\log n)$，稳过。

也可以直接用 `set`/`unordered_set` 求交集，代码更短。

## 3. 易错点

1. 输出要求：先输出数量 $k$，再输出 $k$ 个串；**$k=0$ 时不输出第二行**。
2. 特判空集合，否则会多打一行。
