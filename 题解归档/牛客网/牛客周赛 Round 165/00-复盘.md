### C · 小月的程序 —— 37.5/150 ⚠️【本场最值钱的一课】

**题意**：可选一个 k，把前 k 个元素**原地翻转**，要求翻转后 `b1 ≤ b2 ≤ … ≤ bn`（非递减），数合格 k 的个数。

**你的写法**（截图）：对每个候选前缀长度 j，**从备份恢复 → `reverse` 前 j+1 个 → 逐位检查 → 计数**。

| # | 问题 | 后果 |
| :--: | :-- | :-- |
| 1 | **复杂度 O(n²)**：每个 j 都恢复+翻转+全扫 | n≤2×10⁵（且 sum n≤2×10⁵）→ 约 10¹⁰ 量级 → **TLE**；37.5/150 = 25% 与"只过最小子任务"吻合 |
| 2 | **数组开小**：`int a[100000]`，题面 n 上限 **2×10⁵** | 大样例越界 → RE/WA |
| 3 | 判定也许写成"恰好变成 1..n" | 题面只要求**非递减**，若按 1..n 判则偏严 |

**正解（O(n)，已对拍验证）**：不要模拟。翻转前 k 个后 `b = a[k],…,a[1], a[k+1],…,a[n]`，要求 `b` 非递减 ⟺ 三条：

1. **前 k 个在原序下非增**：`a1 ≥ a2 ≥ … ≥ ak`
2. **后缀非减**：`a[k+1] ≤ … ≤ an`
3. **交界**：`a1 ≤ a[k+1]`（k=n 时无交界，需整个数组非增）

预处理两条 O(n) 量：`L1` = 最长非增前缀长度、`R0` = 最短非减后缀起点，扫一遍即可计数。
✅ 代码见 [`C_小月的程序/C_小月的程序.cpp`](C_小月的程序/C_小月的程序.cpp)（样例全过、对拍 300/300）。

> 定位：命中**块 7 前缀和/差分**思想——"枚举位置 + 模拟"类题，第一步永远是"把判定压成 O(1) 或均摊 O(1)"。

### D · 小月的删数 —— 赛内 0 / 赛后 +70

**题意**：选一个出现过的值 c，删除所有等于 c 的元素，其余保持相对顺序；**读数 = b1 − b2 + b3 − …**（按新位置逐元素交替）；求所有 c 中 `|读数|` 的最小值。

**你的写法**（截图）：按值分组 + 前缀和 → 对每个 c 把各"保留段"**整段乘一个符号、段间交替**累加。

- 方向对：分组 + 前缀和是这类题的标准起手，赛后能拿 70/200 说明思路站得住。
- **但口径错了（关键）**：读数要求"**逐元素**交替"，而你的写法是"**整段**交替"（把一整段的**总和**当成一项）。只有当每段长度都 = 1 时两者才等价。
  手算自检：样例 `[3,1,3,2,1]`、`c=3` → 剩余 `[1,2,1]`，读数 `1−2+1=0`；你的整段法给 `|1−(2+1)|=2`。**与样例对不上 → 方法错**（这是第三次"样例过≠对"的同型错误）。

**正解（O(n)，已对拍验证）**：仍按 c 的分布把数组切成"保留段" [L,R]，但

- 每段贡献 =（该段**起始符号**）×（该段**以 + 打头的交替和**），段内不再当成一个数；
- 段内交替和用"前缀交替和" `pref[i]=a1−a2+a3−…` 在 O(1) 内求出；
- 起始符号由 L 的**新位置奇偶**决定：L 之前删了 t 个 c，则新位置 `rank=(L+1)−t`，奇数为 +、偶数为 −。

✅ 代码见 [`D_小月的删数/D_小月的删数.cpp`](D_小月的删数/D_小月的删数.cpp)（样例全过、对拍 300/300）。

> 卡常提醒：`unordered_map` 在牛客可能被卡哈希；n=2×10⁵ 建议排序 + 离散化。
