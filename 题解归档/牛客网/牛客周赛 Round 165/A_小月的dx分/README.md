## 1. 题意

音乐游戏判定五类：Critical Perfect 计 3 分、Perfect 计 2 分、Great 计 1 分、Good / Miss 计 0 分。
给定五类数量 `a b c d e`（依次 CP / Perfect / Great / Good / Miss），求 DX 总分。

样例：`100 20 3 4 5` → `3×100 + 2×20 + 1×3 = 343`。

## 2. 解法

`a*3 + b*2 + c*1`（Good/Miss 不计分）。本题考的是**读题速度**，目标 ≤ 3 分钟。

## 3. 易错点

1. 五类顺序别搞混（CP=3、Perfect=2、Great=1、其余 0）。
2. `d*0` 是废写法，直接不加即可。
