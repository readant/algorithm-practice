## 1. 题意

`x_i ∈ [l_i, r_i]`，要求存在 `p (2 ≤ p ≤ n-1)` 使 `x_1 < x_2 < … < x_p > x_{p+1} > … > x_n`（先严格升后严格降）。
步幅 = `max |x_{i+1} − x_i|`。求所有合法方案中步幅的最小值；无解输出 `-1`。

样例：`n=5, [0,0] [1,4] [5,5] [2,3] [0,0]` → `3`；全 `[0,0]` → `-1`。

## 2. 正解：二分答案 + O(n) 可行判定

**二分行幅 B**（越大越容易，单调）。判定 `feasible(B)`：

- 记 `L(i)` = "以 i 结尾的严格上升链"（步长 ∈ [1,B]，每项落在各自区间）的可行取值集合。它一定是**区间**：
  `L(1)=[l1,r1]`；`L(i)=[ max(l_i, aL(i-1)+1), min(r_i, bL(i-1)+B) ]`。
- 对称地 `R(i)` = "以 i 为首的严格下降链"：
  `R(n)=[ln,rn]`；`R(i)=[ max(l_i, aR(i+1)+1), min(r_i, bR(i+1)+B) ]`。
- **峰值取 p 可行 ⟺ `L(p) ∩ R(p) ≠ ∅`**（两条链只在 p 处共享一个取值）。存在某 `p` 满足即 `feasible`。

上界：值域 `[-1e9,1e9]`，最大差 `2e9`，故 `B ∈ [1, 2e9]`；`B=2e9` 仍不可行 → `-1`。复杂度 `O(n log 2e9)`。

## 3. 易错点（本次对拍抓到）

1. **空区间必须传播**：一旦某层的上升/下降链区间变空，**其后所有层都必须保持空**。若只在当层判空、下一层仍用 `aL+1` 递推，会"假性变非空"，把无解判成有解（对拍 40/200 失败后修正）。
2. 严格升降 ⇒ 相邻差至少为 1，`B` 从 **1** 起搜索，不能从 0。
3. 峰值位置 `p ∈ [2, n-1]`，升降两段都必须非空（因此 `n ≥ 3`）。
4. 值域含负、差可达 `2e9`，全程 `long long`。

## 4. 举一反三

- **套路本质**：求"最小化的最大值"→ **二分答案**；`check` 用**区间递推/贪心**判可行。
- **同类**：CF/洛谷「二分答案 + 构造可行性」系列；"构造单调序列，最小化相邻差上限"。
- **切入**：看到"最小化最大值/最大化最小值"先想二分答案，再设计 O(n) 的 `check`。
