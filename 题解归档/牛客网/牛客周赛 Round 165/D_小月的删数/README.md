## 1. 题意

选一个在数组中出现过的值 `c`，删除所有等于 `c` 的元素，其余保持相对顺序，得到 `b`（长度 `m`）。

**读数**定义：

- `m > 0`：`b1 − b2 + b3 − …`（奇数位和 减 偶数位和）
- `m = 0`：`0`

求所有 `c` 中 `|读数|` 的最小值。

## 2. 本场做法的问题（"整段交替"≠"逐元素交替"）

截图写法：按值分组 + 前缀和，对每个 `c` 把各"保留段"**整段乘一个符号、段间交替**累加。

**错在**：读数要求**逐元素**交替；把一整段的**总和**当成一项，只在"每段长度都 = 1"时才等价。

手算反例（样例 1）：`a=[3,1,3,2,1]`，`c=3` → 剩余 `[1,2,1]`，读数 `1−2+1=0`；
"整段法"得 `|1−(2+1)| = 2`。**与样例对不上，方法即错。**

## 3. 正解（O(n)）

仍按 `c` 的出现位置把数组切成"保留段" `[L,R]`（两段之间是被删的 `c`）。每段贡献：

```
贡献 = （该段起始符号）×（该段以 + 打头的交替和）     ← 段内逐元素交替，不是一个数
```

- **段内交替和**：定义 `pref[i] = a1 − a2 + a3 − … ± a_i`，则
  `S(L,R) = Σ_{j=L..R} (−1)^{j−L} a_j = (−1)^L · (pref[R+1] − pref[L])`，O(1) 求出。
- **段起始符号**：由 `L` 在新数组中的位置奇偶决定。`L` 之前删掉了 `t` 个 `c`，则新位置
  `rank = (L+1) − t`，`rank` 为奇数取 `+`、偶数取 `−`。

对每个 `c` 处理 `O(出现次数 + 1)` 段；所有 `c` 合计 `O(n log n)`（或哈希 `O(n)`）。

## 4. 复杂度

`O(n log n)`（排序分组）或期望 `O(n)`（哈希）；`n ≤ 2×10⁵`。

## 5. 易错点

1. **交替的对象**：是"逐个剩余元素"，不是"逐段总和"——本场就栽在这里。
2. **符号漂移**：删除元素会改变后续元素的新位置奇偶，起始符号要用 `rank=(L+1)−t` 算。
3. `unordered_map` 可能被卡哈希；稳妥做法是排序 + 离散化。
4. `m = 0`（所有元素都是 `c`）读数取 0。

## 6. 举一反三

- **套路本质**：删值后整体量变化 = 按值分组 + 前缀（交替）和，把影响写成有限个区间和的函数。
- **同类**：CF「remove value, minimize |alternating sum|」系列。
- **切入**：先把"目标量"用前缀和写成公式，再想 `c` 的分组如何枚举。
