## 1. 题意

给定长度 `n` 的排列 `p_1…p_n` 与正整数 `k`，统计满足 `(i + p_i) 能被 k 整除` 的 `i`（1-based）的个数。
`n ≤ 2×10⁵`，`k ≤ 10⁹`。

样例：`n=5,k=3, p=2 1 5 3 4` → 位置 1、2、5 满足 → `3`。

## 2. 解法

边读边判：`i` 用循环变量，`p_i` 顺序读入，`if ((i + p_i) % k == 0) cnt++;`。O(n)。

`i + p_i ≤ 4×10⁵`，用 `long long` 无溢出风险（`k` 很大时 `(i+p_i)%k == i+p_i ≠ 0`，天然不计数）。

## 3. 易错点

1. **下标从 1 开始**（题面 `i ∈ [1,n]`）。
2. 变量命名别用 `m`（易与取模混淆）。
3. 本题 5 行代码，**目标 5 分钟**；本场用 20 分钟是流程损耗。
