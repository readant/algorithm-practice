## 1. 题意

树 `n` 个点，颜色 `c_i`。统计**无序点对** `{u,v}` 数量，满足 `c_u = c_v`，且 `u→v` 简单路径**恰好换色两次**（每有一对相邻节点颜色不同记一次换色）。

样例：`n=5, c=1 1 2 2 1`，链 `1-2-3-4-5` → `{1,5}`、`{2,5}` → `2`。

## 2. 正解

**关键观察**：一条路径的换色次数 = 路径上"异色边"的条数。把所有**同色边**（`c_u = c_v`）用并查集缩成连通分量，得到**缩点树 T'**（每个分量颜色统一、相邻分量颜色必不同）。于是

> `u,v` 的换色次数 = T' 中 `comp(u)` 到 `comp(v)` 的边数。

"恰好 2 次换色且 `c_u = c_v`" ⟺ `comp(u)`、`comp(v)` 是 T' 中某个**中间分量 C** 的两个邻居，且这两个邻居分量**同色**（路径形如 `X — Y — X`）。

**计数**：答案`= Σ_{分量 C} Σ_{颜色 col} Σ_{C 的 two 同色 col 邻居 A,B} size(A)·size(B)`。
对 C 的邻居按颜色分组，某色组内各邻居分量大小为 `s_1,s_2,…`，则
`Σ_{i<j} s_i s_j = ((Σ s_i)² − Σ s_i²)/2`，O(邻居数) 求出。全体合计 O(n α(n))。

## 3. 复杂度

O(n α(n))（并查集 + 哈希分组）。

## 4. 易错点

1. **"缩点"是缩"同色边"，不是缩"同色点"**——两个同色节点若中间隔着异色，不在同一分量。
2. 中间分量 C 的两个邻居必须**同色**，否则两端 `c_u ≠ c_v`，不计数。
3. 原图是树，缩点后仍是树、无重边，故不会重复计数。
4. 两端点必须在**不同分量**（同分量 = 0 次换色）。

## 5. 举一反三

- **套路本质**：树上路径的"颜色段/换色"问题，先缩同色边得到"颜色树"，把路径性质转成树上距离/结构性质。
- **同类**：AtCoder/CF 的"同色点对 + 路径约束"题；树上颜色连通块计数。
- **切入**：遇到"路径上颜色变化次数"先想"缩同色边"。
