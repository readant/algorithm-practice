## 1. 题意

给定长度 `n` 的数组 `a`。选一个 `k (1 ≤ k ≤ n)`，把**前 k 个元素原地翻转**，得到

```
b = a_k, a_{k-1}, …, a_1, a_{k+1}, …, a_n
```

要求 `b1 ≤ b2 ≤ … ≤ bn`（**非递减**）。统计合格 `k` 的个数。多组数据，`sum n ≤ 2×10⁵`。

## 2. 本场做法的问题

对每个候选 `k` 都"恢复备份 → `reverse` → 逐位检查"：

- **复杂度 O(n²)** → `n ≤ 2×10⁵` 时 TLE（只过多组中的小数据，25% 分）；
- 数组按 `1e5` 开，题面上限是 **2×10⁵** → 大样例越界。

## 3. 正解（O(n)）

翻转前缀 `k` 后 `b` 非递减 ⟺ 同时满足三条：

1. **反转段非减** ⟺ 前 `k` 个原序**非增**：`a1 ≥ a2 ≥ … ≥ ak`
2. **后缀非减**：`a[k+1] ≤ a[k+2] ≤ … ≤ an`
3. **交界**：`a1 ≤ a[k+1]`（`k = n` 时无交界，退化为"整个数组非增"）

预处理：

- `L1` = **最长非增前缀长度**（`a1≥a2≥…≥aL1`，取最大）
- `R0` = **最短非减后缀起点**（`aR0≤…≤an`，取最小）

则 `k` 合法 ⟺ `k ≤ L1` 且（`k = n` 时要求 `L1 = n`；否则 `k ≥ R0` 且 `a1 ≤ a[k+1]`）。

## 4. 复杂度

`O(n)` / 组，`sum n ≤ 2×10⁵` 轻松通过。

## 5. 易错点

1. **把"非递减"读成"恰好变成 1..n"**——题面只要求 `≤`，判等会偏严。
2. `k = n`（整体翻转）是特例，没有交界；别漏。
3. 多组数据 + `sum n` 限制 → 每组都要 `O(n)`，不能带常数大的 `sort`。

## 6. 举一反三

- **套路本质**：把"模拟每次操作"改成"用前后缀单调性直接刻画充要条件"。
