# P5739 阶乘

| 难度 | 标签 | 状态 | 语言 |

## 题目描述

求 $n!$，也就是 $1\times2\times3\dots\times n$。

挑战：尝试不使用循环语句（for、while）完成这个任务。

### 输入格式

第一行输入一个正整数 $n$。

### 输出格式

输出一个正整数，表示 $n!$。

### 输入输出样例 #1

#### 输入 #1

```
3
```

#### 输出 #1

```
6
```

### 说明/提示

数据保证，$1 \leq n\le12$。

## 解题思路

### 审题过程

- 题目要求计算 $n!$，即从 1 连乘到 $n$。
- 常规做法是循环累乘，但题目特意提出“不使用循环语句”的挑战，这明确暗示我们要用**递归**来实现。
- 数据范围很小（$n \le 12$），因此不用担心递归深度或整数溢出的问题。

### 主解法选择说明

本题采用**递归**作为主解法。原因有二：一是题目明确要求不使用循环，递归是替代循环最自然的方式；二是递归是算法初学者必须掌握的核心编程思想，本题非常适合用来演示“递归三步曲”（终止条件、递推关系、函数调用）的教学价值。虽然循环解法更直观，但递归解法更契合题目的“挑战”意图，也更能训练编程思维。

### 主解法核心思路

递归计算阶乘的核心思想是：$n! = n \times (n-1)!$，并且 $0! = 1$（本题中 $n \ge 1$，但为了通用性我们设置 $0! = 1$ 作为终止条件）。  
所以我们可以定义一个函数 `fact(n)`，如果 `n == 0` 则返回 1；否则返回 `n * fact(n - 1)`。  
例如计算 $3!$：`fact(3)` 调用 `3 * fact(2)`，`fact(2)` 调用 `2 * fact(1)`，`fact(1)` 调用 `1 * fact(0)`，`fact(0)` 返回 1，然后逐层返回，最终得到 $3 \times 2 \times 1 = 6$。

### 其他解法思路

- **循环累乘法**：使用 `for` 或 `while` 循环从 1 乘到 $n$，这是最直接的实现方式，代码简单易懂，但不符合题目的“不使用循环”挑战。若在实际开发中，循环往往是首选，因为递归有函数调用开销且可能造成栈溢出，但本题数据范围很小，递归完全没问题。

### 主解法伪代码设计

```
函数 fact(n):
    如果 n == 0:
        返回 1
    否则:
        返回 n * fact(n - 1)

主程序:
    读入 n
    输出 fact(n)
```

## 代码实现

### 主解法逐步讲解（带注释版本）

```cpp
#include <iostream>   // 提供 cin、cout 等输入输出功能

// 递归函数：计算 n!（n 为非负整数）
long long fact(int n) {
    // 终止条件：0! = 1
    if (n == 0) {
        return 1;
    }
    // 递推关系：n! = n * (n-1)!
    return n * fact(n - 1);
}

int main() {
    // 加速 C++ 输入输出流，使 cin/cout 更快（本题数据小，非必须但规范）
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int n;
    std::cin >> n;          // 读取 n
    long long ans = fact(n); // 调用递归函数计算结果
    std::cout << ans << '\n'; // 输出结果，用 '\n' 换行（比 endl 效率高，不强制刷新缓冲区）
    return 0;
}
```

**代码分步解释：**

- **第 1 步**：头文件 `<iostream>` 是输入输出流库，提供了 `std::cin` 和 `std::cout`。我们不需要其他头文件，因为递归不涉及数学函数或容器。
- **第 2 步**：定义递归函数 `long long fact(int n)`。返回类型使用 `long long` 是因为虽然题目保证 $n \le 12$，$12! = 479001600$ 在 `int` 范围内（约 21 亿），但为了代码的普适性和安全性（若数据范围稍大），使用 `long long` 更稳妥。参数类型用 `int` 足够。
- **第 3 步**：在 `fact` 函数中，先写终止条件 `if (n == 0) return 1;`。这是递归的“出口”，防止无限调用。注意这里我们以 $0! = 1$ 作为基准，虽然题目 $n \ge 1$，但这样设计可处理 $n=0$ 的边界情况，且更符合数学定义。
- **第 4 步**：递推部分 `return n * fact(n - 1);` 体现了 $n! = n \times (n-1)!$ 的核心数学关系。每次调用都会把问题规模缩小，直到 $n=0$ 时开始回溯。
- **第 5 步**：主函数 `main` 中，先使用 `std::ios::sync_with_stdio(false);` 和 `std::cin.tie(nullptr);` 来加速输入输出（一般竞赛代码的标配），然后读入 `n`，调用 `fact(n)` 并输出。输出使用 `'\n'` 而不是 `std::endl`，因为 `std::endl` 会强制刷新输出缓冲区，在大量输出时影响性能；本题虽无影响，但养成好习惯。

**关于输入陷阱：** 本题输入为纯整数，没有字符串或混合输入，因此无需处理 `cin` 和 `getline` 混用的问题。直接 `cin >> n` 即可。

### 其他解法实现

本题解法较为固定，主解法（递归）已覆盖题目要求。循环解法虽然常见，但不符合“不使用循环”的挑战，故在此仅作思路简述，不再提供完整代码。

### 解法对比总结

| 解法     | 时间复杂度 | 空间复杂度 | 代码复杂度 | 适用场景                     |
| :------- | :--------- | :--------- | :--------- | :--------------------------- |
| 递归     | $O(n)$     | $O(n)$（调用栈） | 简单       | 递归思想教学、禁止循环的题目 |
| 循环累乘 | $O(n)$     | $O(1)$     | 非常简单   | 日常开发、性能敏感场景       |

**推荐建议：**

- **初学者**：建议掌握递归解法，因为它能帮助你理解“函数调用自身”这一重要编程范式，为后续学习分治、搜索、动态规划打下基础。
- **竞赛场景**：本题数据小，两种方法均可；若在一般场景下计算阶乘，循环法更省内存且不易栈溢出，是更稳妥的选择。

## 易错点

- **递归终止条件缺失**：如果忘记写 `if (n == 0) return 1;`，递归会无限调用导致栈溢出（Stack Overflow）。必须确保每个递归路径都能到达终止条件。
- **整数类型选择不当**：虽然 $12!$ 不大，但 `int` 最大约 $2.1\times 10^9$，而 $13! = 6227020800$ 已溢出。若题目数据范围改变，使用 `long long` 更安全。本题虽用 `int` 也可，但推荐 `long long` 养成好习惯。
- **递归深度过大**：本题 $n\le 12$ 递归深度很小，但若 $n$ 很大（如 $n=100000$），递归会导致栈溢出。此处的“易错点”是在理解递归的局限性，避免盲目用于大数据。
- **命名冲突**：如果定义变量名为 `n` 同时函数参数也叫 `n`，要注意作用域。以上代码中函数参数 `n` 与主函数的 `n` 互不干扰，因为它们是局部变量。
- **忘记 `return 0`**：虽然主函数不写 `return 0` 编译器也会默认返回 0，但为了清晰和规范，建议加上。
