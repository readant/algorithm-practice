## 题目描述

输入 $x,y$，输出 $[x,y]$ 区间中闰年个数，并在下一行输出所有闰年年份数字，使用空格隔开。

### 输入格式

输入两个正整数 $x,y$，以空格隔开。

### 输出格式

第一行输出一个正整数，表示 $[x,y]$ 区间中闰年个数。

第二行输出若干个正整数，按照年份单调递增的顺序输出所有闰年年份数字。

### 数据范围

数据保证，$1582\le x < y \le 3000$。

### 样例

**输入 #1**

```
1989 2001
```

**输出 #1**

```
3
1992 1996 2000
```

## 解题思路

### 审题过程

- 题目给了一个闭区间 $[x, y]$，需要统计其中闰年的数量，并且把每个闰年的年份都列出来。
- 输入只有两个正整数，输出有两行：第一行是数量，第二行是具体年份（空格隔开）。
- 年份范围从 1582 到 3000，数据规模很小，直接逐个年份判断即可。
- 需要掌握闰年的判断规则：普通闰年（能被4整除但不能被100整除）或者世纪闰年（能被400整除）。

### 核心思路

判断闰年的数学规则是：

- 如果年份 `year` 能被 400 整除，则一定是闰年；
- 否则，如果年份 `year` 能被 4 整除 **且** 不能被 100 整除，则是闰年；
- 其他情况都不是闰年。

通俗来说：**“四年一闰，百年不闰，四百年再闰”**。

我们举个例子，比如样例 $x=1989, y=2001$：

1. 从 1989 年检查到 2001 年：
   - 1989：不能被4整除 → 平年
   - 1990：不能被4整除 → 平年
   - 1991：不能被4整除 → 平年
   - 1992：能被4整除，且不能被100整除 → **闰年**
   - 1993 ~ 1995：平年
   - 1996：能被4整除，且不能被100整除 → **闰年**
   - 1997 ~ 1999：平年
   - 2000：能被400整除 → **闰年**
   - 2001：平年
2. 统计闰年个数为 3，依次记录年份：1992、1996、2000。
3. 输出第一行 `3`，第二行 `1992 1996 2000`。

整个流程就是**循环 + 条件判断 + 存储结果**，非常直观。

### 伪代码设计

```text
输入 x, y

闰年列表 = 空数组
闰年计数 = 0

for 年份从 x 到 y:
    如果 年份能被400整除 或 (年份能被4整除 且 年份不能被100整除):
        闰年计数 += 1
        将 年份 加入 闰年列表

输出 闰年计数
输出 闰年列表中的所有年份，用空格隔开（末尾是否有空格不影响本题）
```

初学者可以清楚地看到：先统计，再输出，逻辑顺序和手算过程完全一致。

## 代码实现

### 逐步讲解（适合初学者）

下面给出完整的 C++ 代码，并逐部分解释。

```cpp
#include <iostream>   // 用于 cin, cout 输入输出
#include <vector>     // 用于 vector 容器，动态存储闰年列表

using namespace std;

int main() {
    int x, y;
    cin >> x >> y;          // 读取区间左右端点

    vector<int> leapYears;  // 存放所有闰年年份
    int count = 0;          // 闰年个数

    for (int year = x; year <= y; year++) {
        // 判断闰年的条件
        if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
            count++;
            leapYears.push_back(year);  // 将闰年存入 vector
        }
    }

    cout << count << '\n';

    // 输出所有闰年，年份之间用空格隔开
    for (int i = 0; i < leapYears.size(); i++) {
        if(i > 0) cout << ' ';  // 前置分隔符,只要不是第一个,前面就加上个空格
        cout << leapYears[i];

    }
    cout << '\n';

    return 0;
}
```

**头文件解释**：

- `#include <iostream>`：标准输入输出流，必须包含，否则无法使用 `cin` 和 `cout`。
- `#include <vector>`：使用 STL 的 `vector` 容器。这里我们可以用普通数组，但 `vector` 可以动态增长，更灵活。我们也可以用两个变量记录数量后第二遍遍历输出，但 `vector` 是最方便存储不确定个数数据的方式。

**为什么不用普通数组？** 因为普通数组需要预先定义大小，虽然数据范围最大 3000，可以直接开一个 3000 大小的数组，但 `vector` 更安全、更常用，在这里也是很好的学习机会。

**为什么用 `int` 而不用 `double`？** 年份和数量都是整数，`int` 足够（-2^31 ~ 2^31-1，本题最大 3000），没有任何小数运算，用 `double` 反而可能引入精度问题且浪费内存。

**输出空格控制**：第二个 for 循环中，我们采用了‘前置空格’技巧：只要当前不是第一个元素（i > 0），就在输出数字前先输出一个空格。这样末尾绝对不会有空格，比判断末尾要自然得多。

### C++ 完整代码

提供带 `ios::sync_with_stdio(false)` 的高效简洁版本：

```cpp
#include <bits/stdc++.h>   // 万能头文件，仅竞赛常用，简化代码
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int x, y;
    cin >> x >> y;

    vector<int> ans;
    int cnt = 0;

    for (int i = x; i <= y; ++i) {
        if ((i % 4 == 0 && i % 100 != 0) || i % 400 == 0) {
            cnt++;
            ans.push_back(i);
        }
    }

    cout << cnt << '\n';
    for (size_t i = 0; i < ans.size(); ++i) {
        cout << ans[i] << (i + 1 == ans.size() ? '\n' : ' ');
    }

    return 0;
}
```

说明：`bits/stdc++.h` 在 GNU C++ 编译器中可用，包含几乎所有标准库，虽然移植性略差，但竞赛中常用。`size_t` 是 `vector::size()` 返回的类型，用 `int` 也可以（注意比较时可能 warning，但无伤大雅）。

## 易错点

- **闰年判断条件书写错误**：常见错误是只写 `year % 4 == 0` 或者忘记 `% 100 != 0` 部分。记住规则：能被400整除 **或者**（能被4整除且不能被100整除）。建议把 `||` 两边的条件用括号明确分开，避免优先级误解。
- **输出格式末尾空格**：虽然多数 OJ 不严格检查行末空格，但某些题目会严格比对，最好按标准格式输出，最后一个年份后不加空格。使用循环时用条件判断控制。
- **数据类型选择**：年份和数量都是整数，使用 `int` 完全足够，不要使用 `double` 或 `float`，避免不必要的麻烦。
- **区间闭区间问题**：题目说 `[x,y]`，循环条件应为 `year <= y`，不要漏掉 `y` 本身。
- **年份范围起点**：题目保证 `x >= 1582`，这已经满足格里高利历，不用额外处理历史特殊规则。

## 总结发散

### 核心模式

**“区间枚举 + 条件判定 + 格式化输出”** —— 这是模拟题中最常见的套路，关键在于把题目描述的规则准确转换成代码逻辑。

### 延伸/推导

- **闰年规则的由来**：地球绕太阳公转一周约为 365.2422 天，为了让日历与四季对应，每 4 年加一天（闰日）。但这样每 400 年会多出约 3 天，所以每 400 年要减掉 3 个闰年，于是规定“百年不闰，四百年再闰”。这就是 `%100` 和 `%400` 的数学背景。
- **扩展到其他日期问题**：如果你遇到“判断某年某月有多少天”的题目，也会用到闰年判断（因为 2 月的天数取决于是否为闰年）。
- **扩展到三维**：如果题目变成“求三维空间内满足某种条件的点”，思路仍然相同——枚举所有候选点，用条件函数过滤，然后输出结果。这种“生成-过滤”的模式在算法中非常通用。
