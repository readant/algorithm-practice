# P5736 质数筛

## 元数据

| 项目 | 内容 |
|------|------|
| 难度 | 入门 |

## 题目描述

### 问题描述

输入 $n$ 个不大于 $10^5$ 的正整数。要求全部储存在数组中，去除掉不是质数的数字，依次输出剩余的质数。

### 输入格式

第一行输入一个正整数 $n$，表示整数个数。

第二行输入 $n$ 个正整数 $a_i$，以空格隔开。

### 输出格式

输出一行，依次输出 $a_i$ 中剩余的质数，以空格隔开。

### 数据范围

- $1 \le n \le 100$
- $1 \le a_i \le 10^5$

### 样例

#### 输入 #1

```
5
3 4 5 6 7
```

#### 输出 #1

```
3 5 7
```

#### 边界用例（自测用）

- 输入 `1\n1`，输出为空行（1 不是质数）。
- 输入 `3\n4 6 8`，输出为空行（全是合数）。
- 输入 `4\n2 3 5 7`，输出 `2 3 5 7`（全是质数）。

## 解题思路

### 审题过程

- 题目给出 $n$ 个正整数，需要按原顺序输出其中所有质数。
- 质数定义：大于 1 的自然数，且只能被 1 和自身整除。
- 需要将输入全部存起来，然后逐个判断每个数是否为质数，最后输出符合条件的数。
- 数据范围较小（$n \le 100$，$a_i \le 10^5$），即使对每个数单独做试除判断，计算量也微乎其微。

### 主解法选择说明（重要）

**本题位于洛谷官方题单【函数与结构体】章节**。因此，主解法必须优先服务于该章节的教学目标：**练习函数的定义与调用，以及结构体的封装与传参**。

虽然埃氏筛是数学上更优的解法，但在这里属于“杀鸡用牛刀”，且无法练习到函数封装。因此，我们选择**试除法 + 函数封装**作为主解法，将“判断质数”的逻辑独立成 `isPrime` 函数，并将数据用 `struct NumberSet` 结构体进行封装。这既能完美通过本题，又能切中该专题的考点。

### 主解法核心思路

**通俗来说**：我们把“判断一个数是不是质数”这件事，单独写成一个“小工具”（函数）。当主程序拿到一个数时，只要调用这个小工具，就能得到是或否的答案。

具体操作：

1. 定义一个结构体 `NumberSet`，里面放一个数组和一个计数器，用来装下所有的输入数字。
2. 定义一个函数 `bool isPrime(int x)`，用试除法（检查从 2 到 $\sqrt{x}$ 有没有能整除 $x$ 的数）来判断质数。
3. 主函数中，把输入装进结构体，然后遍历数组，依次调用 `isPrime` 函数，把结果为 `true` 的数字输出。

### 其他解法思路

- **埃拉托斯特尼筛法（埃氏筛）**：预处理出从 2 到最大值之间所有的质数，标记在数组中。查询时直接 $O(1)$ 查表。虽然数学效率高（$O(M \log \log M)$），但代码中没有出现独立的判断函数和结构体，不符合本专题的练习初衷，适合作为“数学篇”的进阶内容。
- **欧拉筛（线性筛）**：埃氏筛的优化版，时间复杂度 $O(M)$。同样属于数学优化范畴，适合对算法效率有极致要求的场景。

### 主解法伪代码设计

```
// 定义结构体，用来装数据
结构体 NumberSet {
    整型 数组 data[105]
    整型 长度 len
}

// 定义函数：判断一个数是不是质数
函数 isPrime(整型 x) -> 布尔值 {
    如果 x < 2: 返回 假
    如果 x == 2: 返回 真
    如果 x 是偶数: 返回 假
    循环 i = 3; i * i <= x; i += 2:
        如果 x 能被 i 整除:
            返回 假
    返回 真
}

主函数 {
    输入 n
    定义 NumberSet 变量 nums
    nums.len = n

    // 读取数据存入结构体
    循环 i = 0 到 n-1:
        输入 nums.data[i]

    // 筛选并输出
    循环 i = 0 到 n-1:
        如果 isPrime(nums.data[i]) 为 真:
            输出 nums.data[i]（注意空格格式）
    输出换行
}
```

## 代码实现

### 主解法逐步讲解（带注释版本）

```cpp
#include <iostream>   // 提供 cin, cout 等输入输出流
using namespace std;  // 使用标准命名空间，简化代码书写

// 【1. 结构体定义】把“数组”和“元素个数”打包在一起
// 作用：便于管理数据，以后如果要传参给函数，只需要传一个结构体变量即可
// 通俗来说：就像一个文具盒，把笔（数据）和笔的数量（长度）都装在一起
struct NumberSet {
    int data[105];   // 根据数据范围 n <= 100，多开一点空间防止越界（防御性编程）
    int count;       // 实际存储的数字个数
};

// 【2. 函数封装】判断一个整数 x 是否为质数
// 这是本专题的核心考点：把独立的逻辑块封装成函数，让主函数更清晰
// 参数：int x（值传递，传入一个整数副本，函数内部修改不影响外部）
// 返回值：bool 类型（true 表示是质数，false 表示不是）
bool isPrime(int x) {
    // 第一步：排除 0 和 1（它们不是质数）
    if (x < 2) return false;

    // 第二步：处理偶数（除了 2 以外，偶数都不是质数）
    // 这里提前处理偶数，可以让后续循环只检查奇数，速度翻倍
    if (x == 2) return true;      // 2 是质数，直接返回
    if (x % 2 == 0) return false; // 其他偶数直接排除

    // 第三步：检查奇数因子（从 3 开始，步长为 2）
    // 为什么只用检查到 i * i <= x ？
    // 因为如果 x = a * b，那么 a 和 b 中必有一个 <= sqrt(x)
    // 例如 36 = 4 * 9，4 <= 6，检查到 4 就能发现它不是质数了
    // 这里用 i * i <= x 代替 i <= sqrt(x)，完全避免浮点数精度问题
    for (int i = 3; i * i <= x; i += 2) {
        if (x % i == 0) {
            return false; // 发现能整除的因子，说明是合数
        }
    }

    // 循环结束都没找到因子，说明是质数
    return true;
}

// 【3. 处理函数】（可选，但推荐，进一步体现结构化）
// 作用：遍历结构体中的数据，调用 isPrime 函数，输出质数
// 参数：const NumberSet& nums（const 引用传递）
// 为什么用 const 引用？
//   - 不用值传递（NumberSet nums）：因为结构体包含数组，复制整个结构体会消耗额外内存和时间。
//   - 用引用（&）：可以直接操作原数据，避免拷贝。
//   - 加 const：保证函数内不会意外修改原数据，安全且让编译器能优化。
void printPrimes(const NumberSet& nums) {
    bool first = true; // 控制空格分隔，避免行尾多余空格

    for (int i = 0; i < nums.count; ++i) {
        // 调用 isPrime 函数判断
        if (isPrime(nums.data[i])) {
            if (!first) {
                cout << ' '; // 先输出空格再输出数字
            }
            cout << nums.data[i];
            first = false;
        }
    }
    cout << '\n'; // 输出换行，使用 '\n' 而非 endl，避免强制刷新缓冲区影响性能
}

int main() {
    // 加速输入输出（虽然本题数据量小，但这是良好的编码习惯）
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 定义结构体变量 nums
    NumberSet nums;

    // 读取数字个数，存入结构体的 count 成员
    cin >> nums.count;

    // 读取 n 个数字，存入结构体的 data 数组
    for (int i = 0; i < nums.count; ++i) {
        cin >> nums.data[i];
    }

    // 调用处理函数，输出结果
    printPrimes(nums);

    return 0; // 程序正常结束
}
```

**逐步讲解（主解法核心点）**：

1. **头文件**：只用了 `<iostream>`，因为我们的逻辑全用整数运算，不需要 `<cmath>` 中的 `sqrt()`，直接使用 `i * i <= x` 规避了浮点数，更精简安全。

2. **`struct NumberSet`（结构体）**：
   - 我们在结构体里定义了一个 `data[105]` 和一个 `count`。这样就把数据打包成了一个整体。
   - **C++ 内存知识**：`nums` 变量在 `main` 函数中定义，它在**栈**（Stack）上分配内存。栈空间通常较小（几 MB），但放 105 个 int（约 420 字节）绰绰有余。如果数据量极大（如 100 万个），才需要考虑在**堆**（Heap）上用 `vector` 动态分配。

3. **`bool isPrime(int x)`（函数）**：
   - **返回值类型 `bool`**：结果只有“真”或“假”，用 `bool` 最贴切。
   - **参数传递**：这里是值传递，即 `x` 是主调函数传入值的副本。这很安全，因为函数内部修改 `x` 不会影响外部的原始数据。
   - **为什么是 `i * i <= x`**：这是初学者最容易迷糊的地方。通俗解释：如果 $x$ 是合数，比如 $x = a \times b$，假设 $a \le b$，那么 $a$ 肯定不大于 $\sqrt{x}$。所以我们只需要检查 2 到 $\sqrt{x}$ 之间有没有因子就够了。用乘法 `i * i <= x` 判断，完美避开调用 `sqrt()` 函数。

4. **`void printPrimes(const NumberSet& nums)`（函数传结构体）**：
   - **为什么用 `const` 引用**？初学者容易写成 `void printPrimes(NumberSet nums)`（值传递）。但结构体里有个数组，值传递会把整个数组复制一份，浪费内存且耗时。使用引用 `&` 直接操作原对象，加上 `const` 保护数据不被修改，是 C++ 中传递较大结构体/类对象的**最佳实践**。

5. **输出格式控制**：
   - `bool first` 是处理输出格式的经典技巧。如果直接输出 `cout << nums.data[i] << " "`，行尾会多一个空格，虽然很多 OJ 能容忍，但严格来说不符合题目要求。
   - 使用 `'\n'` 而非 `endl`：`endl` 会强制刷新输出缓冲区（flush），频繁操作会拖慢程序。这里用 `'\n'` 更高效。

6. **`ios::sync_with_stdio(false);`**：取消了 C++ 输入输出流与 C 标准 I/O 的同步，让 `cin/cout` 接近 `scanf/printf` 的速度。

### 其他解法实现

#### 埃拉托斯特尼筛法（数学进阶版）

**思路说明**：  
如果题目变成“多组输入”或“查询次数极多”，试除法就不够看了。埃氏筛预处理出所有质数，之后查询是 $O(1)$ 的。它的核心思想是：从 2 开始，把每个质数的倍数全部标记为“合数”。此版本虽然不符合本专题的结构体要求，但作为算法思维拓展极佳。

```cpp
#include <iostream>
#include <vector>   // 用于动态数组
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, max_a = 0;
    cin >> n;
    vector<int> a(n);

    for (int i = 0; i < n; ++i) {
        cin >> a[i];
        if (a[i] > max_a) max_a = a[i];
    }

    // 标记数组：true 表示质数
    vector<char> isPrime(max_a + 1, true);
    if (max_a >= 0) isPrime[0] = false;
    if (max_a >= 1) isPrime[1] = false;

    // 埃氏筛：从 2 到 sqrt(max_a)
    for (int i = 2; i * i <= max_a; ++i) {
        if (isPrime[i]) {
            for (int j = i * i; j <= max_a; j += i) {
                isPrime[j] = false;
            }
        }
    }

    bool first = true;
    for (int x : a) { // 范围 for 循环，C++11 语法
        if (isPrime[x]) {
            if (!first) cout << ' ';
            cout << x;
            first = false;
        }
    }
    cout << '\n';
    return 0;
}
```

**复杂度分析**：

- 时间复杂度：$O(M \log \log M)$，其中 $M = \max a_i$。
- 空间复杂度：$O(M)$。

### 解法对比总结

| 解法 | 时间复杂度 | 空间复杂度 | 代码复杂度 | 是否符合本专题要求 |
| ------ | ------------ | ------------ | ------------ | ------------------- |
| **函数+结构体（主解法）** | $O(n \sqrt{M})$ | $O(n)$ | 低（结构清晰） | **是（完美契合）** |
| 试除法（无封装） | $O(n \sqrt{M})$ | $O(1)$ | 极低 | 否（无函数/结构体） |
| 埃氏筛（数学优化） | $O(M \log \log M)$ | $O(M)$ | 中 | 否（纯算法，无专题语法） |

**明确推荐建议**：

- **刷洛谷官方题单的新手**：**务必掌握主解法（函数+结构体）**。这是本题的标准答案写法，能帮你扎实学会如何封装逻辑和打包数据，对后续学习类和对象也有帮助。
- **进阶算法学习者**：在掌握主解法的基础上，可了解埃氏筛。它在处理“大规模范围内质数查询”时效率远超试除法。
- **竞赛实战中**：如果数据范围如本题一样极小（$n \le 100$），直接写试除法判断最快最省事；但如果遇到 $n \le 10^5$ 且 $a_i \le 10^6$，则务必使用埃氏筛或欧拉筛。

## 易错点

- **1 不是质数**：这是最经典的认知错误。在 `isPrime` 函数开头必须加上 `if (x < 2) return false;` 排除 0 和 1。
- **结构体传参的拷贝开销**：新手容易写 `void printPrimes(NumberSet nums)`，导致数组被整个复制一遍（虽然本题只有 100 个数影响不大，但习惯不好）。应养成使用 `const NumberSet& nums` 的习惯。
- **浮点数精度与 sqrt**：如果使用 `int limit = sqrt(x); for (int i=2; i<=limit; i++)`，当 $x$ 是完全平方数（如 25）时，`sqrt(25)` 可能因浮点误差返回 `4.999999`，截断成 4，导致漏判 5 这个因子，误判 25 为质数。**推荐直接使用 `i * i <= x` 作为循环条件**，零精度风险。
- **变量未初始化**：结构体里的 `count` 如果忘记赋值，其值是随机的（内存残留数据）。必须在 `main` 中显式 `cin >> nums.count;` 或在定义时初始化（C++11 支持 `NumberSet nums{};` 清零）。
- **数组越界**：定义了 `data[105]`，循环时务必保证 `i < nums.count` 且 `nums.count <= 100`。数据范围明确给出，但建议多开几个空间（如 105）并加断言检查，是防御性编程的好习惯。

## 总结发散

### 核心模式

**逻辑封装 + 数据打包**：把“做什么”（判断质数）和“存什么”（输入数据）分离开来，各司其职，让代码更清晰、易维护、可复用。

### 延伸/推导

**试除法的进一步优化**：除了跳过偶数，我们还可以提前用 `if (x % 2 == 0)` 排除偶数，这样循环只检查奇数，速度直接翻倍。更进一步，可以维护一个质数表（如 2,3,5,7...），只检查质数因子，但这需要预处理好，属于“空间换时间”的范畴。在工程中，如果需要判断 $10^9$ 级别的大质数，Miller-Rabin 素性测试则是更专业的数论工具，它通过费马小定理等数论基础，能在 $O(\log^3 n)$ 的时间内给出高概率正确的结果。
