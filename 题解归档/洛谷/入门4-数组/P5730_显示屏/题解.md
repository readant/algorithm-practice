## 题目描述

用字符画显示数字。每个数字用 5 行×3 列的点阵表示，数字间用 `.` 分隔。

## 输入格式

第一行：n（位数）。
第二行：n 个数字组成的字符串。

## 输出格式

5 行，显示数字的字符画。

## 数据范围

$1 \le n \le 5$

## 样例

### 输入

```
3
123
```

### 输出

```
..X.XXX.XXX
..X...X...X
..X.XXX.XXX
..X.X...X..X
..X.XXX.XXX
```

---

## 解题思路

### 审题过程

1. **理解题意**：用 5 行×3 列的字符画显示数字，数字间用 `.` 分隔。
2. **关键观察**：每个数字的点阵图案是固定的，可以预存。
3. **建模**：查表法——用二维数组预存图案，按行输出。

### 方法一：查表法

**核心**：`num[digit][row]` 直接获取数字的某一行图案。

**输出逻辑**：外层循环行（0~4），内层循环每个数字，输出对应行的图案。

用二维数组预存每个数字的 5 行点阵图案，按行输出时查表即可。

## 代码实现

```cpp
#include <iostream>
#include <string>
using namespace std;

const string num[10][5] = {
    {"XXX", "X.X", "X.X", "X.X", "XXX"},  // 0
    {"..X", "..X", "..X", "..X", "..X"},  // 1
    {"XXX", "..X", "XXX", "X..", "XXX"},  // 2
    {"XXX", "..X", "XXX", "..X", "XXX"},  // 3
    {"X.X", "X.X", "XXX", "..X", "..X"},  // 4
    {"XXX", "X..", "XXX", "..X", "XXX"},  // 5
    {"XXX", "X..", "XXX", "X.X", "XXX"},  // 6
    {"XXX", "..X", "..X", "..X", "..X"},  // 7
    {"XXX", "X.X", "XXX", "X.X", "XXX"},  // 8
    {"XXX", "X.X", "XXX", "..X", "XXX"}   // 9
};

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;
    string s;
    cin >> s;

    for (int i = 0; i < 5; ++i) {
        for (int j = 0; j < n; ++j) {
            int d = s[j] - '0';
            cout << num[d][i];
            if (j != n - 1) cout << '.';
        }
        cout << '\n';
    }
    return 0;
}
```

## 易错点

1. 数字间用 `.` 分隔，最后一个数字后不加
2. `s[j] - '0'` 将字符转为数字
3. 外层循环是行，内层循环是数字

## 算法总结

| 项目 | 说明 |
|------|------|
| 算法类型 | 查表法, 模拟 |
| 时间复杂度 | $O(n \times 5)$ |
| 空间复杂度 | $O(1)$ |
| 核心技巧 | 预存点阵图案，按行查表输出 |
