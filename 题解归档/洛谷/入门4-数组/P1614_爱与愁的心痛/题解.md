## 题目描述

给定 n 个数和一个整数 m，求连续 m 个数的和的最小值。

## 输入格式

第一行：n 和 m。
第二行：n 个整数。

## 输出格式

一个整数，连续 m 个数的最小和。

## 数据范围

$1 \le m \le n \le 2 \times 10^5$

## 样例

### 输入

```
5 3
1 2 3 4 5
```

### 输出

```
6
```

---

## 解题思路

### 审题过程

1. **理解题意**：给定 n 个数，求连续 m 个数的和的最小值。
2. **关键观察**：滑动窗口——窗口大小固定为 m，向右滑动时，减去最左元素，加上最右元素。
3. **建模**：先计算前 m 个数的和，然后滑动取最小值。

### 方法一：滑动窗口

**核心公式**：`sum = sum - a[i-m] + a[i]`

```
数组：1 2 3 4 5，m=3
初始窗口：[1 2 3] → sum=6
滑动1次：[2 3 4] → sum = 6-1+4 = 9
滑动2次：[3 4 5] → sum = 9-2+5 = 12
最小值：6
```

## 代码实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<int> a(n);
    for (int j = 0; j < n; ++j) {
        cin >> a[j];
    }

    int sum = 0;
    for (int i = 0; i < m; ++i) sum += a[i];
    int minSum = sum;

    for (int i = m; i < n; ++i) {
        sum = sum - a[i - m] + a[i];
        minSum = min(minSum, sum);
    }

    cout << minSum << endl;
    return 0;
}
```

## 易错点

1. 先计算前 m 个数的和作为初始值
2. 滑动窗口从第 m 个元素开始
3. 注意 n 和 m 的大小关系

## 总结发散

### 核心模式：滑动窗口

滑动窗口是处理**连续子数组**问题的经典技巧：

| 问题类型 | 窗口操作 |
|----------|----------|
| 固定窗口求和 | 本题：`sum = sum - left + right` |
| 可变窗口 | LeetCode 3: 无重复字符的最长子串 |
| 前缀和 | 用 `prefix[r] - prefix[l-1]` 求区间和 |

### 进阶方向

- **前缀和**：预处理前缀和数组，区间和查询 O(1)
- **单调队列**：滑动窗口最大/最小值
