# 压缩技术 vs 压缩技术续集版 对比总结

## 题目概述

| 题目 | P1319 压缩技术 | P1320 压缩技术（续集版） |
|------|----------------|--------------------------|
| **方向** | 解压（压缩码 → 点阵图） | 压缩（点阵图 → 压缩码） |
| **输入** | 压缩码（数字序列） | 点阵图（01字符串） |
| **输出** | N×N的01矩阵 | 压缩码（数字序列） |
| **核心操作** | 根据数字重复输出字符 | 统计连续相同字符的个数 |

## 算法对比

### P1319 压缩技术（解压）

**算法思路**：
1. 读入压缩码，第一个数字N确定点阵大小
2. 初始化当前字符为'0'
3. 遍历压缩码，输出对应数量的当前字符
4. 每次输出后切换字符（0↔1）
5. 每N个字符换行

**关键技巧**：
- 使用异或操作 `cur ^= 1` 快速切换0/1
- 使用计数器控制换行位置

**复杂度**：
- 时间：O(N²)
- 空间：O(1)

### P1320 压缩技术（续集版）（压缩）

**算法思路**：
1. 读入所有输入字符串，合并为一个连续字符串
2. 计算字符串长度，开平方得到N
3. 初始化压缩码，第一个数字为N
4. 处理特殊情况：如果首字符是'1'，先补一个0
5. 遍历字符串，统计连续相同字符的个数
6. 当字符变化或到达末尾时，记录计数

**关键技巧**：
- 处理首字符为'1'的特殊情况（压缩码总是从0的个数开始）
- 使用计数器统计连续字符

**复杂度**：
- 时间：O(N²)
- 空间：O(N²)（需要存储整个字符串）

## 主要区别

### 1. 输入输出方向相反
- **原版**：输入压缩码，输出点阵图（解压过程）
- **续集版**：输入点阵图，输出压缩码（压缩过程）

### 2. 数据处理方式不同
- **原版**：根据数字重复输出字符，需要控制换行
- **续集版**：统计连续相同字符，需要处理首字符特殊情况

### 3. 空间复杂度差异
- **原版**：O(1)，只需要几个变量
- **续集版**：O(N²)，需要存储整个字符串

### 4. 实现难点不同
- **原版**：控制换行位置，确保输出N×N格式
- **续集版**：处理首字符为'1'的特殊情况

## 代码实现对比

### 原版代码（解压）
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, x;
    cin >> n;  // 第一个数是 N
    int cur = 0;  // 0 表示输出 '0'，1 表示输出 '1'
    int cnt = 0;  // 已输出字符数
    while (cin >> x) {
        for (int i = 0; i < x; ++i) {
            cout << (cur ? '1' : '0');
            ++cnt;
            if (cnt % n == 0) cout << '\n';  // 每行满 N 个换行
        }
        cur ^= 1;  // 切换 0/1
    }
    return 0;
}
```

### 续集版代码（压缩）
```cpp
#include <iostream>
#include <cmath>
#include <vector>
using namespace std;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s,t;
    while(cin >> t){
        s += t;
    }

    int N = sqrt(s.size());
    vector<int> ans = {N};
    if(s[0]=='1') ans.push_back(0);
    for(int i = 1,cnt = 1;i<=(int)s.size();++i){
        if(i == (int)s.size()||s[i] != s[i-1]){
            ans.push_back(cnt);
            cnt = 1;
        }
        else cnt++;
    }
    for(int i = 0; i <(int)ans.size();++i){
        if(i) cout << ' ';
        cout << ans[i];
    }
    return 0;
}
```

## 学习要点

1. **理解互逆操作**：这两道题是压缩和解压的互逆过程
2. **掌握模拟算法**：都是典型的模拟题，需要仔细处理边界情况
3. **注意特殊情况**：续集版需要处理首字符为'1'的情况
4. **选择合适的数据结构**：原版用简单变量，续集版需要vector存储结果
