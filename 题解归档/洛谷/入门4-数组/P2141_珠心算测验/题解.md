## 题目描述

给定 n 个数，问有多少个数可以表示为另外两个不同数的和。

## 输入格式

第一行：n。
第二行：n 个正整数。

## 输出格式

一个整数，满足条件的数的个数。

## 数据范围

$3 \le n \le 100$，数值不超过 10000

## 样例

### 输入

```
5
1 2 3 4 5
```

### 输出

```
3
```

---

## 解题思路

### 审题过程

1. **理解题意**：n 个数中，有多少个数可以表示为另外两个不同数的和。
2. **关键观察**：对每个数 x，检查是否存在 a+b=x（a≠b，且 a、b 在集合中）。
3. **建模**：先枚举所有两数之和并标记，再检查哪些原数被标记。

### 方法一：枚举 + 标记数组

**第一步**：双循环枚举所有两数之和，用 `mark[a[i]+a[j]] = true` 标记。
**第二步**：遍历原数组，如果 `mark[a[i]]` 为 true，说明 a[i] 可以表示为两个数之和。

```
输入：1 2 3 4 5
枚举和：1+2=3✓, 1+3=4✓, 1+4=5✓, 1+5=6, 2+3=5✓, ...
标记：mark[3]=true, mark[4]=true, mark[5]=true, mark[6]=true, ...
检查：1? mark[1]=false ✗, 2? mark[2]=false ✗, 3? mark[3]=true ✓, 4? ✓, 5? ✓
答案：3
```

## 代码实现

```cpp
#include <iostream>
using namespace std;

int a[105];
bool mark[20001];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; ++i) cin >> a[i];

    for (int i = 0; i < n; ++i)
        for (int j = i + 1; j < n; ++j)
            mark[a[i] + a[j]] = true;

    int ans = 0;
    for (int i = 0; i < n; ++i)
        if (mark[a[i]]) ans++;

    cout << ans << endl;
    return 0;
}
```

## 易错点

1. 布尔数组要开到 20001（10000+10000）
2. 枚举两数之和时 j 从 i+1 开始，避免重复
3. 检查时是看原数组的数是否在标记中

### 核心模式：两数之和
