## 题目描述

输出一个固定的字符画图案，即超级玛丽游戏的经典画面。

## 输入格式

无输入。

## 输出格式

输出若干行字符，组成超级玛丽的图案。

## 数据范围

无。

## 样例

（题目要求原样输出，样例即为完整输出）

---

## 解题思路

### 方法一：直接输出

最基础的顺序结构练习。不需要任何变量或循环，直接用 `cout` 逐行输出即可。

**核心要点**：照着题目给的图案，一行一行用 `cout << "..." << endl;` 输出。

## 代码实现

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "                ********" << endl;
    cout << "               ************" << endl;
    cout << "               ####....#." << endl;
    cout << "             #..###.....##...." << endl;
    cout << "             ###.......######              ###            ###" << endl;
    cout << "                ...........               #...#          #...#" << endl;
    cout << "               ##*#######                 #.#.#          #.#.#" << endl;
    cout << "            ####*******######             #.#.#          #.#.#" << endl;
    cout << "           ...#***.****.*###....          #...#          #...#" << endl;
    cout << "           ....**********##.....           ###            ###" << endl;
    cout << "           ....****    *****...." << endl;
    cout << "             ####        ####" << endl;
    cout << "           ######        ######" << endl;
    cout << "##############################################################" << endl;
    cout << "#...#......#.##...#......#.##...#......#.##------------------#" << endl;
    cout << "###########################################------------------#" << endl;
    cout << "#..#....#....##..#....#....##..#....#....#####################" << endl;
    cout << "##########################################    #----------#" << endl;
    cout << "#.....#......##.....#......##.....#......#    #----------#" << endl;
    cout << "##########################################    #----------#" << endl;
    cout << "#.#..#....#..##.#..#....#..##.#..#....#..#    #----------#" << endl;
    cout << "##########################################    ############" << endl;
    return 0;
}
```

## 易错点

1. 注意空格和特殊字符的位置，一个字符打错就 WA
2. 每行末尾用 `endl` 换行
3. 这道题纯粹考验细心程度，没有算法难度
