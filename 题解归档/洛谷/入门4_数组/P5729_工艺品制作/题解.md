## 题目描述

一个 n×m 的矩形工艺品，经过 q 次挖洞操作（每次挖一个矩形区域），求剩余多少块。

## 输入格式

第一行：n, m, q。
接下来 q 行，每行四个整数 x1, y1, x2, y2（挖洞区域）。

## 输出格式

一个整数，剩余块数。

## 数据范围

$1 \le n, m \le 50$，$0 \le q \le 100$

## 样例

### 输入

```
4 4 1
2 2 3 3
```

### 输出

```
12
```

---

## 解题思路

### 审题过程

1. **理解题意**：n×m 矩形，q 次挖洞（每次挖一个矩形区域），求剩余块数。
2. **关键观察**：挖洞就是把对应区域标记为"已挖"。
3. **建模**：二维数组标记，挖洞区域设为 1，最后统计 0 的个数。

### 方法一：二维数组标记

**核心**：和 P1047 一样是标记思想，只是从一维升级到二维。

## 代码实现

```cpp
#include <iostream>
using namespace std;

int main() {
    int n, m, q;
    cin >> n >> m >> q;

    int grid[55][55] = {0};

    while (q--) {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;

        for (int i = x1; i <= x2; ++i) {
            for (int j = y1; j <= y2; ++j) {
                grid[i][j] = 1;
            }
        }
    }

    int count = 0;
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= m; ++j) {
            if (grid[i][j] == 0) count++;
        }
    }

    cout << count << endl;
    return 0;
}
```

## 易错点

1. 下标从 1 开始
2. 挖洞区域是闭区间
3. 数组要开大一点避免越界
