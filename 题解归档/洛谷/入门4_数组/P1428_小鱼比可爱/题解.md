## 题目描述

输入 n 个整数，对每个数，输出在它之前比它小的数的个数。

## 输入格式

第一行：n。
第二行：n 个整数。

## 输出格式

一行，n 个整数，空格分隔。

## 数据范围

$1 \le n \le 100$，数值范围 0~10

## 样例

### 输入

```
5
1 2 3 4 5
```

### 输出

```
0 1 2 3 4
```

---

## 解题思路

### 审题过程

1. **理解题意**：对每个数，输出在它之前比它小的数的个数。
2. **关键观察**：需要知道"之前有多少个数比当前数小"——这是前缀信息。
3. **建模**：用计数数组 `cnt[x]` 记录数值 x 出现的次数，累加 `cnt[0]~cnt[x-1]` 即可。

### 方法一：计数数组

**核心思想**：不存具体数值，只存每个数值出现的次数。

```
输入：1 2 3 4 5
处理1：cnt[0..0]之和=0，输出0，cnt[1]++
处理2：cnt[0..1]之和=1，输出1，cnt[2]++
处理3：cnt[0..2]之和=2，输出2，cnt[3]++
...
```

**技巧**：`" "[i == n-1]` 利用数组下标，最后一个元素后输出空格（下标为0的字符串），其余输出空格。

## 代码实现

```cpp
#include <iostream>
using namespace std;

int main() {
    int n, x;
    int cnt[11] = {0};
    cin >> n;

    for (int i = 0; i < n; ++i) {
        cin >> x;
        int less = 0;
        for (int v = 0; v < x; ++v)
            less += cnt[v];

        cout << less << " "[i == n-1];
        ++cnt[x];
    }
    return 0;
}
```

## 易错点

1. `" "[i == n-1]` 是技巧：最后一个元素后不加空格
2. 计数数组要在读入当前数之后再更新
3. 数值范围 0~10，数组开到 11

## 总结发散

### 核心模式：前缀信息统计

本题的 `cnt` 数组记录的是"到当前为止，每个值出现了多少次"。累加 `cnt[0..x-1]` 就是"比 x 小的数有多少个"——这就是**前缀和**的思想雏形。

### 进阶方向

- **树状数组**：如果数值范围很大，可以用树状数组高效维护前缀和
- **归并排序求逆序对**：如果问"比它大的数有多少个"，就是逆序对问题
