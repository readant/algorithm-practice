## 题目描述

### 问题描述

我有一个长度为 $l$ 的字符串，最开始时，这个字符串由 $l$ 个句号（`.`）组成。

我在这个字符串中，将多次把 `boy` 或者 `girl` 两单词，依次贴到这个字符串中。

后贴上单词，会覆盖之前贴上的单词，或者覆盖句号。最终，每个单词至少有一个字符没有被覆盖。

请问，一共贴有几个 `boy` 几个 `girl`？

### 输入格式

一行被反复贴有 `boy` 和 `girl` 两单词的字符串。

### 输出格式

两行，两个整数。第一行为 `boy` 的个数，第二行为 `girl` 的个数。

### 数据范围

$3 \le l \le 255$，字符串仅仅包含如下字符：`.bgilory`。

### 样例

#### 输入 #1

```
......boyogirlyy......girl.......
```

#### 输出 #1

```
4
2
```

## 解题思路

### 审题过程

- 初始字符串全是句号 `.`，然后不断往上贴单词 `boy` 或 `girl`，每次覆盖原位置的部分字符。
- 最终每个被贴过的单词，**至少有一个字符没有被后续覆盖**，因此最终字符串中，属于该单词的某个字母会保留下来。
- 我们需要根据最终字符串，反推出共贴了多少个 `boy` 和多少个 `girl`。
- 注意：同一个单词可能残留多个字符（例如 `boy` 的 `b` 和 `o` 都没被覆盖），不能简单数每个字母出现次数。

### 主解法选择说明

本题属于字符串模拟题，教科书级解法是**标记起始位置**：扫描最终字符串，遇到某个单词的残留字符时，根据该字符在单词中的偏移量推算出该单词的起始位置，然后用标记数组记录这个起始位置是否已被统计过。这种方法比标记整个区间更精准，不会因区间重叠而误判，且代码逻辑清晰，非常适合初学者建立“反推起点”的思维。

### 主解法核心思路

我们维护一个标记数组 `mark`，`mark[pos] = true` 表示起始位置 `pos` 已经被某个单词统计过。从左到右扫描字符串：

- 如果当前位置是 `'b'`，说明某个 `boy` 的起始位置就是 `i`；如果是 `'o'`，起始位置是 `i-1`；如果是 `'y'`，起始位置是 `i-2`。  
  对于 `girl` 同理：`'g'` → `i`，`'i'` → `i-1`，`'r'` → `i-2`，`'l'` → `i-3`。

- 当我们计算出起始位置 `start` 后，首先检查 `start` 是否合法（即能容纳整个单词，不越界），然后检查 `mark[start]` 是否为 `false`。如果都满足，说明这是一个新单词，计数加 1，并将 `mark[start]` 设为 `true`。

- 因为同一个单词的各个残留字符计算出的 `start` 都相同，所以即使该单词残留多个字母，也只会计数一次；而不同单词的起始位置必然不同（因为占据不同区间），所以不会互相干扰。

### 其他解法思路

本题解法较为固定，主要就是上述标记起始位置法。统计每个字母出现次数的方法不可行，因为一个单词可能残留多个字符导致重复统计。

### 主解法伪代码设计

```
输入字符串 s，长度 n
创建布尔标记数组 mark，大小 n，初始 false
boy = 0, girl = 0

for i = 0 to n-1:
    // 处理 boy
    start = -1
    if s[i] == 'b': start = i
    else if s[i] == 'o': start = i - 1
    else if s[i] == 'y': start = i - 2

    if start >= 0 且 start + 2 < n 且 mark[start] == false:
        boy = boy + 1
        mark[start] = true

    // 处理 girl
    start = -1
    if s[i] == 'g': start = i
    else if s[i] == 'i': start = i - 1
    else if s[i] == 'r': start = i - 2
    else if s[i] == 'l': start = i - 3

    if start >= 0 且 start + 3 < n 且 mark[start] == false:
        girl = girl + 1
        mark[start] = true

输出 boy 和 girl
```

## 代码实现

### 主解法逐步讲解（带注释版本）

```cpp
#include <iostream>   // 提供 cin, cout
#include <string>     // 提供 string 类型
#include <vector>     // 提供 vector 容器

using namespace std;  // 使用标准命名空间

int main() {
    // 关闭 C 与 C++ 的输入输出同步，提高 cin/cout 速度
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;          // 输入一行字符串，不含空格，直接使用 cin

    int n = (int)s.size();
    // mark[i] = true 表示起始位置 i 已经被某个单词占用
    vector<char> mark(n, 0);   // 初始全为 false

    int boy = 0, girl = 0;

    for (int i = 0; i < n; ++i) {
        // ---------- 处理 boy ----------
        int start = -1;   // 初始为非法值
        if (s[i] == 'b') {
            start = i;            // 'b' 是 boy 的第一个字符
        } else if (s[i] == 'o') {
            start = i - 1;        // 'o' 是第二个字符，起点在前一位
        } else if (s[i] == 'y') {
            start = i - 2;        // 'y' 是第三个字符，起点在前两位
        }

        // 检查起始位置是否合法，且该起始位置未被统计过
        if (start >= 0 && start + 2 < n && !mark[start]) {
            boy++;
            mark[start] = 1;      // 标记该起始位置已被占用
        }

        // ---------- 处理 girl ----------
        start = -1;
        if (s[i] == 'g') {
            start = i;
        } else if (s[i] == 'i') {
            start = i - 1;
        } else if (s[i] == 'r') {
            start = i - 2;
        } else if (s[i] == 'l') {
            start = i - 3;
        }

        if (start >= 0 && start + 3 < n && !mark[start]) {
            girl++;
            mark[start] = 1;
        }
    }

    // 使用 '\n' 而不是 endl，避免强制刷新缓冲区，提高效率
    cout << boy << '\n' << girl << '\n';
    return 0;
}
```

**逐步解释**：

1. **头文件选择**：  
   - `<iostream>`：提供 `cin`、`cout` 等输入输出对象。  
   - `<string>`：提供 `string` 类型，方便存储和遍历字符串。  
   - `<vector>`：提供动态数组 `vector`，我们用它来创建标记数组。  
   - `using namespace std;`：允许直接使用标准库中的名称，简化代码。在大型项目中可能引起命名冲突，但竞赛中使用是安全的。

2. **输入输出加速**：  
   `ios::sync_with_stdio(false);` 和 `cin.tie(nullptr);` 取消 C 和 C++ 的输入输出同步，并解除 `cin` 与 `cout` 的绑定，能显著提高大量数据读写的速度。本题数据量小，但习惯上加上无害。

3. **标记数组 `vector<char>`**：  
   我们使用 `vector<char>` 而不是 `vector<bool>`，因为 `vector<bool>` 是特化版本，其元素访问返回代理对象，可能导致取地址失败或赋值异常。`vector<char>` 行为与普通数组完全一致，且内存开销极小（长度最大 255，仅几百字节），更加安全直观。

4. **边界检查**：  
   在计算出起始位置 `start` 后，必须检查 `start >= 0` 且 `start + 单词长度 - 1 < n`，确保整个单词能放在字符串内。这是防止数组越界的关键。

5. **计数逻辑**：  
   扫描每个位置，如果当前字符属于 `boy` 或 `girl`，根据偏移量反推起始位置。只要该位置合法且未被标记，就认为存在一个单词，计数并标记。这样每个单词只会被统计一次，即使它的多个字符残留，也会得到相同的 `start`，因而第二次遇到时因 `mark[start]` 为 `true` 而跳过。

6. **输出换行**：  
   使用 `'\n'` 而非 `endl`，因为 `endl` 会强制刷新输出缓冲区，降低性能；`'\n'` 仅换行，效率更高。

### 其他解法实现

本题主解法已覆盖全部情况，无其他典型实现。

### 解法对比总结

| 方法 | 时间复杂度 | 空间复杂度 | 代码复杂度 | 适用场景 |
| ------ | ------------ | ------------ | ------------ | ---------- |
| 标记起始位置（主解法） | O(n) | O(n) | 低 | 覆盖还原类问题，通用性强 |
| 标记整个区间（易错） | O(n) | O(n) | 中 | 可能导致误判，不推荐 |

**推荐建议**：  
初学者建议掌握主解法（标记起始位置），因为它从“起点”角度去重，逻辑严密且易于理解，是解决覆盖类问题的通用模式。

## 易错点

- **数组越界**：反推起始位置时，必须检查 `start` 是否合法（`>=0`）以及 `start + len - 1 < n`。例如处理 `'o'` 时 `start = i-1`，若 `i==0`，则 `start` 为负数，若不检查直接访问 `mark[start]` 会越界。**正确做法**：每次使用前都进行边界判断。

- **重复统计**：如果不使用标记数组，可能会把同一个单词的多个残留字符都计数。例如 `"boy"` 残留了 `b` 和 `o`，分别遇到时若都 `boy++` 就会得到 2 次，而正确答案是 1 次。**正确做法**：统计后立即标记起始位置，后续残留字符因标记而跳过。

- **`vector<char>` vs `vector<bool>`**：初学者容易用 `vector<bool>` 做标记，但它的 `operator[]` 返回代理对象，可能导致无法按预期赋值或取地址。**正确做法**：优先使用 `vector<char>`，行为和普通数组完全一致。

- **字符判断顺序**：`boy` 和 `girl` 的字符集不重叠（`b,o,y` 与 `g,i,r,l` 互斥），所以可以分别处理，不会互相干扰。

- **未初始化变量**：`boy` 和 `girl` 必须显式初始化为 0，否则局部变量的初值是随机的。

## 总结发散

### 核心模式

标记起始位置 + 反推偏移量：利用每个字符在单词中的固定位置，反推出单词起点，并用标记数组确保每个单词只统计一次。

### 延伸/推导

本题是“区间覆盖”问题的逆向应用。更一般地，若有多个不同单词（长度不同、字符可能重叠），我们依然可以用类似方法：为每个字符记录其可能属于的单词及偏移，再结合标记起始位置来去重。若单词字符集有重叠（例如 `boy` 和 `yo` 共享 `o`），则需要更复杂的处理，但本题字符集完全分离，使解法保持简洁。
