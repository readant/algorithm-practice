## 题目描述

**问题描述**  
众所周知，在每一个彗星后都有一只 UFO。这些 UFO 时常来收集地球上的忠诚支持者。不幸的是，他们的飞碟每次出行都只能带上一组支持者。因此，他们要用一种聪明的方案让这些小组提前知道谁会被彗星带走。他们为每个彗星起了一个名字，通过这些名字来决定这个小组是不是被带走的那个特定的小组（你认为是谁给这些彗星取的名字呢？）。关于如何搭配的细节会在下面告诉你；你的任务是写一个程序，通过小组名和彗星名来决定这个小组是否能被那颗彗星后面的 UFO 带走。

小组名和彗星名都以下列方式转换成一个数字：最终的数字就是名字中所有字母的积，其中 `A` 是 `1`，`Z` 是 `26`。例如，`USACO` 小组就是 `21 × 19 × 1 × 3 × 15 = 17955`。如果小组的数字 `mod 47` 等于彗星的数字 `mod 47`，你就得告诉这个小组需要准备好被带走！（记住“`a mod b`”是 `a` 除以 `b` 的余数，例如 `34 mod 10` 等于 `4`）

写出一个程序，读入彗星名和小组名并算出用上面的方案能否将两个名字搭配起来，如果能搭配，就输出 `GO`，否则输出 `STAY`。小组名和彗星名均是没有空格或标点的一串大写字母（不超过 `6` 个字母）。

**输入格式**  
第 1 行：一个长度为 `1` 到 `6` 的大写字母串，表示彗星的名字。  
第 2 行：一个长度为 `1` 到 `6` 的大写字母串，表示队伍的名字。

**输出格式**  
一行内输出 `GO` 或 `STAY`。

**数据范围**  

- 字符串长度：`1 ≤ len ≤ 6`，仅含大写字母 `A~Z`。

**样例**

输入 #1  

```
COMETQ
HVNGAT
```

输出 #1  

```
GO
```

输入 #2  

```
ABSTAR
USACO
```

输出 #2  

```
STAY
```

## 解题思路

### 审题过程

- 题目给了两个字符串（彗星名和小组名），长度均不超过 6，全为大写字母。
- 需要分别把每个字符串“翻译”成一个数字：每个字母对应 `1~26`，所有字母对应的数字相乘。
- 如果两个乘积分别对 `47` 取模后相等，则输出 `GO`，否则输出 `STAY`。
- 这是一个**纯粹的模拟题**，只需按照规则一步步计算即可。

### 主解法选择说明

本题是 USACO 入门题，**没有多种算法**，唯一的做法就是遍历字符串、累乘并取模。选择最直接、最易理解的“顺序遍历 + 边乘边取模”作为主解法，这也是教科书级的标准实现方式。

### 主解法核心思路

1. 读入两个字符串 `comet` 和 `group`。
2. 编写一个辅助函数 `getNumber(s)`，它接受一个字符串，返回该字符串的“编号”：
   - 初始化结果 `res = 1`（因为要连乘）。
   - 遍历字符串的每个字符 `ch`：
     - 将字母转成数字：`ch - 'A' + 1`（因为 `A` 对应 `1`）。
     - 将 `res` 乘以该数字，并对 `47` 取模，避免中间结果过大。
   - 返回最终的 `res`。
3. 比较 `getNumber(comet)` 和 `getNumber(group)` 是否相等，相等输出 `GO`，否则输出 `STAY`。

> 为什么要边乘边取模？  
> 即使只有 6 个字母，最大乘积 `26^6 = 308,915,776`，仍在 `int` 范围内，但为了养成好习惯（应对更长的字符串），我们每一步都对 `47` 取模。由于 `(a × b) % mod = ((a % mod) × (b % mod)) % mod`，这样做不会改变最终余数。

### 其他解法思路

本题解法固定，无其他常见算法思路。以下只介绍主解法的完整实现。

### 主解法伪代码设计

```
函数 calc(字符串 s):
    res = 1
    mod = 47
    对于 s 中的每个字符 ch:
        num = ch - 'A' + 1   // 将字母转为 1~26
        res = (res * num) % mod
    返回 res

主程序:
    读入 comet, group
    如果 calc(comet) == calc(group):
        输出 "GO"
    否则:
        输出 "STAY"
```

## 代码实现

### 主解法逐步讲解（带注释版本）

```cpp
#include <iostream>   // 提供 cin, cout 等输入输出功能
#include <string>     // 提供 string 类型，用于存储字符串

using namespace std;  // 允许直接使用标准库中的名称（如 cin、cout、string）

// 定义常量，表示取模的除数
const int MOD = 47;

// 函数：计算一个字符串的“编号”
// 参数：const string& s 表示传入的字符串（引用传递，避免拷贝，const 表示不修改）
// 返回值：int 类型，为 s 的字母乘积对 MOD 取模后的结果
int calc(const string& s) {
    int res = 1;  // 乘积的初始值设为 1（因为要连乘）
    // 使用范围 for 循环遍历字符串中的每个字符，简洁且安全
    for (char ch : s) {
        // 将字符转换为数字：'A'->1, 'B'->2, ..., 'Z'->26
        int num = ch - 'A' + 1;
        // 累乘并取模，保证 res 始终小于 MOD
        res = (res * num) % MOD;
    }
    return res;
}

int main() {
    // 加速输入输出，取消 C 和 C++ 的输入输出同步，让 cin/cout 更快
    ios::sync_with_stdio(false);
    // 解除 cin 和 cout 的绑定，避免不必要的刷新，进一步提高效率
    cin.tie(nullptr);

    string comet, group;  // 定义两个 string 变量存放彗星名和小组名

    // 读取两行字符串（由于题目保证不含空格，直接使用 cin >> 即可）
    cin >> comet >> group;

    // 分别计算两个字符串的编号
    int numComet = calc(comet);
    int numGroup = calc(group);

    // 根据比较结果输出对应单词，并换行（使用 '\n' 而非 endl，避免强制刷新缓冲区）
    if (numComet == numGroup) {
        cout << "GO\n";
    } else {
        cout << "STAY\n";
    }

    return 0;  // 程序正常结束
}
```

**逐步解释**：

1. **头文件**  
   - `<iostream>`：提供了 `cin`、`cout` 等输入输出流对象，是几乎每个 C++ 程序必备的“工具箱”。  
   - `<string>`：提供了 `string` 类型，它比 C 风格的字符数组更安全、更方便，支持直接赋值、比较、遍历等操作。

2. **`using namespace std;`**  
   - 作用：让我们写 `cin`、`cout`、`string` 时不必加 `std::` 前缀。  
   - 风险：在大型项目中可能导致命名冲突，但本题规模小，使用无妨。通俗来说，这相当于“打开标准库命名空间，里面的工具可以直接叫名字”。

3. **常量 `MOD`**  
   - 定义为 `const int`，表示在程序运行过程中不会改变。使用常量比直接写数字 `47` 更清晰，也便于修改。

4. **函数 `calc`**  
   - 参数 `const string& s`：  
     - `&` 表示**引用传递**，避免复制整个字符串，节省时间和内存。  
     - `const` 表示函数内部不会修改 `s`，这是良好的编程习惯。  
   - 返回值 `int`：计算出的编号，范围永远是 `0~46`。  
   - 范围 for 循环 `for (char ch : s)` 是 C++11 引入的写法，会自动遍历字符串中的每个字符，比传统下标循环更简洁、更安全（不会越界）。

5. **`main` 函数中的优化**  
   - `ios::sync_with_stdio(false);`：关闭 C 和 C++ 输入输出流的同步，让 `cin`/`cout` 速度接近 `scanf`/`printf`。  
   - `cin.tie(nullptr);`：解除 `cin` 与 `cout` 的绑定，避免每次 `cin` 前自动刷新 `cout`，提高效率。  
   - 这两行是竞赛中常用的“加速黑科技”，初学者可以记住这个固定写法。

6. **输入读取**  
   - 由于字符串不含空格或标点，直接用 `cin >>` 读取即可，不需要处理 `getline` 的缓冲区问题。

7. **输出换行**  
   - 使用 `'\n'` 而不是 `endl`，因为 `endl` 会强制刷新输出缓冲区，可能降低性能；而 `'\n'` 仅换行，更高效。

8. **数据类型选择**  
   - 用 `int` 足够：中间结果每次都取模，不会超过 `47`。即便不取模，最大乘积约 `3.09×10^8`，也在 `int`（约 `2.1×10^9`）范围内，所以本题用 `int` 完全安全。

## 易错点

- **字母转数字时搞错偏移量**  
  - 错误：`ch - 'A'` 得到 `0~25`，但题目要求 `A=1`，所以必须 `+1`。  
  - 正确：`ch - 'A' + 1`。

- **乘积未及时取模，可能导致溢出**  
  - 虽然本题最大乘积不会溢出 `int`，但如果题目改成更长的字符串，就可能溢出。  
  - 正确做法：每次乘后都 `% MOD`，利用取模性质保证结果正确且不溢出。

- **忘记初始化 `res = 1`**  
  - 如果初始化为 `0`，乘积永远为 `0`，答案错误。  
  - 因为乘法需要从 `1` 开始累乘。

- **输出大小写错误**  
  - 题目要求输出 `GO` 或 `STAY`，均为大写，不能写成 `go` 或 `Go`。

- **比较的是取模后的值**  
  - 不是直接比较乘积，而是比较乘积 `% 47` 的结果。

## 总结发散

### 核心模式  

“字符串遍历 + 字母映射 + 边乘边取模” — 典型的“模拟题”套路，即按照题目描述的规则一步步实现。

### 延伸/推导  

取模运算具有分配律：`(a × b) % mod = ((a % mod) × (b % mod)) % mod`。  
本题每次乘法后都取模，保证了中间结果永远小于 `47`，无论字符串多长都不会溢出。这种技巧在需要计算大整数乘积或幂的余数时非常常用，例如快速幂、哈希等场景。
