## 题目描述

笨小猴的词汇量很小，所以每次做英语选择题的时候都很头疼。但是他找到了一种方法，经试验证明，用这种方法去选择选项的时候选对的几率非常大！

这种方法的具体描述如下：假设 `maxn` 是单词中出现次数最多的字母的出现次数，`minn` 是单词中出现次数最少的字母的出现次数，如果 `maxn - minn` 是一个质数，那么笨小猴就认为这是个 Lucky Word，这样的单词很可能就是正确的答案。

### 输入格式

一个单词，其中只可能出现小写字母，并且长度小于 `100`。

### 输出格式

共两行，第一行是一个字符串，假设输入的单词是 Lucky Word，那么输出 `Lucky Word`，否则输出 `No Answer`；

第二行是一个整数，如果输入的单词是 Lucky Word，输出 `maxn - minn` 的值，否则输出 `0`。

### 输入输出样例 #1

#### 输入 #1

```
error
```

#### 输出 #1

```
Lucky Word
2
```

### 输入输出样例 #2

#### 输入 #2

```
olympic
```

#### 输出 #2

```
No Answer
0
```

### 说明/提示

【输入输出样例 1 解释】

单词 `error` 中出现最多的字母 `r` 出现了 `3` 次，出现次数最少的字母出现了 `1` 次，`3-1=2`，`2` 是质数。

【输入输出样例 2 解释】

单词 `olympic` 中出现最多的字母 `i` 出现了 `1` 次，出现次数最少的字母出现了 `1` 次，`1-1=0`，`0` 不是质数。

## 解题思路

### 审题过程

- 输入一个只含小写字母的单词（长度 < 100）。
- 需要统计每个字母出现的次数。
- 找出出现次数最多（`maxn`）和最少的字母（`minn`），但注意：`minn` 只考虑**出现过**的字母，未出现的字母不计入。
- 计算 `ans = maxn - minn`。
- 判断 `ans` 是否为质数。
- 若是质数，输出 `Lucky Word` 和 `ans`；否则输出 `No Answer` 和 `0`。

### 主解法选择说明

本题的核心就是**字母频次统计**与**质数判断**。最教科书、最适合初学者的做法是用一个长度为 26 的数组进行“桶计数”，然后直接遍历数组找出最大最小值，最后用质数判断函数得出结果。该方法代码直观、思维清晰，且对于本题数据规模完全足够。

### 主解法核心思路

1. **桶计数**：因为只含小写字母，所以可以开一个大小为 26 的整型数组 `cnt`，下标 `0` 对应 `'a'`，下标 `25` 对应 `'z'`。遍历单词的每个字符，利用 `字符 - 'a'` 得到下标，然后将对应计数器加 1。
2. **找最大最小值**：遍历 `cnt` 数组，但只考虑值大于 0 的位置（即出现过该字母），不断更新最大值和最小值。
3. **质数判断**：写一个函数，对差值 `ans` 进行判断。注意处理 `ans < 2` 的情况（0 和 1 都不是质数），以及枚举因子时只需检查到 `√ans`。
4. **输出**：根据质数判断结果按要求输出。

> 以样例 `error` 为例：  
> 统计得 `e:1, r:3, o:1`，`maxn=3`，`minn=1`，差为 `2`，质数，输出 `Lucky Word` 和 `2`。

### 其他解法思路

本题解法较为固定，以下主要介绍最优解。  
也可以先用排序方法：将频次数组中非零值收集到一个 `vector` 中，排序后取首尾元素作为最小最大值，但这样多了一次排序，时间复杂度稍高（O(26 log 26)），而直接遍历是 O(26)，所以直接遍历更优。因此不做展开。

### 主解法伪代码设计

```
输入单词 s
定义数组 cnt[26] = {0}

对于 s 中的每个字符 ch:
    cnt[ch - 'a']++

maxn = 0
minn = 一个很大的数（如 1000）

对于 i 从 0 到 25:
    如果 cnt[i] > 0:
        如果 cnt[i] > maxn: maxn = cnt[i]
        如果 cnt[i] < minn: minn = cnt[i]

ans = maxn - minn

定义函数 isPrime(x):
    如果 x < 2: 返回 false
    如果 x == 2: 返回 true
    如果 x 是偶数: 返回 false
    对于 i 从 3 到 i*i <= x，步长 2:
        如果 x % i == 0: 返回 false
    返回 true

如果 isPrime(ans):
    输出 "Lucky Word"
    输出 ans
否则:
    输出 "No Answer"
    输出 0
```

## 代码实现

### 主解法逐步讲解（带注释版本）

```cpp
#include <iostream>   // 提供 cin, cout
#include <string>     // 提供 string 类型
#include <cmath>      // 提供 sqrt() 函数（可选，这里用 i*i 代替）
using namespace std;  // 允许直接使用 std 命名空间中的标识符

// 质数判断函数
bool isPrimeNumber(int x) {
    // 小于2的数都不是质数
    if (x < 2) return false;
    // 2 是质数
    if (x == 2) return true;
    // 偶数（大于2）不是质数
    if (x % 2 == 0) return false;
    // 从3开始检查奇数因子，只需要检查到 sqrt(x)
    for (int i = 3; i * i <= x; i += 2) {
        if (x % i == 0) {
            return false;  // 找到因子，不是质数
        }
    }
    return true;  // 没有找到因子，是质数
}

int main() {
    // 加速输入输出（关闭 C 和 C++ 流同步，提高效率）
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string word;
    cin >> word;  // 读入单词，没有空格，所以直接用 cin

    // 第1步：统计每个字母出现次数
    // 使用大小为26的数组，下标0~25对应 'a'~'z'
    // 初始化所有元素为0（在栈上分配，必须显式初始化）
    int cnt[26] = {0};

    // 遍历单词的每个字符
    for (char ch : word) {
        // 计算下标：'a'->0, 'b'->1, ... 'z'->25
        int idx = ch - 'a';
        cnt[idx]++;  // 对应字母出现次数加1
    }

    // 第2步：找出出现过的字母中的最大次数和最小次数
    // minn 初始化为一个很大的数（因为单词长度<100，所以100足够大）
    int maxn = 0;
    int minn = 100;

    for (int i = 0; i < 26; ++i) {
        if (cnt[i] == 0) {
            continue;  // 该字母没出现，跳过
        }
        if (cnt[i] > maxn) {
            maxn = cnt[i];
        }
        if (cnt[i] < minn) {
            minn = cnt[i];
        }
    }

    // 第3步：计算差值
    int ans = maxn - minn;

    // 第4步：判断差值是否为质数并输出
    if (isPrimeNumber(ans)) {
        cout << "Lucky Word\n";   // 使用 '\n' 而非 endl，避免刷新缓冲区
        cout << ans << '\n';
    } else {
        cout << "No Answer\n";
        cout << 0 << '\n';
    }

    return 0;
}
```

**逐步解释**：

- **第1步（头文件引入）**：  
  - `<iostream>`：提供 `cin`、`cout` 等输入输出对象，用于从键盘读入数据并输出结果。  
  - `<string>`：提供 `string` 类型，方便存储和遍历单词。  
  - `<cmath>`：本来可以用于 `sqrt()`，但我们在循环中直接用 `i * i <= x` 判断，避免了浮点数精度问题，因此本代码其实不需要 `<cmath>`，但为了教学完整性，可以保留它，不过实际上可以去掉。这里保留是便于说明，但实际编译时若未用到 `sqrt`，可以省略。为了规范，我们移除它，因为未使用。  
  - `using namespace std;`：让我们可以直接写 `cin`、`cout`、`string` 而不必加 `std::` 前缀。对于初学者简化代码，但要注意可能引起命名冲突（竞赛中通常可以接受）。

- **第2步（主函数中的加速语句）**：  
  `ios::sync_with_stdio(false);` 和 `cin.tie(nullptr);` 用于加速 `cin`/`cout`，使它们接近 `scanf`/`printf` 的速度，适合竞赛场景。

- **第3步（数据存储与统计）**：  
  使用 `int cnt[26] = {0};` 创建数组并全部初始化为 0。因为数组在栈上分配，若不初始化，内容将是随机值，可能导致统计错误。  
  使用范围 for 循环 `for (char ch : word)` 遍历字符串的每个字符，简洁安全。

- **第4步（找最大最小值）**：  
  遍历 `cnt` 数组，只对非零值进行处理。`minn` 初值设为 100（单词长度<100，所以任何一个出现过的字母次数都不会超过100，这样初始化是安全的）。  
  也可以用 `INT_MAX`（需要 `<climits>`），但这里用 100 更直观。

- **第5步（质数判断函数）**：  
  - 函数返回 `bool` 类型，使用 `true`/`false` 表示是否为质数。  
  - 先处理边界情况（`x<2`，`x==2`）。  
  - 再排除偶数（除 2 外），减少一半循环次数。  
  - 循环从 3 开始，只检查奇数因子，条件 `i * i <= x` 相当于 `i <= sqrt(x)`，用乘法避免了浮点数精度问题。  
  - 如果找到因子则不是质数，循环结束仍无因子则为质数。

- **第6步（输出）**：  
  使用 `'\n'` 而不是 `endl`，因为 `endl` 会强制刷新输出缓冲区，效率较低，竞赛中通常用 `'\n'` 即可。

**头文件逐个说明**：

- `<iostream>`：输入输出流，必备。
- `<string>`：字符串类，提供 `string` 类型和相关操作（如 `size()`、`operator[]` 等），用于存储单词。
- （未使用 `<cmath>`，因此不包含）  
  本代码仅使用基础语法，未使用特殊STL容器或算法，因此头文件很简单。

**数据类型选择**：

- 字母出现次数最多不超过 100，因此用 `int` 完全足够。  
- 差值 `ans` 也在 `[-99, 99]` 范围内，`int` 足够。  
- 未使用浮点数，无需考虑 `double`/`float`。

**输入陷阱专项提醒**：  
本题只输入一个单词，不包含空格，直接用 `cin >> word` 即可，无需处理 `getline` 和缓冲区问题。因此代码中不包含 `cin.ignore()`。

## 易错点

- **未考虑未出现的字母**：统计 `minn` 时，若将未出现的字母（计数为0）也算进去，那么 `minn` 始终为0，导致结果错误。**正确做法**：遍历时跳过 `cnt[i] == 0` 的项。
- **质数判断边界错误**：很多同学会忘记判断 `x < 2`，导致输入 0 或 1 时误判为质数。**正确做法**：函数开头先判断 `if (x < 2) return false;`。
- **循环因子范围错误**：若循环写成 `for (int i = 2; i < x; ++i)`，对于较大的 `x` 会超时（虽然本题范围很小，但习惯不好）。**正确做法**：只需检查到 `sqrt(x)`，即 `i * i <= x`。
- **数组越界**：如果使用 `cnt[200]` 并用 ASCII 码直接作为下标（如 `cnt[j]++` 中 `j` 为 97），虽然不会立即越界（ASCII 码在 97~122 之间，小于 200），但这是不规范的，容易出错。**正确做法**：使用下标映射 `ch - 'a'`，数组大小固定为26。
- **变量未初始化**：局部数组若不初始化，元素值为随机垃圾值，统计前必须清零。**正确做法**：使用 `int cnt[26] = {0};`。
- **输出格式不符**：题目要求输出两行，第一行是字符串，第二行是整数。注意换行，不要多输出空格。

## 总结发散

### 核心模式

**桶计数 + 数学判定**：用数组作为“桶”统计频次，再对结果进行质数判定。

### 延伸/推导

- 若题目改为统计大写字母或数字，只需调整数组大小和映射方式（如大写字母用 `ch - 'A'`，数字用 `ch - '0'`）。
- 若单词长度非常大（如 10^5 或更多），桶计数依然高效（O(n)），但质数判定中的平方根优化依然适用。
- 质数判定还可以用更快的 Miller-Rabin 算法，但本题数据量小，基础方法足够。
