## 题目描述

凯凯刚写了一篇美妙的作文，请问这篇作文的标题中有多少个字符？

注意：标题中可能包含大、小写英文字母、数字字符、空格和换行符。统计标题字符数时，空格和换行符不计算在内。

## 输入格式

输入文件只有一行，一个字符串 $s$。

## 输出格式

输出文件只有一行，包含一个整数，即作文标题的字符数（不含空格和换行符）。

## 数据范围

$1 \leq |s| \leq 5$（注意：题目描述中数据范围标注有误，实际 $|s|$ 可达 $255$）

## 样例

### 样例 1

输入：

```
234
```

输出：

```
3
```

### 样例 2

输入：

```
Ca 45
```

输出：

```
4
```

## 解题思路

### 审题过程

1. **理解题意**：给定一行字符串，统计其中**非空格字符**的个数。
2. **关键观察**：输入包含空格，不能用 `cin >> s` 读取（`cin >>` 遇到空格会截断），必须用 `getline` 读取整行。
3. **建模**：遍历字符串，跳过空格，累加其他字符。

### 核心思路

**直接遍历法**：读取整行 → 逐字符检查 → 不是空格就计数。

```
输入: "Ca 45"
遍历: C → 非空格, cnt=1
      a → 非空格, cnt=2
      ' ' → 空格, 跳过
      4 → 非空格, cnt=3
      5 → 非空格, cnt=4
输出: 4
```

## 代码实现

### 逐步讲解

先把最简单的完整代码列出来，然后逐行解释：

```cpp
#include <iostream>   // 输入输出库
#include <string>     // 字符串库
using namespace std;

int main() {
    string s;
    getline(cin, s);           // 第1步：读入一整行

    int cnt = 0;               // 第2步：计数器，初始为0
    for (int i = 0; i < s.size(); i++) {  // 第3步：循环每个字符
        if (s[i] != ' ') {     // 第4步：如果不是空格
            cnt++;             // 第5步：计数器+1
        }
    }

    cout << cnt;               // 第6步：输出结果
    return 0;
}
```

#### 第1步：为什么用 `getline` 而不是 `cin >>`？

```cpp
// 输入: "Ca 45"（注意 C 和 a 之间没有空格，a 和 4 之间有一个空格）

// 如果用 cin >> s：
cin >> s;    // s = "Ca"  ← 遇到空格就停了！后面的 45 丢了

// 用 getline：
getline(cin, s);  // s = "Ca 45"  ← 读完整整一行，包含空格
```

**记住**：输入可能有空格，必须用 `getline` 读整行。

#### 第2步：`cnt` 是什么？

`cnt` 是 count（计数）的缩写，用来记录"到现在为止找到了几个非空格字符"。

```cpp
int cnt = 0;   // 开始时一个都没找到，所以是 0
```

#### 第3步：for 循环怎么跑的？

以输入 `"Ca 45"` 为例，`s.size()` 是 5（字符串有 5 个字符）。

```
s[0] = 'C'    // 第一个字符
s[1] = 'a'    // 第二个字符
s[2] = ' '    // 第三个字符（空格！）
s[3] = '4'    // 第四个字符
s[4] = '5'    // 第五个字符
```

for 循环 `for (int i = 0; i < s.size(); i++)` 做的事情：

```
i=0: s[0]='C' → 不是空格 → cnt=1
i=1: s[1]='a' → 不是空格 → cnt=2
i=2: s[2]=' ' → 是空格 → 不动，cnt 还是 2
i=3: s[3]='4' → 不是空格 → cnt=3
i=4: s[4]='5' → 不是空格 → cnt=4
循环结束，i=5 时 5<5 不成立，退出循环
```

#### 第4步：`s[i]` 是什么意思？

`s[i]` 就是"取字符串 s 的第 i 个字符"，下标从 0 开始：

```
下标:   0   1   2   3   4
字符:   C   a   空格  4   5
```

#### 第5步：`cnt++` 是什么？

`cnt++` 就是 `cnt = cnt + 1`，把计数器加 1。

---

### C++ — 三种 for 循环写法

上面是最基础的写法。下面展示三种不同风格，效果完全一样：

#### 写法一：下标遍历（最基础，上面已经讲过）

```cpp
int cnt = 0;
for (int i = 0; i < s.size(); i++) {
    if (s[i] != ' ') {
        cnt++;
    }
}
```

- `int i = 0`：从下标 0 开始
- `i < s.size()`：只要 i 还没超过字符串长度就继续
- `i++`：每次循环 i 加 1
- `s[i]`：取第 i 个字符

#### 写法二：范围 for 循环（C++11，推荐）

```cpp
int cnt = 0;
for (char c : s) {
    if (c != ' ') {
        cnt++;
    }
}
```

**和写法一的区别**：不需要自己管理下标 `i`，`c` 会自动依次变成 `s` 里的每个字符。

```
第1轮: c = 'C'
第2轮: c = 'a'
第3轮: c = ' '
第4轮: c = '4'
第5轮: c = '5'
```

写法二比写法一少写了 `int i = 0; i < s.size(); i++` 这些模板代码，更简洁。

#### 写法三：STL 算法（进阶，了解即可）

```cpp
int cnt = count_if(s.begin(), s.end(), [](char c) {
    return c != ' ';
});
```

`count_if` 是 C++ 标准库提供的函数，意思是"统计满足条件的元素个数"：

- `s.begin()`：字符串的起始位置
- `s.end()`：字符串的结束位置
- `[](char c) { return c != ' '; }`：判断条件，"c 不是空格就返回 true"

等价于上面两种写法，只是把循环封装成了一个函数调用。

### Python 实现

```python
s = input()
cnt = sum(1 for c in s if c != ' ')
print(cnt)
```

- `input()` 读入一整行
- `for c in s` 遍历每个字符
- `if c != ' '` 只保留非空格的
- `sum(1 ...)` 数一数有多少个

## 易错点

### 1. `cin >>` vs `getline` —— 最容易犯的错

```
输入: "Hello World"

cin >> s;        // s = "Hello"     ← 错！空格后面的 World 丢了
getline(cin, s); // s = "Hello World"  ← 对！完整读入
```

题目要求输入可能包含空格，所以**必须用 `getline`**。

### 2. 空格字符 `' '` 不要漏掉

比较时用的是**单引号** `' '`（字符），不是双引号 `" "`（字符串）：

```cpp
if (s[i] != ' ')   // 对：比较单个字符
if (s[i] != " ")   // 错：这是字符串比较，编译会报错
```

### 3. 换行符不用担心

`getline` 读完一行后，字符串末尾**不包含**换行符 `\n`，所以不需要额外处理。

### 4. 字符串下标从 0 开始

```
字符串:  H  e  l  l  o
下标:    0  1  2  3  4
```

`s.size()` 返回 5，但最后一个字符的下标是 4（不是 5），所以循环条件是 `i < s.size()`，不是 `i <= s.size()`。
