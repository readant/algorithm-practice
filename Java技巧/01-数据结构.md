# Java 数据结构

## 数组

```java
// 声明与初始化
int[] arr = new int[10];           // 默认值0
int[] arr = {1, 2, 3, 4, 5};      // 直接初始化
int[] arr = new int[]{1, 2, 3};    // 匿名数组

// 二维数组
int[][] matrix = new int[3][4];
int[][] matrix = {{1,2},{3,4},{5,6}};
```

## 集合框架

```java
// ArrayList - 动态数组
ArrayList<Integer> list = new ArrayList<>();
list.add(1);
list.get(0);
list.remove(0);
list.size();

// HashMap - 哈希表
HashMap<String, Integer> map = new HashMap<>();
map.put("key", 1);
map.get("key");
map.containsKey("key");

// HashSet - 哈希集合
HashSet<Integer> set = new HashSet<>();
set.add(1);
set.contains(1);

// LinkedList - 链表
LinkedList<Integer> linkedList = new LinkedList<>();
linkedList.addFirst(1);
linkedList.addLast(2);
```

## 字符串

```java
// 字符串是不可变的
String s = "hello";
s.charAt(0);           // 获取字符
s.substring(1, 3);     // 子串 [1,3)
s.length();            // 长度
s.toCharArray();       // 转字符数组
s.indexOf("ll");       // 查找子串

// StringBuilder - 可变字符串
StringBuilder sb = new StringBuilder();
sb.append('a');
sb.toString();         // 转字符串
```
