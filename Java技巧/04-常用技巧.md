# Java 常用技巧

## 基础语法

```java
// 三元运算符
int max = (a > b) ? a : b;

// 增强for循环
for (int x : arr) {
    System.out.println(x);
}

// 逻辑运算符短路
if (a != 0 && b / a > 1) { ... }  // a!=0先判断，避免除零
```

## 进制转换

```java
Integer.toBinaryString(n);   // 转二进制
Integer.toOctalString(n);    // 转八进制
Integer.toHexString(n);      // 转十六进制
Integer.parseInt("ff", 16);  // 十六进制转十进制
```

## 高精度运算（BigInteger/BigDecimal）

```java
import java.math.BigInteger;

BigInteger a = new BigInteger("123456789");
BigInteger b = new BigInteger("987654321");
BigInteger sum = a.add(b);       // 加法
BigInteger mul = a.multiply(b);  // 乘法
```

## 日期时间

```java
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

LocalDateTime now = LocalDateTime.now();
String formatted = now.format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss"));
```

## 泛型与比较

```java
// Comparable 接口
class Student implements Comparable<Student> {
    int score;
    @Override
    public int compareTo(Student other) {
        return this.score - other.score;  // 升序
    }
}

// Comparator 比较器
Arrays.sort(arr, (a, b) -> a - b);  // 升序
Arrays.sort(arr, (a, b) -> b - a);  // 降序
```
