# 数据结构模板

## 栈

```cpp
stack<int> st;
st.push(x);
st.top();
st.pop();
st.empty();
```

## 队列

```cpp
queue<int> q;
q.push(x);
q.front();
q.pop();
q.empty();
```

## 并查集

```cpp
int parent[N];
void init() { for (int i = 0; i < N; i++) parent[i] = i; }
int find(int x) { return parent[x] == x ? x : parent[x] = find(parent[x]); }
void unite(int x, int y) { parent[find(x)] = find(y); }
```

## 堆（优先队列）

```cpp
priority_queue<int> pq; // 大根堆
priority_queue<int, vector<int>, greater<int>> pq; // 小根堆
pq.push(x);
pq.top();
pq.pop();
```
