# 变量与基本数据类型

## 概述

变量是程序中用于存储数据的命名空间。C++提供了丰富的数据类型，选择合适的数据类型对算法实现的正确性和效率至关重要。

## 基本数据类型

### 整数类型

| 类型 | 大小 | 范围 | 用途 |
|------|------|------|------|
| `short` | 2字节 | -32,768 ~ 32,767 | 小范围整数 |
| `int` | 4字节 | -2^31 ~ 2^31-1 | 最常用整数类型 |
| `long long` | 8字节 | -2^63 ~ 2^63-1 | 大数计算 |

### 浮点类型

| 类型 | 大小 | 精度 | 用途 |
|------|------|------|------|
| `float` | 4字节 | 6-7位 | 一般浮点计算 |
| `double` | 8字节 | 15-16位 | 高精度计算 |

### 字符类型

| 类型 | 大小 | 说明 |
|------|------|------|
| `char` | 1字节 | ASCII字符 |
| `bool` | 1字节 | true/false |

## 变量声明与初始化

```cpp
#include <iostream>
using namespace std;

int main() {
    // 声明并初始化
    int a = 10;
    double b = 3.14;
    char c = 'A';
    bool d = true;
    
    // C++11 统一初始化
    int x{20};
    double y{3.14};
    
    // auto 自动推导类型
    auto z = 100;        // int
    auto pi = 3.14;      // double
    
    // 常量
    const int MAX = 100;
    
    cout << "a = " << a << endl;
    cout << "b = " << b << endl;
    cout << "c = " << c << endl;
    cout << "d = " << d << endl;
    
    return 0;
}
```

## 变量作用域

```cpp
#include <iostream>
using namespace std;

int globalVar = 100;  // 全局变量

int main() {
    int localVar = 10;  // 局部变量
    
    {  // 块作用域
        int blockVar = 20;
        cout << "块内: " << blockVar << endl;
    }
    // cout << blockVar;  // 错误：blockVar不可见
    
    cout << "全局: " << globalVar << endl;
    cout << "局部: " << localVar << endl;
    
    return 0;
}
```

## 常见类型转换

```cpp
#include <iostream>
using namespace std;

int main() {
    // 隐式转换（可能丢失精度）
    int a = 10;
    double b = a;  // int -> double，安全
    
    int c = 3.9;   // double -> int，截断小数，c = 3
    
    // 显式转换（推荐）
    double d = 3.14;
    int e = static_cast<int>(d);  // e = 3
    
    // 字符与数字转换
    char ch = 'A';
    int ascii = ch;           // ascii = 65
    char back = static_cast<char>(65);  // back = 'A'
    
    cout << "d = " << d << ", e = " << e << endl;
    cout << "ascii = " << ascii << ", back = " << back << endl;
    
    return 0;
}
```

## 算法中常用技巧

### 无穷大表示

```cpp
const int INF = 0x3f3f3f3f;  // 常用无穷大
// 或
const long long INF = 1e18;
```

### 取模运算

```cpp
int mod = 1e9 + 7;
int result = (a + b) % mod;
// 注意：(a * b) % mod 可能溢出，需用快速乘或long long
long long safeMod = (1LL * a * b) % mod;
```

## 练习题

### 题目1：Hello World

**题目描述**：输出 "Hello, World!" 和你的名字。

**参考代码**：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    cin >> name;
    cout << "Hello, World!" << endl;
    cout << "My name is " << name << endl;
    return 0;
}
```

### 题目2：数据类型大小

**题目描述**：输出int、long long、double、char的大小（字节数）。

**参考代码**：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "int: " << sizeof(int) << " bytes" << endl;
    cout << "long long: " << sizeof(long long) << " bytes" << endl;
    cout << "double: " << sizeof(double) << " bytes" << endl;
    cout << "char: " << sizeof(char) << " bytes" << endl;
    return 0;
}
```

## 小结

1. 算法竞赛中最常用 `int`、`long long`、`double`
2. 注意整数溢出，大数运算用 `long long`
3. 常用 `const int INF = 0x3f3f3f3f` 表示无穷大
4. `auto` 可以简化类型声明
