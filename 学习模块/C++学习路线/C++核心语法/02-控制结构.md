# 控制结构

## 概述

控制结构决定了程序的执行流程。掌握if-else、for、while、switch是编写算法的基础。

## 条件语句

### if-else

```cpp
#include <iostream>
using namespace std;

int main() {
    int x;
    cin >> x;
    
    if (x > 0) {
        cout << "正数" << endl;
    } else if (x < 0) {
        cout << "负数" << endl;
    } else {
        cout << "零" << endl;
    }
    
    // 三元运算符
    string result = (x > 0) ? "正" : "非正";
    cout << result << endl;
    
    return 0;
}
```

### switch

```cpp
#include <iostream>
using namespace std;

int main() {
    int day;
    cin >> day;
    
    switch (day) {
        case 1: cout << "Monday" << endl; break;
        case 2: cout << "Tuesday" << endl; break;
        case 3: cout << "Wednesday" << endl; break;
        case 4: cout << "Thursday" << endl; break;
        case 5: cout << "Friday" << endl; break;
        case 6: cout << "Saturday" << endl; break;
        case 7: cout << "Sunday" << endl; break;
        default: cout << "Invalid" << endl;
    }
    
    return 0;
}
```

## 循环语句

### for循环

```cpp
#include <iostream>
using namespace std;

int main() {
    // 基本for循环
    for (int i = 0; i < 10; i++) {
        cout << i << " ";
    }
    cout << endl;
    
    // C++11 范围for
    int arr[] = {1, 2, 3, 4, 5};
    for (int x : arr) {
        cout << x << " ";
    }
    cout << endl;
    
    // 多变量for
    for (int i = 0, j = 10; i < j; i++, j--) {
        cout << i << " " << j << endl;
    }
    
    return 0;
}
```

### while循环

```cpp
#include <iostream>
using namespace std;

int main() {
    // while循环
    int n = 1;
    while (n <= 10) {
        cout << n << " ";
        n *= 2;
    }
    cout << endl;
    
    // do-while循环（至少执行一次）
    int count = 0;
    do {
        cout << count << " ";
        count++;
    } while (count < 5);
    cout << endl;
    
    return 0;
}
```

### 嵌套循环

```cpp
#include <iostream>
using namespace std;

int main() {
    // 九九乘法表
    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= i; j++) {
            cout << j << "×" << i << "=" << i * j << "\t";
        }
        cout << endl;
    }
    
    return 0;
}
```

## 跳转语句

### break和continue

```cpp
#include <iostream>
using namespace std;

int main() {
    // break：跳出循环
    for (int i = 0; i < 100; i++) {
        if (i == 10) break;  // i=10时跳出
        cout << i << " ";
    }
    cout << endl;
    
    // continue：跳过本次迭代
    for (int i = 0; i < 10; i++) {
        if (i % 2 == 0) continue;  // 跳过偶数
        cout << i << " ";
    }
    cout << endl;
    
    return 0;
}
```

### 标签和goto（不推荐）

```cpp
// goto在特定场景（多层循环跳出）有用，但应谨慎使用
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 10; j++) {
        if (i * j == 42) goto found;
    }
}
found:
cout << "Found!" << endl;
```

## 算法中的控制结构技巧

### 提前返回

```cpp
// 比深层嵌套更清晰
bool check(int x) {
    if (x < 0) return false;
    if (x > 100) return false;
    if (x % 2 != 0) return false;
    return true;
}
```

### 哨兵值

```cpp
// 在数组末尾添加哨兵，简化边界检查
int arr[101];
for (int i = 0; i < n; i++) cin >> arr[i];
arr[n] = -1;  // 哨兵

int i = 0;
while (arr[i] != -1) {
    // 处理arr[i]
    i++;
}
```

## 练习题

### 题目1：求和
**题目描述**：输入n，求1+2+...+n的和。

**参考代码**：
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    // 方法1：循环
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        sum += i;
    }
    cout << sum << endl;
    
    // 方法2：公式 O(1)
    // cout << n * (n + 1) / 2 << endl;
    
    return 0;
}
```

### 题目2：判断素数
**题目描述**：输入n，判断n是否为素数。

**参考代码**：
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    if (n < 2) {
        cout << "No" << endl;
        return 0;
    }
    
    bool isPrime = true;
    for (int i = 2; i <= sqrt(n); i++) {
        if (n % i == 0) {
            isPrime = false;
            break;
        }
    }
    
    cout << (isPrime ? "Yes" : "No") << endl;
    return 0;
}
```

## 小结

1. `for`循环适合已知次数的遍历
2. `while`适合条件控制的循环
3. `break`和`continue`可优化循环逻辑
4. 算法中常用"提前返回"减少嵌套
