# 暴力法

## 概述

暴力法（Brute Force）是最直接的算法设计方法，通过穷举所有可能的情况来找到问题的解。虽然效率不高，但简单直观，适合作为其他算法的对比基准。

## 算法原理

暴力法的核心思想是：
1. 列举所有可能的解
2. 逐一验证是否满足条件
3. 返回满足条件的解

## 经典应用

### 暴力搜索

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 查找最大子数组和（暴力法）
int maxSubArray(vector<int>& nums) {
    int n = nums.size();
    int maxSum = INT_MIN;
    
    for (int i = 0; i < n; i++) {
        int sum = 0;
        for (int j = i; j < n; j++) {
            sum += nums[j];
            maxSum = max(maxSum, sum);
        }
    }
    
    return maxSum;
}

int main() {
    vector<int> nums = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
    cout << maxSubArray(nums) << endl;  // 6
    
    return 0;
}
```

### 暴力枚举

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 两数之和（暴力法）
vector<int> twoSum(vector<int>& nums, int target) {
    int n = nums.size();
    
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (nums[i] + nums[j] == target) {
                return {i, j};
            }
        }
    }
    
    return {};
}

int main() {
    vector<int> nums = {2, 7, 11, 15};
    int target = 9;
    
    auto result = twoSum(nums, target);
    cout << result[0] << ", " << result[1] << endl;
    
    return 0;
}
```

### 暴力递归

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 爬楼梯（暴力递归）
int climbStairs(int n) {
    if (n <= 1) return 1;
    return climbStairs(n - 1) + climbStairs(n - 2);
}

// 斐波那契数列
int fibonacci(int n) {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}

int main() {
    cout << climbStairs(5) << endl;  // 8
    cout << fibonacci(10) << endl;   // 55
    
    return 0;
}
```

## 暴力法的优化

### 剪枝

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 子集（带剪枝）
void subsets(vector<int>& nums, vector<int>& current, int start, vector<vector<int>>& result) {
    result.push_back(current);
    
    for (int i = start; i < nums.size(); i++) {
        current.push_back(nums[i]);
        subsets(nums, current, i + 1, result);
        current.pop_back();
    }
}

int main() {
    vector<int> nums = {1, 2, 3};
    vector<vector<int>> result;
    vector<int> current;
    
    subsets(nums, current, 0, result);
    
    for (auto& subset : result) {
        cout << "{ ";
        for (int x : subset) cout << x << " ";
        cout << "}" << endl;
    }
    
    return 0;
}
```

### 记忆化

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 斐波那契数列（记忆化）
vector<long long> memo(100, -1);

long long fibonacciMemo(int n) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    
    memo[n] = fibonacciMemo(n - 1) + fibonacciMemo(n - 2);
    return memo[n];
}

int main() {
    cout << fibonacciMemo(50) << endl;  // 12586269025
    
    return 0;
}
```

## 暴力法的复杂度

| 问题 | 时间复杂度 | 说明 |
|------|------------|------|
| 两数之和 | O(n²) | 两层循环 |
| 最大子数组和 | O(n²) | 两层循环 |
| 爬楼梯（递归） | O(2^n) | 指数级 |
| 子集枚举 | O(2^n) | 每个元素选或不选 |
| 排列生成 | O(n!) | 全排列 |

## 适用场景

1. 数据规模小
2. 作为其他算法的对比基准
3. 没有更优算法时
4. 问题简单，暴力解法可接受

## 练习题

### 题目1：Fizz Buzz
**题目描述**：给你一个整数n，对于从1到n的每个整数i：
- 如果i是3的倍数，输出"Fizz"
- 如果i是5的倍数，输出"Buzz"
- 如果i同时是3和5的倍数，输出"FizzBuzz"
- 否则，输出数字i

**参考代码**：
```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

vector<string> fizzBuzz(int n) {
    vector<string> result;
    
    for (int i = 1; i <= n; i++) {
        if (i % 15 == 0) {
            result.push_back("FizzBuzz");
        } else if (i % 3 == 0) {
            result.push_back("Fizz");
        } else if (i % 5 == 0) {
            result.push_back("Buzz");
        } else {
            result.push_back(to_string(i));
        }
    }
    
    return result;
}

int main() {
    auto result = fizzBuzz(15);
    for (const string& s : result) {
        cout << s << " ";
    }
    cout << endl;
    
    return 0;
}
```

### 题目2：杨辉三角
**题目描述**：给定一个非负整数 numRows，生成杨辉三角的前numRows行。

**参考代码**：
```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<vector<int>> generate(int numRows) {
    vector<vector<int>> result;
    
    for (int i = 0; i < numRows; i++) {
        vector<int> row(i + 1, 1);
        
        for (int j = 1; j < i; j++) {
            row[j] = result[i - 1][j - 1] + result[i - 1][j];
        }
        
        result.push_back(row);
    }
    
    return result;
}

int main() {
    auto result = generate(5);
    
    for (auto& row : result) {
        for (int x : row) cout << x << " ";
        cout << endl;
    }
    
    return 0;
}
```

## 小结

1. 暴力法简单直观，适合作为起点
2. 效率低，通常需要优化
3. 剪枝和记忆化可大幅提升效率
4. 理解暴力法有助于设计更优算法
