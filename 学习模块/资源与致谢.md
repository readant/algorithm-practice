## 网站

| 类别 | 网站 | 核心定位 | 简述 |
|------|------|----------|----------------|
| 系统学习路线 | [Hello 算法](https://www.hello-algo.com/) | 动画图解算法入门书 | 豆瓣8.5，GitHub 104k星，零基础友好，李沐推荐 |
| 系统学习路线 | [labuladong 算法笔记](https://labuladong.online/zh/roadmap/algo/) | 算法框架思维 + 刷题路线图 | 框架思维串联题目，可视化递归，适合刷题无思路者 |
| 系统学习路线 | [算法通关手册](https://algo.itcharge.cn/) | LeetCode 系统教程（Python） | GitHub好评，理论+实战结合，适合 Python 开发者 |
| 刷题平台 | [LeetCode](https://leetcode.cn/) | 面试刷题平台 | 全球主流，题目贴近面试，社区题解丰富 |
| 刷题平台 | [洛谷](https://www.luogu.com.cn/) | 竞赛刷题（信奥/NOIP） | 国内信奥知名，体系完善，不适合零基础/大学生 |
| 知识库 / 参考 | [OI Wiki](https://oi-wiki.org/) | 算法竞赛知识库 | 免费开放，知识点全面，但非权威，质量参差 |
| 知识库 / 参考 | [CP-Algorithms](https://cp-algorithms.com/) | 算法与数据结构（英文） | 源自 e-maxx，讲解清晰，适合有英文基础者 |
| 知识库 / 参考 | [菜鸟教程 - 数据结构](https://www.runoob.com/data-structures/dsl-intro.html) | 基础入门教程 | 完全免费，讲解详细，深度有限，适合快速了解 |
| 可视化工具 | [Visualgo](https://visualgo.net/) | 数据结构可视化 | 新加坡国立大学出品，24种算法，无代码过程演示 |
| 可视化工具 | [算法导航](https://algo.codefather.cn/) | 交互式可视化学习 | 免费，动画+调试，支持多语言，内部测试中 |
