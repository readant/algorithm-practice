# cin、cout 和命名空间

---

## 1. 基本概念

| 概念 | 说明 |
|------|------|
| `cin` | 标准输入流对象，从键盘读取数据 |
| `cout` | 标准输出流对象，向屏幕输出数据 |
| `endl` | 换行并刷新缓冲区 |
| `namespace std` | 标准命名空间，存放 cin/cout 等标准库组件 |

---

## 2. cout — 输出

### 基本语法

```cpp
cout << 变量或字符串;
```

`<<` 是**插入运算符**，把右边的内容"插入"到 cout 流中。

### 示例

```cpp
#include <iostream>
using namespace std;

int main() {
    // 输出单个值
    cout << "Hello World" << endl;

    // 链式输出（连续 <<）
    int a = 10, b = 20;
    cout << "a = " << a << ", b = " << b << endl;

    return 0;
}
```

### 输出格式控制

| 控制符 | 作用 | 示例 |
|--------|------|------|
| `endl` | 换行 + 刷新缓冲区 | `cout << "hi" << endl;` |
| `"\n"` | 仅换行（推荐，更快） | `cout << "hi\n";` |
| `fixed << setprecision(2)` | 保留两位小数 | 见下方 |

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double pi = 3.14159;

    // 保留两位小数
    cout << fixed << setprecision(2) << pi << endl;  // 输出 3.14

    // 设置宽度（右对齐）
    cout << setw(10) << 42 << endl;  // 输出 "        42"

    // 左对齐
    cout << left << setw(10) << 42 << endl;  // 输出 "42        "

    return 0;
}
```

## 3. cin — 输入

### 基本语法

```cpp
cin >> 变量;
```

`>>` 是**提取运算符**，从 cin 流中"提取"数据存入变量。

### 示例

```cpp
#include <iostream>
using namespace std;

int main() {
    int a;
    double b;
    char c;

    // 输入单个值
    cin >> a;

    // 链式输入
    cin >> a >> b >> c;

    // 输出验证
    cout << "a = " << a << ", b = " << b << ", c = " << c << endl;

    return 0;
}
```

### 输入规则

| 规则 | 说明 |
|------|------|
| 以空白字符分隔 | 空格、换行、Tab 都算分隔符 |
| 自动跳过空白 | `cin >> a >> b` 时，输入 `10 20` 和 `10\n20` 效果一样 |
| 遇到非数字停止 | 输入 `abc` 给 `int a`，`a` 会为 0 且进入错误状态 |

### getline — 读取整行

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string line;

    // 读取整行（包含空格）
    getline(cin, line);

    cout << "你输入了: " << line << endl;

    return 0;
}
```

### cin 与 getline 混用的坑

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    string s;

    cin >> n;          // 读取整数，但换行符留在缓冲区
    getline(cin, s);   // ❌ 这里会读到换行符，s 为空

    // 解决方法：cin >> n 后加 cin.ignore()
    cin >> n;
    cin.ignore();       // 丢弃缓冲区中的换行符
    getline(cin, s);    // ✅ 现在能正确读取

    cout << "n = " << n << ", s = " << s << endl;

    return 0;
}
```

## 4. using namespace std

### 为什么需要

```cpp
#include <iostream>

int main() {
    // 没有 using namespace std 时，必须加 std::
    std::cout << "Hello" << std::endl;

    return 0;
}
```

```cpp
#include <iostream>
using namespace std;  // 声明使用标准命名空间

int main() {
    // 现在可以直接用 cout，不用加 std::
    cout << "Hello" << endl;

    return 0;
}
```

### std 命名空间包含什么

| 组件 | 头文件 | 说明 |
|------|--------|------|
| `cout`, `cin`, `endl` | `<iostream>` | 输入输出 |
| `string` | `<string>` | 字符串类 |
| `vector` | `<vector>` | 动态数组 |
| `sort` | `<algorithm>` | 排序函数 |
| `abs`, `pow`, `sqrt` | `<cmath>` | 数学函数 |

### 命名冲突问题

```cpp
#include <iostream>
#include <algorithm>  // std 也有 swap
using namespace std;

int main() {
    // 如果你定义了自己的 swap 函数，会和 std::swap 冲突
    // 所以竞赛中 using namespace std 一般没问题
    // 但大型项目中建议只引入需要的：

    using std::cout;    // 只引入 cout
    using std::endl;    // 只引入 endl
    using std::string;  // 只引入 string

    return 0;
}
```

### 竞赛写法 vs 工程写法

| 场景 | 推荐写法 |
|------|----------|
| 竞赛/刷题 | `using namespace std;`（方便） |
| 工程/大型项目 | `std::cout` 或 `using std::cout;`（避免污染） |

## 5. 完整示例

### 示例：输入两个数，输出它们的和

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}
```

### 示例：格式化输出表格

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    cout << left << setw(10) << "姓名" 
         << setw(5) << "年龄" 
         << setw(10) << "成绩" << endl;

    cout << left << setw(10) << "Alice" 
         << setw(5) << 20 
         << setw(10) << 95.5 << endl;

    cout << left << setw(10) << "Bob" 
         << setw(5) << 18 
         << setw(10) << 88.0 << endl;

    return 0;
}
```

## 6. 易错点

| 错误 | 原因 | 解决方法 |
|------|------|----------|
| `cin >> a >> b` 输入 `10,20` | 逗号不是分隔符 | 用空格或换行：`10 20` |
| `getline` 读到空字符串 | 前面有 `cin >>` 残留换行符 | `cin.ignore()` 清除缓冲区 |
| 输出乱码 | 文件编码与控制台编码不一致 | 用 `-fexec-charset=GBK` 编译 |
| `cout` 输出科学计数法 | 数值太大或太小 | 用 `fixed << setprecision(n)` |
