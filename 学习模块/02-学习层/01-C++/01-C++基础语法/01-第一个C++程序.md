# 第一个 C++ 程序

## 基本结构

```cpp
#include <iostream>   // 头文件：输入输出
using namespace std;  // 命名空间：直接使用 cout/cin

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

### 逐行解释

| 代码 | 作用 |
|------|------|
| `#include <iostream>` | 引入输入输出流库，提供 `cin`、`cout` |
| `using namespace std;` | 使用标准命名空间，省去 `std::` 前缀 |
| `int main()` | 程序入口，每个 C++ 程序必须有且只有一个 |
| `cout << "..." << endl;` | 输出内容并换行 |
| `return 0;` | 返回 0 表示程序正常结束 |

## 运行方式

```bash
# 编译
g++ -o hello hello.cpp

# 运行
./hello          # Linux/Mac
hello.exe        # Windows
```

## 常见变体

### 变体 1：多行输出

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "姓名: readant" << endl;
    cout << "年龄: 20" << endl;
    cout << "专业: 物联网工程" << endl;
    return 0;
}
```

### 变体 2：使用变量

```cpp
#include <iostream>
using namespace std;

int main() {
    string name = "L君";
    int age = 20;
    cout << "姓名: " << name << endl;
    cout << "年龄: " << age << endl;
    return 0;
}
```

### 变体 3：不换行输出

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello";   // 没有 endl，不换行
    cout << " World";  // 紧接着输出
    cout << endl;      // 最后换行
    return 0;
}
```

## 易错点

| 错误 | 说明 |
|------|------|
| 忘记 `#include <iostream>` | 无法使用 `cout`、`cin` |
| 忘记分号 `;` | C++ 每条语句必须以分号结尾 |
| 中文标点 | 代码中的括号、分号必须是英文半角 |
| `main` 写成 `Main` | C++ 区分大小写，入口函数必须是小写 `main` |
