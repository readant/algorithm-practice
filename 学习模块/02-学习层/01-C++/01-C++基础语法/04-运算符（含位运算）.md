# 运算符（含位运算）

## 1. 算术运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `+` | 加 | `a + b` |
| `-` | 减 | `a - b` |
| `*` | 乘 | `a * b` |
| `/` | 除（整数除法截断） | `7 / 2 = 3` |
| `%` | 取模 | `7 % 2 = 1` |

## 2. 关系运算符

| 运算符 | 说明 |
|--------|------|
| `==` | 等于 |
| `!=` | 不等于 |
| `<` | 小于 |
| `>` | 大于 |
| `<=` | 小于等于 |
| `>=` | 大于等于 |

## 3. 逻辑运算符

| 运算符 | 说明 | 短路特性 |
|--------|------|----------|
| `&&` | 与 | 左边为 false，右边不执行 |
| `\|\|` | 或 | 左边为 true，右边不执行 |
| `!` | 非 | 取反 |

## 4. 位运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `&` | 按位与 | `5 & 3 = 1` (101 & 011 = 001) |
| `\|` | 按位或 | `5 \| 3 = 7` (101 \| 011 = 111) |
| `^` | 按位异或 | `5 ^ 3 = 6` (101 ^ 011 = 110) |
| `~` | 按位取反 | `~0 = -1` |
| `<<` | 左移 | `1 << 3 = 8` (相当于 ×2^n) |
| `>>` | 右移 | `8 >> 2 = 2` (相当于 ÷2^n) |

### 位运算技巧

```cpp
// 判断奇偶
if (n & 1) { /* 奇数 */ }

// 除以2
n >>= 1;

// 乘以2
n <<= 1;

// 交换两个数（不用临时变量）
a ^= b; b ^= a; a ^= b;

// 判断是否是2的幂
bool isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;
}

// 取第k位 (0-indexed)
int bit = (n >> k) & 1;

// 设置第k位为1
n |= (1 << k);

// 清除第k位
n &= ~(1 << k);
```

## 5. 赋值运算符

| 运算符 | 等价于 |
|--------|--------|
| `=` | 赋值 |
| `+=` | `a = a + b` |
| `-=` | `a = a - b` |
| `*=` | `a = a * b` |
| `/=` | `a = a / b` |
| `%=` | `a = a % b` |
| `&=` | `a = a & b` |
| `\|=` | `a = a \| b` |
| `^=` | `a = a ^ b` |
| `<<=` | `a = a << b` |
| `>>=` | `a = a >> b` |

## 6. 三元运算符

```cpp
// 条件 ? 真值 : 假值
int max = (a > b) ? a : b;
```

## 7. 运算符优先级

```
高: () [] -> . ::              后缀
    ++ -- ! ~ + - * & (type)   一元
    * / %                      乘除模
    + -                        加减
    << >>                      移位
    < <= > >=                  关系
    == !=                      等于
    &                          按位与
    ^                          按位异或
    |                          按位或
    &&                         逻辑与
    ||                         逻辑或
    ?: = += -= ...             赋值
低: ,                          逗号
```

## 易错点

| 问题 | 说明 |
|------|------|
| 整数除法截断 | `7 / 2 = 3`，不是 3.5 |
| 负数取模 | `-7 % 2 = -1`（C++11 规定） |
| 位运算优先级 | `if (a & 1 == 0)` 实际是 `if (a & (1 == 0))`，要加括号 |
| 短路求值 | `a && b` 中 a 为 false 时 b 不执行 |
