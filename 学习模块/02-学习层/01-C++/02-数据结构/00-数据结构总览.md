## 5. C++ 备赛硬约定

| 约定 | 说明 |
| :--- | :--- |
| 语言 | 主语言 **C++**；Python 副对照；C 仅随 C++ 调整；**Java 不在考虑** |
| 头文件 | 可用 `#include <bits/stdc++.h>`；笔记仍写清真实头文件 |
| 复杂度 | 每模板写均摊/最坏；看清 n 上限 |
| 数组 | 大数组放全局；多开 5–10；前缀和习惯 `long long` + 下标从 1 |
| STL | 优先标准容器；卡常再手写；**入队时 vis，BFS 不回溯** |
| 练习 | 每章「例题 + 洛谷/真题」；卡题较久先看题解再重写 |

## 7. 块5 自检

- [ ] n≤1e5、矩阵 n·m≤1e6 时会用 `vector<vector<int>>`
- [ ] 说清 stack/queue 不能下标遍历；pq 只读堆顶
- [ ] set 去重 + 有序；map 计数；存在性用 count/find
- [ ] map 的 `[]` 会默认插入
- [ ] 小顶堆：`priority_queue<T,vector<T>,greater<T>>`
- [ ] 结构体 + `cmp` 多关键字排序
- [ ] 能对 1～2 道题完整走完「读题 → 选容器 → 实现 → 测边界」
