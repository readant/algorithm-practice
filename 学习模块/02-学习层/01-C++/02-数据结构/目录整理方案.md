## 3. 新建章节大纲（每章「应写到什么程度」）

每章建议固定骨架（与总览第 5 节一致）：

1. 大纲要求与考点密度  
2. 概念与存储（可画 ASCII 示意）  
3. 核心操作 + 复杂度表  
4. 408 常见问法（选择/综合）  
5. 与 STL 对照（短）+ 模板链接  
6. 练习（真题风格优先）  
7. 延伸：竞赛向可选  

### 01-绪论与复杂度

- [ ] 数据/数据元素/数据对象；四类逻辑结构；四类存储结构  
- [ ] 算法五特性；时间复杂度计算（最好/最坏/平均）；常见数量级排序  
- [ ] 「逻辑独立于存储」辨析题  

### 02-线性表

- [ ] 顺序表：插入删除移动次数、优缺点  
- [ ] 单链表：头插/尾插、逆置、归并  
- [ ] 双链表、循环链表、静态链表  
- [ ] 顺序 vs 链式对比表；指针填空型综合题模板  

### 03-栈与队列

- [ ] 栈 ADT；顺序栈/链栈；共享栈  
- [ ] 出栈序列合法性（会算卡特兰相关判断）  
- [ ] 括号匹配、表达式（中缀→后缀）  
- [ ] 循环队列：判空判满两种约定；front/rear 变化过程  
- [ ] 链队列；栈与队列模拟递归  

### 04-数组与压缩存储

- [ ] 行优先/列优先地址计算公式（一维、二维）  
- [ ] 对称矩阵、三角矩阵压缩下标映射  
- [ ] 对角矩阵；稀疏矩阵三元组表（概念）  
- [ ] 多维数组在选择题中的下标换算  

### 05-串与KMP

- [ ] 串概念与定长/堆分配存储  
- [ ] 朴素匹配过程与失败次数  
- [ ] next 数组定义、手算、nextval 改进  
- [ ] 与语法层 string 用法分界说明  

### 06-树与二叉树

- [ ] 术语；树的性质（度结点关系、层数）  
- [ ] 满/完全二叉树性质与存储（顺序编号性质）  
- [ ] 四种遍历；由遍历序列建树（必会）  
- [ ] 层序与完全二叉树数组下标关系（堆的前置）  

### 07-线索树与哈夫曼

- [ ] 线索化过程；中序线索树遍历思想  
- [ ] 树/森林与二叉树转换（孩子兄弟）  
- [ ] 树的先根/后根与二叉树遍历对应  
- [ ] 哈夫曼构造步骤、WPL、编码与译码  

### 08-图的存储与遍历

- [ ] 图术语；邻接矩阵、邻接表（含网）  
- [ ] 邻接多重表、十字链表：**会认、会填空**，实现从简  
- [ ] DFS/BFS 序列；连通分量；生成树  

### 09-图的应用算法

- [ ] Prim / Kruskal 过程与适用图  
- [ ] Dijkstra 步骤表；Floyd 与邻接矩阵幂  
- [ ] 拓扑排序；AOE 关键路径求法  
- [ ] 与模板库链接，不在正文重复超长模板  

### 10-查找

- [ ] 顺序/折半：ASL、判定树、mid 取法  
- [ ] B 树、B+ 树：阶、插入删除思想、对比（概念+画图）  
- [ ] 散列：H(k)、开放定址、链地址、ASL、装填因子  
- [ ] AVL：平衡因子、四类旋转、插入后调整分类  
- [ ] （旧哈希文迁入）  

### 11-排序

- [ ] 八种内排序过程表解  
- [ ] 稳定性总表；时间复杂度与初始序列关系

- [ ] 简单选择/希尔/归并/基数过程

### A1 STL工具箱
