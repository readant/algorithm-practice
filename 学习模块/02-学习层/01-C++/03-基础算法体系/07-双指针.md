# 双指针

## 概述

双指针技巧用两个指针同时遍历数组（或链表），把两重循环的 **O(n²) 暴力优化为 O(n)**。核心思想：**利用指针移动的单调性，跳过已经确定无效的区间，避免重复扫描**。

按指针移动方式分为三种变体：

| 变体 | 移动方式 | 典型应用 |
| ------ | --------- | --------- |
| 快慢指针 | 同向，速度不同 | 链表环检测、找中点、链表倒数第 k 个 |
| 对撞指针 | 相向而行 | 有序数组两数之和、回文判断 |
| 同向指针 | 同向，同步移动 | 去重、滑动窗口（见 [08-滑动窗口.md](08-滑动窗口.md)） |

---

## 一、快慢指针

### 原理

`slow` 每次走 1 步，`fast` 每次走 2 步（或更多）。若存在环，`fast` 最终会追上 `slow`；若 `fast` 先到达末尾（`nullptr`），则无环。

### 代码模板

```cpp
// 1. 链表是否有环
bool hasCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;   // 相遇即有环
    }
    return false;
}

// 2. 找链表中间节点（快慢指针走完全程，slow 即中点）
ListNode* middleNode(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}

// 3. 链表倒数第 k 个节点（快指针先走 k 步，再同步走）
ListNode* findFromEnd(ListNode* head, int k) {
    ListNode *fast = head, *slow = head;
    while (k-- > 0) fast = fast->next;
    while (fast) {
        fast = fast->next;
        slow = slow->next;
    }
    return slow;
}
```

### 应用场景

- 链表环检测（LeetCode 141）
- 找链表中间节点（LeetCode 876）—— 归并排序找中点、回文链表判断的预处理
- 寻找链表中点后反转后半段（LeetCode 234 回文链表）
- 求链表中点 + 快慢指针找环入口（LeetCode 142）

## 二、对撞指针

### 原理

`left` 从头部、`right` 从尾部相向移动。适用于**有序数组**或**双端可比较**的场景，每步可以确定排除一端，从而把 O(n²) 降为 O(n)。

### 代码模板

```cpp
// 1. 有序数组两数之和
vector<int> twoSum(vector<int>& nums, int target) {
    int left = 0, right = nums.size() - 1;
    while (left < right) {
        int sum = nums[left] + nums[right];
        if (sum == target)      return {left, right};
        else if (sum < target)  left++;    // 和小了，left 右移
        else                    right--;   // 和大了，right 左移
    }
    return {};
}

// 2. 判断回文（字符串）
bool isPalindrome(string s) {
    int left = 0, right = s.size() - 1;
    while (left < right) {
        if (s[left] != s[right]) return false;
        left++; right--;
    }
    return true;
}
```

### 应用场景

- 有序数组的两数之和 / 三数之和（LeetCode 167、15）
- 盛最多水的容器（LeetCode 11）
- 回文判断（LeetCode 125）
- 反转数组 / 原地交换

> 注意：对撞指针要求数组**有序**（两数之和）或问题本身对称（回文）。若数组无序，先 `sort()` 再对撞。

## 三、同向指针（快慢同向）

### 原理

两个指针同向移动，`slow` 指向"已处理区"末尾，`fast` 遍历整个数组，把符合条件的元素搬到 `slow` 位置。常用于**原地去重 / 原地过滤**。

### 代码模板

```cpp
// 原地去重（数组已排序）
int removeDuplicates(vector<int>& nums) {
    if (nums.empty()) return 0;
    int slow = 0;
    for (int fast = 1; fast < nums.size(); fast++) {
        if (nums[fast] != nums[slow]) {
            slow++;
            nums[slow] = nums[fast];   // 覆盖到 slow 位置
        }
    }
    return slow + 1;   // 新长度
}
```

### 应用场景

- 有序数组去重（LeetCode 26、80）
- 原地移除指定值（LeetCode 27）
- 滑动窗口的基础（见 [08-滑动窗口.md](08-滑动窗口.md)）

## 复杂度分析

| 变体 | 时间复杂度 | 空间复杂度 | 适用前提 |
| ------ | ----------- | ----------- | --------- |
| 快慢指针 | O(n) | O(1) | 链表 / 可顺序访问 |
| 对撞指针 | O(n) | O(1) | 有序数组 / 对称结构 |
| 同向指针 | O(n) | O(1) | 可原地覆盖 |

三种变体都只需要常数空间，是数组类题目的最优解模板。

---

## 易错点

1. **快慢指针判环**：循环条件写 `while (fast && fast->next)`，`fast` 走两步前必须确认 `fast->next` 不为空，否则空指针解引用。
2. **对撞指针边界**：循环用 `while (left < right)`，相遇时停止，避免重复使用同一个元素。
3. **对撞指针前提**：两数之和必须**有序**，无序先排序；排序会破坏原数组下标，题目要求返回下标时需复制原数组或改用哈希。
4. **同向指针去重**：必须处理空数组边界（`if (nums.empty()) return 0;`）。
5. **指针移动方向写反**：对撞指针"和小了动 left、和大了动 right"，逻辑要对应单调性。
