# 单调栈与单调队列

## 概述

单调栈和单调队列是两种**维护单调性**的进阶数据结构，专门解决"找下一个更大/更小元素"和"窗口内最值"问题。它们把 O(n²) 暴力优化为 **O(n)**。

| 结构 | 维护的数据 | 解决的问题 |
|------|-----------|-----------|
| 单调栈 | 栈内元素单调 | 下一个更大/更小元素、柱状图最大矩形 |
| 单调队列 | 队内元素单调 | 滑动窗口最大值/最小值 |

---

## 一、单调栈

### 原理

栈内元素**保持单调**（递增或递减）。入栈时，把所有破坏单调性的元素弹出，弹出的瞬间就是"下一个更大/更小元素"的答案。

**记忆口诀**：

| 问题 | 栈的单调性 | 弹出时得到 |
|------|-----------|-----------|
| 下一个更大元素 | 单调递减栈（栈顶最小） | 当前元素是栈顶的下一个更大值 |
| 下一个更小元素 | 单调递增栈（栈顶最大） | 当前元素是栈顶的下一个更小值 |

### 代码模板：下一个更大元素

```cpp
vector<int> nextGreaterElement(vector<int>& nums) {
    int n = nums.size();
    vector<int> result(n, -1);
    stack<int> stk;                    // 存下标
    for (int i = 0; i < n; i++) {
        while (!stk.empty() && nums[stk.top()] < nums[i]) {
            result[stk.top()] = nums[i];   // nums[i] 是栈顶的下一个更大元素
            stk.pop();
        }
        stk.push(i);
    }
    return result;                     // 栈里剩下的没有更大元素，保持 -1
}
```

### 经典应用：柱状图最大矩形（LeetCode 84）

每个柱子能形成的最大矩形 = 高度 × 左右两侧第一个比它矮的柱子之间的距离。左右边界正好用两次单调栈（或一次栈 + 哨兵）求出。

## 二、单调队列

### 原理

用双端队列 `deque` 维护窗口内元素，**队头是窗口最值，队内从队头到队尾单调**。每滑动一步：

1. 队尾插入新元素前，弹出所有比它小（求最大值时）的元素；
2. 队头若滑出窗口（下标 < left），弹出。

### 代码模板：滑动窗口最大值

```cpp
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    deque<int> dq;                      // 存下标，队头是窗口最大值
    vector<int> result;
    for (int i = 0; i < nums.size(); i++) {
        // 1. 队尾维护单调递减：弹出所有 <= 当前值的
        while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back();
        dq.push_back(i);
        // 2. 队头滑出窗口
        while (!dq.empty() && dq.front() <= i - k) dq.pop_front();
        // 3. 窗口成型后记录答案
        if (i >= k - 1) result.push_back(nums[dq.front()]);
    }
    return result;
}
```

> 三个步骤的顺序可微调，但**必须先维护队尾单调、再剔除过期队头**，否则过期元素可能被错误地当作新窗口最大值。

## 三、单调栈 vs 单调队列

| 对比项 | 单调栈 | 单调队列 |
|--------|--------|---------|
| 数据结构 | stack | deque |
| 进出方向 | 只在栈顶进出 | 队尾进、队头/队尾出 |
| 典型问题 | 下一个更大/更小元素 | 滑动窗口最值 |
| 代表题目 | LeetCode 496/739/84 | [P1886 滑动窗口](https://www.luogu.com.cn/problem/P1886) |

共同点：**每个元素最多进一次、出一次，均摊 O(n)**；都靠"破坏单调性时弹出"来得到答案。

---

## 易错点

1. **单调性方向**："下一个更大元素"用**递减栈**（栈顶最小），口诀记反会导致答案全错。
2. **存下标还是存值**：题目要求结果与位置相关（如宽度计算）时，务必存**下标**。
3. **单调队列弹出条件**：求最大值时是弹出 `<=` 当前值的（相等也弹，保证窗口里有更新的更大值）；求最小值则反向。
4. **窗口成型时机**：`i >= k - 1` 才开始记录，前 k-1 个元素窗口未满。
5. **过期判定**：队头下标 `<= i - k` 表示已滑出窗口，用 `while` 清理。
