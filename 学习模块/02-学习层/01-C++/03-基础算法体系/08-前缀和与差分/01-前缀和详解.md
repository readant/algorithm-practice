# 前缀和与差分

## 核心思想

**前缀和**：预处理前缀和，将区间和查询从 O(n) 优化为 O(1)
**差分数组**：将区间修改从 O(n) 优化为 O(1)

---

## 一维前缀和

```cpp
// 构建前缀和数组
vector<int> prefix(n + 1, 0);
for (int i = 0; i < n; i++) {
    prefix[i + 1] = prefix[i] + nums[i];
}

// 求 [l, r] 区间和
int rangeSum = prefix[r + 1] - prefix[l];
```

### 应用：和为 K 的子数组

```cpp
int subarraySum(vector<int>& nums, int k) {
    unordered_map<int, int> map;
    map[0] = 1;

    int sum = 0, count = 0;
    for (int num : nums) {
        sum += num;

        if (map.count(sum - k)) {
            count += map[sum - k];
        }
        map[sum]++;
    }

    return count;
}
```

## 差分数组

**核心思想**：将区间 [l, r] 加 v 操作，从 O(n) 优化为 O(1)

```cpp
// 差分数组
vector<int> diff(n + 1, 0);

// 区间 [l, r] 加 v
void add(int l, int r, int v) {
    diff[l] += v;
    diff[r + 1] -= v;
}

// 还原原数组
vector<int> result(n);
result[0] = diff[0];
for (int i = 1; i < n; i++) {
    result[i] = result[i - 1] + diff[i];
}
```

## 对比总结

| 数据结构 | 区间查询 | 区间修改 | 适用场景 |
|----------|----------|----------|----------|
| 原数组 | O(n) | O(1) | 单点修改 |
| 前缀和 | O(1) | O(n) | 只读查询 |
| 差分数组 | O(n) | O(1) | 大量区间修改 |
| 线段树 | O(log n) | O(log n) | 通用 |

---

## 适用场景

| 问题类型 | 推荐方法 |
|----------|----------|
| 区间和查询 | 前缀和 |
| 多次区间修改 | 差分数组 |
| 二维区间和 | 二维前缀和 |
| 子数组和为K | 前缀和 + 哈希表 |
