# 高精度算法（蓝桥杯 · 块2）

> 蓝桥杯等竞赛中处理超过 `long long` 范围的大整数运算。  
> 备赛主线：[备赛路线.md](../02-数据结构/备赛路线.md) · STL 基础：[A1-STL工具箱](../02-数据结构/A1-STL容器与算法（工具箱）.md)

---

## 1. 何时用

| 数据范围 | 做法 |
| :--- | :--- |
| ≤ `long long`（约 1e18） | 原生类型 |
| **超过** `long long`，或精确大整数运算 | **高精度**：用 `vector<int>` 或 `string` 模拟竖式 |

蓝桥杯常见：位数上千的加减乘、高精 × 低精、高精 ÷ 低精。

---

## 2. 总套路（四步）

1. **读入**：字符串读入  
2. **逆序存**：个位放 `a[0]`，方便进/借位  
3. **竖式计算**  
4. **去前导 0 + 逆序输出**

```cpp
vector<int> readNum() {
    string s; cin >> s;
    vector<int> a;
    for (int i = (int)s.size() - 1; i >= 0; i--) a.push_back(s[i] - '0');
    return a;
}

void printNum(const vector<int>& a) {
    int i = (int)a.size() - 1;
    while (i > 0 && a[i] == 0) i--;   // 去前导 0，至少保留一位
    for (; i >= 0; i--) cout << a[i];
    cout << '\n';
}
```

## 3. 高精度加法 A + B

**公式**：`t = A[i] + B[i] + t`；结果位 `t % 10`；进位 `t / 10`。

```cpp
vector<int> add(vector<int>& A, vector<int>& B) {
    vector<int> C;
    int t = 0;
    for (int i = 0; i < (int)A.size() || i < (int)B.size() || t; i++) {
        if (i < (int)A.size()) t += A[i];
        if (i < (int)B.size()) t += B[i];
        C.push_back(t % 10);
        t /= 10;
    }
    return C;
}
```

## 4. 高精度减法 A − B（先保证 A ≥ B）

**公式**：`t = A[i] − B[i] − t`；若 `t < 0` 则 `t += 10`，借位 `1`；否则借位 `0`。

```cpp
vector<int> sub(vector<int>& A, vector<int>& B) {
    vector<int> C;
    int t = 0;
    for (int i = 0; i < (int)A.size(); i++) {
        t = A[i] - t;
        if (i < (int)B.size()) t -= B[i];
        if (t < 0) { C.push_back(t + 10); t = 1; }
        else       { C.push_back(t);     t = 0; }
    }
    while ((int)C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}

// 若可能 A < B：先比较再决定 sub(B,A) 并输出负号
```

## 5. 高精度 × 低精 A × b（b 为 int/long long）

```cpp
vector<int> mul(vector<int>& A, int b) {
    vector<int> C;
    int t = 0;
    for (int i = 0; i < (int)A.size() || t; i++) {
        if (i < (int)A.size()) t += A[i] * b;
        C.push_back(t % 10);
        t /= 10;
    }
    while ((int)C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```

## 6. 高精度 ÷ 低精 A ÷ b（返回商，余数用引用）

**特点**：从**最高位**开始；余数 `r` 贯穿始终。

```cpp
vector<int> div(vector<int>& A, int b, int& r) {
    vector<int> C;
    r = 0;
    for (int i = (int)A.size() - 1; i >= 0; i--) {
        r = r * 10 + A[i];
        C.push_back(r / b);
        r %= b;
    }
    reverse(C.begin(), C.end());          // 先高位后低位，最后翻成低位在前
    while ((int)C.size() > 1 && C.back() == 0) C.pop_back();
    return C;                             // 余数在 r
}
```

## 7. 坑总表

| 坑 | 原因 | 做法 |
| :--- | :--- | :--- |
| 存成 `"123"` 顺序 | 进位在「高位增加」 | **逆序**存，个位在下标 0 |
| 减法前导 0 | 结果可能 `00123` | `while (C.back()==0 && C.size()>1) pop_back()` |
| 减法 A < B | 借位逻辑按 A≥B 写 | 比较长度/字典序，交换后打负号 |
| 除法方向 | 加减乘从低位，除从高位 | 从 `size-1` 递减，最后 `reverse` |
| b 过大 | 低精仍要能放下进位 | 注意 `b` 与中间量类型（必要时 `long long`） |
| 输出 | 多打印前导 0 | 统一用 `printNum` 逻辑 |
