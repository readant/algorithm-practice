# 字符串算法（KMP）

## 概述

字符串匹配是最经典的字符串问题：在文本串 `s` 中查找模式串 `p` 出现的所有位置。朴素做法逐位比较，最坏 **O(n × m)**；KMP 算法利用 **next 数组**（前缀函数）跳过无效比较，把复杂度降到 **O(n + m)**。

KMP 是"入门 → 进阶"的桥梁：掌握它之后，字符串类题目（自动机、AC 自动机）才有基础。

| 算法 | 时间复杂度 | 空间复杂度 | 适用场景 |
| ------ | ----------- | ----------- | --------- |
| 朴素匹配 | O(n × m) | O(1) | 文本很短 |
| **KMP** | **O(n + m)** | **O(m)** | 通用匹配、循环节判断 |
| strstr / find | 库函数 | — | 单次匹配（实现通常也是 KMP） |

---

## 一、朴素匹配的问题

```cpp
// 朴素匹配：文本 s，模式 p
for (int i = 0; i + p.size() <= s.size(); i++) {
    int j = 0;
    while (j < p.size() && s[i + j] == p[j]) j++;
    if (j == p.size()) 找到一处匹配（位置 i）;
}
```

每次失配都要把模式串**从头**开始，之前已经匹配的部分全被浪费。KMP 的核心：**利用已匹配部分的前后缀信息，失配时模式串只回退一小步，文本串永不回退**。

---

## 二、next 数组（前缀函数）

### 定义

`next[i]` = 模式串 `p[0..i]` 这个前缀中，**最长的相同真前缀和后缀的长度**。

```
模式串:  a b a b c
next[0] = 0            // 单字符无真前后缀
next[1] = 0            // "ab" 无相同前后缀
next[2] = 1            // "aba": 前缀 a == 后缀 a
next[3] = 2            // "abab": 前缀 ab == 后缀 ab
next[4] = 0            // "ababc" 无
```

### 求解代码

```cpp
vector<int> buildNext(const string& p) {
    int m = p.size();
    vector<int> next(m, 0);
    int j = 0;                                  // j = next 前缀长度（也是指针）
    for (int i = 1; i < m; i++) {
        while (j > 0 && p[i] != p[j]) j = next[j - 1];  // 失配回退
        if (p[i] == p[j]) j++;
        next[i] = j;
    }
    return next;
}
```

> 口诀：**求 next 的过程，就是在模式串自己身上做一次 KMP**。

## 三、KMP 匹配过程

```cpp
vector<int> kmpSearch(const string& s, const string& p) {
    vector<int> next = buildNext(p);
    vector<int> positions;
    int j = 0;
    for (int i = 0; i < s.size(); i++) {
        while (j > 0 && s[i] != p[j]) j = next[j - 1];  // 失配，p 回退
        if (s[i] == p[j]) j++;
        if (j == p.size()) {                            // 完全匹配
            positions.push_back(i - j + 1);             // 起点下标（0 基）
            j = next[j - 1];                            // 继续找下一个匹配
        }
    }
    return positions;
}
```

### 匹配过程模拟（s = "abababc", p = "ababc"）

| 步骤 | 文本指针 | 模式指针 | 动作 |
| ------ | --------- | --------- | ------ |
| 1 | i=0 | j=0 | a==a，j=1 |
| 2 | i=1 | j=1 | b==b，j=2 |
| 3 | i=2 | j=2 | a==a，j=3 |
| 4 | i=3 | j=3 | b==b，j=4 |
| 5 | i=4 | j=4 | a≠c，回退 j=next[3]=2 |
| 6 | i=4 | j=2 | a==a，j=3 |
| 7 | i=5 | j=3 | b==b，j=4 |
| 8 | i=6 | j=4 | c==c，j=5=len，匹配成功 |

## 四、经典应用：循环节

若字符串长度 `n`，`next[n-1] = k`，则：

- 最小循环节长度 = `n - k`
- 若 `n % (n - k) == 0`，则整个串由整数个循环节构成

```cpp
// 判断 s 是否由循环节构成（[P4391 无线传输](https://www.luogu.com.cn/problem/P4391) 的推论）
int cycleLen(const string& s) {
    int n = s.size();
    int k = buildNext(s)[n - 1];
    return n - k;   // 最小循环节长度
}
```

---

## 易错点

1. **next 数组下标语义**：`next[i]` 对应的是 `p[0..i]`，回退用 `next[j-1]`（不是 `next[j]`），这是最常见的 bug。
2. **边界**：`next[0] = 0`；`j > 0` 才允许回退，防止死循环。
3. **匹配完成后继续**：`j = next[j-1]` 再接着找，否则会漏掉重叠匹配（如 "aaaa" 中找 "aa"）。
4. **模式串为空**：提前特判，避免越界。
5. **next 构建与匹配代码几乎一致**：两者都遵循"失配回退 → 相同则前进"，可对比记忆。
