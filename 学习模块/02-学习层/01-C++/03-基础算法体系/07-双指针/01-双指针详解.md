# 双指针

## 核心思想

用两个指针遍历数组/链表，将 O(n²) 的暴力解法优化为 O(n)。

---

## 三种变体

### 1. 快慢指针

**场景**：链表环检测、找中间节点

```cpp
// 判断链表是否有环
bool hasCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;

    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast) return true;
    }
    return false;
}

// 找链表中间节点
ListNode* middleNode(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}
```

### 2. 对撞指针

**场景**：已排序数组、两数之和

```cpp
// 两数之和（已排序数组）
vector<int> twoSum(vector<int>& numbers, int target) {
    int left = 0, right = numbers.size() - 1;

    while (left < right) {
        int sum = numbers[left] + numbers[right];

        if (sum == target) return {left + 1, right + 1};
        else if (sum < target) left++;
        else right--;
    }
    return {};
}
```

### 3. 同向指针（滑动窗口基础）

**场景**：去重、子数组

```cpp
// 移除有序数组中的重复项
int removeDuplicates(vector<int>& nums) {
    if (nums.empty()) return 0;

    int slow = 0;
    for (int fast = 1; fast < nums.size(); fast++) {
        if (nums[fast] != nums[slow]) {
            slow++;
            nums[slow] = nums[fast];
        }
    }
    return slow + 1;
}
```

---

## 对比总结

| 变体 | 指针移动方向 | 典型应用 |
|------|-------------|----------|
| 快慢指针 | 同向，速度不同 | 链表环、中间节点 |
| 对撞指针 | 相向而行 | 两数之和、回文判断 |
| 同向指针 | 同向，同步移动 | 去重、子数组问题 |

---

## 适用场景

| 问题类型 | 是否适用 |
|----------|----------|
| 已排序数组 | ✅ 对撞指针 |
| 链表问题 | ✅ 快慢指针 |
| 子数组/子串 | ✅ 同向指针 |
| 无序数组 | ❌ 先排序再用 |
| 三维及以上 | ❌ 不适用 |
