# 离散化

## 概述

离散化（坐标压缩）把**值域很大、但个数很少**的数据映射到连续的整数区间。本质是"只关心数据之间的**大小关系**，不关心具体数值"。

**典型场景**：数值范围 `1e9`，但只有 `n ≤ 1e5` 个不同的数。直接开 1e9 的数组不现实，离散化后只需 1e5 的空间。

| 数据 | 原值域 | 离散化后 |
|------|--------|---------|
| [100, 50, 200, 50] | 0 ~ 200 | [2, 1, 3, 1] |
| [1e9, 1, 5e8] | 1 ~ 1e9 | [3, 1, 2] |

---

## 一、标准做法（sort + unique + lower_bound）

```cpp
vector<int> discretize(vector<int>& nums) {
    vector<int> sorted = nums;
    sort(sorted.begin(), sorted.end());
    sorted.erase(unique(sorted.begin(), sorted.end()), sorted.end());  // 去重

    vector<int> result;
    for (int x : nums)
        result.push_back(lower_bound(sorted.begin(), sorted.end(), x) - sorted.begin());
    return result;
}
// 例: [100, 50, 200, 50] -> [1, 0, 2, 0]
```

### 三个步骤拆解

1. **排序**：得到值的大小顺序；
2. **去重**（`unique` + `erase`）：相同的值映射到同一个下标；
3. **二分查找**（`lower_bound`）：原值 → 排名（0 基下标）。

---

## 二、为什么需要离散化

### 场景 1：开不了的大数组

区间覆盖问题（如 [P1496 火烧赤壁](https://www.luogu.com.cn/problem/P1496)）：坐标范围 1e9，实际只有 n 个点。把端点离散化后再差分/标记。

### 场景 2：只关心相对大小

- 求"比 x 大的数有几个"（配合树状数组/线段树）
- 逆序对统计（值域压缩后开树状数组）
- 哈希表的值域优化

---

## 三、离散化 + 差分（区间覆盖经典组合）

```cpp
// 坐标压缩 + 差分：求被覆盖的总长度
// 1. 收集所有端点 -> sort + unique -> 映射
// 2. 在压缩后的下标上做差分
// 3. 前缀和还原，累加覆盖长度（注意原坐标差）
```

离散化常用于把"区间题"压缩到可开数组的规模，是许多进阶题目的前置步骤。

---

## 复杂度分析

| 步骤 | 时间复杂度 |
|------|-----------|
| 排序 | O(n log n) |
| 去重 | O(n) |
| 逐元素 lower_bound | O(n log n) |
| 总计 | O(n log n) |

---

## 易错点

1. **必须先排序再 unique**：`unique` 只能去除相邻重复，乱序数组直接 unique 无效。
2. **unique 不真正删除元素**：`unique` 返回新的逻辑结尾，必须配合 `erase` 截断。
3. **离散化后丢失原值**：需要原值参与计算（如长度、面积）时，保留一份原数组或端点映射表。
4. **保序性**：`lower_bound` 得到的下标就是排名，保证原来小的数映射后仍然小。
5. **去重后大小**：`sorted.size()` 即不同值的个数，新数组下标范围 0 ~ size-1。
