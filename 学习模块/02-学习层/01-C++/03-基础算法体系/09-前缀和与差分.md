# 前缀和与差分

## 概述

前缀和与差分是一对**互逆**的预处理技巧，解决两类高频问题：

| 技巧 | 解决的问题 | 效果 |
| ------ | ----------- | ------ |
| 前缀和 | 频繁**查询**区间和 | 单次查询 O(1) |
| 差分数组 | 频繁**修改**区间 | 单次修改 O(1) |

核心思想：**预处理一个数组，把"查询/修改"的时间摊到"预处理"上**。

---

## 一、一维前缀和

### 原理

`prefix[i]` 表示原数组前 i 个元素的和（**下标从 1 开始**，`prefix[0] = 0` 哨兵）。

```
prefix[i] = prefix[i-1] + nums[i-1]
区间 [l, r] 的和 = prefix[r+1] - prefix[l]
```

### 代码模板

```cpp
vector<int> buildPrefix(const vector<int>& nums) {
    int n = nums.size();
    vector<int> prefix(n + 1, 0);
    for (int i = 0; i < n; i++)
        prefix[i + 1] = prefix[i] + nums[i];
    return prefix;
}

// 查询 [l, r] 区间和（0 下标），O(1)
int rangeSum(const vector<int>& prefix, int l, int r) {
    return prefix[r + 1] - prefix[l];
}
```

> 关键：`prefix` 长度是 `n+1`，`prefix[i]` 存前 i 个（nums[0..i-1]）。这样 `prefix[r+1] - prefix[l]` 天然避开下标边界问题。

## 二、二维前缀和

### 原理

`sum[i][j]` 表示左上角 `(0,0)` 到 `(i-1,j-1)` 的矩形和，用**容斥原理**递推和查询：

```
sum[i][j] = sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1] + a[i-1][j-1]
矩形 (x1,y1)-(x2,y2) 的和 = sum[x2+1][y2+1] - sum[x1][y2+1] - sum[x2+1][y1] + sum[x1][y1]
```

### 代码模板

```cpp
vector<vector<int>> buildPrefix2D(const vector<vector<int>>& a) {
    int n = a.size(), m = a[0].size();
    vector<vector<int>> sum(n + 1, vector<int>(m + 1, 0));
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            sum[i][j] = sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1] + a[i-1][j-1];
    return sum;
}
```

## 三、一维差分

### 原理

差分数组 `diff[i] = a[i] - a[i-1]`（`diff[0] = a[0]`）。对区间 `[l, r]` 整体加 `v`，只需：

```
diff[l] += v;      // 从 l 开始生效
diff[r+1] -= v;    // 在 r+1 处抵消
```

最后对 `diff` 求**前缀和**还原原数组。

### 代码模板

```cpp
// 对 nums 的 [l, r]（0 下标）区间加 v，共 m 次操作
vector<int> rangeAdd(int n, vector<pair<int,int>> ops, int v) {
    vector<int> diff(n + 1, 0);          // 多开一个位置存 r+1
    for (auto [l, r] : ops) {
        diff[l] += v;
        diff[r + 1] -= v;
    }
    vector<int> result(n);
    int cur = 0;
    for (int i = 0; i < n; i++) {
        cur += diff[i];                  // 前缀和还原
        result[i] = cur;
    }
    return result;
}
```

### 经典应用

- 区间整体加/减（数组、棋盘、灯泡开关）
- 一维：[P1047 校门外的树](https://www.luogu.com.cn/problem/P1047)、[P3397 地毯](https://www.luogu.com.cn/problem/P3397)
- 差分 + 贪心求最大重叠区间数

## 四、前缀和 vs 差分对比

| 数据结构 | 区间查询 | 区间修改 | 典型场景 |
| ---------- | --------- | --------- | --------- |
| 前缀和 | O(1) | O(n) | 多次查询区间和，数据不变 |
| 差分数组 | O(n)（需还原） | O(1) | 多次区间修改，最后一次性查询 |
| 树状数组 | O(log n) | O(log n) | 查询和修改混合（进阶内容，暂不展开） |

> 口诀：**查询多用前缀和，修改多用差分**。两者混合高频交替时，再引入树状数组 / 线段树。

---

## 易错点

1. **下标从 1 开始**：前缀和数组长度是 n+1，`prefix[0]=0` 是哨兵，写错下标会导致边界错误。
2. **差分还原顺序**：`cur += diff[i]` 是前缀和，不是 `diff[i] += diff[i-1]` 之外再额外操作；最后结果长度是 n，但 diff 要开到 n+1。
3. **二维容斥符号**：`sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1]`，加多了要减回来，少减多加。
4. **差分越界**：`diff[r+1] -= v` 中 r 是数组末尾时，`r+1 = n`，所以 diff 必须开到 n+1。
5. **区间是左闭右闭**：`[l, r]` 含两端，计算长度是 `r - l + 1`。
