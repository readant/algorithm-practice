# 通用技巧

## 概述

这些技巧是算法竞赛中的常用工具，掌握它们能大幅提升解题效率。

## 1. 双指针

**核心思想**：用两个指针遍历数组，减少嵌套循环

### 快慢指针

```cpp
// 判断链表是否有环
bool hasCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        
        if (slow == fast) return true;
    }
    return false;
}
```

### 对撞指针

```cpp
// 两数之和（已排序数组）
vector<int> twoSum(vector<int>& numbers, int target) {
    int left = 0, right = numbers.size() - 1;
    
    while (left < right) {
        int sum = numbers[left] + numbers[right];
        
        if (sum == target) return {left + 1, right + 1};
        else if (sum < target) left++;
        else right--;
    }
    return {};
}
```

## 2. 前缀和

**核心思想**：预处理前缀和，快速求区间和

```cpp
// 一维前缀和
vector<int> prefix(n + 1, 0);
for (int i = 0; i < n; i++) {
    prefix[i + 1] = prefix[i] + nums[i];
}

// 求 [l, r] 区间和
int rangeSum = prefix[r + 1] - prefix[l];
```

### 应用：和为K的子数组

```cpp
int subarraySum(vector<int>& nums, int k) {
    unordered_map<int, int> map;
    map[0] = 1;
    
    int sum = 0, count = 0;
    for (int num : nums) {
        sum += num;
        
        if (map.count(sum - k)) {
            count += map[sum - k];
        }
        map[sum]++;
    }
    
    return count;
}
```

## 3. 滑动窗口

**核心思想**：维护一个窗口，动态调整左右边界

```cpp
// 最长无重复子串
int lengthOfLongestSubstring(string s) {
    unordered_map<char, int> map;
    int maxLen = 0;
    int left = 0;
    
    for (int right = 0; right < s.size(); right++) {
        if (map.count(s[right])) {
            left = max(left, map[s[right]] + 1);
        }
        
        map[s[right]] = right;
        maxLen = max(maxLen, right - left + 1);
    }
    
    return maxLen;
}
```

### 模板

```cpp
int slidingWindow(vector<int>& nums, int k) {
    int left = 0, windowSum = 0, result = 0;
    
    for (int right = 0; right < nums.size(); right++) {
        // 扩大窗口
        windowSum += nums[right];
        
        // 收缩窗口
        while (right - left + 1 > k) {
            windowSum -= nums[left];
            left++;
        }
        
        // 更新答案
        if (right - left + 1 == k) {
            result = max(result, windowSum);
        }
    }
    
    return result;
}
```

## 4. 离散化

**核心思想**：将大范围映射到小范围，方便处理

```cpp
// 将数组离散化
vector<int> discretize(vector<int>& nums) {
    vector<int> sorted = nums;
    sort(sorted.begin(), sorted.end());
    sorted.erase(unique(sorted.begin(), sorted.end()), sorted.end());
    
    vector<int> result;
    for (int x : nums) {
        result.push_back(lower_bound(sorted.begin(), sorted.end(), x) - sorted.begin());
    }
    
    return result;
}

// 例: [100, 50, 200, 50] -> [1, 0, 2, 0]
```

## 6. 单调栈

**核心思想**：维护一个单调递增/递减的栈

```cpp
// 下一个更大元素
vector<int> nextGreaterElement(vector<int>& nums) {
    int n = nums.size();
    vector<int> result(n, -1);
    stack<int> stk;
    
    for (int i = 0; i < n; i++) {
        while (!stk.empty() && nums[stk.top()] < nums[i]) {
            result[stk.top()] = nums[i];
            stk.pop();
        }
        stk.push(i);
    }
    
    return result;
}
```

## 7. 并查集

**核心思想**：处理动态连通性问题

```cpp
class UnionFind {
private:
    vector<int> parent, rank;
    
public:
    UnionFind(int n) : parent(n), rank(n, 0) {
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);  // 路径压缩
        }
        return parent[x];
    }
    
    void unite(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return;
        
        if (rank[px] < rank[py]) swap(px, py);
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
    }
    
    bool connected(int x, int y) {
        return find(x) == find(y);
    }
};
```
