# 桶模型（映射统计）：数值即数组下标

## 核心思想

不要把数值仅仅看作数据，要把数值看作是 **数组的地址**。建立一种`数值 -> 数组下标`的直接映射关系。

## 实现技巧

创建一个稍大于数据范围的数组，用数组的值作为索引。

## 前提约定

数据范围`0 ~1000`，桶数组`bucket[1001]`,初始全0

```cpp
const int MAXN = 1000;
int bucket[MAXN + 1] = {0};
```

## 核心代码

读入数据，构成桶

```cpp
int bucket[1001] = {0};
int x;
while(cin >> x) {
    bucket[x]++;   // 数字x出现了，对应的‘抽屉’加一个计数
}
```

## 应用场景

- 统计数字频次：`bucket[x]` 表示数字 x 出现的次数

```cpp
int x;
cin >> x;
cout << x << "一共出现：" << bucket[x] << "次\n";
```

- 判断某个数是否出现过： `if(bucket[x] > 0)`

```cpp
int x;
cin >> x;
if(bucket[x] > 0) {
    cout << x << "出现过\n";
}
else {
    cout << x << "没有出现过\n";
}
```

- 去重输出：从小到大输出，只输出一次`bucket[i]>0`的i,每次只打印一次，天然升序

```cpp
for(int i = 0; i <= MAXN; i++) {
    if(bucket[i] > 0) {
        cout << i << " ";
    }
}
```

- 升序排序：从小到大遍历i，循环输出i共`bucket[i]`次(桶计数排序核心)

```cpp
for(int i = 0; i <= MAXN; i++) {
    // i出现的次数，就打印i
    for(int j = 0; j < bucket[i]; j++) {
        cout << i << " ";
    }
}
```
