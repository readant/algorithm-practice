# 滑动窗口

## 核心思想

维护一个窗口 [left, right]，动态调整左右边界，将 O(n²) 优化为 O(n)。

---

## 两种类型

### 1. 固定窗口

**场景**：窗口大小固定为 k

```cpp
// 固定窗口模板
int fixedWindow(vector<int>& nums, int k) {
    int left = 0, windowSum = 0, result = 0;

    for (int right = 0; right < nums.size(); right++) {
        // 扩大窗口
        windowSum += nums[right];

        // 收缩窗口（固定大小）
        if (right - left + 1 > k) {
            windowSum -= nums[left];
            left++;
        }

        // 更新答案
        if (right - left + 1 == k) {
            result = max(result, windowSum);
        }
    }

    return result;
}
```

### 2. 可变窗口

**场景**：窗口大小动态调整

```cpp
// 可变窗口模板
int variableWindow(vector<int>& nums, int target) {
    int left = 0, windowSum = 0, result = 0;

    for (int right = 0; right < nums.size(); right++) {
        // 扩大窗口
        windowSum += nums[right];

        // 收缩窗口（满足条件时）
        while (windowSum >= target) {
            result = max(result, right - left + 1);
            windowSum -= nums[left];
            left++;
        }
    }

    return result;
}
```

## 经典应用

### 最长无重复子串

```cpp
int lengthOfLongestSubstring(string s) {
    unordered_map<char, int> map;
    int maxLen = 0;
    int left = 0;

    for (int right = 0; right < s.size(); right++) {
        if (map.count(s[right])) {
            left = max(left, map[s[right]] + 1);
        }

        map[s[right]] = right;
        maxLen = max(maxLen, right - left + 1);
    }

    return maxLen;
}
```

### 最小覆盖子串

```cpp
string minWindow(string s, string t) {
    unordered_map<char, int> need, window;
    for (char c : t) need[c]++;

    int left = 0, valid = 0;
    int start = 0, len = INT_MAX;

    for (int right = 0; right < s.size(); right++) {
        char c = s[right];
        if (need.count(c)) {
            window[c]++;
            if (window[c] == need[c]) valid++;
        }

        while (valid == need.size()) {
            if (right - left + 1 < len) {
                start = left;
                len = right - left + 1;
            }
            char d = s[left];
            left++;
            if (need.count(d)) {
                if (window[d] == need[d]) valid--;
                window[d]--;
            }
        }
    }

    return len == INT_MAX ? "" : s.substr(start, len);
}
```

## 模板总结

```
for (right = 0; right < n; right++) {
    1. 扩大窗口：加入 nums[right]

    while (窗口需要收缩) {
        2. 收缩窗口：移除 nums[left]
        3. left++
    }

    4. 更新答案
}
```

## 适用场景

| 问题类型 | 窗口类型 |
|----------|----------|
| 固定大小子数组 | 固定窗口 |
| 最长/最短子串 | 可变窗口 |
| 子数组和 ≥ K | 可变窗口 |
| 字符串包含 | 可变窗口 |
