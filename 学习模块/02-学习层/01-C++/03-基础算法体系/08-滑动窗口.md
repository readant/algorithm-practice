# 滑动窗口

## 概述

滑动窗口是**同向双指针**的进阶应用：用两个指针 `left`、`right` 维护一个区间（窗口），`right` 负责"扩张"，`left` 负责"收缩"，窗口始终满足某个条件。适合解决 **子数组 / 子串** 的连续区间问题，把 O(n²) 暴力降为 **O(n)**。

核心思想：**窗口右端每次只移动一步，左端按需收缩，保证每个元素最多进窗一次、出窗一次**。

---

## 一、定长窗口 vs 变长窗口

| 类型 | 窗口大小 | 典型问题 | 解法 |
|------|---------|---------|------|
| 定长窗口 | 固定为 k | 大小为 k 的子数组最大/最小和 | 先初始化前 k 个，再每次滑动一格 |
| 变长窗口 | 不固定 | 和 ≥ target 的最短子数组 | 条件不满足时收缩 left |

### 定长窗口模板：大小为 k 的最大子数组和

```cpp
int maxSumFixedWindow(vector<int>& nums, int k) {
    int n = nums.size();
    if (n < k) return -1;
    int windowSum = 0;
    for (int i = 0; i < k; i++) windowSum += nums[i];  // 初始化窗口
    int maxSum = windowSum;
    for (int i = k; i < n; i++) {
        windowSum += nums[i] - nums[i - k];            // 滑入一个，滑出一个
        maxSum = max(maxSum, windowSum);
    }
    return maxSum;
}
```

### 变长窗口模板：最短子数组（和 ≥ target）

```cpp
int minSubArrayLen(vector<int>& nums, int target) {
    int left = 0, windowSum = 0, result = INT_MAX;
    for (int right = 0; right < nums.size(); right++) {
        windowSum += nums[right];          // 右指针扩张
        while (windowSum >= target) {      // 条件满足，尝试收缩
            result = min(result, right - left + 1);
            windowSum -= nums[left];       // 左指针收缩
            left++;
        }
    }
    return result == INT_MAX ? 0 : result;
}
```

## 二、经典应用：最长无重复子串

用哈希表记录每个字符最后出现的位置，出现重复时直接把 `left` 跳到重复字符的下一个位置。

```cpp
int lengthOfLongestSubstring(string s) {
    unordered_map<char, int> lastPos;
    int maxLen = 0, left = 0;
    for (int right = 0; right < s.size(); right++) {
        if (lastPos.count(s[right])) {
            left = max(left, lastPos[s[right]] + 1);  // 收缩到不重复
        }
        lastPos[s[right]] = right;
        maxLen = max(maxLen, right - left + 1);
    }
    return maxLen;
}
```

> 注意 `left = max(left, ...)` 而不是直接赋值：防止 `lastPos` 中的旧位置比当前 `left` 还靠左，导致窗口倒退。

## 三、滑动窗口与单调队列的区别

| | 滑动窗口 | 单调队列 |
|--|---------|---------|
| 解决的问题 | 窗口内**和 / 计数 / 满足条件** | 窗口内**最大值 / 最小值** |
| 数据结构 | 双指针 + 哈希/计数 | 双端队列 deque |
| 典型题 | 最大子数组和、无重复子串 | [P1886 滑动窗口](https://www.luogu.com.cn/problem/P1886) |

求**窗口最值**时滑动窗口不够用，必须上单调队列，见 [10-单调栈与单调队列.md](10-单调栈与单调队列.md)。

## 复杂度分析

| 类型 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 定长窗口 | O(n) | O(1) |
| 变长窗口 | O(n) | O(1) 或 O(字符集大小) |

每个元素最多被 `right` 进入一次、被 `left` 弹出一次，均摊 O(n)。

---

## 易错点

1. **初始化窗口**：定长窗口先计算前 k 个，再开始滑动，否则漏掉第一个窗口。
2. **收缩时机**：变长窗口是 `while` 循环收缩（可能一次收缩多个），不是 `if`。
3. **left 倒退**：最长无重复子串中必须用 `left = max(left, ...)`。
4. **窗口合法性**：收缩后 `left` 可能超过 `right`，保证 `result` 计算只在窗口有效时进行。
5. **数据类型**：`INT_MAX` 作为初始结果时，注意无解情况要返回 0（见模板）。
