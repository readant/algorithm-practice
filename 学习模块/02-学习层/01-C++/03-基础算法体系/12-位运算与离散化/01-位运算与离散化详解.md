# 位运算与离散化

## 1. 位运算技巧

### 基础操作

```cpp
// 判断奇偶
if (n & 1) { /* 奇数 */ }

// 除以2
n >>= 1;

// 乘以2
n <<= 1;

// 交换两个数（不用临时变量）
a ^= b; b ^= a; a ^= b;

// 判断是否是2的幂
bool isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;
}
```

### 位操作应用

```cpp
// 取第k位 (0-indexed)
int bit = (n >> k) & 1;

// 设置第k位为1
n |= (1 << k);

// 清除第k位
n &= ~(1 << k);

// 翻转第k位
n ^= (1 << k);

// 统计1的个数
int count = __builtin_popcount(n);
```

### 状态压缩

```cpp
// 用整数表示集合
int mask = 0;
mask |= (1 << i);   // 添加元素i
mask &= ~(1 << i);  // 删除元素i
mask ^= (1 << i);   // 翻转元素i
if (mask & (1 << i)) // 判断元素i是否存在

// 遍历所有子集
for (int sub = mask; sub; sub = (sub - 1) & mask) {
    // sub 是 mask 的一个非空子集
}
```

## 2. 离散化

### 核心思想

将大范围值映射到小范围，便于用数组处理。

```cpp
vector<int> discretize(vector<int>& nums) {
    vector<int> sorted = nums;
    sort(sorted.begin(), sorted.end());
    sorted.erase(unique(sorted.begin(), sorted.end()), sorted.end());

    vector<int> result;
    for (int x : nums) {
        result.push_back(lower_bound(sorted.begin(), sorted.end(), x) - sorted.begin());
    }

    return result;
}

// 例: [100, 50, 200, 50] -> [1, 0, 2, 0]
```

### 应用：区间覆盖

```cpp
// 离散化坐标
vector<int> coords = {1, 5, 10, 100, 1000};
sort(coords.begin(), coords.end());
coords.erase(unique(coords.begin(), coords.end()), coords.end());

// 用 lower_bound 找到坐标对应的索引
int idx = lower_bound(coords.begin(), coords.end(), x) - coords.begin();
```
