# 位运算

## 概述

位运算是直接操作二进制位的高效技巧，比算术运算快得多。它在**奇偶判断、集合操作、状态压缩、哈希散列**等场景有奇效，是竞赛中"卡常"和优化暴力的常用手段。

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `&` | 按位与 | `5 & 3 = 1`（101 & 011） |
| `\|` | 按位或 | `5 \| 3 = 7` |
| `^` | 按位异或 | `5 ^ 3 = 6` |
| `~` | 按位取反 | `~5 = -6` |
| `<<` | 左移（×2^k） | `1 << 3 = 8` |
| `>>` | 右移（÷2^k） | `8 >> 2 = 2` |

---

## 一、常用技巧速查

```cpp
if (n & 1) { }              // 判断奇偶（n 的二进制最后一位）
n >>= 1;                    // 除以 2
n <<= 1;                    // 乘以 2
(n & (n - 1)) == 0          // 判断 2 的幂（消去最低位的 1）
(n >> k) & 1                // 取第 k 位（0 基）
n |= (1 << k)               // 设置第 k 位为 1
n &= ~(1 << k)              // 清除第 k 位（置 0）
n ^= (1 << k)               // 翻转第 k 位
lowbit(x) = x & (-x)        // 取出最低位的 1（树状数组核心）
```

### 异或的重要性质（重点）

```
a ^ 0 = a        // 与 0 异或不变
a ^ a = 0        // 与自己异或为 0（自我抵消）
a ^ b = b ^ a    // 交换律
a ^ b ^ a = b    // 消去相同项
```

**经典应用：找出现奇数次的数** —— 把所有数异或一遍，成对的数全部抵消，剩下的就是答案。

## 二、状态压缩（状压 DP 入门）

用一个整数的二进制位表示一组布尔状态，`第 i 位 = 1` 表示选中第 i 个元素。

```cpp
int mask = 0;
mask |= (1 << i);            // 添加元素 i
mask &= ~(1 << i);           // 删除元素 i
mask ^= (1 << i);            // 翻转元素 i
(mask >> i) & 1              // 查询元素 i 是否在集合中
mask & (-mask)               // 最低位的 1（取出一个元素）
```

状态压缩是"集合型 DP"（旅行商、子集划分）的基础，进阶见 [04-进阶算法体系/01-动态规划基础.md](../04-进阶算法体系/01-动态规划基础.md)。

## 三、枚举子集技巧

```cpp
// 枚举 mask 的所有非空子集 sub
for (int sub = mask; sub; sub = (sub - 1) & mask) {
    // 处理子集 sub
}
```

这是状压 DP 中枚举子集的标准写法，复杂度 O(3^n)。

## 易错点

1. **运算符优先级**：`&`、`|`、`^` 的优先级低于 `==`、`!=`，判断时务必加括号，如 `if ((n & 1) == 0)`。
2. **负数移位**：右移负数是算术右移（补符号位），与直觉不同，尽量避免对负数做移位。
3. **int 溢出**：`1 << 31` 会溢出为负数，需要 long long 时用 `1LL << k`。
4. **异或混淆**：异或不是"取反"，`~x` 才是按位取反；异或满足交换律和结合律但**没有"幂等"性质**（`a^a=0` 不是 `a`）。
5. **n & (n-1)** 用途：消去最低位的 1，可用于统计二进制中 1 的个数（循环直到 n=0）。
