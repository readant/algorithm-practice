# 双指针

> 双指针不是真的"指针"，就是**两个数组下标**。
> 它的价值在于：把暴力解法的两层循环 **O(n²)** 压成一遍扫描 **O(n)**。

| 模型 | 两个指针怎么动 | 前提 | 典型 |
| :-- | :-- | :-- | :-- |
| **对撞指针** | 一个从左、一个从右，向中间靠 | 数组**有序** | 两数之和、回文判断、三数之和 |
| **快慢指针** | 同向，速度不同 | 无 | 去重、找中点、判环 |
| **滑动窗口** | 右指针扩张、左指针收缩 | 无（但要有单调性） | 最长不重复子串、最短覆盖区间 |

---

## 一、核心算法模型

### 1. 对撞指针：两头往中间夹

#### 1.1 核心思想

数组**有序**时，"和太大"和"和太小"能明确告诉你要动哪一边：

```
sum = a[left] + a[right]
sum 太大  →  left 太小或 right 太大  →  right 左移（让和变小）
sum 太小  →  left 右移（让和变大）
```

这就是为什么**必须有序**——无序你就不知道该动哪边。

#### 1.2 例题：两数之和（有序数组）

**题意**：有序数组里找两个数，和等于 target。

```cpp
#include <iostream>
using namespace std;

int a[100005];

int main() {
    int n, target;
    cin >> n >> target;
    for (int i = 0; i < n; i++) cin >> a[i];

    int left = 0, right = n - 1;
    while (left < right) {
        int sum = a[left] + a[right];
        if (sum == target) {
            cout << left << " " << right << "\n";
            return 0;
        } else if (sum < target) {
            left++;              // 和小了 → 左指针右移（值变大）
        } else {
            right--;             // 和大了 → 右指针左移（值变小）
        }
    }
    cout << "-1 -1\n";           // 没找到
    return 0;
}
```

**为什么这样不会漏解**：每次移动都是"排除一批不可能的答案"。
`right--` 排除的是"以当前 right 结尾的所有组合"——因为它们只会更小。

**复杂度**：每个元素最多被访问一次，**O(n)**。暴力是 O(n²)。

#### 1.3 变体：回文判断

```cpp
bool isPalindrome(const string& s) {
    int left = 0, right = (int)s.size() - 1;
    while (left < right) {
        if (s[left] != s[right]) return false;
        left++;
        right--;
    }
    return true;
}
```

> 注意这里 `right` 不需要在循环里额外判断，因为 `left < right` 已经保证不越界。

### 2. 快慢指针：同向，速度不同

#### 2.1 核心思想

两个指针都从左边出发，但一个走得快、一个走得慢。**慢指针记录"结果写到哪"，快指针负责"扫描源数据"**。

#### 2.2 例题：数组去重（原地）

**题意**：有序数组去掉重复元素，返回新长度，要求原地修改。

```cpp
int removeDuplicates(int a[], int n) {
    if (n == 0) return 0;
    int slow = 0;                        // 指向"最后一个有效位置"
    for (int fast = 1; fast < n; fast++) {
        if (a[fast] != a[slow]) {        // 发现新的不同元素
            slow++;
            a[slow] = a[fast];           // 写到 slow 后面
        }
    }
    return slow + 1;                     // 长度
}
```

**为什么有效**：`slow` 之前全是"已经处理好的不重复部分"，
`fast` 扫过的地方要么被复制、要么被丢弃。**一趟扫描，O(n)。**

#### 2.3 变体：找中点（链表常用）

```cpp
// 快指针走两步，慢指针走一步，快的到终点时慢的正好在中间
while (fast != NULL && fast->next != NULL) {
    slow = slow->next;
    fast = fast->next->next;
}
// slow 就是中点
```

### 3. 滑动窗口：右扩左缩

#### 3.1 核心思想

维护一个**区间** `[left, right]`，右指针负责**扩张**（纳入新元素），
左指针负责**收缩**（排除不满足的元素）。

```
right 一直往右走，每一步把 a[right] 加进窗口
如果窗口不满足条件，就 left++ 直到重新满足
每次满足时更新答案
```

**关键**：`right` 只前进不后退，`left` 也只前进不后退 → 总共 O(n) 次移动。

#### 3.2 例题：最长不含重复字符的子串

**题意**：给一个字符串，找最长的一段，里面没有重复字符。

```cpp
#include <iostream>
#include <string>
using namespace std;

int cnt[256];               // 每个字符在窗口里出现的次数

int main() {
    string s;
    cin >> s;

    int ans = 0;
    int left = 0;
    for (int right = 0; right < (int)s.size(); right++) {
        cnt[(unsigned char)s[right]]++;         // ① 右端纳入窗口

        while (cnt[(unsigned char)s[right]] > 1) {   // ② 出现重复了
            cnt[(unsigned char)s[left]]--;           // 左端移出窗口
            left++;
        }

        if (right - left + 1 > ans) {           // ③ 更新答案
            ans = right - left + 1;
        }
    }
    cout << ans << "\n";
    return 0;
}
```

**三个必看点**：

1. **`while` 而不是 `if`**：重复的字符可能不止一个，要一直收缩到不重复
2. **窗口长度 = `right - left + 1`**（两端都含）
3. **`cnt` 要跟着 left 的移动同步减少**，否则状态和窗口对不上

#### 3.3 变体：定长窗口

求"连续 k 个数的最大和"这种，窗口长度固定，就不用 `while` 收缩，直接滑：

```cpp
int sum = 0;
for (int i = 0; i < k; i++) sum += a[i];       // 第一个窗口
int best = sum;
for (int i = k; i < n; i++) {
    sum += a[i] - a[i - k];                    // 进一个、出一个
    if (sum > best) best = sum;
}
```

> 定长窗口其实就是**前缀和**的另一种写法，两者等价。用哪个看哪个顺手。

### 怎么选

1. **数组有序，找两个数 / 判断回文** → 对撞指针
2. **原地去重、找中点、判环** → 快慢指针
3. **求"最长/最短的满足条件的连续区间"** → 滑动窗口
4. **窗口长度固定** → 直接滑，或用前缀和

## 二、必须掌握的"编程利器"

| 利器 | 怎么用 | 为什么重要 |
| :-- | :-- | :-- |
| **`while (left < right)`** | 对撞指针的循环条件 | 写成 `<=` 会把同一个元素用两次 |
| **`while` 收缩** | 滑动窗口里用 while 不用 if | 可能一次要收缩多步 |
| **计数数组** | `cnt[c]` 记录窗口内频率 | 判断窗口是否满足条件 |
| **原地修改** | `slow` 指向写入位置 | 省空间，O(1) 额外空间 |

```cpp
int left = 0, right = n - 1;         // 对撞
while (left < right) { ... }         // 注意是 <，不是 <=
```

## 三、初学者必踩的坑

**坑 1：循环条件写成 `left <= right`**

- 现象：对撞指针用过同一个元素，或出现诡异答案
- 原因：`left == right` 时两个指针指向同一个位置，"两个数"变成了同一个数
- 解决：对撞指针一律 `left < right`

**坑 2：滑动窗口用 `if` 代替 `while`**

- 现象：窗口里有重复却只收缩了一次，答案偏大
- 原因：一次移动可能只排出**一个**字符，但重复可能持续
- 解决：**收缩一律用 `while`**

**坑 3：窗口状态没同步更新**

- 现象：答案忽大忽小
- 原因：`left++` 时忘了把 `cnt[a[left]]--`
- 解决：移动指针和更新状态**写在同一个地方**，不要分开

**坑 4：无序数组上用对撞指针**

- 现象：漏解
- 原因：对撞指针依赖"有序 → 和的大小可以指导移动方向"
- 解决：先排序，或者改用哈希表 / 双循环

**坑 5：窗口长度算错**

- 现象：答案差 1
- 原因：`[left, right]` 两端都含，长度是 `right - left + 1`，不是 `right - left`
- 解决：用一个长度为 2 的小例子验证

## 四、学习建议

按 5 小时推进：

| 时段 | 题目 | 练什么 | 验收标准 |
| :-- | :-- | :-- | :-- |
| 第 1 小时 | 两数之和（有序） | 对撞指针 | 能解释"为什么可以排除一批答案" |
| 第 2 小时 | 回文判断 / 验证回文串 | 对撞指针 | 循环条件正确，不越界 |
| 第 3 小时 | 数组去重（原地） | 快慢指针 | 能说清 `slow` 的含义 |
| 第 4 小时 | 最长不重复子串 | 滑动窗口 | `while` 收缩，`cnt` 同步 |
| 第 5 小时 | 蓝桥真题：日志统计 / 统计子矩阵 | 综合 | 能判断这题该用哪种双指针 |

**每题验收动作**：

1. 说出这题属于**哪一种**双指针，为什么不是另外两种
2. 说出**两个指针各代表什么**（这是最容易讲不清的地方）
3. 对撞题：说出数组是否必须有序，为什么
4. 窗口题：说出 `while` 里在收缩什么条件

> 双指针是把 O(n²) 压成 O(n) 最常用的手法。**能说出"每个指针移动的理由"，这题就真懂了。**
