# 差分：两种维度

> 差分是前缀和的**逆运算**。
> 前缀和解决「频繁查询、不修改」；差分解决「频繁修改、最后统一查询」。

| 维度 | 操作 | 复杂度 | 用来做什么 |
| :-- | :-- | :-- | :-- |
| **一维** | `b[L] += c; b[R+1] -= c;` | 修改 O(1) | 给区间 [L,R] 整体加 c |
| **二维** | 四个角各加减一次 | 修改 O(1) | 给子矩阵整体加 c |
| **还原** | 对 `b` 求前缀和 | O(n) 或 O(n·m) | 得到修改后的原数组 |

---

## 一、核心算法模型

### 1. 一维差分：用两个操作代替一层循环

#### 1.1 问题是什么

给一个长度为 n 的数组，m 次操作，每次给区间 `[L, R]` 的每个元素加 `c`。
最后输出整个数组。

**暴力**：每次操作都 `for (i = L; i <= R; i++) a[i] += c;`
复杂度 `O(n·m)`。n=m=10⁵ 时是 10¹⁰，**必然超时**。

**差分的做法**：不管区间多长，**每次操作只改两个位置**。总复杂度 `O(n + m)`。

#### 1.2 差分数组怎么定义

`b[i] = a[i] - a[i-1]`（`b[1] = a[1]`）。

也就是说：**`b[i]` 存的是"第 i 个元素比前一个多多少"**。

#### 1.3 为什么 `b[L] += c; b[R+1] -= c;` 就够

关键在于**还原**时要做一次前缀和：

```
初始 a:    0   0   0   0   0   0
           b: 0   0   0   0   0   0

执行 b[2] += 5：
           b: 0   5   0   0   0   0
还原（前缀和）:
           a: 0   5   5   5   5   5     ← 从第 2 位开始，后面全变 5

再执行 b[5] -= 5：        （R = 4，所以 R+1 = 5）
           b: 0   5   0   0  -5   0
还原（前缀和）:
           a: 0   5   5   5   0   0     ← 第 5 位被抵消回 0
                    └──────┘
                   只看 [2, 4]，正好是 +5
```

**原理**：`b[L] += c` 让前缀和从 L 开始往后**全部** +c；
`b[R+1] -= c` 让前缀和从 R+1 开始往后**再减回去**。两者叠加，效果就**只落在 [L,R] 上**。

#### 1.4 标准代码

```cpp
#include <iostream>
using namespace std;

const int MAXN = 100005;
int a[MAXN], b[MAXN];       // b 是差分数组

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        b[i] = a[i] - a[i - 1];      // 构造差分
    }

    while (m--) {
        int l, r, c;
        cin >> l >> r >> c;
        b[l] += c;                   // 只需要两步
        b[r + 1] -= c;
    }

    // 还原：对 b 求前缀和
    for (int i = 1; i <= n; i++) {
        b[i] += b[i - 1];
        cout << b[i] << " ";
    }
    return 0;
}
```

> 注意最后是**原地还原 `b`**，不需要再开一个数组。还原完 `b[i]` 就是修改后的 `a[i]`。

#### 1.5 例题拆解：区间加法

**题意**：n 个数，m 次操作每次给 `[L,R]` 加 c，最后输出。

**为什么用差分**：m 次操作、n 个数，暴力的 `n×m` 会超时，而差分每次只要 2 次赋值。

**三个易错点**：

1. **`b[r+1] -= c` 里的 `r+1` 可能等于 `n+1`**，数组必须开到 `n+2`
2. **`b` 要在读入时构造**，不能全 0 直接用——除非原数组全是 0
3. **最后要还原**，直接输出 `b` 是错的

### 2. 二维差分：四个角

#### 2.1 问题

给一个 n×m 的矩阵，多次操作，每次给左上 `(x1,y1)` 到右下 `(x2,y2)` 的子矩阵整体加 c。

#### 2.2 四个角的作用

```cpp
b[x1][y1]         += c;   // 从左上角开始，向右下扩散
b[x1][y2 + 1]     -= c;   // 右边那列之后，抵消
b[x2 + 1][y1]     -= c;   // 下边那行之后，抵消
b[x2 + 1][y2 + 1] += c;   // 右下角被减了两次，补回来
```

**为什么是这四个**：二维前缀和会把 `(x1,y1)` 的影响扩散到它**右下方的全部区域**。
要把影响限制在矩形里，必须在**右边界外**和**下边界外**各减一次；
但右下角那块被减了两次，所以要加回来——**这就是容斥**。

```
      y1        y2+1
      ┌─────────┐
 x1   │  +c     │ -c      ← 右上角减
      │  目标   │
      └─────────┘
 x2+1 │  -c     │ +c      ← 右下角补
```

#### 2.3 还原：二维前缀和

```cpp
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        b[i][j] += b[i - 1][j] + b[i][j - 1] - b[i - 1][j - 1];
    }
}
```

> 还原公式和「二维前缀和」的构造公式**完全一样**，因为差分和前缀和互为逆运算。

### 3. 三种做法对比

| 做法 | 修改一次 | m 次修改后 | 适合 |
| :-- | :-- | :-- | :-- |
| **暴力** | O(区间长度) | O(n·m) | 数据很小时 |
| **差分** | **O(1)** | **O(n + m)** | 多次修改 + 最后统一查询 |
| **前缀和** | 不支持 | — | 不修改 + 多次查询 |

**一句话记**：

- **只查不改** → 前缀和
- **只改最后查** → 差分
- **边改边查** → 两个都不行，要树状数组 / 线段树

### 怎么选

1. **多次给区间加值，最后统一输出** → 一维差分
2. **多次给子矩阵加值，最后统一输出** → 二维差分
3. **一边修改一边查询** → 差分不行（每次查询要还原 O(n)），用树状数组

## 二、必须掌握的"编程利器"

| 利器 | 怎么用 | 为什么重要 |
| :-- | :-- | :-- |
| **数组多开 5** | `MAXN + 5` | `R+1` 会访问到 `n+1` |
| **`long long`** | 差分数组与还原都用 | 累加会超 `int` |
| **原地还原** | `b[i] += b[i-1]` | 不需要额外数组 |
| **先想"改几次"** | 判断 m 大不大 | 决定用暴力还是差分 |

```cpp
const int MAXN = 100005;
long long b[MAXN + 5];      // 多开 5，防止 r+1 越界
```

## 三、初学者必踩的坑

**坑 1：`r+1` 越界**

- 现象：RE，或最后一个元素结果错误
- 原因：`b[r+1]` 当 `r = n` 时访问了 `b[n+1]`，而数组只开到 `n`
- 解决：数组开到 `n + 5`

**坑 2：忘了还原就输出**

- 现象：输出全是 0 或乱七八糟的数
- 原因：`b` 里存的是**差值**，不是原值
- 解决：输出前一定要跑一遍前缀和

**坑 3：构造时忘了减**

- 现象：原数组的值全丢，只剩操作的影响
- 原因：只写了 `b[i] = 0`，没写 `b[i] = a[i] - a[i-1]`
- 解决：读入时就构造差分；如果原数组全 0，可以跳过这步

**坑 4：和前缀和搞反**

- 现象：该用差分的地方用了前缀和，或者反过来
- 原因：两者的公式长得很像
- 解决：记住**方向不同**——前缀和是"多次查、不改"，差分是"多次改、最后查"

**坑 5：二维四点写错位置**

- 现象：只有部分区域被修改，或改了不该改的地方
- 原因：`x1-1` / `x2+1` 用反了
- 解决：在纸上画 3×3 矩阵，手动标出四个点，对一遍

## 四、学习建议

按 5 小时推进：

| 时段 | 内容 | 验收标准 |
| :-- | :-- | :-- |
| 第 1 小时 | 一维差分模板 | 能解释为什么只改两个位置就能影响整个区间 |
| 第 2 小时 | 区间加法练习 | 能手算一遍 `b[L]+=c, b[R+1]-=c` 的还原过程 |
| 第 3 小时 | 二维差分 | **在纸上画 3×3，标出四个点**，能独立写对 |
| 第 4 小时 | 对比练习 | 拿到一道题能判断该用暴力/差分/前缀和 |
| 第 5 小时 | 蓝桥真题：棋盘 / 差分 | 能独立完成建模 |

**每题验收动作**：

1. 说出这题**修改多少次**、**查询多少次**、两者的先后顺序
2. 说出为什么差分只改两个点就能覆盖整个区间（讲清"抵消"）
3. 二维题：能在纸上画出四个角并标出加减号

> 差分的本质是「用 O(1) 的修改，代替 O(n) 的遍历；最后用前缀和一次性还原」。
> 只要掌握这个方向感，就不会和前缀和搞混。
