# 函数与结构体的三种模型

> 洛谷 [#105 入门6 函数与结构体](https://www.luogu.com.cn/training/105) 共 15 题。
> 这一篇不讲语法（`int f(int x)` 你早就会写），讲**三个模型该在什么时候用**：
> 把数据打包、把逻辑装箱、把比较规则交给自己定。

---

## 一、核心算法模型

### 1. 结构体封装模型：定制一张"超级表格"

**核心思想**：一个学生有学号、语文、数学、总分——四个值本来就属于同一个人，
用四个平行数组是自找麻烦。**结构体把相关的值绑成一个整体。**

**实现技巧**：`struct` 里放成员；定义时**末尾必须带分号**。

**应用场景**：多属性实体（学生、点、边、区间）、需要整体排序的东西（P5742 综合分数评定）。

```cpp
#include <iostream>
using namespace std;

struct Student {
    int id;
    int chinese;
    int math;
    int total;
};                          // ← 这个分号不能少

Student a[1005];
```

> 好处：`a[i].total` 比 `sumTotal[i]` 更好读；排序时整个结构体会跟着一起换位置，
> 不会出现"分数换了、学号没换"的错位。

### 2. 黑盒函数模型：把逻辑装进流水线

**核心思想**：一段逻辑要用第二次，就该给它一个名字。调用方**只需要知道输入和输出**，不用再关心里面怎么算。

**实现技巧**：先回答两个问题——**它要什么参数？它给出什么结果（返回值还是直接改外面的变量）？**

**应用场景**：判断质数（P1304）、算距离（P5735）、判断闰年（P5737）。

```cpp
#include <iostream>
using namespace std;

bool isPrime(int n) {              // 黑盒：进去一个数，出来真假
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) return false;
    }
    return true;
}
```

> 判据只有一条：**这段逻辑你要写第二遍**。只写一次的不抽，抽了反而要来回翻。

### 3. 结构体排序模型：定制"排队规则"

**核心思想**：告诉电脑怎么比较两个"包裹"——先比总分？总分一样再比学号？

**实现技巧**：写 `bool cmp(const T& a, const T& b)`，交给 `sort`。

**应用场景**：多关键字排序，蓝桥杯几乎每场都有（P5742 综合分数评定）。

```cpp
#include <algorithm>

bool cmp(const Student& a, const Student& b) {
    if (a.total != b.total) return a.total > b.total;  // 总分高的在前
    return a.id < b.id;                                // 同分按学号升序
}

sort(a, a + n, cmp);
```

> 记法：**cmp 回答的是「a 该不该排在 b 前面」，不是「a 是否小于等于 b」。**

## 二、必须掌握的"编程利器"

| 利器 | 怎么用 | 为什么重要 |
| :-- | :-- | :-- |
| **`sort` + 自定义 cmp** | `<algorithm>`，第三参数传函数名 | 任何复杂排序规则都能实现 |
| **引用传递 `&`** | `void f(int& x)` | 能在函数里改调用者的变量；传大对象还能省一次拷贝 |
| **全局数组** | 定义在 `main` 外 | 函数里开 `int a[100000]` 会**爆栈**；全局默认全 0 |
| **显式头文件** | `#include <iostream>` 等逐条列出 | 本仓禁用万能头，考场也建议写清楚 |

```cpp
// 传 string / vector 一律加 const &，省拷贝
int countA(const string& s) {
    int c = 0;
    for (size_t i = 0; i < s.size(); i++) if (s[i] == 'a') c++;
    return c;
}
```

## 三、初学者必踩的坑

**坑 1：修改无效**

- 现象：函数里明明改了，回到 `main` 还是原样
- 原因：**值传递**。你传进去的是副本，函数改的是副本
- 解决：要改就用 `void f(int& x)`，或者干脆用全局变量

**坑 2：结构体排序"玄学"报错**

- 现象：`sort` 后程序崩溃，或结果乱序
- 原因：cmp 里写了 `<=` 或 `>=`。两个相等元素互相"小于"，违反**严格弱序**，`sort` 会越界
- 解决：**cmp 里只写 `<` 或 `>`**，相等的情况交给下一个关键字

**坑 3：分号丢失案**

- 现象：编译报错指到结构体定义的下**一行**，让人找不到错
- 原因：`struct Name { ... }` 后面漏了 `;`
- 解决：记死格式 `struct 名 { 成员 };`

**坑 4：数组当参数，长度丢了**

- 现象：函数里 `sizeof(a)/sizeof(a[0])` 算出来是 1 或 2
- 原因：数组传参会**退化成指针**，长度信息丢失
- 解决：长度必须单独传 `void f(int a[], int n)`
