# 函数与结构体的三种模型

> 洛谷 [#105 入门6 函数与结构体](https://www.luogu.com.cn/training/105) 共 15 题。
> 这一篇不讲语法（`int f(int x)` 你早会写），讲**三个模型该在什么时候用**。

| 模型 | 解决什么 | 关键点 | 典型题 |
| :-- | :-- | :-- | :-- |
| **结构体封装** | 多个值属于同一个东西 | 定义末尾的分号 | P5742 综合分数评定 |
| **黑盒函数** | 一段逻辑要用第二次 | 参数怎么传、结果怎么出 | P1304 哥德巴赫、P5735 距离 |
| **结构体排序** | 多关键字一起排 | cmp 里只能写 `<` | 蓝桥杯几乎每场都有 |

## 一、核心算法模型

### 1. 结构体封装模型：把散装数据装成一张表

#### 1.1 为什么需要打包

一个学生有学号、语文、数学、总分。用四个平行数组：

```cpp
int id[1005], chinese[1005], math[1005], total[1005];
```

问题在哪：

- **下标必须处处对齐**。`id[i]` 和 `total[i]` 是同一个人的，但编译器不知道
- **排序时容易错位**。想把学生按总分排序，你得同时交换四个数组的元素，漏一个就全乱
- **作为参数传递要传四份**，函数签名越来越长

结构体把"属于同一个实体的值"绑成一个整体，**排序时整个结构体一起换位置**，不可能错位。

```cpp
struct Student {
    int id;
    int chinese;
    int math;
    int total;
};                          // ← 这个分号绝对不能少

Student a[1005];
```

> 用结构体之后，`sort(a, a + n, cmp)` 一句话就把整个学生的所有字段一起排好了。

#### 1.2 定义规范

**三条固定规则**：

1. **末尾必须有分号**。`struct X { ... };` 漏了会编译报错，而且报错位置指向下一行，很难找
2. **定义在 `main` 外面**（全局）。和数组一样，函数里定义的大结构体数组会爆栈
3. **成员按用途命名**，不要用 `a` `b` `c`

```cpp
#include <iostream>
using namespace std;

struct Student {
    int id;
    int chinese;
    int math;
    int total;
};

Student a[1005];                // 全局，自动全 0
```

#### 1.3 四种用法变体

**变体 A：整体赋值与比较（逐字段）**

```cpp
Student x, y;
x = y;                          // 可以整体赋值，逐字段复制
// 但不能直接 if (x == y)，要自己逐字段比
```

**变体 B：结构体数组**（最常用）

```cpp
Student a[1005];
for (int i = 0; i < n; i++) {
    cin >> a[i].id >> a[i].chinese >> a[i].math;
    a[i].total = a[i].chinese + a[i].math;   // 派生字段自己算
}
```

**变体 C：结构体作为函数参数**——**一定加 `const &`**

```cpp
int calcTotal(const Student& s) {     // 不复制，只读
    return s.chinese + s.math;
}
```

**变体 D：嵌套结构体**

```cpp
struct Point { int x, y; };
struct Line  { Point a, b; };         // 线段由两个点组成
```

#### 1.4 例题拆解：P5742 综合分数评定

**题意**：n 个学生，每人有学号、语文、数学，总分 = 语 + 数。
若总分 ≥ 140 **且** 语文 + 数学 都 ≥ 60，评为"优秀"，否则"不合格"，输出学号和评级。

**为什么用结构体**：每个学生有 4 个属性，且要按学号顺序输出。

```cpp
struct Student {
    int id;
    int chinese;
    int math;
    int total;
};
Student a[1005];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i].id >> a[i].chinese >> a[i].math;
        a[i].total = a[i].chinese + a[i].math;
    }
    for (int i = 0; i < n; i++) {
        bool good = (a[i].total >= 140) && (a[i].chinese >= 60) && (a[i].math >= 60);
        cout << a[i].id << " " << (good ? "Excellent" : "Not excellent") << "\n";
    }
    return 0;
}
```

**易错点**：

1. **总分是派生字段**，读入时就该算好，不要每次用的时候现加
2. **两个判断都要满足**，不是"总分够就行"
3. 输出格式要和题目要求逐字对齐（大小写、空格）

#### 1.5 边界与坑

| 坑 | 说明 |
| :-- | :-- |
| 定义末尾漏分号 | 编译报错指到下一行，最难找的错误之一 |
| 结构体数组定义在函数里 | 大会爆栈，一律放全局 |
| 不能直接用 `==` 比较 | C++ 不会自动生成，要逐字段比 |
| 成员没初始化 | 全局数组默认全 0；局部结构体变量不会，要手动赋 |

### 2. 黑盒函数模型：把逻辑装进流水线

#### 2.1 什么时候该抽函数

**唯一判据：这段逻辑你要写第二遍。**

只写一次的不抽——抽了反而要在两个地方之间来回翻。这是很多人的通病：
为了"看起来专业"把所有东西都包成函数，结果代码更难读。

**该抽的三种信号**：

1. 同一段判断出现两次以上（如判质数）
2. 一段逻辑有 15 行以上，且能一句话说清它干什么（如"算两点距离"）
3. 这段逻辑将来可能换实现（如"判断闰年"）

#### 2.2 抽之前先回答两个问题

| 问题 | 决定什么 |
| :-- | :-- |
| **它需要什么？** | 参数列表 |
| **它要给出什么？** | 返回值（`return`）还是直接改外面的变量（引用参数） |

答不上这两个问题，说明你还没想清楚，先别抽。

#### 2.3 参数传递：三种方式完整对比

| 方式 | 写法 | 函数里改得动原变量吗 | 拷贝开销 | 什么时候用 |
| :-- | :-- | :--: | :-- | :-- |
| **值传递** | `void f(int x)` | ❌ 改不动 | 小数据无所谓 | 小数据、只读 |
| **引用传递** | `void f(int& x)` | ✅ 改得动 | 无 | 要改调用者的变量 |
| **常量引用** | `void f(const T& x)` | ❌ 改不动 | **无** | 大对象只读（string/vector/结构体） |

**值传递为什么改不动**：函数拿到的是**副本**，改副本对原变量没有任何影响。

```cpp
void addOne(int x)  { x++; }        // 外面不变
void addOne2(int& x){ x++; }        // 外面 +1
```

**大对象为什么必须 `const &`**：

```cpp
int countA(string s)         { }    // 每次调用复制整个串
int countA(const string& s)  { }    // 不复制，快得多
```

> 判据：**参数类型是 `string` / `vector` / 结构体 → 一律 `const &`，
> 除非你要在函数里改它（那就去掉 `const` 只留 `&`）。**

#### 2.4 例题拆解：P1304 哥德巴赫猜想

**题意**：给偶数 N（≥4），把它拆成两个质数之和，找出所有拆分方式。

**为什么需要函数**：判质数会被调用 n/2 次。不抽函数的话，这段循环要在主函数里出现一次，
再加一个嵌套循环就失控了。

```cpp
#include <iostream>
using namespace std;

bool isPrime(int n) {                       // 黑盒：进一个数，出真假
    if (n < 2) return false;                // 0 和 1 不是质数
    for (int i = 2; i * i <= n; i++) {      // 只需试到 sqrt(n)
        if (n % i == 0) return false;
    }
    return true;
}

int main() {
    int n;
    cin >> n;
    for (int i = 2; i <= n / 2; i++) {      // 只试到一半，避免重复
        if (isPrime(i) && isPrime(n - i)) {
            cout << n << "=" << i << "+" << n - i << "\n";
        }
    }
    return 0;
}
```

**三个关键点**：

1. **`i * i <= n`** 等价于 `i <= sqrt(n)`，但不用开根号、不会丢精度
2. **`n < 2` 要单独排除**：0、1 都不是质数，2 是质数
3. **循环只到 `n / 2`**：`3+7` 和 `7+3` 是同一种拆法，写全了会重复输出

#### 2.5 边界与坑

| 坑 | 说明 |
| :-- | :-- |
| 判质数忘排除 0 和 1 | `isPrime(1)` 返回 true，答案错 |
| 用 `i < n` 而不是 `i * i <= n` | 能过但慢，n 大时 TLE |
| 循环到 n 而不是 n/2 | 答案重复输出两遍 |
| 函数改变量却没加 `&` | 改无效，很难发现 |
| 数组当参数 | **退化成指针，长度丢失**，必须另传 `int n` |

### 3. 结构体排序模型：自定义"排队规则"

#### 3.1 核心思想

`sort` 默认只会比大小（`int` 比数值，`string` 比字典序）。
结构体没有天然的大小关系，所以你要**告诉它两条规则**：

1. **先比什么**
2. **相等时再比什么**

#### 3.2 `cmp` 的严格弱序（重要，不看会踩坑）

`sort` 要求比较函数满足**严格弱序**，简化为三条：

| 规则 | 含义 | 违反的后果 |
| :-- | :-- | :-- |
| 非自反 | `cmp(a, a)` 必须是 `false` | 写 `<=` 就违反了 |
| 非对称 | `cmp(a,b)` 和 `cmp(b,a)` 不能同时为 `true` | 同上 |
| 传递性 | `cmp(a,b)` 且 `cmp(b,c)` → `cmp(a,c)` | 复杂规则写错时 |

**为什么写 `<=` 会 RE**：`cmp(a, a)` 返回 `true`，`sort` 内部的划分逻辑会把区间切错，
导致**指针越过数组边界**。表现出来就是随机 RE 或死循环，而不是"结果稍微不对"。

> 记法：**`cmp` 回答的是「a 该不该排在 b 前面」，不是「a 是否小于等于 b」。**

#### 3.3 标准写法

```cpp
#include <algorithm>

bool cmp(const Student& a, const Student& b) {
    if (a.total != b.total) return a.total > b.total;   // 总分高的在前
    return a.id < b.id;                                 // 同分按学号升序
}

sort(a, a + n, cmp);            // 数组
sort(v.begin(), v.end(), cmp);  // vector
```

#### 3.4 四种常见规则

**规则 A：单关键字**（降序）

```cpp
bool cmp(const Student& a, const Student& b) {
    return a.total > b.total;
}
```

**规则 B：先降后升**（上面就是：总分降序，学号升序）

**规则 C：按多个字段依次比较**

```cpp
bool cmp(const Student& a, const Student& b) {
    if (a.chinese != b.chinese) return a.chinese > b.chinese;   // 语文优先
    if (a.math    != b.math)    return a.math    > b.math;      // 再比数学
    return a.id < b.id;                                         // 最后比学号
}
```

**规则 D：重载 `operator<`**——不用写 cmp，直接 `sort(a, a+n)`

```cpp
struct Student {
    int id, total;
    bool operator<(const Student& o) const {     // C++11 支持
        if (total != o.total) return total > o.total;
        return id < o.id;
    }
};
sort(a, a + n);                                  // 自动用这个规则
```

> 两种写法等价。**同一份代码里只用一种**，混用会让读者困惑。

#### 3.5 边界与坑

| 坑 | 现象 | 解决 |
| :-- | :-- | :-- |
| cmp 写 `<=` / `>=` | RE 或死循环 | 只写 `<` / `>` |
| cmp 参数没加 `const &` | 大数据时慢 | 一律 `const T&` |
| 多关键字漏了最后一级 | 结果顺序不稳定 | 最后一定要 return 一个单字段比较 |
| 需要稳定排序 | 相同元素的相对顺序变了 | 用 `stable_sort` 或补一个唯一键（如 id） |

## 二、必须掌握的"编程利器"

| 利器 | 怎么用 | 为什么重要 |
| :-- | :-- | :-- |
| **`sort` + 自定义 cmp** | `<algorithm>`，第三参数传函数名 | 任何排序规则都能实现 |
| **引用传递 `&`** | `void f(int& x)` | 能在函数里改调用者变量 |
| **常量引用 `const T&`** | 传 string/vector/结构体 | 省一次完整拷贝 |
| **全局数组** | 定义在 `main` 外 | 函数内开大会爆栈 |
| **显式头文件** | `#include <iostream>` 等逐条列出 | 本仓禁用万能头；写清楚也不容易漏 |

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
```

## 三、初学者必踩的坑

**坑 1：修改无效**

- 现象：函数里明明改了，回到 `main` 还是原样
- 原因：**值传递**，你传进去的是副本
- 解决：`void f(int& x)`，或直接操作全局变量

**坑 2：结构体排序"玄学"报错**

- 现象：`sort` 后崩溃、死循环，或结果乱序
- 原因：cmp 里写了 `<=` / `>=`，违反严格弱序
- 解决：**只写 `<` 或 `>`**

**坑 3：分号丢失**

- 现象：编译报错指到结构体定义的**下一行**
- 原因：`struct Name { ... }` 后面漏了 `;`
- 解决：记死 `struct 名 { 成员 };`

**坑 4：数组当参数，长度丢了**

- 现象：函数里 `sizeof(a)/sizeof(a[0])` 算出来不对
- 原因：数组传参**退化成指针**
- 解决：长度单独传 `void f(int a[], int n)`

**坑 5：`main` 里定义大结构体数组**

- 现象：程序直接崩，没有任何报错
- 原因：栈空间通常只有 1–8 MB，`Student a[1000000]` 远超
- 解决：一律定义在全局

## 四、学习建议

按 5 小时推进：

| 时段 | 题目 | 练哪个模型 | 验收标准 |
| :-- | :-- | :-- | :-- |
| 第 1 小时 | P5735 距离函数 | 黑盒函数（浮点） | 主函数只剩读入和调用 |
| 第 2 小时 | P5737 闰年展示 | 黑盒函数（判断） | 能写出 `bool isLeap(int)` |
| 第 3 小时 | P1304 哥德巴赫 | 函数 + 循环 | `isPrime` 能反复调用，循环只到 n/2 |
| 第 4 小时 | P5736 质数筛 | 全局数组 + 函数 | 大数组放全局，不爆栈 |
| 第 5 小时 | 结构体排序练习 | 结构体 + cmp | 写 `<=` 能说出为什么会 RE |

**每题验收动作**：

1. 说出这个函数**该不该抽**（是不是要写第二遍）
2. 说出参数为什么用 `&` / `const &` / 值传递
3. 如果写了 cmp，能解释"为什么不能写 `<=`"
