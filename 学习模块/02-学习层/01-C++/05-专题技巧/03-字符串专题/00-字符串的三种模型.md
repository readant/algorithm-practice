# 字符串的三种模型

> 洛谷 [#104 入门5 字符串](https://www.luogu.com.cn/training/104) 共 15 题。
> 表面花样多，本质只有三个动作：**把字符当地址、把字符当数字、把字符串当作可以被切开的东西。**

| 模型 | 关键操作 | 解决什么 | 典型题 |
| :-- | :-- | :-- | :-- |
| **映射** | `s[i] - 'a'` | 统计、去重、判断组成 | P1125 笨小猴、P1765 手机 |
| **偏移** | `±32`、`% 26` | 大小写、位移、加密 | P1914 凯撒、P5733 自动修正 |
| **解析** | `find` / `substr` / 切分 | 找片段、拆词、插入翻转 | P308 统计单词、P5734 文件处理 |

## 一、核心算法模型

### 1. 映射模型（哈希思想）：字符的"门牌号"

#### 1.1 核心思想

计算机里**字符本来就是整数**（ASCII 码）。所以「统计 26 个字母出现几次」不用真的去建立哈希表——
直接把字母序号当数组下标。

关键在于：`'a'` 不是 1，是 97。所以要减去 `'a'` 把它拉回 `0`。

#### 1.2 必须记住的四个 ASCII 值

| 字符 | ASCII | 记忆点 |
| :-- | :--: | :-- |
| `'0'` | 48 | 数字字符的起点 |
| `'A'` | 65 | 大写字母的起点 |
| `'a'` | 97 | 小写字母的起点 |
| 大小写差值 | **32** | `'a' - 'A' == 32` |

由此推出的常用换算：

```cpp
int d = c - '0';        // 数字字符 → 整数值：'7' → 7
char c = '0' + d;       // 整数值 → 数字字符：7 → '7'
int idx = c - 'a';      // 'a'~'z' → 0~25
int up = c - 32;        // 小写 → 大写（'a'→'A'）
```

> **不要硬编码 97 / 65**。写 `c - 'a'` 比写 `c - 97` 更安全，也更容易看出意图。

#### 1.3 标准写法

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;

    int cnt[26] = {0};
    for (size_t i = 0; i < s.size(); i++) {
        if (s[i] >= 'a' && s[i] <= 'z') {
            cnt[s[i] - 'a']++;         // 字母 → 抽屉号 → 加一
        }
    }

    for (int i = 0; i < 26; i++) {
        if (cnt[i] > 0) cout << char('a' + i) << ": " << cnt[i] << "\n";
    }
    return 0;
}
```

#### 1.4 四种变体

**变体 A：计数**（上面就是）

**变体 B：去重 / 判断是否出现过**

```cpp
bool vis[26] = {false};
vis[s[i] - 'a'] = true;
```

**变体 C：判断两个串"字母组成是否相同"**（异位词）

```cpp
int c1[26] = {0}, c2[26] = {0};
for (size_t i = 0; i < a.size(); i++) c1[a[i] - 'a']++;
for (size_t i = 0; i < b.size(); i++) c2[b[i] - 'a']++;
bool same = true;
for (int i = 0; i < 26; i++) {
    if (c1[i] != c2[i]) { same = false; break; }
}
```

**变体 D：打表**——规则不规则时，直接写死对照表

```cpp
// P1765：a~r 每 3 个一组，s~z 是 4 个一组
int key[26] = {1,2,3, 1,2,3, 1,2,3, 1,2,3, 1,2,3, 1,2,3, 1,2,3, 1,2,3, 1,2,3,4};
int presses = key[c - 'a'];
```

> **判据**：规则能用一句话说清（如"往后移 k 位"）就写公式；
> 规则要靠数（如电话键盘的按键次数）就打表。**打表永远不会算错。**

#### 1.5 例题拆解：P1125 笨小猴

**题意**：给一个单词，统计各字母出现次数，求 `出现最多的次数 - 出现最少的次数`，
判断这个差是不是质数。

**为什么是映射模型**：要统计的是 26 种东西。

**三个容易错的地方**：

1. **"最少"只统计出现过的字母**。如果直接把 `cnt[]` 的 26 个数全拿去求 min，
   没出现过的字母是 0，min 永远是 0，答案必错。
2. **`maxn` 初值设 0，`minn` 初值设一个足够大的数**（如 1000）。
   不能设 0，否则 min 永远 0。
3. **差值可能是 0 或 1**，`isPrime` 里必须把 `n < 2` 排除掉。

```cpp
int cnt[26] = {0};
for (size_t i = 0; i < s.size(); i++) cnt[s[i] - 'a']++;

int maxn = 0, minn = 1000;
for (int i = 0; i < 26; i++) {
    if (cnt[i] == 0) continue;         // 只统计出现过的
    if (cnt[i] > maxn) maxn = cnt[i];
    if (cnt[i] < minn) minn = cnt[i];
}

int d = maxn - minn;
// 再判断 d 是否质数
```

#### 1.6 边界与坑

| 坑 | 说明 |
| :-- | :-- |
| 统计范围含其他字符 | 先判 `'a' <= c && c <= 'z'` 再减，否则 `cnt[c-'a']` 会越界 |
| 大小写混着统计 | 要么先统一转小写，要么开 52 个桶 |
| 求 min 时带上未出现的 0 | 见上面 P1125 的第一条 |
| 用 `c - 97` 硬编码 | 能跑，但可读性差；统一写 `c - 'a'` |

### 2. 偏移模型（转换思想）：字符的"变身术"

#### 2.1 核心思想

既然字符是数字，那么**加减一个量就变成另一个字符**。三种典型：

| 需求 | 公式 | 关键点 |
| :-- | :-- | :-- |
| 小写 → 大写 | `c - 32` | 差值固定 |
| 大写 → 小写 | `c + 32` | 同上 |
| 往后移 k 位（加密） | `(c - 'a' + k) % 26 + 'a'` | **必须取模回绕** |

#### 2.2 三个必备写法

**写法 A：大小写互换**

```cpp
#include <cctype>

char up = toupper(c);       // 小写转大写，其他字符原样
char lo = tolower(c);
```

> `toupper` / `tolower` 的**形参是 `int`**。直接传 `char` 在某些平台上会因符号扩展出错，
> 安全写法：`(char)tolower((unsigned char)c)`。比赛里直接写 `c ± 32` 也够用。

**写法 B：循环位移（凯撒）**

```cpp
// 'z' 再往后移 1 位要绕回 'a'
char next = (c - 'a' + k) % 26 + 'a';
```

**为什么必须取模**：`'z' - 'a' = 25`，`25 + 1 = 26`，直接加会得到 `'{'`（下一个 ASCII 字符），
不是 `'a'`。`% 26` 把它拉回 0。

**写法 C：位移量可能为负或超 26**

```cpp
k = ((k % 26) + 26) % 26;    // 把 k 归一到 [0, 25]，负数也能处理
char next = (c - 'a' + k) % 26 + 'a';
```

> C++ 的 `%` 对负数结果是负的（`-3 % 26 == -3`），所以要先 `+26` 再 `%`。

#### 2.3 例题拆解：P1914 小书童——凯撒密码

**题意**：给一个字符串和位移量 n，每个字母往后移 n 位，`z` 之后绕回 `a`。

**核心一行**：

```cpp
for (size_t i = 0; i < s.size(); i++) {
    s[i] = (s[i] - 'a' + n) % 26 + 'a';
}
```

**必须先确认的事**：题目里的串**全是小写字母**。如果混有大写或其他字符，
这个公式会把它们也"位移"成乱码——那时要先判断范围：

```cpp
if (s[i] >= 'a' && s[i] <= 'z') {
    s[i] = (s[i] - 'a' + n) % 26 + 'a';
}
```

> 题目说"仅含小写字母"就可以省这个判断；没说的话**必须判**。

#### 2.4 边界与坑

| 坑 | 说明 |
| :-- | :-- |
| 忘取模 | `'z' + 1` 变成 `'{'`，后面全乱 |
| 负位移 | C++ 的 `%` 对负数返回负值，要 `((k % 26) + 26) % 26` |
| 没判字符范围 | 大写、数字、空格被一起位移 |
| 用 `toupper` 但忘了 include | 需要 `<cctype>` |

### 3. 解析模型：文字"裁纸刀"

#### 3.1 核心思想

前两个模型是**逐字符**看；这个模型是**把字符串当作整体**，找人要的片段。

三种动作：
1. **找**——某个片段在哪（`find`）
2. **切**——把某一段取出来（`substr`）
3. **拆**——按分隔符拆成多个词（`stringstream` 或双指针）

#### 3.2 `find` 的行为必须搞清楚

```cpp
size_t pos = s.find(t);          // 从开头找
size_t pos2 = s.find(t, 5);      // 从下标 5 开始找
size_t pos3 = s.rfind(t);        // 从后往前找
```

**`npos` 是什么**：找不到时返回 `string::npos`，它的值是 `size_t` 的最大值
（不是 0，也不是 -1）。所以**判断存在性必须和它比**：

```cpp
if (s.find(t) != string::npos) { /* 找到了 */ }
```

**循环数出现几次，最容易死循环**：

```cpp
int cnt = 0;
size_t pos = 0;
while ((pos = s.find(t, pos)) != string::npos) {
    cnt++;
    pos += t.size();             // 不重叠计数
    // 如果允许重叠，改成 pos + 1
}
```

> 不推进 `pos` 的话，每次 `find` 都返回同一个位置，**无限循环**。

#### 3.3 三种切分方式怎么选

| 方式 | 写法 | 优点 | 缺点 |
| :-- | :-- | :-- | :-- |
| `stringstream` | `while (ss >> w)` | 最简单 | **合并连续空格**，丢失位置信息；较慢 |
| 双指针扫 | 自己写两个下标 | 位置精确、快 | 代码稍长 |
| 手动 `find` 循环 | `find(' ')` 循环切 | 可控 | 要处理末尾无分隔符的情况 |

**判据**：**题目要不要"第几个位置"？**
- 不要位置，只要词 → `stringstream`
- 要位置（如"第一次出现的位置"）→ 双指针

#### 3.4 例题拆解：P308 统计单词数

**题意**：给一个单词和一篇文章，问这个单词在文章里出现了几次、**第一次出现在第几个字符**。

**这一题正好卡在两个模型的交叉点上**：

1. 文章**含空格**，必须 `getline` 读整行 —— 不能用 `cin >>`
2. 要输出**位置**，所以**不能用 `stringstream`**（它会把连续空格合并，位置就算不准了）
3. 大小写不敏感，比较前要统一转小写

**双指针切词骨架**：

```cpp
string art;
getline(cin, art);              // 整篇文章

int n = (int)art.size();
int i = 0;
int cnt = 0;
int firstPos = -1;

while (i < n) {
    while (i < n && art[i] == ' ') i++;      // 跳过空格
    if (i >= n) break;

    int start = i;
    while (i < n && art[i] != ' ') i++;      // 走到这个词的末尾
    string word = art.substr(start, i - start);

    // 统一转小写后比较
    for (size_t k = 0; k < word.size(); k++) {
        if (word[k] >= 'A' && word[k] <= 'Z') word[k] += 32;
    }
    if (word == target) {
        cnt++;
        if (firstPos == -1) firstPos = start;   // 第一次出现的位置
    }
}
```

**三个关键点**：

1. **两层 while**：外层跳空格，内层取词。少一层就切不开。
2. **`i` 是共享的**，不是局部变量——它必须一路往前走，不能每轮重置。
3. **`firstPos` 用 `-1` 标记"还没有"**，因为 0 是合法位置。

#### 3.5 边界与坑

| 坑 | 说明 |
| :-- | :-- |
| 用 `cin >>` 读整篇 | 只读到第一个词，后面全丢 |
| `getline` 前有 `cin >> n` | 会读到空串，要先 `cin.ignore()` |
| 用 `stringstream` 却要输出位置 | 连续空格被合并，位置不准 |
| `find` 循环不推进 | 死循环 |
| `s.size()` 与 `int` 比较 | `size()` 返回 `size_t`（无符号），写 `(int)s.size()` |
| 循环里反复调 `s.size()` | 超长串时可能 TLE，先存 `int len` |

## 二、必须掌握的"编程利器"

| 利器 | 怎么用 | 为什么重要 |
| :-- | :-- | :-- |
| **`std::string` 自带操作** | `+` 拼接、`==` 比内容、`.size()` | 不用手写字符数组和 `strlen` |
| **`getline(cin, s)`** | 读一整行含空格 | `cin >>` 遇空格就停 |
| **`stringstream`** | 按空格自动拆词 | 不要位置时最省事 |
| **`toupper` / `tolower`** | `<cctype>` | 大小写转换不用手算 ±32 |
| **`find` + `substr`** | 找 + 切 | 处理子串的两件套 |

```cpp
#include <iostream>
#include <string>
#include <sstream>
#include <cctype>
using namespace std;
```

## 三、初学者必踩的坑

**坑 1：消失的输入（缓冲区残留）**

- 现象：执行到 `getline` 直接跳过，不让你输入
- 原因：前面的 `cin >> n` 只拿走了数字，**把回车留在缓冲区**，`getline` 一看有回车以为你输完了
- 解决：`getline` 之前先 `cin.ignore();`

> 这是入门5 最高频的坑，**只要用了 `cin >>` 又用 `getline`，就必须处理**。

**坑 2：下标越界（RE）**

- 现象：RE 或输出乱码
- 原因：长度为 10 的串最大下标是 9，写成 `i <= s.length()` 就越界
- 解决：循环一律 `i < s.length()`

**坑 3：效率陷阱（TLE）**

- 现象：逻辑正确但超时
- 原因：`for (i = 0; i < s.length(); i++)` 每轮重算长度
- 解决：`int len = s.size();` 先存

**坑 4：`find` 死循环**

- 现象：程序卡住
- 原因：每次都从 0 开始找，永远同一个位置
- 解决：`pos = s.find(t, pos + 1)` 或 `pos + t.size()`

**坑 5：`s.size()` 参与算术**

- 现象：`s.size() - 1` 结果是个巨大正数
- 原因：`size_t` 是无符号，0 - 1 会绕回最大值
- 解决：先转 `int`：`int n = (int)s.size();`

## 四、学习建议

按 5 小时推进，一题一个模型：

| 时段 | 题目 | 练哪个模型 | 验收标准 |
| :-- | :-- | :-- | :-- |
| 第 1 小时 | P5733 自动修正 | 偏移（±32） | 能判大小写并正确转换 |
| 第 2 小时 | P1914 凯撒密码 | 偏移（取模） | 能写出 `% 26` 并解释为什么必须有 |
| 第 3 小时 | P5015 标准统计 | 解析（读整行） | 知道什么时候必须 `getline` |
| 第 4 小时 | P1125 笨小猴 | 映射（计数） | min 只算出现过的，不漏 |
| 第 5 小时 | P308 统计单词数 | 解析（双指针切词） | 能说清为什么不能用 `stringstream` |

**每题验收动作**：

1. 说出这题属于哪个模型，**为什么不是另外两个**
2. 如果是解析题，说清"要不要位置"——这决定了用不用 `stringstream`
3. 记一条自己真踩过的坑（例如"`cin >>` 后 `getline` 读到空串"）

> 加练：P1765 手机（映射 + 打表）、P5734 文件处理软件（解析 + 插入翻转）、
> P1321 单词覆盖还原（映射 + 解析混合）。
