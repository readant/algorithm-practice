# 广度搜索（BFS）

> BFS 是「**地毯式搜索**」：从起点开始，先把距离为 1 的都走一遍，再走距离为 2 的……
> 所以它天然能求**最少步数**。DFS 是"不撞南墙不回头"，BFS 是"水波纹扩散"。

| 用途 | 能不能用 BFS | 原因 |
| :-- | :-- | :-- |
| **最少步数 / 最短路径**（每步代价相同） | ✅ 首选 | 第一次到达就是最短 |
| **有多少个连通块** | ✅ 好用 | 从一个点扩散完一片 |
| **枚举所有路径** | ❌ 用 DFS | BFS 会漏掉不同路径 |
| **步长不同的最短路** | ❌ | 要用 Dijkstra |

---

## 一、核心算法模型

### 1. 五步框架（背下来）

BFS 的代码**结构极其固定**，五步一个都不能少：

```
① 起点入队，并且立刻标记"已访问"
② while (队列非空)
③     取出队头
④     遍历它的所有邻居（方向数组），能走的入队并标记
⑤ 队列空了 → 结束
```

**为什么用队列**：队列是**先进先出**，所以距离为 1 的点一定比距离为 2 的先处理完。
这就是"层层递进"的实现方式。

### 2. 例题拆解：走迷宫（最短步数）

**题意**：n×m 的迷宫，0 能走 1 是墙，从 `(0,0)` 到 `(n-1,m-1)`，求最少步数。

```cpp
#include <iostream>
#include <queue>
#include <cstring>
using namespace std;

const int MAXN = 105;
int g[MAXN][MAXN];              // 迷宫
int d[MAXN][MAXN];              // 到起点的距离，-1 表示没走过
int n, m;

int bfs() {
    queue<pair<int,int> > q;
    memset(d, -1, sizeof(d));   // 全部置 -1（未访问）
    d[0][0] = 0;                // 起点距离 0
    q.push(make_pair(0, 0));    // ① 入队

    int dx[] = {0, 0, 1, -1};
    int dy[] = {1, -1, 0, 0};

    while (!q.empty()) {                        // ②
        pair<int,int> t = q.front();
        q.pop();                                // ③ 取队头

        for (int k = 0; k < 4; k++) {           // ④ 扩展邻居
            int x = t.first + dx[k];
            int y = t.second + dy[k];
            if (x < 0 || y < 0 || x >= n || y >= m) continue;   // 越界
            if (g[x][y] == 1) continue;                         // 撞墙
            if (d[x][y] != -1) continue;                        // 已走过

            d[x][y] = d[t.first][t.second] + 1;                 // 距离 +1
            q.push(make_pair(x, y));                            // 入队
        }
    }
    return d[n-1][m-1];         // 到不了就是 -1
}
```

**五个关键点**：

1. **`d` 初始化为 -1**，不是 0。因为 0 是"距离为 0"的合法值，用 0 当"未访问"会和起点冲突
2. **入队时就标记**（`d[x][y] = ...` 写在 `push` 之前或同时）
3. **`d[x][y] = d[当前] + 1`**，不是 `d[当前] + 代价`——BFS 只适合每步代价相同
4. **越界、墙、已访问三个判断**缺一不可
5. **`pair<int,int>` 要 `#include <utility>`**（`<queue>` 通常会带，但显式写更稳）

### 3. 三种常见变体

**变体 A：连通块计数**

从一个未访问的点开始 BFS，能扩散到的所有点属于同一个连通块；再找下一个未访问的点。

```cpp
int blocks = 0;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        if (g[i][j] == 0 && d[i][j] == -1) {   // 找到一个新块
            blocks++;
            bfs(i, j);                          // 把这一片全标记
        }
    }
}
```

**变体 B：多源 BFS**

多个起点同时入队，然后一起扩散。典型是"多片草地同时长草，问多久全绿"。

```cpp
queue<pair<int,int> > q;
for (每个起点) {
    d[x][y] = 0;
    q.push(make_pair(x, y));       // 全部先入队
}
// 后面完全一样
```

**变体 C：状态 BFS（九宫重排这类）**

不是走格子，而是**一个状态**在变。状态要用字符串或数组存起来，用一个 `map` 记录"这个状态走过没有"。

```cpp
queue<string> q;
map<string, int> dist;             // 状态 → 步数
q.push(start);
dist[start] = 0;

while (!q.empty()) {
    string cur = q.front(); q.pop();
    if (cur == target) return dist[cur];
    for (每种变换) {
        string nxt = 变换(cur);
        if (dist.count(nxt)) continue;    // 这个状态来过
        dist[nxt] = dist[cur] + 1;
        q.push(nxt);
    }
}
```

> 这类题的关键：**把"局面"抽象成一个可比较的状态**（字符串最简单），
> 然后用 `map` 去重。九宫重排、魔板、倒水问题都是这个套路。

### 怎么选

1. **网格里求最少步数** → 标准 BFS
2. **求有几片连在一起的区域** → BFS 连通块
3. **多个源头同时扩散** → 多源 BFS（全部先入队）
4. **状态在变（拼图、倒水）** → 状态 BFS + `map` 去重

## 二、必须掌握的"编程利器"

| 利器 | 怎么用 | 为什么重要 |
| :-- | :-- | :-- |
| **`queue`** | `push` / `front` / `pop` | BFS 必须先进先出，`stack` 会退化成 DFS |
| **方向数组** | `dx[]` / `dy[]` 循环 | 比写四个 if 清晰得多 |
| **距离数组初始化 -1** | `memset(d, -1, sizeof(d))` | 0 是合法距离，不能当"未访问" |
| **`pair<int,int>`** | `make_pair(x, y)` | 一次存两个坐标 |

```cpp
#include <iostream>
#include <queue>
#include <cstring>
using namespace std;
```

## 三、初学者必踩的坑

**坑 1：用了 `stack` 而不是 `queue`**

- 现象：能跑出结果，但不是最短的
- 原因：`stack` 是先进后出，BFS 就退化成 DFS 了
- 解决：**BFS 必须用 `queue`**

**坑 2：出队时才标记（最致命）**

- 现象：MLE（内存超限）或 TLE，队列爆炸
- 原因：同一个点被多个邻居重复入队。层数越多越严重，指数级增长
- 解决：**入队时立刻标记**，不要等出队

```cpp
// ❌ 错：出队才标记
q.push(start);
while (!q.empty()) {
    auto t = q.front(); q.pop();
    if (d[t.x][t.y] != -1) continue;   // 太晚了，已经入队很多次
    d[t.x][t.y] = 1;
    ...
}

// ✅ 对：入队就标记
d[start] = 0;
q.push(start);
while (!q.empty()) {
    auto t = q.front(); q.pop();
    for (每个邻居) {
        if (d[nx][ny] != -1) continue;
        d[nx][ny] = d[t.x][t.y] + 1;
        q.push(...);                    // 标记完立刻入队
    }
}
```

**坑 3：`d` 数组初始化为 0**

- 现象：答案偏小，或起点被判成"已访问"
- 原因：0 是合法距离值
- 解决：用 -1 表示未访问

**坑 4：忘记判断越界**

- 现象：RE，或答案诡异
- 原因：`x`/`y` 超出网格范围还在访问 `g[x][y]`
- 解决：三个判断（越界、障碍、已访问）一个都不能少

**坑 5：空间超限（MLE）**

- 现象：小数据能过，大数据 MLE
- 原因：BFS 队列会存**一整层**的节点，空间比 DFS 大
- 解决：能用 BFS 就用，但网格特别大时注意队列规模

## 四、学习建议

按 5 小时推进：

| 时段 | 题目 | 练什么 | 验收标准 |
| :-- | :-- | :-- | :-- |
| 第 1 小时 | 走迷宫 | 五步框架 | 能闭卷写出框架，入队即标记 |
| 第 2 小时 | 最少操作数 | 状态转换 | 能定义"状态"和"一步操作" |
| 第 3 小时 | 长草（蓝桥） | 多源 BFS | 所有起点先入队再一起扩散 |
| 第 4 小时 | 岛屿个数（蓝桥） | 连通块 | 能正确数出块数 |
| 第 5 小时 | 九宫重排 | 状态 BFS | 能用 `map` 去重，能说清状态怎么表示 |

**每题验收动作**：

1. 说出**起点是什么**、**一步操作是什么**、**目标状态是什么**
2. 说出为什么这题"第一次到达就是最短"（每步代价相同）
3. 检查三件事：`queue` 而不是 `stack`、入队即标记、`d` 初始为 -1

> BFS 的框架非常固定，建议**死记硬背** `while (!q.empty())` 那个结构。
> 蓝桥杯里它常用于"地毯覆盖""传染病扩散""矩阵最短路"。
