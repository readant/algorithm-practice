# 高精度：四种运算

> `long long` 只到约 9×10¹⁸。再大的数（比如 100 位）C++ 没有内置类型，只能**自己模拟竖式**。
> 这块是模板题——**背下来就能用**，不要求推导。

> 本专题的结构和其他块不同：它按**运算**分，不是按模型分。

---

## 一、核心套路（四种运算共用）

不管加减乘除，套路都是三步：

1. **存**：用字符串读入，**逆序**存进 `vector<int>`（个位在下标 0，方便进位）
2. **算**：模拟小学竖式，逐位算，处理进位 / 借位
3. **收尾**：去掉前导 0，再逆序输出

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// 字符串 → 逆序 vector
vector<int> toVec(const string& s) {
    vector<int> A;
    for (int i = (int)s.size() - 1; i >= 0; i--) {
        A.push_back(s[i] - '0');
    }
    return A;
}
```

### 1. 高精度加法 A + B

**关键**：`t = A[i] + B[i] + 进位`；当前位 `t % 10`；新进位 `t / 10`。

```cpp
vector<int> add(vector<int>& A, vector<int>& B) {
    vector<int> C;
    int t = 0;                          // 进位
    for (size_t i = 0; i < A.size() || i < B.size() || t; i++) {
        if (i < A.size()) t += A[i];
        if (i < B.size()) t += B[i];
        C.push_back(t % 10);
        t /= 10;
    }
    return C;
}
```

### 2. 高精度减法 A - B

**关键**：`t = A[i] - B[i] - 借位`；若 `t < 0` 则当前位 `t + 10`、借位 1。

**前提**：要求 `A >= B`。若 `A < B`，先交换、算 `B - A`，再输出负号。

```cpp
vector<int> sub(vector<int>& A, vector<int>& B) {
    vector<int> C;
    int t = 0;                          // 借位
    for (size_t i = 0; i < A.size(); i++) {
        t = A[i] - t;
        if (i < B.size()) t -= B[i];
        C.push_back((t + 10) % 10);     // 借位与不借位统一成一行
        t = (t < 0) ? 1 : 0;
    }
    while (C.size() > 1 && C.back() == 0) C.pop_back();   // 去前导 0
    return C;
}
```

### 3. 高精度乘法 A × b（高精 × 低精）

**场景**：大数乘一个普通 `int`。

**关键**：把 `b` 当成一个整体去乘每一位。**中间变量必须用 `long long`**。

```cpp
vector<int> mul(vector<int>& A, int b) {
    vector<int> C;
    long long t = 0;                    // 一定要 long long
    for (size_t i = 0; i < A.size() || t; i++) {
        if (i < A.size()) t += (long long)A[i] * b;
        C.push_back((int)(t % 10));
        t /= 10;
    }
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```

### 4. 高精度除法 A ÷ b（高精 ÷ 低精）

**特点**：**从最高位开始算**，和其他三种相反。

**关键**：`r = r * 10 + A[i]`；当前商 `r / b`；新余数 `r % b`。

```cpp
// 返回值是商；余数通过引用带出
vector<int> divide(vector<int>& A, int b, int& r) {
    vector<int> C;
    r = 0;
    for (int i = (int)A.size() - 1; i >= 0; i--) {   // 从高位往低位
        r = r * 10 + A[i];
        C.push_back(r / b);
        r %= b;
    }
    reverse(C.begin(), C.end());        // 翻回个位在前
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```

### 怎么选

1. 加 / 减 → 从**低位**往高位，处理进位/借位
2. 乘低精度 → 从低位往高位，中间量用 `long long`
3. 除低精度 → 从**高位**往低位，带着余数走

## 二、必须掌握的"编程利器"

| 利器 | 怎么用 | 为什么重要 |
| :-- | :-- | :-- |
| **`vector<int>` 当容器** | `push_back` 逐位存 | 位数不定，比定长数组安全 |
| **逆序存储** | 读串时从 `size()-1` 往 0 走 | 进位发生在高位，逆序后 `push_back` 就够，不用头部插 |
| **`pop_back()` 去前导 0** | `while (C.size() > 1 && C.back() == 0)` | 减法、除法极易产生 `00123` |
| **`reverse`** | `<algorithm>` | 除法算完顺序是反的，要翻回来 |

## 三、初学者必踩的坑

**坑 1：忘了逆序存**

- 现象：加法结果整体错位，或进位加到了错误的位置
- 原因：`"123"` 正序存成 `{1,2,3}`，个位在末尾，进位要往头部插
- 解决：读入时就从 `size()-1` 到 `0`，让个位落在下标 0

**坑 2：前导 0 没去掉**

- 现象：输出 `00123` 而不是 `123`；减法结果是 `000`
- 原因：高位相消后留下了一串 0
- 解决：`while (C.size() > 1 && C.back() == 0) C.pop_back();`
  ——**条件里的 `size() > 1` 是为了保留唯一的 `0`**，否则结果 0 会被删空

**坑 3：中间变量用 int，乘法溢出**

- 现象：乘法答案莫名其妙变小或变负
- 原因：`A[i] * b` 中 `b` 接近 `int` 上限时，乘积爆 `int`
- 解决：中间变量 `t` 用 `long long`，或写 `1LL * A[i] * b`

**坑 4：减法没处理 A < B**

- 现象：结果是乱码或超大正数
- 原因：竖式减法假设被减数更大
- 解决：先比较长度和字典序，`A < B` 时交换、算完补负号

## 四、学习建议

按 5 小时推进，**每段代码都要自己敲一遍**，不要复制：

| 时段 | 内容 | 验收 |
| :-- | :-- | :-- |
| 第 1 小时 | 加法 + `toVec` | 能算 100 位 + 100 位 |
| 第 2 小时 | 减法 | 能处理借位，会去前导 0 |
| 第 3 小时 | 乘法（高精 × 低精） | 能解释为什么 `t` 要 `long long` |
| 第 4 小时 | 除法（高精 ÷ 低精） | 能说清"从高位开始"和其他的区别 |
| 第 5 小时 | 蓝桥真题 | 最小公倍数、R 格式、六六大顺 |

> 高精度是**蓝桥杯真题的高频载体**（LCM、格式转换、大数取模都套它）。
> 四个模板必须能**闭卷默写**，考场没时间推。
