# 高精度：四种运算

> `long long` 最大约 9×10¹⁸（19 位）。再大的数——100 位、1000 位——C++ 没有内置类型，
> 只能**自己模拟竖式计算**。这块是纯模板：**背下来就能用，考场上不推**。

| 运算 | 循环方向 | 核心变量 | 典型题 |
| :-- | :-- | :-- | :-- |
| 加法 `A + B` | 低位 → 高位 | 进位 `t` | P1601 A+B Problem |
| 减法 `A - B` | 低位 → 高位 | 借位 `t` | P2142 高精度减法 |
| 乘法 `A × b` | 低位 → 高位 | `long long t` | P1303、阶乘 |
| 除法 `A ÷ b` | **高位 → 低位** | 余数 `r` | P1480 A/B Problem |

**一句话记住差异**：加减乘都从个位（低位）算起，**只有除法从最高位算起**。

---

## 一、核心套路（四种运算共用三步）

### 步骤 1：存 —— 为什么必须逆序

C++ 的 `string` 和 `vector` 都只能高效地在**尾部**增删（`push_back`）。

- 竖式加法里，进位是往**高位**走的
- 如果正序存（个位在末尾），进位就要插到**头部**，每次都是 O(n)，总共 O(n²)
- 逆序存（个位在下标 0），进位就是 `push_back`，每次 O(1)

所以约定：**下标 0 是个位**。`"123"` 存成 `{3, 2, 1}`。

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// 字符串 → 逆序 vector<int>
vector<int> toVec(const string& s) {
    vector<int> A;
    for (int i = (int)s.size() - 1; i >= 0; i--) {
        A.push_back(s[i] - '0');
    }
    return A;
}

// 逆序 vector<int> → 字符串
string toStr(const vector<int>& A) {
    string s;
    for (int i = (int)A.size() - 1; i >= 0; i--) {
        s += char('0' + A[i]);
    }
    return s;
}
```

### 步骤 2：算 —— 模拟竖式

逐位算，把进位/借位/余数带下去。四种运算的差别只在"带什么"和"从哪头开始"。

### 步骤 3：收尾 —— 去前导 0 再输出

减法、除法极易产生 `00123` 这种。收尾动作是固定的：

```cpp
while (C.size() > 1 && C.back() == 0) C.pop_back();
```

> **为什么条件是 `size() > 1`**：如果结果就是 0，`C = {0}`，没有这个条件会把它删空，
> 输出空字符串。**保留最后一位是 0 的情况。**

## 二、四种运算

### 1. 高精度加法 A + B

**关键**：当前位 = `(A[i] + B[i] + 进位) % 10`，新进位 = `/ 10`。

```cpp
vector<int> add(vector<int>& A, vector<int>& B) {
    vector<int> C;
    int t = 0;                                      // 进位
    for (size_t i = 0; i < A.size() || i < B.size() || t; i++) {
        if (i < A.size()) t += A[i];
        if (i < B.size()) t += B[i];
        C.push_back(t % 10);                        // 当前位
        t /= 10;                                    // 进位给下一位
    }
    return C;
}
```

**循环条件为什么有 `|| t`**：两个数都算完了，进位可能还剩 1。
例：`99 + 1 = 100`，前两位算完 `t` 还是 1，必须再补一位。

**完整可运行**：

```cpp
int main() {
    string a, b;
    cin >> a >> b;
    vector<int> A = toVec(a), B = toVec(b);
    vector<int> C = add(A, B);
    cout << toStr(C) << "\n";
    return 0;
}
```

### 2. 高精度减法 A - B

**前提**：`A >= B`。在 `main` 里先判断，不满足就交换并记一个负号。

**关键**：当前位 = `(A[i] - B[i] - 借位 + 10) % 10`，若原差值 < 0 则借位 1。

```cpp
vector<int> sub(vector<int>& A, vector<int>& B) {
    vector<int> C;
    int t = 0;                                      // 借位
    for (size_t i = 0; i < A.size(); i++) {
        t = A[i] - t;
        if (i < B.size()) t -= B[i];
        C.push_back((t + 10) % 10);                 // 借位与不借位统一成一行
        t = (t < 0) ? 1 : 0;
    }
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```

**`(t + 10) % 10` 为什么能一行搞定两种情况**：

| `t` 原值 | `t + 10` | `% 10` | 正确结果？ |
| :-- | :-- | :-- | :-- |
| 7 | 17 | 7 | ✅ 不借位 |
| -1 | 9 | 9 | ✅ 借位，9 |
| -3 | 7 | 7 | ✅ 借位，7 |

不借位时 `t + 10 ≥ 10`，`% 10` 后回到 `t`；借位时 `t + 10 < 10`，`% 10` 就是 `t + 10`。

**比较大小（A < B 时必须处理）**：

```cpp
// A >= B 返回 true
bool geq(vector<int>& A, vector<int>& B) {
    if (A.size() != B.size()) return A.size() > B.size();
    for (int i = (int)A.size() - 1; i >= 0; i--) {   // 从高位往低位比
        if (A[i] != B[i]) return A[i] > B[i];
    }
    return true;                                    // 完全相等
}
```

**完整流程**：

```cpp
int main() {
    string a, b;
    cin >> a >> b;
    vector<int> A = toVec(a), B = toVec(b);
    if (!geq(A, B)) {
        swap(A, B);
        cout << "-";                                // 记得负号
    }
    cout << toStr(sub(A, B)) << "\n";
    return 0;
}
```

### 3. 高精度乘法 A × b（高精 × 低精）

**场景**：一个大数乘一个普通的 `int`（`b` 在 `int` 范围内）。**高精 × 高精是另一套（双重循环），这里不讲**。

**关键**：把 `b` 当成整体去乘每一位，**中间变量必须是 `long long`**。

```cpp
vector<int> mul(vector<int>& A, int b) {
    vector<int> C;
    long long t = 0;                                // 必须 long long
    for (size_t i = 0; i < A.size() || t; i++) {
        if (i < A.size()) t += (long long)A[i] * b;
        C.push_back((int)(t % 10));
        t /= 10;
    }
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```

**为什么一定要 `long long`**：`A[i]` 最大 9，`b` 最大约 2×10⁹，乘积最大约 1.8×10¹⁰，
**远超 `int` 的 2.1×10⁹**。用 `int` 会静默溢出成负数。

### 4. 高精度除法 A ÷ b（高精 ÷ 低精）

**特点**：**从最高位开始算**，和加减乘完全相反。为什么？因为除法是"高位先定商"。

**关键**：`r = r * 10 + A[i]`；当前商 = `r / b`；新余数 = `r % b`。

```cpp
// 返回商；余数通过引用带出
vector<int> divide(vector<int>& A, int b, long long& r) {
    vector<int> C;
    r = 0;
    for (int i = (int)A.size() - 1; i >= 0; i--) {   // 高位 → 低位
        r = r * 10 + A[i];
        C.push_back((int)(r / b));
        r %= b;
    }
    reverse(C.begin(), C.end());                    // 翻回个位在前
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```

> **余数变量必须是 `long long`**：`r * 10 + A[i]` 最大可到 `b × 10`，
> 当 `b` 接近 `int` 上限时（约 2×10⁹）结果约 2×10¹⁰，**用 `int` 会溢出**。

> 算出来时 `C` 是**高位在前**（每个元素就是那一位的商），所以最后要 `reverse`。

### 怎么选

1. 两个大数相加/相减 → 低位起，带进位/借位
2. 大数乘普通整数 → 低位起，中间量 `long long`
3. 大数除普通整数 → **高位起**，带余数
4. 两个大数相乘 → 本表不覆盖，需要双重循环（见 [15-高精度算法](../../03-基础算法体系/15-高精度算法.md)）

## 三、必须掌握的"编程利器"

| 利器 | 怎么用 | 为什么重要 |
| :-- | :-- | :-- |
| **`vector<int>` 当容器** | `push_back` 逐位存 | 位数不定，比定长数组安全 |
| **逆序存储** | 读串时从 `size()-1` 往下走 | 进位方向决定必须逆序 |
| **`pop_back()` 去前导 0** | 条件带 `size() > 1` | 减法/除法必做，否则输出 `00123` |
| **`reverse`** | `<algorithm>` | 除法算完顺序是反的 |
| **`long long` 中间量** | `t += 1LL * A[i] * b` | 乘法最容易在这里爆 |

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>          // reverse / swap
using namespace std;
```

## 四、初学者必踩的坑

| 坑 | 现象 | 原因 | 解决 |
| :-- | :-- | :-- | :-- |
| **忘了逆序存** | 结果整体错位，进位跑到奇怪的位置 | 正序存时个位在末尾，进位要插头部 | 读入就从 `size()-1` 开始 |
| **前导 0 没删** | 输出 `00123`；减法结果是 `000` | 高位相消留下 0 | `while (C.size() > 1 && C.back() == 0) C.pop_back();` |
| **删空成空串** | 结果是 0 但输出什么都没有 | `pop_back` 条件漏了 `size() > 1` | 条件必须两个都写 |
| **中间量用 int** | 乘法答案变小或变负 | `A[i] * b` 超 `int` | `t` 用 `long long`，或写 `1LL *` |
| **除法余数用 int** | 商整体算错 | `r * 10 + A[i]` 超 `int` | 余数变量用 `long long` |
| **减法没处理 A < B** | 输出乱码或巨大正数 | 竖式减法假设被减数更大 | 先 `geq` 比较，交换并补负号 |
| **除法没 reverse** | 商是反的 | 除法从高位算，结果高位在前 | 结尾 `reverse(C.begin(), C.end())` |

## 五、学习建议

按 5 小时推进。**每段代码都要自己敲一遍，不要复制**——考场上要的是默写能力。

| 时段 | 内容 | 题目 | 验收标准 |
| :-- | :-- | :-- | :-- |
| 第 1 小时 | `toVec` / `toStr` + 加法 | P1601 A+B Problem | 能算 500 位，能解释 `\|\| t` |
| 第 2 小时 | 减法 + `geq` | P2142 高精度减法 | 能处理 `A < B`，输出带负号 |
| 第 3 小时 | 乘法（高精 × 低精） | P1303 或求 `100!` | 能解释为什么 `t` 要 `long long` |
| 第 4 小时 | 除法（高精 ÷ 低精） | P1480 A/B Problem | 能说清"从高位算"和另外三个的区别 |
| 第 5 小时 | 综合 | 蓝桥真题：最小公倍数、R 格式、六六大顺 | 四个模板能闭卷默写 |

**每题验收动作**：

1. 不看模板，能在 5 分钟内默写出这个运算的完整函数
2. 能手算一遍 `99 + 1`、`100 - 1`、`9 × 9` 的每一位，和代码对得上
3. 说出这题的中间量会不会超 `int`，为什么

> 高精度是**蓝桥杯真题的高频载体**——最小公倍数、格式转换、大数取模都套它。
> 四个模板必须能闭卷默写，考场没时间现场推。
