# 字符串的几种打法

> 字符串题看起来花样多，但你真正要做的动作只有六种。
> **先认出是哪一种，再去查对应写法。**

| 打法 | 什么时候用 | 关键操作 | 典型题 |
| :-- | :-- | :-- | :-- |
| **读整行** | 输入里带空格 | `getline(cin, s)` | P5015 统计 · P308 单词数 |
| **逐字符扫** | 每个字符都要变/算 | `for (char c : s)` | P1914 凯撒 · P5733 自动修正 |
| **查表** | 字符要换成一个数值 | `int t[26]` | P1765 手机 · P1125 笨小猴 |
| **切分** | 要按空格拆出一个个词 | `stringstream` / 双指针 | P308 单词数 |
| **子串** | 找某段、替换某段、数出现几次 | `find` + `substr` | P1321 覆盖还原 · P3741 键盘 |
| **改结构** | 在中间插入、删除、翻转 | `insert` / `erase` / `reverse` | P5734 文件处理 |

---

## 零、先把整行读进来（所有题的前置）

`cin >> s` **遇到空格就停**，只能读一个词。句子题必须用 `getline`。

```cpp
#include <iostream>
#include <string>
using namespace std;

string s;
getline(cin, s);          // 读一整行，含空格
```

**坑**：如果前面用了 `cin >> n`，换行符还留在缓冲区里，`getline` 会立刻读到空串。
必须先吃掉它：

```cpp
int n;
cin >> n;
cin.ignore();             // 吃掉 n 后面的换行
getline(cin, s);
```

> 判断标准：**题目说「一行」「包含空格」「一句话」→ getline；说「一个单词」「不含空格」→ `cin >>`。**
> P5015、P308 属于前者；P1914、P5733 属于后者。

---

## 一、逐字符扫：每个字符都要参与运算

```cpp
for (int i = 0; i < (int)s.size(); i++) {
    char c = s[i];
    ...
}
// 或者
for (char c : s) { ... }
```

**大小写转换**（需要 `<cctype>`）：

```cpp
char up = toupper(c);     // 小写转大写，其他字符原样返回
char lo = tolower(c);
// 手写也行： c - 'a' + 'A'
```

**字符位移**（凯撒密码）：关键是**取模回绕**，别写成 `c + k` 越界。

```cpp
// 往后移 k 位，超过 z 绕回 a
c = (c - 'a' + k) % 26 + 'a';
```

**坑**：`toupper` / `tolower` 的形参是 `int`，直接传 `char` 在部分环境下可能因符号扩展出错，
保险写法是 `(char)tolower((unsigned char)c)`。

---

## 二、查表：字符 ↔ 数值的对照

最常见的是 26 个字母的桶：

```cpp
int cnt[26] = {0};
for (char c : s) {
    if (c >= 'a' && c <= 'z') cnt[c - 'a']++;
}
```

规则不规则时直接打表（P1765 手机按键次数）：

```cpp
// a~r 每 3 个一组，s~z 是 4 个一组
int key[26] = {1,2,3, 1,2,3, 1,2,3, 1,2,3, 1,2,3, 1,2,3, 1,2,3, 1,2,3,  1,2,3,4};
int presses = key[c - 'a'];
```

> 打表 > 现场算。**规则能一眼看穿就写死，比推公式可靠。**

---

## 三、切分：按空格拆词

```cpp
#include <sstream>
stringstream ss(s);
string w;
while (ss >> w) {
    // 每次拿到一个词
}
```

**坑**：`stringstream` 会**合并连续空格**，丢掉词与词之间的真实位置。
如果题目要输出「第一次出现的位置」（P308 就是），必须自己用双指针扫，记录下标。

---

## 四、子串：查找、替换、计数

```cpp
size_t pos = s.find("abc");     // 找不到返回 string::npos
if (pos != string::npos) { ... }

string part = s.substr(pos, 3); // 从 pos 开始取 3 个字符
```

**数出现几次**要注意推进位置，否则死循环：

```cpp
int cnt = 0;
size_t pos = 0;
while ((pos = s.find(t, pos)) != string::npos) {
    cnt++;
    pos += t.size();          // 不重叠计数；要允许重叠就改成 pos + 1
}
```

> `<string>::npos` 不是 0，是「找不到」的专用值。**判断存在性必须和它比，不能当布尔用。**

---

## 五、改结构：插入、删除、翻转

```cpp
s.insert(pos, t);                 // 在 pos 前插入 t
s.erase(pos, len);                // 从 pos 删 len 个
reverse(s.begin(), s.end());      // 整串翻转（需要 <algorithm>）
s = s + t;                        // 拼接
int len = (int)s.size();          // 长度
```

**坑**：`s.size()` 返回 `size_t`（无符号），`for (int i = 0; i < s.size(); i++)` 会报警告，
比较时转一下 `(int)s.size()`。`insert` 之后下标会整体后移，后面再用旧下标就错了。

---

## 怎么选（看到题先问这一句）

1. **题目给的是「一行话」还是「一个词」** → 决定 `getline` 还是 `cin >>`
2. **每个字符都要动** → 逐字符扫
3. **要统计字符出现次数 / 字符换成数值** → 查表（26 桶或打表）
4. **要按空格拆词** → 不关心位置用 `stringstream`，关心位置用双指针
5. **要找/数某个片段** → `find` + `substr`
6. **要在中间插、删、翻** → `insert` / `erase` / `reverse`
