# 数组的三种用法：计数 · 标记 · 搬运

> 数组题看起来五花八门，用法基本就这三种。**先判断属于哪一种，再动手。**
>
> | 用法 | 数组下标是 | 数组元素是 | 典型题 |
> | :-- | :-- | :-- | :-- |
> | **计数** | 数值本身 | 出现次数 | 统计频次、去重、桶排序 |
> | **标记** | 位置 / 编号 | 状态 0 或 1 | 砍树、开关灯、是否出现过 |
> | **搬运** | 位置 | 数据本体 | 倒序输出、旋转、蛇形填充 |

---

## 一、计数：数值即下标（桶模型）

**核心思想**：不要把数值仅仅看作数据，要把数值看作 **数组的地址**，建立 `数值 -> 数组下标` 的直接映射。

**前提约定**：数据范围 `0 ~ 1000`，桶数组开 `1001`，初始全 0。

```cpp
const int MAXN = 1000;
int bucket[MAXN + 1] = {0};
```

**核心代码**：边读边计数。

```cpp
int x;
while (cin >> x) {
    bucket[x]++;   // 数字 x 出现了，对应抽屉加一个
}
```

**四种典型用途**：

- 统计频次：`bucket[x]` 就是 x 出现的次数
- 判断是否出现过：`if (bucket[x] > 0)`
- 去重输出：从 0 遍历到 MAXN，`bucket[i] > 0` 才输出，天然升序
- 桶计数排序：遍历 i，把 i 打印 `bucket[i]` 次

```cpp
for (int i = 0; i <= MAXN; i++) {
    for (int j = 0; j < bucket[i]; j++) {
        cout << i << " ";
    }
}
```

> 代价：**时间 O(n + 值域)**。值域开得动才用桶；值域上亿就换成 `map` 或排序。

---

## 二、标记：值只存状态（布尔映射）

**核心思想**：数组元素不存数值，只存"是 / 否"两种状态。适合"某个位置有没有被处理过"。

**典型题**：P1047 校门外的树（砍树）、开灯问题。

```cpp
int road[10005] = {0};        // 0 表示树还在
// 砍掉 [u, v] 区间的树
for (int i = u; i <= v; i++) {
    road[i] = 1;              // 标记为 1，表示被砍
}
// 最后数一遍还在的
int cnt = 0;
for (int i = 0; i <= l; i++) {
    if (road[i] == 0) cnt++;
}
```

**与「计数」的区别**：计数关心"几次"，标记只关心"有没有"。用 `bool` 数组或 `int` 存 0/1 都行。

> 二维同理：网格题里 `vis[x][y]` 就是"这个格子走没走过"的标记数组，BFS 的第一块砖。

---

## 三、搬运：下标当坐标

**核心思想**：通过控制下标的移动顺序或映射关系，实现倒序、旋转、蛇形填充等空间操作。数组内容不变，**变的是访问顺序**。

**倒序搬运**（最常见）：

```cpp
for (int i = n - 1; i >= 0; i--) {
    cout << a[i] << " ";
}
```

**蛇形填充**（P5731）：用方向数组控制下标移动，撞边界就转向。

```cpp
int dx[] = {0, 1, 0, -1};
int dy[] = {1, 0, -1, 0};
// 每步 a[x][y] = 下一个数；越界或已填就转方向
```

> 判断关键：**题目要你改"数据"还是改"顺序"**。改顺序且不要求原地，通常最省事的是直接按目标顺序访问。

---

## 怎么选

写题前问自己一句：

1. **要统计"出现了几次"** → 计数（桶）
2. **要记录"有没有 / 走没走过"** → 标记（布尔数组）
3. **要改变"输出顺序 / 摆放位置"** → 搬运（控制下标）

三者会叠用：P1047 就是"标记 + 最后计数"；BFS 是"标记 + 搬运"。
