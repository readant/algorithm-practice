# 数组的三种模型

> 洛谷 [#103 入门4 数组](https://www.luogu.com.cn/training/103) 一共 20 题，看起来五花八门，
> 但**解法只有三个模型**。先认出属于哪一个，再动手。

---

## 一、核心算法模型

### 1. 桶模型（映射统计）：数值即下标

**核心思想**：不要把数值只看成数据，要看成**数组的地址**。建立 `数值 → 下标` 的直接映射，
下标访问是 O(1)，所以统计、去重、查存在性都能一次到位。

**实现技巧**：开一个比数据范围略大的数组，用数据值当索引。

**应用场景**：统计频次、判断是否出现过、去重输出、桶计数排序（P1554 梦中的统计）。

```cpp
const int MAXN = 1000;
int bucket[MAXN + 1] = {0};   // 1001 个抽屉，初始全 0

int x;
while (cin >> x) {
    bucket[x]++;              // 数字 x 出现了，对应抽屉 +1
}
```

### 2. 状态标签模型（布尔映射）：灯泡开关

**核心思想**：数组里存的不是数值，而是**状态**——亮/灭、砍/没砍、走过/没走过。

**实现技巧**：下标对应位置，值对应状态（0 或 1）；区间操作用一层 for 循环改状态。

**应用场景**：区间覆盖、区域标记、访问标记（P1047 校门外的树、P1161 开灯）。

```cpp
int road[10005] = {0};        // 0 = 树还在
// 砍掉 [u, v] 区间的树
for (int i = u; i <= v; i++) {
    road[i] = 1;              // 标记为 1，表示被砍
}
```

> 二维同理：网格题里的 `vis[x][y]` 就是"这个格子走没走过"，BFS 的第一块砖。

### 3. 模拟位移模型：坐标搬运工

**核心思想**：数组内容不变，**变的是访问顺序**。靠控制下标怎么走，实现倒序、旋转、蛇形填充。

**实现技巧**：逆向循环 `i--`；二维用方向数组 `dx[]/dy[]` 控制移动。

**应用场景**：倒序输出（P1427）、矩阵旋转（P1205）、蛇形填充（P5731）、二维坐标模拟（P1789）。

```cpp
// 倒序搬运：从最后一个抽屉往前拿
for (int i = n - 1; i >= 0; i--) {
    cout << a[i] << " ";
}
```

### 怎么选

1. 要**数出现几次** → 桶模型
2. 要**记录有没有 / 走没走过** → 状态标签
3. 要**改变输出顺序或摆放位置** → 模拟位移

三者会叠用：P1047 是"标记 + 最后计数"，BFS 是"标记 + 搬运"。

## 二、必须掌握的"编程利器"

| 利器 | 怎么用 | 为什么重要 |
| :-- | :-- | :-- |
| **全局数组** | 定义在 `main` 外面 | 自动清零，且能开得比局部大得多 |
| **多开 5–10 个单位** | 题目要 1000 就开 1010 | 挡住 0/1 起下标混乱导致的边界错误 |
| **`sort(a, a + n)`** | `<algorithm>` 头文件 | 需要排序时的首选，不必手写 |
| **`long long` 接累加** | `long long sum = 0;` | 累加会超 `int`（约 21 亿） |

```cpp
#include <algorithm>

const int MAXN = 1005;
int a[MAXN];                  // 全局：多开 5 个，默认全 0
```

## 三、初学者必踩的坑

**坑 1：随机数惊魂**

- 现象：每次运行结果不一样，或输出莫名其妙的负数
- 原因：**局部数组没初始化**，里面是内存残留的垃圾值
- 解决：定义成全局，或写 `int a[100] = {0};`

**坑 2：越界访问（RE 元凶）**

- 现象：洛谷报 RE，本地直接闪退
- 原因：`for (i = 0; i <= n; i++)` 访问了 `a[n]`，而数组只开到 `n-1`
- 解决：循环边界一律 `i < n`，牢记下标范围是 `0 ~ n-1`

**坑 3：小桶装大水（类型溢出）**

- 现象：正数范围题里算出负数
- 原因：累加过程中超过了 `int` 上限
- 解决：求和、乘积用 `long long`；乘法先转 `1LL * a * b`

## 四、学习建议

按 5 小时推进，一题一个模型，做完立刻回看对应小节：

| 时段 | 题目 | 练哪个模型 | 验收 |
| :-- | :-- | :-- | :-- |
| 第 1 小时 | P1427 小鱼的数字游戏 | 模拟位移 | 能读入不定长、倒序输出 |
| 第 2 小时 | P1047 校门外的树 | 状态标签 | 能说清"0/1 分别代表什么" |
| 第 3 小时 | P1554 梦中的统计 | 桶模型 | 能拆出每一位数字并计数 |
| 第 4 小时 | P1789 插火把 | 位移 + 标记（二维） | 边界写对，不越界 |
| 第 5 小时 | P2615 幻方 | 二维填数 | 只看规则就能写出循环 |

> 每做完一题，在 [题解归档](../../../../../题解归档/) 里找到对应目录，只记**一条**自己真踩过的坑，
> 不要抄整段题解。
