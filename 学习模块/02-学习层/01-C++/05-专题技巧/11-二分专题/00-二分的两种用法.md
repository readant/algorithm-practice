# 二分：两种用法

> 二分的本质不是"在有序数组里找数"，而是**利用单调性，每次砍掉一半**。
> 前提是**二段性**：区间能被分成"满足条件"和"不满足条件"两段。

| 用法 | 用来回答 | 前提 | 典型 |
| :-- | :-- | :-- | :-- |
| **二分查找** | 某个值在哪 / 有没有 | 数组**有序** | 查找、找左右边界 |
| **二分答案** | 最大能到多少 / 最小要多少 | 答案**有单调性** | 分巧克力、木棒切割 |

> **实际比赛里 90% 用的是二分答案**，不是二分查找。这也是最容易和"查找"搞混的地方。

---

## 一、核心算法模型

### 1. 前提：二段性，不是"有序"

很多人以为二分只能用在有序数组上。其实**有序只是二段性的一种特例**。

真正的条件：**存在一个分界点，左边全满足条件、右边全不满足**（或反过来）。

```
满足 满足 满足 满足 | 不满足 不满足 不满足
                ↑
             分界点（答案就在这附近）
```

所以像"求最小的 x 使 f(x) ≥ 目标"这种题，只要 `f` 单调，就能二分。

### 2. 两个模板（整数二分）

整数二分最大的坑是**死循环**和**差一**。所以不建议现场推，**背这两个模板**。

#### 模板 1：找左边界（满足条件的第一个）

区间划分为 `[l, mid]` 和 `[mid+1, r]`：

```cpp
while (l < r) {
    int mid = (l + r) >> 1;      // 偏左
    if (check(mid)) r = mid;     // mid 满足 → 答案在左半（含 mid）
    else l = mid + 1;            // 不满足 → 答案在右半（不含 mid）
}
// 结束时 l == r，就是答案
```

#### 模板 2：找右边界（满足条件的最后一个）

区间划分为 `[l, mid-1]` 和 `[mid, r]`：

```cpp
while (l < r) {
    int mid = (l + r + 1) >> 1;  // 必须 +1，偏右
    if (check(mid)) l = mid;     // mid 满足 → 答案在右半（含 mid）
    else r = mid - 1;            // 不满足 → 答案在左半
}
```

#### 为什么模板 2 必须 `+1`（死循环的根源）

假设 `l = 0, r = 1`：

```
mid = (0 + 1) / 2 = 0            ← 不 +1 时，mid 落在左边
如果 check(0) 为真，执行 l = mid = 0
→ l 还是 0，r 还是 1，区间完全没变 → 死循环
```

`+1` 之后 `mid = (0+1+1)/2 = 1`，`l = mid = 1`，区间缩小成 `[1,1]`，循环结束。

**记法：写 `l = mid` 的模板，`mid` 必须 `+1`。**

### 3. 二分答案：猜一个答案，验证它行不行

**核心思路**：不去直接求解，而是**在答案范围里猜一个值**，然后写一个 `check(mid)` 判断它是否可行。

**三步**：

1. **确定答案范围** `[l, r]`（不是数组下标，是答案可能的取值）
2. **写 `check(mid)`**：给定这个答案，能不能成立
3. **确定"最大化"还是"最小化"**，选对模板

#### 例题一：木棒切割

**题意**：n 根木棒，长度不等。要切出 K 段**等长**的木棒，求每段最长能多长。

**为什么能二分**：切的长度越短，能切出的段数越多——**单调**。

```cpp
// check：按长度 x 切，总段数够不够 K
bool check(int x, int a[], int n, int k) {
    long long cnt = 0;
    for (int i = 0; i < n; i++) cnt += a[i] / x;
    return cnt >= k;
}

int main() {
    int l = 1, r = maxLen;           // 答案范围：至少 1，最多取最长那根
    while (l < r) {
        int mid = (l + r + 1) >> 1;  // 求"最大"，用模板 2
        if (check(mid, a, n, k)) l = mid;
        else r = mid - 1;
    }
    cout << l << "\n";
}
```

**两个关键点**：

1. **求"最大"用模板 2**（`l = mid`，`mid +1`）；求"最小"用模板 1
2. **`cnt` 用 `long long`**：n 和段数都大时会超 `int`

#### 例题二：分巧克力（蓝桥真题）

**题意**：n 块巧克力，每块 `hᵢ × wᵢ`。要分给 K 个小朋友，每人一块**正方形**、大小相同。
求正方形边长最大是多少。

**check 怎么写**：边长为 `x` 时，每块巧克力能切出 `(hᵢ/x) × (wᵢ/x)` 块。

```cpp
bool check(int x) {
    long long cnt = 0;
    for (int i = 0; i < n; i++) {
        cnt += (long long)(h[i] / x) * (w[i] / x);
    }
    return cnt >= k;
}
```

**答案范围**：`l = 1, r = 100000`（题目给的边长上限），求最大 → 模板 2。

> 这题和木棒切割是同一个模型：**"每份能切出几个，累加起来够不够目标"**。
> 掌握了这个 check 写法，一类题全通。

### 怎么选

1. **数组有序，找某个值 / 左右边界** → 二分查找
2. **题目问"最大能是多少""最少要多少"，且答案越大越难满足** → 二分答案
3. **求最大值** → 模板 2（`l = mid`，`mid +1`）
4. **求最小值** → 模板 1（`r = mid`）

## 二、必须掌握的"编程利器"

| 利器 | 怎么用 | 为什么重要 |
| :-- | :-- | :-- |
| **背两个模板** | 别现场推 | 死循环和差一是二分最常见的错误 |
| **`check` 函数独立写** | 单独一个函数 | 二分只是框架，核心在 check |
| **`long long` 计数** | `cnt` 用 `long long` | 累加容易超 `int` |
| **`mid = l + (r-l)/2`** | 防溢出写法 | `l+r` 可能超 `int`（本题一般不需要） |

```cpp
// 求"满足条件的最小值"：模板 1
int l = 1, r = n;
while (l < r) {
    int mid = (l + r) >> 1;
    if (check(mid)) r = mid;
    else l = mid + 1;
}
// 此时 l 是最小可行值
```

## 三、初学者必踩的坑

**坑 1：死循环（最致命）**

- 现象：程序卡住不结束
- 原因：写了 `l = mid` 但 `mid` 没 `+1`，区间无法缩小
- 解决：**看到 `l = mid` 就写 `mid = (l+r+1)/2`**

**坑 2：差一（答案差 1）**

- 现象：提交后答案总是差 1
- 原因：`check` 的边界条件写错（`>=` 和 `>` 混用），或该用模板 1 用了模板 2
- 解决：用小数据（n=1 或 2）手动跑一遍，看 `l` 和 `r` 最后停在哪

**坑 3：`check` 写错，二分白搭**

- 现象：逻辑看着对，答案不对
- 原因：`check` 返回 true 时，答案应该在左半边还是右半边搞反了
- 解决：**先单独测试 `check`**，不要直接塞进二分里调试

**坑 4：答案范围设错**

- 现象：答案超出预期，或根本没搜到
- 原因：`r` 设小了（漏掉更大的可能），或 `l` 设大了
- 解决：先想清楚**答案的理论上界和下界**，宁大勿小

**坑 5：浮点二分没控制精度**

- 现象：死循环或精度不够
- 原因：浮点用 `while (l < r)` 永远不相等
- 解决：改成固定循环次数（如 100 次），或 `while (r - l > 1e-6)`

## 四、学习建议

按 5 小时推进：

| 时段 | 题目 | 练什么 | 验收标准 |
| :-- | :-- | :-- | :-- |
| 第 1 小时 | 二分查找模板 | 两个模板 | 能手写两个模板，说出 `+1` 的原因 |
| 第 2 小时 | 找左右边界 | 区间范围 | 能在一个有重复的数组里找出 `[first, last]` |
| 第 3 小时 | 木棒切割 | 二分答案 | 能写出 check，能说清"答案越大越难满足" |
| 第 4 小时 | 分巧克力（蓝桥） | 二分答案 | check 里能正确算 `(h/x)*(w/x)` |
| 第 5 小时 | 冶炼金属 / 123 | 综合 | 能独立把题目转成"求最大/最小的可行值" |

**每题验收动作**：

1. 说出这题是**二分查找**还是**二分答案**
2. 如果是二分答案：说出 `l` 和 `r` 的**含义**和范围
3. 说出用的是**模板 1 还是模板 2**，为什么
4. 说出 `check(mid)` 返回 true 时，答案在哪半边

> 二分的代码都很短，但**每一行都有讲究**。建议把两个模板抄在纸上，做题时对照。
