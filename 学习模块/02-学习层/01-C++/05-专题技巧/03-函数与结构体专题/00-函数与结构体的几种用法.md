# 函数与结构体的几种用法

> 这一篇不是讲语法（`int f(int x)` 怎么写你早就会了），而是讲**什么时候该动这四样东西**：
> 抽函数、引用传参、结构体打包、递归。

| 打法 | 什么时候用 | 关键点 | 典型题 |
| :-- | :-- | :-- | :-- |
| **抽函数** | 同一段逻辑要写第二遍 | 先想清楚「进去什么、出来什么」 | P1304 · P5735 · P5737 |
| **引用传参** | 要在函数里改调用者的变量；或传大对象 | 加 `&`，不改就加 `const` | P5736 |
| **结构体 + cmp** | 好几个字段要一起排序 | cmp 里只写 `<`，不写 `<=` | 蓝桥杯多关键字排序高频 |
| **递归** | 问题能拆成**同样形状**的小问题 | 先写出口，再写自己 | P5739 |
| **全局数组** | 几个函数共用一份数据 / 开得很大 | 放 `main` 外面，默认全 0 | P5736 |

## 一、抽函数：什么时候值得抽

**判据只有一条：这段逻辑你要写第二遍。** 只写一次的，不要抽——抽了反而要来回翻。

```cpp
#include <iostream>
using namespace std;

bool isPrime(int x) {            // 进去：一个数；出来：真假
    if (x < 2) return false;
    for (int i = 2; i * i <= x; i++) {
        if (x % i == 0) return false;
    }
    return true;
}
```

**抽函数时先回答两个问题**，答不上就别抽：

1. **它需要什么**（参数）
2. **它要给出什么**（返回值 vs 直接改外面的变量）

> P1304 哥德巴赫猜想里，`isPrime` 一个函数被调用上百次——这才是抽函数的意义。
> P5735 距离函数、P5737 闰年判断，都是「一段判断/计算用一个名字代替」。

## 二、引用传参：`&` 加不加，结果不一样

```cpp
void addOne(int x)  { x++; }      // 改的是副本，外面不变
void addOne2(int& x){ x++; }      // 改的就是外面那个
```

**三种写法，用途不同**：

| 写法 | 用途 |
| :-- | :-- |
| `int x` | 小数据，只读，不想被改 |
| `int& x` | 要在函数里改调用者的变量 |
| `const string& s` | 大数据只读——**省一次拷贝** |

```cpp
// 传 string / vector 一律加 const &
int countA(const string& s) {
    int c = 0;
    for (char ch : s) if (ch == 'a') c++;
    return c;
}
```

**坑**：数组当参数会**退化成指针**，长度丢了，必须另外传：

```cpp
void fill(int a[], int n) {       // n 必须单独传，别指望 sizeof
    for (int i = 0; i < n; i++) a[i] = 0;
}
```

## 三、结构体 + cmp：多关键字排序

蓝桥杯几乎每场都有「按第一关键字升序、第二关键字降序」这种题。

```cpp
#include <algorithm>

struct Node {
    int id;
    int score;
};

bool cmp(const Node& a, const Node& b) {
    if (a.score != b.score) return a.score > b.score;  // 分数高的在前
    return a.id < b.id;                                // 同分按 id 升序
}

// 用法
Node a[1005];
sort(a, a + n, cmp);
```

**坑（这条最容易错）**：cmp 里**只能写 `<` 或 `>`，绝不能写 `<=`**。
写成 `<=` 时，两个相等的元素互相「小于」，排序会越界或死循环。

> 记法：**cmp 回答的是「a 该不该排在 b 前面」，不是「a 是否小于等于 b」。**

## 四、递归：先写出口，再写自己

```cpp
long long fact(int n) {
    if (n <= 1) return 1;         // 出口必须第一句写
    return 1LL * n * fact(n - 1); // 注意 1LL，阶乘很快溢出 int
}
```

**写递归的顺序永远是**：

1. 出口是什么（n=0 / n=1 / 边界）
2. 大问题怎么变成小一号的同一个问题
3. 小问题的答案怎么拼成大问题的答案

**坑**：没写出口 → 栈溢出（本地表现为程序直接崩，OJ 上是 RE）。
P5739 计算阶乘就是最小的递归练习：出口 `n<=1` 返回 1。

## 五、全局数组：跨函数共用

```cpp
const int MAXN = 100005;
int a[MAXN];            // 放 main 外面：默认全 0，且不占栈

void init() { for (int i = 0; i < MAXN; i++) a[i] = 0; }
```

**为什么放外面**：

1. 函数里开 `int a[100000]` 会**爆栈**（栈通常只有几 MB）
2. 全局默认初始化为 0，省去 memset
3. 多个函数要访问同一份数据时，不用一层层传参

> 代价：全局变量谁都能改，出了 bug 难查。**只给「确实要共享」的数组用**，别把所有变量都扔全局。

---

## 怎么选（动手前问自己）

1. **这段逻辑要写第二遍吗** → 是就抽函数，否就不抽
2. **函数要改外面的变量吗** → 要就 `int&`；只是读大对象就 `const T&`
3. **是不是好几个字段要一起排序** → 结构体 + `cmp`，且 cmp 里只写 `<`
4. **能不能拆成同样形状的小问题** → 能就递归，先写出口
5. **数据要跨函数共享 / 量大** → 全局数组
