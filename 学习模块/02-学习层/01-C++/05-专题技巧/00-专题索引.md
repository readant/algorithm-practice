# 专题技巧

> **这一层按 12 个专题组织**，一块一篇，顺序是：
> 数组 → 高精度 → 字符串 → 函数与结构体 → C++数据结构 → 递归 → 前缀和 → 差分 →
> 模拟 → 贪心 → 二分 → 广度搜索。
> 另附两篇补充：搜索（DFS）、双指针。

| 层 | 回答什么 |
| :-- | :-- |
| **专题（本层）** | 这块有哪几种模型？会踩什么坑？该练哪几道题？ |
| [算法篇](../03-基础算法体系/) | 某一个技术具体怎么写？ |

## 每篇固定四段式

固定这四段，不另发明格式：

1. **核心算法模型** —— 2~3 个模型，每个给：核心思想 / 实现技巧 / 应用场景 / 核心代码
2. **必须掌握的编程利器** —— 这块最实用的 3~5 个工具或写法
3. **初学者必踩的坑** —— 现象 / 原因 / 解决，一条一个坑
4. **学习建议** —— 分小时节奏 + 指定题目 + 验收标准

> 第 3、4 段是最容易被省略、也最值钱的两段。**只写 1、2 段的不算完成。**

两处例外，已在各自篇首注明：高精度按**运算**分（加/减/乘/除，不是按模型分）；
C++数据结构专注**怎么选容器**，用法细节指向 A1。

## 怎么用

**专题是刷完题回头归纳用的，不是刷之前通读的。**

1. 按块次推进：当前在哪一块，就读哪一篇
2. 读到"三、必踩的坑"，**逐条对照自己有没有犯过**
3. 读到"四、学习建议"，按小时做那几道题
4. 做完题回到"一、核心算法模型"，确认自己用的是哪个模型

> 每篇末尾的验收动作不是摆设。**能说出"这题属于哪个模型、为什么不是另外两个"，
> 才算真过了这一块。**

## 为什么不按「算法名」分

按算法名分（二分/贪心/前缀和）是**看完题之后**才知道的。这一层要解决的是
「这块该学什么、练哪几道」，所以跟块次走，而不是跟你还没学到的算法名走。
