# 搜索（DFS）

> DFS 是「**不撞南墙不回头**」：一条路走到黑，走不通就退回上一个路口换条路。
> 它靠**递归**实现，本质是**枚举所有可能**。

| 用途 | 用 DFS 还是 BFS | 原因 |
| :-- | :-- | :-- |
| **最短路 / 最少步数** | BFS | DFS 第一次到的不一定最短 |
| **有没有一条路能到** | 都行 | DFS 代码更短 |
| **枚举所有方案**（排列、组合、棋盘） | **DFS** | BFS 会把所有方案挤在队列里，爆内存 |
| **求连通块** | 都行 | 两者都能做 |

## 一、核心算法模型

### 1. 两种形态

**形态 A：只问"能不能到"**——不需要记录路径，走到就返回

```cpp
bool dfs(int x, int y) {
    if (x == 目标x && y == 目标y) return true;   // 出口：到了
    vis[x][y] = true;                            // 标记已访问
    for (int k = 0; k < 4; k++) {
        int nx = x + dx[k], ny = y + dy[k];
        if (越界(nx, ny) || vis[nx][ny] || 是墙(nx, ny)) continue;
        if (dfs(nx, ny)) return true;            // 有一条路能到就够
    }
    return false;                                // 四条路都不通
}
```

**形态 B：枚举所有方案**——必须**回溯**（撤销标记），否则后面的方案会受影响

```cpp
void dfs(int step) {
    if (step == n) {          // 出口：凑够了，输出一个方案
        print();
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (used[i]) continue;
        used[i] = true;       // ① 选择
        path[step] = i;
        dfs(step + 1);        // ② 递归
        used[i] = false;      // ③ 撤销（回溯）← 关键
    }
}
```

> **形态 B 的 ③ 是最容易忘的**。忘了就是"前面的选择影响了后面的分支"，
> 结果是方案少了或多了。这叫**回溯**，是 DFS 的核心动作。

### 2. 例题拆解：全排列

**题意**：输出 1~n 的所有排列。

**为什么用 DFS**：要**枚举所有**方案，而且每个方案是一条"路径"。

```cpp
#include <iostream>
using namespace std;

int n;
int path[10];
bool used[10];

void dfs(int step) {
    if (step == n) {                       // 出口：n 个位置都填满了
        for (int i = 0; i < n; i++) cout << path[i] << " ";
        cout << "\n";
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (used[i]) continue;             // 已经用过的数不能再选
        used[i] = true;                    // 选择
        path[step] = i;
        dfs(step + 1);                     // 进入下一层
        used[i] = false;                   // 撤销 —— 关键的一行
    }
}
```

**执行过程**（n=3）：

```
选 1 → 选 2 → 选 3 → 输出 1 2 3 → 撤销 3
              → 撤销 2 → 选 3 → 选 2 → 输出 1 3 2 → ...
选 2 → ...
```

**递归树是一棵"选择树"**：每一层代表"第 step 个位置填什么"。

### 3. 例题拆解：N 皇后（约束型）

**题意**：n×n 棋盘放 n 个皇后，任意两个不能同行、同列、同对角线。问有多少种放法。

**和全排列的区别**：不是"随便选"，而是**选的时候要检查约束**。

```cpp
int n, ans = 0;
bool col[20], d1[40], d2[40];        // 列、主对角线、副对角线

void dfs(int row) {
    if (row == n) { ans++; return; }         // 每行都放好了
    for (int c = 0; c < n; c++) {
        if (col[c] || d1[row + c] || d2[row - c + n]) continue;   // 冲突就跳过
        col[c] = d1[row + c] = d2[row - c + n] = true;
        dfs(row + 1);
        col[c] = d1[row + c] = d2[row - c + n] = false;           // 回溯
    }
}
```

**对角线怎么表示**（这题的关键技巧）：

- 主对角线（↘方向）：`行 - 列` 是定值 → 用 `row - c + n` 平移成正数当数组下标
- 副对角线（↙方向）：`行 + 列` 是定值 → 直接 `row + c`

> 用**数组记录约束状态**，把 O(n) 的检查降到 O(1)，这是所有"约束型搜索"的通用手法。

### 4. 剪枝：让 DFS 能跑完

DFS 最怕**方案爆炸**。n 稍大一点，`2ⁿ` 或 `n!` 就爆了。

**剪枝** = 提前判断"这条路走下去不可能有答案"，直接返回。

```cpp
void dfs(int step, int cost) {
    if (cost >= best) return;         // 剪枝：已经比当前最优差，没必要走
    if (step == n) { best = cost; return; }
    ...
}
```

三种常见剪枝：

| 类型 | 什么时候用 | 例 |
| :-- | :-- | :-- |
| **最优性剪枝** | 求最小值/最大值 | 当前花费已超过已知最优 → 返回 |
| **可行性剪枝** | 有约束条件 | 剩余步数不够 / 已经超限 → 返回 |
| **顺序剪枝** | 同上 | 先试更有希望的分支，让最优值尽早变小 |

> 剪枝能过多少，取决于你找的"提前否决条件"有多强。**这是 DFS 提分的核心。**

### 5. DFS 与 BFS 怎么选

| 维度 | DFS | BFS |
| :-- | :-- | :-- |
| 实现 | 递归（或栈） | 队列 |
| 最短路 | ❌ 不保证 | ✅ 保证（等代价） |
| 内存 | 小（只存一条路径） | 大（存一整层） |
| 枚举所有方案 | ✅ 天然适合 | ❌ 队列会爆 |
| 常见用途 | 排列组合、棋盘、连通性 | 最短路、层序遍历 |

**一句话**：**要"最少"用 BFS，要"所有"用 DFS。**

## 二、必须掌握的"编程利器"

| 利器 | 怎么用 | 为什么重要 |
| :-- | :-- | :-- |
| **回溯（撤销）** | 递归返回后把标记改回去 | 忘了它，后续分支就错了 |
| **访问标记** | `vis[]` / `used[]` | 防止重复访问和死循环 |
| **约束状态数组** | N 皇后的 `col[]`、`d1[]` | 把 O(n) 检查降到 O(1) |
| **剪枝** | 提前 `return` | 不剪枝，n=15 就跑不动 |

```cpp
#include <iostream>
using namespace std;

int n;
int path[20];
bool used[20];
```

## 三、初学者必踩的坑

**坑 1：忘了回溯**

- 现象：方案数量不对（偏少），或者输出重复
- 原因：递归返回后没把 `used[i] = false`，后面的分支以为这个数还被占着
- 解决：**"选择"和"撤销"必须成对出现**，写在递归调用的前后

**坑 2：递归太深，栈溢出**

- 现象：n 到几千时崩
- 原因：DFS 深度 = 递归层数，超过栈容量
- 解决：改 BFS 或迭代写法；题目一般会限制深度

**坑 3：没有剪枝，超时**

- 现象：小数据能过，大数据 TLE
- 原因：方案数指数增长
- 解决：找"提前否决条件"，写最优性/可行性剪枝

**坑 4：求最短路却用了 DFS**

- 现象：答案不是最短的
- 原因：DFS 第一次到达终点的路径**不一定最短**
- 解决：求最短路一律用 BFS（等代价）或 Dijkstra（不等代价）

**坑 5：全局变量在多次调用间没清空**

- 现象：多组数据时，第二组答案被第一组污染
- 原因：`vis` / `used` / `ans` 是全局的，上一组没清零
- 解决：每组数据开头 `memset`，或把状态改成函数参数

## 四、学习建议

按 5 小时推进：

| 时段 | 题目 | 练什么 | 验收标准 |
| :-- | :-- | :-- | :-- |
| 第 1 小时 | 全排列 | 选择 + 回溯 | 能画出 n=3 的选择树，`used[]` 变化正确 |
| 第 2 小时 | 迷宫能否到达 | 网格 DFS | 三个判断（越界/墙/已访问）一个不少 |
| 第 3 小时 | 组合数（C(n,m)） | 剪枝入门 | 能加一个"剩余不够"的剪枝 |
| 第 4 小时 | N 皇后 | 约束状态数组 | 能用 `row±col` 表示两条对角线 |
| 第 5 小时 | 蓝桥真题：小朋友崇拜圈 / 最大数字 | 综合 | 能判断该用 DFS 还是 BFS |

**每题验收动作**：

1. 说出**出口**是什么（什么时候算找到一个方案）
2. 说出**"选择"和"撤销"**分别在哪一行
3. 说出这题能不能剪枝，剪什么

> DFS 的代码短，但**每一层的状态都要想清楚**。建议先在纸上画 n=3 的选择树。
