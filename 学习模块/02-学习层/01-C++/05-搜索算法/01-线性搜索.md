# 线性搜索

## 概述

线性搜索（顺序搜索）是最简单的搜索算法，逐个遍历数组中的元素，直到找到目标值或遍历完整个数组。

## 算法原理

1. 从数组的第一个元素开始
2. 依次比较每个元素与目标值
3. 如果找到目标值，返回其索引
4. 如果遍历完整个数组都没找到，返回-1

## C++实现

### 基本版本

```cpp
#include <iostream>
#include <vector>
using namespace std;

int linearSearch(vector<int>& arr, int target) {
    for (int i = 0; i < arr.size(); i++) {
        if (arr[i] == target) {
            return i;
        }
    }
    return -1;
}

int main() {
    vector<int> arr = {10, 23, 45, 70, 11, 15};
    int target = 70;
    
    int result = linearSearch(arr, target);
    
    if (result != -1) {
        cout << "Found at index: " << result << endl;
    } else {
        cout << "Not found" << endl;
    }
    
    return 0;
}
```

### 哨兵线性搜索

```cpp
#include <iostream>
#include <vector>
using namespace std;

int sentinelLinearSearch(vector<int>& arr, int target) {
    int n = arr.size();
    int last = arr[n - 1];
    
    // 设置哨兵
    arr[n - 1] = target;
    
    int i = 0;
    while (arr[i] != target) {
        i++;
    }
    
    // 恢复原值
    arr[n - 1] = last;
    
    if (i < n - 1 || arr[n - 1] == target) {
        return i;
    }
    
    return -1;
}

int main() {
    vector<int> arr = {10, 23, 45, 70, 11, 15};
    int target = 70;
    
    int result = sentinelLinearSearch(arr, target);
    cout << "Found at index: " << result << endl;
    
    return 0;
}
```

### 查找所有出现位置

```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<int> findAllOccurrences(vector<int>& arr, int target) {
    vector<int> indices;
    
    for (int i = 0; i < arr.size(); i++) {
        if (arr[i] == target) {
            indices.push_back(i);
        }
    }
    
    return indices;
}

int main() {
    vector<int> arr = {1, 3, 5, 3, 7, 3, 9};
    int target = 3;
    
    vector<int> indices = findAllOccurrences(arr, target);
    
    cout << "Found at indices: ";
    for (int idx : indices) {
        cout << idx << " ";
    }
    cout << endl;
    
    return 0;
}
```

### 查找最小/最大值

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

int findMin(vector<int>& arr) {
    if (arr.empty()) return -1;
    
    int minVal = INT_MAX;
    for (int x : arr) {
        minVal = min(minVal, x);
    }
    return minVal;
}

int findMax(vector<int>& arr) {
    if (arr.empty()) return -1;
    
    int maxVal = INT_MIN;
    for (int x : arr) {
        maxVal = max(maxVal, x);
    }
    return maxVal;
}

pair<int, int> findMinAndMax(vector<int>& arr) {
    if (arr.empty()) return {-1, -1};
    
    int minVal = arr[0], maxVal = arr[0];
    
    for (int i = 1; i < arr.size(); i++) {
        if (arr[i] < minVal) minVal = arr[i];
        if (arr[i] > maxVal) maxVal = arr[i];
    }
    
    return {minVal, maxVal};
}

int main() {
    vector<int> arr = {3, 1, 4, 1, 5, 9, 2, 6};
    
    cout << "Min: " << findMin(arr) << endl;
    cout << "Max: " << findMax(arr) << endl;
    
    auto [min, max] = findMinAndMax(arr);
    cout << "Min and Max: " << min << ", " << max << endl;
    
    return 0;
}
```

## 复杂度分析

| 情况 | 时间复杂度 | 说明 |
|------|------------|------|
| 最好 | O(1) | 第一个元素就是目标 |
| 最坏 | O(n) | 目标在最后或不存在 |
| 平均 | O(n) | - |
| 空间复杂度 | O(1) | - |

## 适用场景

1. 数据量小（n < 100）
2. 数据未排序
3. 只需要查找一次
4. 链表等不支持随机访问的数据结构

## 练习题

### 题目1：找不同
**题目描述**：给定两个字符串s和t，找出它们中不同的字符。

**参考代码**：
```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

char findTheDifference(string s, string t) {
    vector<int> count(26, 0);
    
    for (char c : s) {
        count[c - 'a']++;
    }
    
    for (char c : t) {
        count[c - 'a']--;
        if (count[c - 'a'] < 0) {
            return c;
        }
    }
    
    return ' ';
}

int main() {
    cout << findTheDifference("abcd", "abcde") << endl;  // 'e'
    cout << findTheDifference("", "y") << endl;          // 'y'
    
    return 0;
}
```

### 题目2：只出现一次的数字
**题目描述**：给定一个非空整数数组，除了某个元素只出现一次以外，其余每个元素均出现两次。

**参考代码**：
```cpp
#include <iostream>
#include <vector>
using namespace std;

int singleNumber(vector<int>& nums) {
    int result = 0;
    for (int num : nums) {
        result ^= num;
    }
    return result;
}

int main() {
    vector<int> nums = {4, 1, 2, 1, 2};
    cout << singleNumber(nums) << endl;  // 4
    
    return 0;
}
```

## 线性搜索的优化

### 二分搜索对比

| 特性 | 线性搜索 | 二分搜索 |
|------|----------|----------|
| 时间复杂度 | O(n) | O(log n) |
| 数据要求 | 无 | 有序 |
| 实现难度 | 简单 | 中等 |
| 空间复杂度 | O(1) | O(1) |

## 小结

1. 线性搜索简单易实现
2. 适合小规模或未排序数据
3. 时间复杂度O(n)，效率较低
4. 实际应用中较少单独使用
