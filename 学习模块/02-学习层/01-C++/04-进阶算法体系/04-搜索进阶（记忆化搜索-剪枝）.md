# 搜索进阶

## 1. 记忆化搜索

**核心思想**：DFS + 缓存，避免重复计算

### 斐波那契数列

```cpp
int memo[100];

int fib(int n) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    
    memo[n] = fib(n - 1) + fib(n - 2);
    return memo[n];
}
```

### 零钱兑换

```cpp
int coinChange(vector<int>& coins, int amount) {
    vector<int> memo(amount + 1, -1);
    
    function<int(int)> dfs = [&](int remaining) -> int {
        if (remaining == 0) return 0;
        if (remaining < 0) return -1;
        if (memo[remaining] != -1) return memo[remaining];
        
        int minCoins = INT_MAX;
        for (int coin : coins) {
            int result = dfs(remaining - coin);
            if (result != -1) {
                minCoins = min(minCoins, result + 1);
            }
        }
        
        memo[remaining] = (minCoins == INT_MAX) ? -1 : minCoins;
        return memo[remaining];
    };
    
    return dfs(amount);
}
```

## 2. 剪枝

**核心思想**：提前排除不可能的分支

### 全排列剪枝

```cpp
void permute(vector<int>& nums, vector<bool>& used, vector<int>& path, 
             vector<vector<int>>& result) {
    if (path.size() == nums.size()) {
        result.push_back(path);
        return;
    }
    
    for (int i = 0; i < nums.size(); i++) {
        if (used[i]) continue;
        
        // 剪枝：跳过重复元素
        if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;
        
        used[i] = true;
        path.push_back(nums[i]);
        permute(nums, used, path, result);
        path.pop_back();
        used[i] = false;
    }
}
```

### N皇后剪枝

```cpp
void solveNQueens(int n, int row, vector<int>& queens,
                  vector<bool>& col, vector<bool>& diag1, vector<bool>& diag2,
                  vector<vector<string>>& result) {
    if (row == n) {
        // 构造棋盘
        vector<string> board(n, string(n, '.'));
        for (int i = 0; i < n; i++) {
            board[i][queens[i]] = 'Q';
        }
        result.push_back(board);
        return;
    }
    
    for (int c = 0; c < n; c++) {
        // 剪枝：检查列和对角线
        if (col[c] || diag1[row + c] || diag2[row - c + n - 1]) continue;
        
        queens[row] = c;
        col[c] = diag1[row + c] = diag2[row - c + n - 1] = true;
        
        solveNQueens(n, row + 1, queens, col, diag1, diag2, result);
        
        col[c] = diag1[row + c] = diag2[row - c + n - 1] = false;
    }
}
```

## 3. 迭代加深

**核心思想**：限制搜索深度，逐步加深

```cpp
bool dfs(vector<int>& nums, int target, int depth, int maxDepth) {
    if (target == 0) return true;
    if (depth == maxDepth) return false;
    
    for (int num : nums) {
        if (num <= target) {
            if (dfs(nums, target - num, depth + 1, maxDepth)) {
                return true;
            }
        }
    }
    
    return false;
}

bool isSumPossible(vector<int>& nums, int target) {
    for (int depth = 1; depth <= nums.size(); depth++) {
        if (dfs(nums, target, 0, depth)) return true;
    }
    return false;
}
```

## 剪枝策略

| 策略 | 说明 |
|------|------|
| 可行性剪枝 | 提前判断不可能得到解 |
| 最优性剪枝 | 当前解已不如已知最优解 |
| 对称性剪枝 | 跳过等价的情况 |
| 排序剪枝 | 排序后跳过重复元素 |
