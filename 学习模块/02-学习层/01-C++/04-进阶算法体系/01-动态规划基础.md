# 动态规划基础

## 概述

动态规划（DP）通过将问题分解为子问题，存储子问题的解来避免重复计算。

---

## 核心概念

| 概念 | 说明 |
|------|------|
| 最优子结构 | 问题的最优解包含子问题的最优解 |
| 重叠子问题 | 相同子问题被多次计算 |
| 状态转移方程 | dp[i] 与 dp[i-1], dp[i-2]... 的关系 |
| 边界条件 | 初始状态的值 |

---

## 解题步骤

```
1. 定义状态：dp[i] 表示什么
2. 写出状态转移方程
3. 确定边界条件
4. 确定遍历顺序
5. 验证（手动模拟小规模数据）
```

## 经典入门题

### 斐波那契数列

```cpp
int fib(int n) {
    if (n <= 1) return n;
    
    vector<int> dp(n + 1);
    dp[0] = 0;
    dp[1] = 1;
    
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    
    return dp[n];
}
```

### 爬楼梯

```cpp
int climbStairs(int n) {
    if (n <= 2) return n;
    
    vector<int> dp(n + 1);
    dp[1] = 1;
    dp[2] = 2;
    
    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    
    return dp[n];
}
```

### 最大子数组和

```cpp
int maxSubArray(vector<int>& nums) {
    int maxSum = nums[0];
    int currentSum = nums[0];
    
    for (int i = 1; i < nums.size(); i++) {
        currentSum = max(nums[i], currentSum + nums[i]);
        maxSum = max(maxSum, currentSum);
    }
    
    return maxSum;
}
```

## 一维DP模板

```cpp
// 线性DP
for (int i = 1; i <= n; i++) {
    dp[i] = 某个基于dp[i-1], dp[i-2]的表达式;
}
```

---

## 二维DP模板

```cpp
// 网格DP
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        dp[i][j] = 某个基于dp[i-1][j], dp[i][j-1]的表达式;
    }
}
```
