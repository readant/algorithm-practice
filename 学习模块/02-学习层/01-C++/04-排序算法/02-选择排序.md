# 选择排序

## 概述

选择排序是一种简单直观的排序算法，每次从未排序部分选择最小元素，放到已排序部分的末尾。

## 算法原理

1. 在未排序序列中找到最小元素，存放到排序序列的起始位置
2. 再从剩余未排序元素中继续寻找最小元素，然后放到已排序序列的末尾
3. 重复第二步，直到所有元素均排序完毕

## C++实现

### 基本版本

```cpp
#include <iostream>
#include <vector>
using namespace std;

void selectionSort(vector<int>& arr) {
    int n = arr.size();
    
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        
        // 在未排序部分找到最小元素
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) {
                minIdx = j;
            }
        }
        
        // 将最小元素放到正确位置
        if (minIdx != i) {
            swap(arr[i], arr[minIdx]);
        }
    }
}

int main() {
    vector<int> arr = {64, 25, 12, 22, 11};
    
    selectionSort(arr);
    
    cout << "Sorted array: ";
    for (int x : arr) cout << x << " ";
    cout << endl;
    
    return 0;
}
```

### 优化版本（双向选择排序）

```cpp
#include <iostream>
#include <vector>
using namespace std;

void doubleSelectionSort(vector<int>& arr) {
    int left = 0;
    int right = arr.size() - 1;
    
    while (left < right) {
        int minIdx = left;
        int maxIdx = right;
        
        for (int i = left; i <= right; i++) {
            if (arr[i] < arr[minIdx]) minIdx = i;
            if (arr[i] > arr[maxIdx]) maxIdx = i;
        }
        
        // 将最小值放到左边
        swap(arr[left], arr[minIdx]);
        
        // 如果最大值在left位置，需要更新maxIdx
        if (maxIdx == left) maxIdx = minIdx;
        
        // 将最大值放到右边
        swap(arr[right], arr[maxIdx]);
        
        left++;
        right--;
    }
}

int main() {
    vector<int> arr = {64, 25, 12, 22, 11};
    
    doubleSelectionSort(arr);
    
    for (int x : arr) cout << x << " ";
    cout << endl;
    
    return 0;
}
```

## 执行过程演示

```
原始数组: [64, 25, 12, 22, 11]

第1轮:
[64, 25, 12, 22, 11] -> 找到最小值11，与64交换 -> [11, 25, 12, 22, 64]
                        ↑ 已排序部分: [11]

第2轮:
[11, 25, 12, 22, 64] -> 找到最小值12，与25交换 -> [11, 12, 25, 22, 64]
                        ↑ 已排序部分: [11, 12]

第3轮:
[11, 12, 25, 22, 64] -> 找到最小值22，与25交换 -> [11, 12, 22, 25, 64]
                        ↑ 已排序部分: [11, 12, 22]

第4轮:
[11, 12, 22, 25, 64] -> 找到最小值25，已在正确位置
                        ↑ 已排序部分: [11, 12, 22, 25, 64]

排序完成: [11, 12, 22, 25, 64]
```

## 复杂度分析

| 情况 | 时间复杂度 | 说明 |
|------|------------|------|
| 最好 | O(n²) | 即使有序也要扫描 |
| 最坏 | O(n²) | 逆序 |
| 平均 | O(n²) | - |
| 空间复杂度 | O(1) | 原地排序 |

## 稳定性

选择排序是**不稳定排序**，相等元素的相对位置可能改变。

例如：[5, 5, 3]，第一次选择3与第一个5交换，得到[3, 5, 5]，两个5的相对位置改变了。

## 与冒泡排序的比较

| 特性 | 选择排序 | 冒泡排序 |
|------|----------|----------|
| 交换次数 | O(n) | O(n²) |
| 比较次数 | O(n²) | O(n²) |
| 稳定性 | 不稳定 | 稳定 |
| 适用场景 | 交换代价大 | 需要稳定排序 |

## 练习题

### 题目1：最小交换次数排序
**题目描述**：给定一个数组，求将其排序所需的最小交换次数。

**参考代码**：
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int minSwaps(vector<int>& nums) {
    int n = nums.size();
    vector<pair<int, int>> arr(n);
    
    for (int i = 0; i < n; i++) {
        arr[i] = {nums[i], i};
    }
    
    sort(arr.begin(), arr.end());
    
    vector<bool> visited(n, false);
    int swaps = 0;
    
    for (int i = 0; i < n; i++) {
        if (visited[i] || arr[i].second == i) continue;
        
        int cycleSize = 0;
        int j = i;
        
        while (!visited[j]) {
            visited[j] = true;
            j = arr[j].second;
            cycleSize++;
        }
        
        if (cycleSize > 0) {
            swaps += cycleSize - 1;
        }
    }
    
    return swaps;
}

int main() {
    vector<int> nums = {4, 3, 1, 2};
    cout << minSwaps(nums) << endl;  // 3
    
    return 0;
}
```

### 题目2：数组的第K大元素
**题目描述**：在未排序的数组中找到第K大的元素。

**参考代码**：
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 选择排序思想：找到第K大的元素
int findKthLargest(vector<int>& nums, int k) {
    int n = nums.size();
    
    for (int i = 0; i < k; i++) {
        int maxIdx = i;
        
        for (int j = i + 1; j < n; j++) {
            if (nums[j] > nums[maxIdx]) {
                maxIdx = j;
            }
        }
        
        swap(nums[i], nums[maxIdx]);
    }
    
    return nums[k - 1];
}

int main() {
    vector<int> nums = {3, 2, 1, 5, 6, 4};
    int k = 2;
    
    cout << findKthLargest(nums, k) << endl;  // 5
    
    return 0;
}
```

## 小结

1. 选择排序简单，但效率较低
2. 交换次数少，适合交换代价大的场景
3. 不稳定排序，不适合需要稳定性的场景
4. 实际应用中较少使用
