# 冒泡排序

## 概述

冒泡排序是最简单的排序算法之一，通过重复比较相邻元素并交换位置，将最大元素逐步"冒泡"到数组末尾。

## 算法原理

1. 比较相邻的元素，如果第一个比第二个大，就交换它们
2. 对每一对相邻元素做同样的工作，从开始第一对到结尾的最后一对
3. 针对所有的元素重复以上的步骤，除了最后一个
4. 重复上述步骤，直到排序完成

## C++实现

### 基本版本

```cpp
#include <iostream>
#include <vector>
using namespace std;

void bubbleSort(vector<int>& arr) {
    int n = arr.size();
    
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
            }
        }
    }
}

int main() {
    vector<int> arr = {64, 34, 25, 12, 22, 11, 90};
    
    bubbleSort(arr);
    
    cout << "Sorted array: ";
    for (int x : arr) cout << x << " ";
    cout << endl;
    
    return 0;
}
```

### 优化版本（提前终止）

```cpp
#include <iostream>
#include <vector>
using namespace std;

void bubbleSortOptimized(vector<int>& arr) {
    int n = arr.size();
    bool swapped;
    
    for (int i = 0; i < n - 1; i++) {
        swapped = false;
        
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }
        
        // 如果没有交换，说明已经有序
        if (!swapped) break;
    }
}

int main() {
    vector<int> arr = {1, 2, 3, 4, 5};  // 已有序
    
    bubbleSortOptimized(arr);
    
    for (int x : arr) cout << x << " ";
    cout << endl;
    
    return 0;
}
```

### 记录最后一次交换位置

```cpp
#include <iostream>
#include <vector>
using namespace std;

void bubbleSortEnhanced(vector<int>& arr) {
    int n = arr.size();
    int lastSwapPos;
    
    while (n > 1) {
        lastSwapPos = 0;
        
        for (int i = 0; i < n - 1; i++) {
            if (arr[i] > arr[i + 1]) {
                swap(arr[i], arr[i + 1]);
                lastSwapPos = i + 1;
            }
        }
        
        n = lastSwapPos;  // 优化：只排序未确定的部分
    }
}

int main() {
    vector<int> arr = {5, 3, 1, 2, 4};
    
    bubbleSortEnhanced(arr);
    
    for (int x : arr) cout << x << " ";
    cout << endl;
    
    return 0;
}
```

## 执行过程演示

```
原始数组: [64, 34, 25, 12]

第1轮:
[64, 34, 25, 12] -> 比较64和34，交换 -> [34, 64, 25, 12]
[34, 64, 25, 12] -> 比较64和25，交换 -> [34, 25, 64, 12]
[34, 25, 64, 12] -> 比较64和12，交换 -> [34, 25, 12, 64]

第2轮:
[34, 25, 12, 64] -> 比较34和25，交换 -> [25, 34, 12, 64]
[25, 34, 12, 64] -> 比较34和12，交换 -> [25, 12, 34, 64]

第3轮:
[25, 12, 34, 64] -> 比较25和12，交换 -> [12, 25, 34, 64]

排序完成: [12, 25, 34, 64]
```

## 复杂度分析

| 情况 | 时间复杂度 | 说明 |
|------|------------|------|
| 最好 | O(n) | 已有序，优化版本 |
| 最坏 | O(n²) | 逆序 |
| 平均 | O(n²) | - |
| 空间复杂度 | O(1) | 原地排序 |

## 稳定性

冒泡排序是**稳定排序**，相等元素的相对位置不会改变。

## 练习题

### 题目1：排序数组
**题目描述**：给定一个整数数组，将其升序排列。

**参考代码**：
```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<int> sortArray(vector<int>& nums) {
    int n = nums.size();
    
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        
        for (int j = 0; j < n - i - 1; j++) {
            if (nums[j] > nums[j + 1]) {
                swap(nums[j], nums[j + 1]);
                swapped = true;
            }
        }
        
        if (!swapped) break;
    }
    
    return nums;
}

int main() {
    vector<int> nums = {5, 2, 3, 1};
    sortArray(nums);
    
    for (int x : nums) cout << x << " ";
    cout << endl;
    
    return 0;
}
```

### 题目2：排序链表
**题目描述**：对链表进行插入排序。

**参考代码**：
```cpp
#include <iostream>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

ListNode* insertionSortList(ListNode* head) {
    if (!head || !head->next) return head;
    
    ListNode* dummy = new ListNode(0);
    ListNode* curr = head;
    
    while (curr) {
        ListNode* next = curr->next;
        ListNode* prev = dummy;
        
        while (prev->next && prev->next->val < curr->val) {
            prev = prev->next;
        }
        
        curr->next = prev->next;
        prev->next = curr;
        curr = next;
    }
    
    return dummy->next;
}

void printList(ListNode* head) {
    while (head) {
        cout << head->val << " -> ";
        head = head->next;
    }
    cout << "NULL" << endl;
}

int main() {
    ListNode* head = new ListNode(4);
    head->next = new ListNode(2);
    head->next->next = new ListNode(1);
    head->next->next->next = new ListNode(3);
    
    head = insertionSortList(head);
    printList(head);
    
    return 0;
}
```

## 小结

1. 冒泡排序简单易懂，适合教学
2. 优化版本可在已有序时达到O(n)
3. 稳定排序，空间复杂度O(1)
4. 实际应用中较少使用，效率较低
