# 插入排序

## 概述

插入排序的工作原理是通过构建有序序列，对于未排序数据，在已排序序列中从后向前扫描，找到相应位置并插入。

## 算法原理

1. 从第一个元素开始，该元素可以认为已经被排序
2. 取出下一个元素，在已经排序的元素序列中从后向前扫描
3. 如果该元素（已排序）大于新元素，将该元素移到下一位置
4. 重复步骤3，直到找到已排序的元素小于或者等于新元素的位置
5. 将新元素插入到该位置后
6. 重复步骤2~5

## C++实现

### 基本版本

```cpp
#include <iostream>
#include <vector>
using namespace std;

void insertionSort(vector<int>& arr) {
    int n = arr.size();
    
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        
        // 将大于key的元素向后移动
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        
        arr[j + 1] = key;
    }
}

int main() {
    vector<int> arr = {12, 11, 13, 5, 6};
    
    insertionSort(arr);
    
    cout << "Sorted array: ";
    for (int x : arr) cout << x << " ";
    cout << endl;
    
    return 0;
}
```

### 二分插入排序

```cpp
#include <iostream>
#include <vector>
using namespace std;

void binaryInsertionSort(vector<int>& arr) {
    int n = arr.size();
    
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        
        // 二分查找插入位置
        int left = 0, right = i - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (arr[mid] > key) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        
        // 移动元素
        for (int j = i - 1; j >= left; j--) {
            arr[j + 1] = arr[j];
        }
        
        arr[left] = key;
    }
}

int main() {
    vector<int> arr = {12, 11, 13, 5, 6};
    
    binaryInsertionSort(arr);
    
    for (int x : arr) cout << x << " ";
    cout << endl;
    
    return 0;
}
```

### Shell排序（希尔排序）

```cpp
#include <iostream>
#include <vector>
using namespace std;

void shellSort(vector<int>& arr) {
    int n = arr.size();
    
    // 使用Knuth序列
    int gap = 1;
    while (gap < n / 3) {
        gap = gap * 3 + 1;
    }
    
    while (gap > 0) {
        for (int i = gap; i < n; i++) {
            int temp = arr[i];
            int j = i;
            
            while (j >= gap && arr[j - gap] > temp) {
                arr[j] = arr[j - gap];
                j -= gap;
            }
            
            arr[j] = temp;
        }
        
        gap /= 3;
    }
}

int main() {
    vector<int> arr = {12, 11, 13, 5, 6, 7};
    
    shellSort(arr);
    
    for (int x : arr) cout << x << " ";
    cout << endl;
    
    return 0;
}
```

```

第1轮 (i=1):
key = 11, 扫描 [12]

第2轮 (i=2):
key = 13, 扫描 [11, 12]

第3轮 (i=3):
key = 5, 扫描 [11, 12, 13]
[11, 12, 13, 13] -> [11, 12, 12, 13] -> [11, 11, 12, 13] -> [5, 11, 12, 13, 6]

第4轮 (i=4):
key = 6, 扫描 [5, 11, 12, 13]
[5, 11, 12, 13, 13] -> [5, 11, 12, 12, 13] -> [5, 11, 11, 12, 13] -> [5, 6, 11, 12, 13]

```

## 复杂度分析

| 版本 | 最好 | 最坏 | 平均 | 空间 |
|------|------|------|------|------|
| 基本插入排序 | O(n) | O(n²) | O(n²) | O(1) |
| 二分插入排序 | O(n log n) | O(n²) | O(n²) | O(1) |
| Shell排序 | O(n log n) | O(n²) | O(n^1.3) | O(1) |

## 稳定性

插入排序是**稳定排序**。

## 适用场景

1. 数据量小
2. 数据基本有序
3. 在线算法（边接收边排序）

## 练习题

### 题目1：对链表进行插入排序
**题目描述**：对链表进行插入排序。

**参考代码**：
```cpp
#include <iostream>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

ListNode* insertionSortList(ListNode* head) {
    if (!head || !head->next) return head;
    
    ListNode* dummy = new ListNode(0);
    ListNode* curr = head;
    
    while (curr) {
        ListNode* next = curr->next;
        ListNode* prev = dummy;
        
        // 找到插入位置
        while (prev->next && prev->next->val < curr->val) {
            prev = prev->next;
        }
        
        // 插入
        curr->next = prev->next;
        prev->next = curr;
        curr = next;
    }
    
    return dummy->next;
}

void printList(ListNode* head) {
    while (head) {
        cout << head->val << " -> ";
        head = head->next;
    }
    cout << "NULL" << endl;
}

int main() {
    ListNode* head = new ListNode(4);
    head->next = new ListNode(2);
    head->next->next = new ListNode(1);
    head->next->next->next = new ListNode(3);
    
    cout << "Original: ";
    printList(head);
    
    head = insertionSortList(head);
    
    cout << "Sorted: ";
    printList(head);
    
    return 0;
}
```

### 题目2：扑克牌问题
**题目描述**：给定N张扑克牌，每次取一张插入到前面已排序的牌中，求排序完成后的总操作次数。

**参考代码**：
```cpp
#include <iostream>
#include <vector>
using namespace std;

int countOperations(vector<int>& cards) {
    int n = cards.size();
    int operations = 0;
    
    for (int i = 1; i < n; i++) {
        int key = cards[i];
        int j = i - 1;
        
        while (j >= 0 && cards[j] > key) {
            cards[j + 1] = cards[j];
            j--;
            operations++;
        }
        
        cards[j + 1] = key;
        if (j + 1 != i) operations++;  // 插入操作
    }
    
    return operations;
}

int main() {
    vector<int> cards = {3, 1, 4, 1, 5};
    cout << countOperations(cards) << endl;
    
    return 0;
}
```

## 小结

1. 插入排序对小规模数据效率高
2. 数据基本有序时效率接近O(n)
3. 稳定排序，适合在线排序
4. Shell排序通过分组插入提高效率
