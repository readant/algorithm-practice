# Java 常用函数

## Math 类

```java
Math.abs(x);       // 绝对值
Math.max(a, b);    // 最大值
Math.min(a, b);    // 最小值
Math.pow(a, b);    // 幂运算
Math.sqrt(x);      // 平方根
Math.floor(x);     // 向下取整
Math.ceil(x);      // 向上取整
Math.round(x);     // 四舍五入
```

## 数组工具

```java
import java.util.Arrays;

Arrays.sort(arr);                    // 排序
Arrays.fill(arr, 0);                // 填充
Arrays.toString(arr);               // 转字符串
Arrays.copyOf(arr, newLength);      // 复制数组
Arrays.binarySearch(arr, key);      // 二分查找（需已排序）
```

## 字符串函数

```java
// Character 类
Character.isDigit(c);      // 是否数字
Character.isLetter(c);     // 是否字母
Character.toLowerCase(c);  // 转小写
Character.toUpperCase(c);  // 转大写

// 字符串方法
s.toLowerCase();           // 转小写
s.toUpperCase();           // 转大写
s.trim();                  // 去首尾空格
s.replace("a", "b");       // 替换
s.split(",");              // 分割
s.contains("abc");         // 包含判断
```

## 类型转换

```java
// 字符串转数字
int n = Integer.parseInt("123");
double d = Double.parseDouble("3.14");

// 数字转字符串
String s = String.valueOf(123);
String s = Integer.toString(123);
String s = 123 + "";
```
