# 算法学习模块

本模块按**用途分层**，为竞赛主线服务。  
**每日入口不在本模块** → [COMPETE.md](../COMPETE.md) · 竞赛主线 → [竞赛轨/蓝桥杯/](../竞赛轨/蓝桥杯/主线.md)

## 三层结构

### 02-学习层 — 按当前块选读

> 不必通读目录。当前块是哪一块，就去读对应讲义。

```
02-学习层/01-C++/
├── 01-C++基础语法/     ← 语法补洞
├── 02-数据结构/        ← 块5：A1 STL 工具箱（主教材）
│                         备赛路线/总览见本目录；竞赛入口在 竞赛轨/
├── 03-基础算法体系/    ← 块7–14 等（排序/二分/搜索/前缀和…）
└── 04-进阶算法体系/    ← DP/图论/数论（ACM 开轨后）
```

块5 主教材：[A1-STL容器与算法（工具箱）.md](02-学习层/01-C++/02-数据结构/A1-STL容器与算法（工具箱）.md)

### 01-参考层 — 遇到问题时快速查阅

> 语言策略：**C++ 主 · Python 副 · C 对照 · Java 不在考虑**。

```
01-参考层/
├── 00-通用规范/   ← 命名
├── 01-C++/        ← 主：STL、algorithm、IO、刷题片段
├── 02-Python/     ← 副：数据结构、字符串、IO、常用函数
└── 03-C/          ← 对照：随 C++ 调整，不单独成线
（04-Java 仅本地存档，不再导航）
```

### 03-实战层 — 做题时复制粘贴

```
03-实战层/
├── 01-算法模板库/   ← 竞赛模板优先：STL/前缀和/二分/搜索/贪心
└── 02-踩坑记录/
```

## 如何配合使用

1. **训练日**：[COMPETE.md](../COMPETE.md) → 当前块讲义 → 手敲 → 块内题 → 记坑  
2. **做题卡住**：查 01-参考层；模板从 03-实战层复制  
3. **复习**：踩坑记录 + 该块验收清单  
4. **进度**：只改 [竞赛轨/蓝桥杯/进度.md](../竞赛轨/蓝桥杯/进度.md)，不以本目录文件数当进度
