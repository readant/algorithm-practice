## 每层只干一件事

> 这一节是防止重复整理的判据。**同一个知识点只该有一份正文**，其余位置只放指针。
> 想加内容前先查这张表：该写进哪一层？如果那层已有一份，就改那份，不要新建。

| 层 | 只放什么 | 不放什么 | 什么时候翻 |
| :-- | :-- | :-- | :-- |
| `01-参考层` | **API 签名级速查**（怎么调用） | 原理、推导、易错点长文、完整模板 | 想不起函数名/参数 |
| `02-学习层` | **原理与推导**（为什么这样） | 可直接复制的完整模板（用指针指向实战层） | 这个块还没学过 |
| `03-实战层` | **可直接复制粘贴的完整代码** + 个人踩坑 | 长篇原理 | 正在写代码 |

判据一句话：**「怎么用」去参考层，「为什么」去学习层，「抄代码」去实战层。**
