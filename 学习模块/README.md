# 算法学习模块

本模块按**用途分层**组织，帮助你在不同场景下快速找到需要的内容。

## 三层结构

### 02-学习层 — 从零学起

> 按顺序阅读，系统掌握 C++ 和算法基础。

```
02-学习层/01-C++/
├── 01-基础学习/        ← 第一个程序、输入输出
├── 02-核心语法/        ← 变量、控制结构、函数、指针、STL
├── 03-基础数据结构/     ← 数组、链表、栈、队列、哈希表、树
├── 04-排序算法/        ← 冒泡、选择、插入、归并、快排、堆排
├── 05-搜索算法/        ← 线性搜索、二分搜索
└── 06-基础算法思想/     ← 暴力法、分治法、贪心算法
```

所有教程使用 **C++** 讲解，每个文件包含原理说明、完整代码示例和练习题。

### 01-参考层 — 遇到问题时快速查阅

> 不用通读，需要时翻阅对应语言的速查卡。

```
01-参考层/
├── 01-C++/        ← STL容器、算法函数、输入输出、常用技巧（首要）
├── 02-Python/     ← 数据结构、字符串处理、输入输出、常用函数
├── 03-C/          ← 数组与指针、输入输出、常用函数、常用技巧
└── 04-Java/       ← 数据结构、输入输出、常用函数、常用技巧
```

每张速查卡只列语法和 API 用法，不解释原理。

### 03-实战层 — 做题时复制粘贴

> 算法模板直接用，踩坑记录帮你避坑。

```
03-实战层/
├── 01-算法模板/        ← 排序、搜索、DP、数据结构、数学（默认 C++ 实现）
└── 02-踩坑记录/        ← 按主题分类的常见错误
    ├── 01-通用踩坑.md  ← 数组越界、溢出、输入输出
    ├── 02-字符串.md    ← getline vs cin、字符比较
    ├── 03-排序与比较.md ← sort、浮点比较
    ├── 04-动态规划.md  ← 背包、LIS、区间DP
    ├── 05-图论.md      ← DFS/BFS、最短路
    └── 06-数学与杂项.md ← 取模、数论、调试技巧
```

模板文件含复杂度分析和适用场景，可直接复制到代码中。踩坑记录每条附带来源题目，方便回溯。

## 如何配合使用

1. **学习阶段**：按 02-学习层/01-C++/ 的目录顺序阅读
2. **做题阶段**：从 03-实战层/01-算法模板/ 复制需要的模板，遇到语法问题查 01-参考层/
3. **复习阶段**：浏览 03-实战层/02-踩坑记录/ 避免重复犯错
