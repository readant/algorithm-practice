# 动态规划踩坑

## 背包问题

- 01 背包内层循环要**逆序**（从大到小），否则一个物品会被重复选
- 完全背包要**正序**（从小到大），允许重复选择
- 多重背包可以用二进制拆分优化

```
01 背包：  for j = W..w[i]    ← 逆序
完全背包：  for j = w[i]..W    ← 正序
```

## LIS（最长递增子序列）

- O(n²) DP：`dp[i] = max(dp[j] + 1)`，其中 `j < i` 且 `a[j] < a[i]`
- O(n log n) 贪心 + 二分：`lower_bound` 找第一个 `>=` 的位置替换
- `lower_bound` 找的是第一个 `>=` 的位置，不是 `>`

## 区间 DP

- 遍历顺序：先枚举区间长度，再枚举起点
- `dp[i][j]` 表示区间 `[i, j]` 的最优解

## 记忆化搜索 vs 递推

- 记忆化搜索和递推 DP 是等价的，选自己习惯的
- 记忆化搜索天然处理了状态的依赖顺序
