# 字符串踩坑

## 输入相关

- `cin >> s` 遇到空格、Tab、换行都会停止，只能读一个"单词"
- `getline(cin, s)` 读取整行，包含空格，直到换行符为止
- `cin >> n` 后紧跟 `getline` 会读到空行（因为 `cin >>` 留下了换行符），需要先 `cin.ignore()`

```cpp
int n;
cin >> n;
cin.ignore();       // 吃掉残留的换行符
string s;
getline(cin, s);    // 现在能正确读到下一行
```

- C 的 `gets()` 已被 C++11 弃用，不要用

## 字符串操作

- `string` 的 `[]` 访问越界是未定义行为，用 `at()` 或检查范围
- C 字符串 `'\0'` 结尾，`sizeof` 包含 `\0`，`strlen` 不包含
- `string` 拼接大量字符串时用 `stringstream` 或 `reserve()` 预分配

## 字符比较

- 比较单个字符用**单引号** `' '`，不是双引号 `" "`
- 大小写转换：`tolower(c)` / `toupper(c)`，需要 `<cctype>` 头文件

## 下标与遍历

- 字符串下标从 0 开始，最后一个字符下标是 `s.size() - 1`
- `s.size()` 返回 `size_t`（无符号），与 `int` 比较时注意负数问题
- 范围 for `for (char c : s)` 适合只读遍历，需要修改时用 `for (char &c : s)`

## 从题目中学到的

### P5015 标题统计

- `getline` vs `cin >>`：含空格输入必须用 `getline`
- 字符串长度 = 非空格字符数，遍历时跳过 `' '`

### P1957 口算练习题

- `cin >> s` 读字符串后再 `stoi(s)` 转数字，比直接 `cin >> int` 灵活
- `to_string(num)` 把数字转回字符串，用于拼接输出

### P1914 小书童——凯撒密码

- 字符加密：`(c - 'a' + k) % 26 + 'a'`，注意先减 `'a'` 归零再取模
