# 排序与比较踩坑

## sort 相关

- `sort` 默认升序，自定义比较函数返回 `true` 表示第一个参数排在前面
- `stable_sort` 保持相等元素的相对顺序
- `sort` 对 `pair` 排序：先比 `first`，再比 `second`

```cpp
// 降序排序
sort(a, a + n, greater<int>());

// 按第二维降序
sort(v.begin(), v.end(), [](const pair<int,int> &a, const pair<int,int> &b) {
    return a.second > b.second;
});
```

## 浮点数比较

- 浮点数比较不要用 `==`，用 `abs(a - b) < 1e-9`
- `double` 精度约 15-16 位有效数字，`float` 约 7 位

## 二分查找

- `lower_bound` 返回第一个 `>=` 的位置
- `upper_bound` 返回第一个 `>` 的位置
- 自定义比较时注意排序方向和比较函数要一致
