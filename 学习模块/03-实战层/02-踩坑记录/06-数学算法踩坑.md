# 数学与杂项踩坑

## 取模运算

- 负数取模：`(a % mod + mod) % mod`，保证结果非负
- `(a * b) % mod` 中 `a * b` 可能溢出，写成 `1LL * a % mod * b % mod`
- `(a + b) % mod` 安全，但连加多次也可能溢出，注意 `long long`

## 数论

- GCD：`__gcd(a, b)` 或手写辗转相除
- 快速幂：`pow_mod(base, exp, mod)`，$O(\log n)$
- 质数筛：埃氏筛 $O(n \log \log n)$，线性筛 $O(n)$

## 组合数学

- 组合数 $C(n, k)$ 可用杨辉三角递推或阶乘逆元
- 杨辉三角第 n 行 = $(a+b)^n$ 的展开系数
- 每行数字之和 = $2^n$

## 常用技巧

- `__builtin_popcount(x)`：统计二进制中 1 的个数
- `__builtin_clz(x)`：前导零个数
- 位运算判断奇偶：`x & 1`
- 位运算除以 2：`x >> 1`

## 从题目中学到的

### P5735 距离函数

- 两点距离公式：`sqrt(pow(x2-x1, 2) + pow(y2-y1, 2))`，需要 `<cmath>` 头文件
- `pow(a, 2)` 也可以手写 `a * a`，避免浮点误差（本题影响不大）
- 输出保留两位小数：`cout << fixed << setprecision(2) << val`，需要 `<iomanip>` 头文件
- 坐标含小数时必须用 `double`，用 `int` 会截断小数部分
