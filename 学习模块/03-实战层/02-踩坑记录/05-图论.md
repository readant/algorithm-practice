# 图论踩坑

## 基础概念

- 有向图和无向图的边数要分清，无向图每条边存两次
- 有向图邻接表存边：`g[u].push_back(v)`；无向图要存两次：`g[u].push_back(v); g[v].push_back(u)`

## DFS / BFS

- DFS 注意标记访问时机：入队时标记还是出队时标记，两种都可以但要统一
- BFS 天然求最短路（无权图）
- DFS 容易栈溢出，节点多时优先考虑 BFS

## 最短路

- Dijkstra 不能处理负权边，负权边用 SPFA 或 Bellman-Ford
- Dijkstra + 堆优化：$O((V+E) \log V)$
- Floyd-Warshall：$O(V^3)$，适合稠密图全源最短路

## 拓扑排序

- 拓扑排序前检查是否有环（入度法：能排序的节点数 < 总节点数则有环）
- DAG（有向无环图）才能做拓扑排序

## 其他

- 连通分量：无向图用 DFS/并查集，有向图用 Kosaraju/Tarjan
- 二分图判定：染色法 BFS/DFS，或并查集
