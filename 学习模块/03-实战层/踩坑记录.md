# 踩坑记录

## 数组相关

- 数组越界：注意下标从 0 还是 1 开始，循环边界 `<` 还是 `<=`
- `bool` 数组在 C++ 中全局/静态时默认 `false`，局部变量不保证
- `vector<bool>` 是特化版本，不是真正的 `bool` 数组，行为可能意外；需要时用 `vector<char>`
- `memset(arr, 1, sizeof(arr))` 不会把 `int` 数组全设为 1，而是 `0x01010101`；只能用于全 0 或全 -1

## 整数溢出

- `int` 范围约 ±21 亿，两数相乘容易溢出，用 `long long` 或 `1LL * a * b`
- 取模运算 `(a * b) % mod` 中 `a * b` 可能先溢出，写成 `1LL * a % mod * b % mod`
- `INT_MIN` 取绝对值会溢出（`-INT_MIN` 超出 `int` 范围）
- 无穷大常用 `0x3f3f3f3f`（约 10 亿，两个相加不会溢出 `int`）

## 输入输出

- `cin/cout` 与 `scanf/printf` 不要混用（除非先 `ios::sync_with_stdio(false)`）
- Python 的 `input()` 读整行，多组输入用 `sys.stdin.read().split()`
- C++ 竞赛推荐关闭同步 + 解绑：`ios::sync_with_stdio(false); cin.tie(nullptr);`
- `getline(cin, s)` 会在 `cin >> n` 后读到空行，需要先 `cin.ignore()`

## 字符串

- `string` 的 `[]` 访问越界是未定义行为，用 `at()` 或检查范围
- C 字符串 `'\0'` 结尾，`sizeof` 包含 `\0`，`strlen` 不包含
- `string` 拼接大量字符串时用 `stringstream` 或 `reserve()` 预分配

## 排序与比较

- `sort` 默认升序，自定义比较函数返回 `true` 表示第一个参数排在前面
- `pair` 排序：先比 `first`，再比 `second`
- 浮点数比较不要用 `==`，用 `abs(a - b) < 1e-9`
- `stable_sort` 保持相等元素的相对顺序

## 图论

- 有向图和无向图的边数要分清，无向图每条边存两次
- DFS 注意标记访问时机（入队时还是出队时）
- Dijkstra 不能处理负权边，负权边用 SPFA 或 Bellman-Ford
- 拓扑排序前检查是否有环

## DP 相关

- 01 背包内层循环要**逆序**，完全背包要**正序**
- LIS 的 O(n log n) 解法中 `lower_bound` 找的是第一个 `>=` 的位置
- 区间 DP 的遍历顺序：先枚举区间长度，再枚举起点
- 记忆化搜索和递推 DP 是等价的，选自己习惯的

## 特殊值处理

- `k = 0` 的情况经常被忽略（如除法、取模）
- `n = 0` 或 `n = 1` 的边界情况
- 空数组、空字符串的处理
- 单个元素既是最大也是最小

## 调试技巧

- 打印中间状态：`cerr` 输出不影响 `cout` 的重定向
- 对拍：写暴力解和优化解，随机生成数据对比
- `assert()` 检查不变量
- 负数取模：`(a % mod + mod) % mod`
