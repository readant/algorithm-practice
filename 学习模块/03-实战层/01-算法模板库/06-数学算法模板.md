# 数学算法模板

## GCD / LCM

```cpp
int gcd(int a, int b) { return b ? gcd(b, a % b) : a; }
int lcm(int a, int b) { return a / gcd(a, b) * b; }
// C++17: gcd(a, b), lcm(a, b) 在 <numeric> 中
```

## 快速幂

```cpp
long long quickPow(long long base, long long exp, long long mod) {
    long long result = 1;
    base %= mod;
    while (exp > 0) {
        if (exp & 1) result = result * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return result;
}
```

**应用**：模逆元 `inv(a) = quickPow(a, mod-2, mod)`（mod 为质数时）

## 素数筛

**埃氏筛** O(n log log n)：

```cpp
vector<int> sieve(int n) {
    vector<bool> isPrime(n + 1, true);
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i * i <= n; i++)
        if (isPrime[i])
            for (int j = i * i; j <= n; j += i)
                isPrime[j] = false;
    vector<int> primes;
    for (int i = 2; i <= n; i++)
        if (isPrime[i]) primes.push_back(i);
    return primes;
}
```

**欧拉筛** O(n)（线性筛）：

```cpp
vector<int> eulerSieve(int n) {
    vector<bool> isPrime(n + 1, true);
    vector<int> primes;
    for (int i = 2; i <= n; i++) {
        if (isPrime[i]) primes.push_back(i);
        for (int j = 0; j < (int)primes.size() && i * primes[j] <= n; j++) {
            isPrime[i * primes[j]] = false;
            if (i % primes[j] == 0) break;
        }
    }
    return primes;
}
```

## 扩展欧几里得

```cpp
int exgcd(int a, int b, int& x, int& y) {
    if (b == 0) { x = 1; y = 0; return a; }
    int g = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return g;
}
```

**应用**：求解 ax + by = gcd(a, b) 的一组整数解

## 前缀和

**一维**：

```cpp
prefix[0] = 0;
for (int i = 1; i <= n; i++) prefix[i] = prefix[i-1] + a[i];
// 查询 [l, r]：prefix[r] - prefix[l-1]
```

**二维**：

```cpp
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        sum[i][j] = sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1] + a[i][j];
// 查询 [(x1,y1), (x2,y2)]：
// sum[x2][y2] - sum[x1-1][y2] - sum[x2][y1-1] + sum[x1-1][y1-1]
```

**差分**（区间加操作）：

```cpp
// 区间 [l, r] 加 val
diff[l] += val;
diff[r + 1] -= val;
// 还原
int cur = 0;
for (int i = 1; i <= n; i++) cur += diff[i], a[i] = cur;
```

## 组合数学

```cpp
const int MOD = 1e9 + 7;
const int N = 2e5 + 5;
long long fact[N], invFact[N];

long long quickPow(long long base, long long exp, long long mod) {
    long long result = 1;
    base %= mod;
    while (exp > 0) {
        if (exp & 1) result = result * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return result;
}

void init() {
    fact[0] = 1;
    for (int i = 1; i < N; i++) fact[i] = fact[i-1] * i % MOD;
    invFact[N-1] = quickPow(fact[N-1], MOD-2, MOD);
    for (int i = N-2; i >= 0; i--) invFact[i] = invFact[i+1] * (i+1) % MOD;
}

long long C(int n, int r) {
    if (r < 0 || r > n) return 0;
    return fact[n] % MOD * invFact[r] % MOD * invFact[n-r] % MOD;
}
```

## 博弈论（Nim 游戏）

```cpp
// 经典 Nim：若干堆石子，每次从一堆中取至少1个，无法取者输
// 策略：所有堆的石子数异或和为 0 则先手必败，否则先手必胜
```
