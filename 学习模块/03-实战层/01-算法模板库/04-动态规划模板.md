# 动态规划模板

## 核心思想

1. **定义状态**：明确 dp[i] 或 dp[i][j] 代表什么
2. **状态转移方程**：当前状态如何从之前的状态推导
3. **初始条件**：dp[0] 或 dp[0][0] 等基础情况
4. **遍历顺序**：确保计算当前状态时，依赖的状态已计算

---

## 01 背包

**问题**：n 个物品，每个物品只能用一次，容量 W，求最大价值。

```cpp
// 一维优化（推荐）
for (int i = 0; i < n; i++)
    for (int j = W; j >= w[i]; j--)  // 逆序！
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

**逆序原因**：正序会导致一个物品被多次使用（变成完全背包）。

---

## 完全背包

**问题**：n 个物品，每个物品可用无限次，容量 W，求最大价值。

```cpp
for (int i = 0; i < n; i++)
    for (int j = w[i]; j <= W; j++)  // 正序
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

## 多重背包

**问题**：n 个物品，每个物品有数量限制 s[i]。

```cpp
// 二进制拆分优化
for (int i = 0; i < n; i++) {
    int k = 1;
    while (k <= s[i]) {
        for (int j = W; j >= w[i] * k; j--)
            dp[j] = max(dp[j], dp[j - w[i] * k] + v[i] * k);
        s[i] -= k;
        k *= 2;
    }
    if (s[i] > 0)
        for (int j = W; j >= w[i] * s[i]; j--)
            dp[j] = max(dp[j], dp[j - w[i] * s[i]] + v[i] * s[i]);
}
```

## 最长公共子序列（LCS）

```cpp
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++) {
        if (a[i] == b[j]) dp[i][j] = dp[i-1][j-1] + 1;
        else dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
    }
// 答案：dp[n][m]
```

---

## 最长递增子序列（LIS）

**O(n²) 解法**：

```cpp
for (int i = 0; i < n; i++) {
    dp[i] = 1;
    for (int j = 0; j < i; j++)
        if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
}
// 答案：max(dp[i])
```

**O(n log n) 解法**（贪心 + 二分）：

```cpp
vector<int> tails;  // tails[i] 表示长度为 i+1 的 LIS 的最小末尾
for (int x : a) {
    auto it = lower_bound(tails.begin(), tails.end(), x);
    if (it == tails.end()) tails.push_back(x);
    else *it = x;
}
// 答案：tails.size()
```

## 最长公共子串

```cpp
for (int i = 1; i <= n; i++)

        if (a[i] == b[j]) dp[i][j] = dp[i-1][j-1] + 1;
        else dp[i][j] = 0;
    }
// 答案：max(dp[i][j])
```

## 编辑距离

```cpp
for (int i = 0; i <= n; i++) dp[i][0] = i;
for (int j = 0; j <= m; j++) dp[0][j] = j;

for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++) {
        if (a[i-1] == b[j-1]) dp[i][j] = dp[i-1][j-1];
        else dp[i][j] = min({dp[i-1][j], dp[i][j-1], dp[i-1][j-1]}) + 1;
    }
// dp[i][j]：将 a[0..i-1] 转换为 b[0..j-1] 的最少操作数
```

## 区间 DP

```cpp
// dp[i][j] 表示区间 [i, j] 的最优解
for (int len = 2; len <= n; len++)       // 区间长度
    for (int i = 0; i + len - 1 < n; i++) {  // 起点
        int j = i + len - 1;              // 终点
        for (int k = i; k < j; k++)       // 分割点
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost(i,j,k));
    }
```

## 数位 DP

```cpp
// 计算 [1, n] 中满足某性质的数的个数
// 通常定义 dp[pos][limit][state]
int dfs(string& s, int pos, int limit, int state) {
    if (pos == s.size()) return check(state);
    if (!limit && dp[pos][state] != -1) return dp[pos][state];
    
    int up = limit ? s[pos] - '0' : 9;
    int ans = 0;
    for (int d = 0; d <= up; d++)
        ans += dfs(s, pos + 1, limit && d == up, newState(state, d));
    
    if (!limit) dp[pos][state] = ans;
    return ans;
}
```
