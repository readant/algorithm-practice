# 数据结构模板

## 栈

**应用**：括号匹配、表达式求值、单调栈、DFS 非递归

```cpp
stack<int> st;
st.push(x);
st.top();     // 查看栈顶
st.pop();     // 弹出（不返回值）
st.empty();
st.size();
```

**单调栈**（下一个更大元素）：

```cpp
vector<int> nextGreater(vector<int>& arr) {
    int n = arr.size();
    vector<int> res(n, -1);
    stack<int> st;
    for (int i = 0; i < n; i++) {
        while (!st.empty() && arr[st.top()] < arr[i]) {
            res[st.top()] = arr[i];
            st.pop();
        }
        st.push(i);
    }
    return res;
}
```

## 队列

**应用**：BFS、滑动窗口、任务调度

```cpp
queue<int> q;
q.push(x);
q.front();    // 查看队首
q.pop();      // 弹出（不返回值）
q.empty();
q.size();
```

**双端队列 deque**：

```cpp
deque<int> dq;
dq.push_front(x);
dq.push_back(x);
dq.front();
dq.back();
dq.pop_front();
dq.pop_back();
```

## 并查集

**应用**：连通分量、最小生成树（Kruskal）、动态连通性

```cpp
int parent[N], rank_[N];

void init(int n) {
    for (int i = 0; i < n; i++) {
        parent[i] = i;
        rank_[i] = 0;
    }
}

int find(int x) {
    return parent[x] == x ? x : parent[x] = find(parent[x]);  // 路径压缩
}

void unite(int x, int y) {
    int rx = find(x), ry = find(y);
    if (rx == ry) return;
    if (rank_[rx] < rank_[ry]) parent[rx] = ry;
    else if (rank_[rx] > rank_[ry]) parent[ry] = rx;
    else { parent[ry] = rx; rank_[rx]++; }  // 按秩合并
}

bool connected(int x, int y) {
    return find(x) == find(y);
}
```

## 堆（优先队列）

**应用**：Top-K、中位数、合并有序序列、Dijkstra

```cpp
// 大顶堆（默认）
priority_queue<int> pq;
// 小顶堆
priority_queue<int, vector<int>, greater<int>> minPq;

pq.push(x);
pq.top();     // 查看堆顶
pq.pop();     // 弹出堆顶
pq.empty();
pq.size();
```

**自定义比较**：

```cpp
// 按绝对值排序的大顶堆
struct Compare {
    bool operator()(int a, int b) { return abs(a) < abs(b); }
};
priority_queue<int, vector<int>, Compare> pq;

// 或用 lambda
auto cmp = [](int a, int b) { return a > b; };
priority_queue<int, vector<int>, decltype(cmp)> pq(cmp);
```

## 树状数组（Fenwick Tree）

**应用**：单点修改 + 区间查询，区间修改 + 单点查询

```cpp
int tree[N];

void update(int i, int val) {
    for (; i <= n; i += i & (-i)) tree[i] += val;
}

int query(int i) {  // 前缀和 [1, i]
    int sum = 0;
    for (; i > 0; i -= i & (-i)) sum += tree[i];
    return sum;
}

int query(int l, int r) {  // 区间和 [l, r]
    return query(r) - query(l - 1);
}
```

## 线段树

**应用**：区间修改 + 区间查询（比树状数组更通用）

```cpp
struct SegmentTree {
    int n;
    vector<long long> tree, lazy;
    
    void build(vector<int>& a, int node, int l, int r) {
        if (l == r) { tree[node] = a[l]; return; }
        int mid = (l + r) / 2;
        build(a, node*2, l, mid);
        build(a, node*2+1, mid+1, r);
        tree[node] = tree[node*2] + tree[node*2+1];
    }
    
    void pushDown(int node, int l, int r) {
        if (lazy[node] == 0) return;
        int mid = (l + r) / 2;
        tree[node*2] += lazy[node] * (mid - l + 1);
        tree[node*2+1] += lazy[node] * (r - mid);
        lazy[node*2] += lazy[node];
        lazy[node*2+1] += lazy[node];
        lazy[node] = 0;
    }
    
    void update(int node, int l, int r, int ql, int qr, int val) {
        if (ql <= l && r <= qr) {
            tree[node] += val * (r - l + 1);
            lazy[node] += val;
            return;
        }
        pushDown(node, l, r);
        int mid = (l + r) / 2;
        if (ql <= mid) update(node*2, l, mid, ql, qr, val);
        if (qr > mid) update(node*2+1, mid+1, r, ql, qr, val);
        tree[node] = tree[node*2] + tree[node*2+1];
    }
    
    long long query(int node, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tree[node];
        pushDown(node, l, r);
        int mid = (l + r) / 2;
        long long res = 0;
        if (ql <= mid) res += query(node*2, l, mid, ql, qr);
        if (qr > mid) res += query(node*2+1, mid+1, r, ql, qr);
        return res;
    }
};
```
