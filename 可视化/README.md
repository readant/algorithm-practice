# 可视化 · 成长仪表盘

> 本目录是**生成物区**：`dashboard.html` 由脚本产出，**勿手改**，改了下次重跑就被覆盖。
> 两个真值源：`真实比赛/比赛记录/*.json`（赛场）+ `训练记录/日志/*.json`（训练）。

## 只有两个文件

| 文件 | 角色 | 谁用 |
| :-- | :-- | :-- |
| `growth_core.py` | **计算内核**：读取 / 校验 / 算派生指标（含快照与摘要组装）。不渲染 | 内部，别单独跑 |
| `build.py` | **唯一入口**：校验 + 导出数据 + 出图，一条命令全做 | **AI / 自动化** |

> **人不需要碰这两个文件。** 人只写根目录的 [`../随手记.md`](../随手记.md)，然后跟 AI 说「整理随手记」。
> 面向 AI 的接口契约见 [`../成长数据/接口说明.md`](../成长数据/接口说明.md)。

## 命令（给 AI 用）

```bash
python 可视化/build.py            # 默认：校验 + 导出 成长数据/ + 生成 dashboard.html
python 可视化/build.py --brief    # 只打印给 AI 读的精简摘要
python 可视化/build.py --check    # 只校验两个真值源
python 可视化/build.py --open     # 跑完顺便打开仪表盘
```

零依赖：只用 Python 标准库（`json / pathlib / datetime / argparse`），无 pip 包、无网络、无 CDN、无前端库。
产物是**纯静态 HTML**（图表为手写 SVG / CSS），`file://` 双击即可打开。

## 页面结构（顺序即优先级）

| # | 版面 | 为什么放这里 |
| :-- | :-- | :-- |
| 1 | **停滞榜（打脸榜）** | 优先暴露「连续多场没变」的项。只看得分率上升会变成安慰剂 |
| 2 | 本场总览 | 最近一场的 4 个硬指标 |
| 3 | 双场对比表 | n 小时只能说对比，不能说趋势 |
| 4 | 难度档分布 | 能力结构落在哪一档 |
| 5 | 期望分 vs 实得 | 直接暴露「该拿没拿」 |
| 6 | 时间线甘特 | 看时间去哪了（含零提交空转段） |
| 7 | 纪律与效率 | 止损 / 空转 / 得分速度 |
| 8 | 定序对照 | 验证「是否按期望分做题」 |
| 9 | 数据溯源 | 诚实标注每场数据来源与置信度 |

## 指标口径

**难度档**（一律用封榜通过率，非自评）：

| 档 | 通过率 | 含义 |
| :-- | :-- | :-- |
| 签到 | ≥ 90% | 流程题 |
| 简单 | 60–90% | 达标档 |
| 中档 | 30–60% | 分水岭 · 能力区 |
| 困难 | < 30% | 多超纲 |

> 通过率距档位边界 ≤ 2pp 的题会标 ⚠︎（档位判定存疑）。

**期望分** = `primary_rate × full_score`（primary_rate 取自 `pass_rates.primary_source`）。

**期望分失分（可达）** = `Σ max(0, 期望分 − 实得)`，只统计主通过率 ≥ 30% 的题——排除超纲噪音，只算"人类能拿"的分。

**单题止损执行** = 该场无「用时 > 25′ 且未完全通过」的题。止损线写死在脚本顶部 `STOP_LOSS_LINE_MINUTES`。

**按期望分定序执行** = 在**非签到**档中，按期望分降序，实际尝试的题构成该序列的**前缀**。
（164：非签到期望序 `E→D→C→G→F`，实际只尝试了 C，不是前缀 → ❌；165：`C→D→E→F`，实际尝试 C、D 是前缀 → ✅）

**停滞 streak** = 从最近一场往前数「值未变」的连续场数；`streak ≥ 2` 进入停滞榜。

## n 小时的诚实规则（硬约束）

| 规则 | 触发 | 替代 |
| :-- | :-- | :-- |
| 禁止跨场趋势线 | 场数 < 4 | 双场对比表 + 变化箭头 |
| 禁止回归 / 预测 | 场数 < 5 | 不画斜率、不写"预计下次" |
| 允许 | 任意 n | 单场剖面（时间线、期望分 vs 实得、纪律榜） |

## 修改脚本时的注意

- 脚本只**读** `真实比赛/比赛记录/*.json`、只**写** `dashboard.html`，绝不回写 JSON。
- 新增图表请继续用手写 SVG / CSS，**不要引入任何外部库或 CDN**（离线优先）。
- 颜色统一取脚本顶部 `C` 字典；主题为浅色。
