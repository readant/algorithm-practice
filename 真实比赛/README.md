# 真实比赛 · 唯一真值源（赛场）

> **本目录是整个仓库唯一可作「赛场能力证据」的数据源。**
> **日常训练的真值源是 [../训练记录/](../训练记录/README.md)**——两者平级，共用同一套管线。
> 其余目录（`学习模块/`、`题解归档/` 里的 AI 生成题解与讲义）一律是**学习材料**，不作为能力证据。

> 分工：赛场（低频高信号）看**名次与每题得分/用时**；训练（高频）看**独立完成度**。
> 只有 `训练记录/` 里的强证据（平台判定 + 原始代码）能证明"独立做出来了"。

---

## 为什么要有这个目录

这个仓库曾经同时扮演「学习资料库 / 竞赛总控 / 题解归档」三个角色，但其中只有**真实赛场数据**能反映真实水平。
AI 可以批量生成"看起来在努力"的题解与讲义，**无法伪造一场比赛的名次、用时、部分分、空转时长**。

所以把真值单独圈出来，规则是：

- **只进不改**：已录入的比赛记录不改数字；发现错误时新增一条 `provenance` 说明并改 `entered_at`，不静默覆盖。
- **不存派生量**：期望分、难度档、得分率、停滞 streak 等一律由 `可视化/build.py` 现算，**不写进 JSON**，避免出现第二个脏源。
- **缺失写 `null`**：不知道就留空，不要省略键、不要猜。

## 录入 SOP

**你不用碰下面的 JSON。** 在根目录 [`../随手记.md`](../随手记.md) 里写下比赛结果（名次/总分/每题得分与用时），跟 AI 说一句「整理随手记」即可。

AI 侧的动作（供参考）：

```
① 截图存进 真实比赛/原始证据/YYYY-MM-DD_赛事名/
② 解析 随手记.md → 生成 真实比赛/比赛记录/YYYY-MM-DD_赛事名.json（可复制 _模板.json）
③ 跑 python 可视化/build.py   （校验 + 导出 + 出图）
```

**单源原则**：所有数字只存在 `比赛记录/*.json` 一处；仪表盘、快照、摘要、全部指标都由它派生。
接口契约（字段语义 / AI 分析硬规则）→ [../成长数据/接口说明.md](../成长数据/接口说明.md)

## 几个必须写对的语义陷阱

| 陷阱 | 正确写法 |
| :-- | :-- |
| **部分分** | `status:"partial"` + `my_score < full_score`，不要靠文字描述 |
| **赛后补题分** | 写进独立字段 `post_contest_score`，`post_contest_counts:false`。**永不并入 `my_total`** |
| **通过率来源** | `pass_rates` 同时存 `frozen`（封榜）与 `official_final`（官方终版）；`primary_source` 指定期望分用哪个 |
| **难度档** | 一律用**封榜**通过率划档（官方终版含赛后补题会虚高，R165 的 E 题 11.9%→28.3% 就是例子） |
| **名次人数** | 榜面没显示总人数就写 `participants: null`，仪表盘会显示「数据缺失」而不是编造百分位 |
| **时间线** | 原始复盘无绝对起止时刻时，用累计时长重建，并把 `timeline_reconstructed` 置 `true` |

## 校验

生成器在构建时会强校验（缺 `primary_source`、缺对应通过率、`status=full` 但分数不满分等），
报错会直接指出**文件名 + 键路径**，脏数据进不了仪表盘。
