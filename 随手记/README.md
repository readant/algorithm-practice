# 随手记

> **这是整个系统里唯一需要你写的地方。** 随便写、写多粗都行，剩下的交给 AI。
>
> 写完跟 AI 说一句「**整理随手记**」即可——AI 会负责：解析 → 补全字段 → 归位素材 → 更新数据 → 刷新网页。

```
随手记/
├── README.md   ← 流水：一行一题（本文件）
└── 素材/       ← 随手丢的原始材料：截图、代码、题面、链接
```

---

## 流水怎么写

**一行一题，能把五件事说清就够了**：

```
日期  平台  题号/题名  结果  独立吗  用时
```

- **结果**：AC / 没过 / 没做出来
- **独立吗**：`独立`（自己想出来的）/ `看了题解`（卡住后看了题解或问了 AI）/ `提示后`（卡了一会儿自己过了）
  —— **这一项最重要**，它决定了这条记录能不能说明"是自己做出来的"。没写的话 AI 只能按"不知道"处理。
- **用时**：不记得就写"不记得"，别估。

### 例子（照抄格式即可）

```text
10-14 洛谷 P1614 爱与愁的心痛 AC 独立 15分钟
10-14 洛谷 P1789 插火把 没做出来 看了题解
10-15 洛谷 P1047 校门外的树 AC 提示后 25分钟 卡在边界条件上
10-15 洛谷 P5731 蛇形方阵 AC 独立（这题之前做过，算复习）
```

## 代码怎么给我（三种都行，挑最省事的）

1. **直接贴在对话里** —— 最省事，我当场分析
2. **丢进 `随手记/素材/`** —— 命名随便，`a.cpp` 也行
3. **只写题号**，回头再补代码 —— 也行，但那条只能算"中证据"

## 素材：随手丢的地方

不要限制自己只写文字——**截图、代码片段、题面、链接，直接扔进 `素材/` 就行**。
命名随便，甚至只叫 `1.png`、`a.cpp` 也没关系，AI 认得出是什么。

AI 整理时会从这里取走，归位到 `.ai/` 下对应的地方：

| 丢进去的 | AI 归位到 |
| :-- | :-- |
| 你在平台上提交的代码 | `.ai/训练记录/原始代码/` 或 `.ai/真实比赛/赛内代码/` |
| 提交记录 / 题面 / 排行榜截图 | `.ai/训练记录/证据/` 或 `.ai/真实比赛/原始证据/` |
| 别的（链接、笔记、半成品） | 按内容判断，或留在原处 |

> **想让记录更可信，就顺手把原始提交的代码丢进来**（不是你事后重写的正解）。
> 不丢也行，但那样只能算"中证据"。

## 你不用做的事

- ❌ 不用管 JSON 格式、字段名
- ❌ 不用管素材放哪、叫什么名字
- ❌ 不用跑任何命令
- ❌ 不用写题解（AI 写的题解只当学习材料，不代表你的水平）
- ❌ 不用整理归档
