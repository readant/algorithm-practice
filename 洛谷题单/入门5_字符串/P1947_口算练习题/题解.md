# P1947 口算练习题

## 题目背景

小杨想要练习口算，于是请你写一个程序来帮他检查答案是否正确。

## 题目描述

小杨有 $T$ 道口算题，每道题都是形如 $a+b=c$ 的等式（其中 $a$、$b$、$c$ 为非负整数）。你需要判断每道题的答案是否正确。

## 输入格式

第一行包含一个正整数 $T$，表示口算题的数量。

接下来 $T$ 行，每行包含一个等式，格式为 `a+b=c`（没有空格），其中 $a$、$b$、$c$ 都是非负整数。

## 输出格式

对于每道题，输出一行：
- 如果等式正确，输出 `YES`
- 如果等式错误，输出 `NO`

## 输入输出样例

### 样例 1

**输入：**
```
3
1+2=3
1+1=3
10+20=30
```

**输出：**
```
YES
NO
YES
```

## 数据范围

- $1 \leq T \leq 100$
- $0 \leq a, b, c \leq 10^9$

---

## 题解分析

### 题目理解

这道题考察的是**字符串处理**和**模拟**。我们需要：
1. 读取一个等式字符串，格式如 `123+456=579`
2. 解析出三个数字：加数、被加数、和
3. 验证等式是否成立

### 核心思路

**方法一：字符串解析法**

直接从字符串中提取数字：
1. 找到 `+` 的位置，分割出第一个数
2. 找到 `=` 的位置，分割出第二个数
3. `=` 后面的部分就是结果
4. 验证 `第一个数 + 第二个数 == 结果`

**方法二：字符处理法**

利用字符的 ASCII 特性：
- 字符 `'0'` 到 `'9'` 的 ASCII 值是连续的
- `字符 - '0'` 可以得到对应的数字
- 遍历字符串，根据 `+` 和 `=` 分割数字

### 解题步骤

1. **读取输入**：先读 T，再循环读取 T 个等式
2. **解析等式**：
   - 遍历字符串，找到 `+` 和 `=` 的位置
   - 用这些位置将字符串分割成三部分
   - 将三部分字符串转换为数字
3. **验证**：判断 `a + b == c` 是否成立
4. **输出**：输出 YES 或 NO

### 易错点

1. **数字范围**：题目说 $0 \leq a, b, c \leq 10^9$，需要用 `long long` 或 `int64` 存储
2. **字符串解析**：注意边界情况，如 `0+0=0`
3. **输出格式**：必须是大写的 YES 和 NO

## 代码实现

### C++ 实现

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T;
    cin >> T;
    
    while (T--) {
        string s;
        cin >> s;
        
        // 找到 + 和 = 的位置
        int plusPos = s.find('+');
        int equalPos = s.find('=');
        
        // 解析三个数字
        long long a = stoll(s.substr(0, plusPos));
        long long b = stoll(s.substr(plusPos + 1, equalPos - plusPos - 1));
        long long c = stoll(s.substr(equalPos + 1));
        
        // 验证等式
        if (a + b == c) {
            cout << "YES\n";
        } else {
            cout << "NO\n";
        }
    }
    
    return 0;
}
```

### Python 实现

```python
T = int(input())
for _ in range(T):
    s = input()
    # 按 + 和 = 分割
    parts = s.replace('=', '+').split('+')
    a, b, c = int(parts[0]), int(parts[1]), int(parts[2])
    print("YES" if a + b == c else "NO")
```

### C 实现

```c
#include <stdio.h>
#include <string.h>

int main() {
    int T;
    scanf("%d", &T);
    
    while (T--) {
        char s[50];
        scanf("%s", s);
        
        long long a = 0, b = 0, c = 0;
        int i = 0;
        
        // 读取第一个数
        while (s[i] != '+') {
            a = a * 10 + (s[i] - '0');
            i++;
        }
        i++; // 跳过 +
        
        // 读取第二个数
        while (s[i] != '=') {
            b = b * 10 + (s[i] - '0');
            i++;
        }
        i++; // 跳过 =
        
        // 读取结果
        while (s[i] != '\0') {
            c = c * 10 + (s[i] - '0');
            i++;
        }
        
        printf("%s\n", (a + b == c) ? "YES" : "NO");
    }
    
    return 0;
}
```

### Java 实现

```java
import java.util.Scanner;

class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();
        
        while (T-- > 0) {
            String s = sc.next();
            String[] parts = s.split("[+=]");
            long a = Long.parseLong(parts[0]);
            long b = Long.parseLong(parts[1]);
            long c = Long.parseLong(parts[2]);
            
            System.out.println(a + b == c ? "YES" : "NO");
        }
    }
}
```

// C++ 字符串分割模板
vector<string> split(string s, char delimiter) {
    vector<string> result;
    stringstream ss(s);
    string token;
    while (getline(ss, token, delimiter)) {
        result.push_back(token);
    }
    return result;
}

long long stringToLong(string s) {
    long long result = 0;

    }
    return result;
}

## 备考建议

1. **字符串处理**是高频考点，掌握 `find`、`substr`、`split` 等操作
2. **字符与数字转换**：`字符 - '0'` 得到数字，`数字 + '0'` 得到字符
3. **数据类型**：注意题目数据范围，选择合适的类型（`int` vs `long long`）
4. **代码风格**：保持一致的缩进和命名，方便调试和阅读
