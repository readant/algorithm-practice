# P1957 口算练习题

## 题目背景

王老师正在教简单算术运算。细心的王老师收集了 $i$ 道学生经常做错的口算题，并且想整理编写成一份练习。编排这些题目是一件繁琐的事情，为此他想用计算机程序来提高工作效率。

## 题目描述

王老师希望尽量减少输入的工作量，比如 `5+8` 的算式最好只要输入 `5` 和 `8`，输出的结果要尽量详细以方便后期排版的使用，比如对于上述输入进行处理后输出 `5+8=13` 以及该算式的总长度 `6`。

## 输入格式

第一行一个整数 $i$。

接着的 $i$ 行为需要输入的算式，每行可能有**三个数据**或**两个数据**：

- 若该行为**三个数据**：第一个数据表示运算类型（`a` 加法，`b` 减法，`c` 乘法），接着的两个数据表示参加运算的运算数。
- 若该行为**两个数据**：表示本题的运算类型与**上一题相同**，这两个数据为运算数。

## 输出格式

输出 $2 \times i$ 行。对于每个输入的算式，输出完整的运算式及结果，第二行输出该**运算式的总长度**。

## 输入输出样例

### 输入

```
4
a 64 46
275 125
c 11 99
b 46 64
```

### 输出

```
64+46=110
9
275+125=400
11
11*99=1089
10
46-64=-18
9
```

## 数据范围

- $0 < i \leq 50$
- 第一个算式一定有三个数据
- 运算数为非负整数且小于 $10000$

---

## 题解分析

### 题目理解

1. 读取题目数量 $i$
2. 对每道题：
   - 如果是三个数据：第一个是运算符（a/b/c），后两个是操作数
   - 如果是两个数据：沿用上一题的运算符，后两个是操作数
3. 输出格式：`操作数1 运算符 操作数2 = 结果`，下一行输出字符串长度

### 核心思路

1. **记住上一题的运算符**：用一个变量 `lastOp` 记住
2. **解析输入**：读取一行，判断是两个数据还是三个数据
3. **计算结果**：根据运算符计算
4. **计算长度**：用 `to_string` 转字符串后求长度

### 易错点

1. **负数的长度**：`46-64=-18` 的长度是 `9`（`46-64=-18` 包含负号）
2. **运算符选择**：a=加法(+)，b=减法(-)，c=乘法(*)
3. **第一个算式一定有三个数据**
4. **乘法结果可能较大**：但题目限制运算数 < 10000，结果最大约 10^8，`int` 够用

**完整正确版本：**

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    char op = 0;  // 当前运算符
    
    for (int i = 0; i < n; i++) {
        char ch;
        cin >> ch;
        
        if (ch == 'a' || ch == 'b' || ch == 'c') {
            // 三个数据：运算符 + 两个数
            op = ch;
            int a, b;
            cin >> a >> b;
            
            int result;
            char symbol;
            if (op == 'a') { result = a + b; symbol = '+'; }
            else if (op == 'b') { result = a - b; symbol = '-'; }
            else { result = a * b; symbol = '*'; }
            
            string expr = to_string(a) + symbol + to_string(b) + "=" + to_string(result);
            cout << expr << endl;
            cout << expr.length() << endl;
        } else {
            // 两个数据：沿用上一题运算符
            // ch 是第一个数字的第一个字符，需要回退重新读取
            // 实际上 ch 不是运算符，而是数字的首位
            // 需要把 ch 放回去
            int a = ch - '0';
            int num;
            cin >> num;
            a = a * ...  // 这种方法不对
            
            // 正确做法：用字符串读取再判断
        }
    }
    
    return 0;
}
```

```python
n = int(input())
op = ''
```

### C 实现

```c
#include <stdio.h>
#include <string.h>

int main() {
    int n;
    scanf("%d", &n);
    
    char op = 0;
    
    for (int i = 0; i < n; i++) {
        char s[20];
        scanf("%s", s);
        
        int a, b, result;
        char symbol;
        
        if (strcmp(s, "a") == 0 || strcmp(s, "b") == 0 || strcmp(s, "c") == 0) {
            if (s[0] == 'a') { op = '+'; symbol = '+'; }
            else if (s[0] == 'b') { op = '-'; symbol = '-'; }
            else { op = '*'; symbol = '*'; }
            scanf("%d %d", &a, &b);
        } else {
            symbol = op;
            a = atoi(s);
            scanf("%d", &b);
        }
        
        if (symbol == '+') result = a + b;
        else if (symbol == '-') result = a - b;
        else result = a * b;
        
        char expr[50];
        sprintf(expr, "%d%c%d=%d", a, symbol, b, result);
        printf("%s\n%d\n", expr, (int)strlen(expr));
    }
    
    return 0;
}
```

### Java 实现

```java
import java.util.Scanner;

class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        
        char op = 0;
        
        for (int i = 0; i < n; i++) {
            String s = sc.next();
            
            int a, b;
            char symbol;
            
            if (s.equals("a") || s.equals("b") || s.equals("c")) {
                if (s.equals("a")) { op = '+'; symbol = '+'; }
                else if (s.equals("b")) { op = '-'; symbol = '-'; }
                else { op = '*'; symbol = '*'; }
                a = sc.nextInt();
                b = sc.nextInt();
            } else {
                symbol = op;
                a = Integer.parseInt(s);
                b = sc.nextInt();
            }
            
            int result;
            if (symbol == '+') result = a + b;
            else if (symbol == '-') result = a - b;
            else result = a * b;
            
            String expr = a + "" + symbol + b + "=" + result;
            System.out.println(expr);
            System.out.println(expr.length());
        }
    }
}
```
