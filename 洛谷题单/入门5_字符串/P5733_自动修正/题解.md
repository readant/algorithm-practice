# P5733 【深基6.例1】自动修正

## 题目描述

大家都知道一些办公软件有自动将字母转换为大写的功能。输入一个长度不超过 $100$ 且不包括空格的字符串。要求将该字符串中的所有小写字母变成大写字母并输出。

## 输入格式

输入一行，一个字符串。

## 输出格式

输出一个字符串，即将原字符串中的所有小写字母转化为大写字母。

## 输入输出样例 #1

### 输入 #1

```
Luogu4!
```

### 输出 #1

```
LUOGU4!
```

## 前置知识

### 1. ASCII 码是什么？

计算机只认识数字，所以每个字符（字母、数字、符号）都对应一个数字编号，这个编号标准叫做 **ASCII 码**。

常用范围：
| 字符类型 | ASCII 范围 | 示例 |
|---------|-----------|------|
| 数字 `0-9` | 48 ~ 57 | `'0'` = 48, `'9'` = 57 |
| 大写字母 `A-Z` | 65 ~ 90 | `'A'` = 65, `'Z'` = 90 |
| 小写字母 `a-z` | 97 ~ 122 | `'a'` = 97, `'z'` = 122 |

**关键发现**：同一字母的大小写，ASCII 值相差 **32**。
- `'a'` = 97, `'A'` = 65, 差值 = 32
- `'b'` = 98, `'B'` = 66, 差值 = 32

### 2. C++ 中的 char 类型

在 C++ 中，`char` 类型本质上就是 **1 字节的整数**，存储的是 ASCII 码值。

```cpp
char c = 'A';
cout << c << endl;    // 输出: A
cout << (int)c << endl; // 输出: 65（ASCII 值）
```

所以字符可以参与运算：
```cpp
char c = 'a';
c = c - 32;  // 'a' - 32 = 97 - 32 = 65 = 'A'
```

### 3. 字符串 string 基础

`string` 是 C++ 中处理字符串的类型，用 `<string>` 头文件。

```cpp
#include <string>
string s = "Hello";

s.size()      // 字符串长度，这里是 5
s[i]          // 访问第 i 个字符（从 0 开始）
s[i] = 'x'   // 修改第 i 个字符
```

### 4. 位运算简介

位运算直接操作二进制位，速度很快。

| 运算符 | 名称 | 示例 | 说明 |
|-------|------|------|------|
| `&` | 按位与 | `a & b` | 两个都是 1 才得 1 |
| `\|` | 按位或 | `a \| b` | 任一个是 1 就得 1 |
| `~` | 按位取反 | `~a` | 0 变 1，1 变 0 |
| `<<` | 左移 | `a << n` | 左移 n 位，相当于 ×2ⁿ |
| `>>` | 右移 | `a >> n` | 右移 n 位，相当于 ÷2ⁿ |

**为什么位运算可以转大小写？**

看二进制：
```
'a' = 97 = 0110 0001
'A' = 65 = 0100 0001
              ↑
           第6位不同（从0数）
```

只要把第 6 位从 1 变成 0，小写就变大写了。

`~32` = `~0010 0000` = `1101 1111`（第 6 位是 0，其他都是 1）

`ch & ~32` 就是：保留其他位不变，第 6 位强制变成 0。

## 解题思路

### 方法一：位运算（推荐，最简洁）

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);  // 关闭同步，加速 I/O
    cin.tie(nullptr);
    
    string s;
    cin >> s;
    
    for (int i = 0; i < s.size(); ++i) {
        // 判断是否为小写字母（'a'~'z'）
        if (s[i] >= 'a' && s[i] <= 'z') {
            // 位运算：清除第6位，小写转大写
            // 32 = 0010 0000，~32 = 1101 1111
            s[i] &= ~32;
        }
    }
    
    cout << s << '\n';
    return 0;
}
```

### 方法二：标准库函数 toupper

```cpp
#include <iostream>
#include <string>
#include <cctype>  // toupper 函数
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    string s;
    cin >> s;
    
    // toupper()：小写字母转大写，非字母原样返回
    for (int i = 0; i < s.size(); ++i) {
        s[i] = toupper(s[i]);
    }
    
    cout << s << '\n';
    return 0;
}
```

### 方法三：手动加减偏移量

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    string s;
    cin >> s;
    
    for (int i = 0; i < s.size(); ++i) {
        if (s[i] >= 'a' && s[i] <= 'z') {
            // 减去小写基准 'a'（得到0~25），加上大写基准 'A'
            s[i] = s[i] - 'a' + 'A';
        }
    }
    
    cout << s << '\n';
    return 0;
}
```

## 其他语言版本

### C 语言

```c
#include <stdio.h>
#include <string.h>

int main() {
    char s[101];
    scanf("%s", s);
    
    int len = strlen(s);
    for (int i = 0; i < len; i++) {
        if (s[i] >= 'a' && s[i] <= 'z') {
            s[i] &= ~32;
        }
    }
    
    printf("%s\n", s);
    return 0;
}
```

**C 语言要点**：
- 字符串用 `char` 数组存储，需要预分配空间（题目说最长 100，所以开 101 留余量）
- `strlen(s)` 获取字符串实际长度
- `scanf("%s", s)` 读入字符串（不加 `&`）
- `printf("%s", s)` 输出字符串

### Python

```python
s = input()
print(s.upper())
```

**Python 要点**：
- `input()` 读入一行字符串
- `upper()` 是字符串的内置方法，直接返回大写版本
- Python 字符串是不可变的，`upper()` 返回新字符串，不会修改原字符串

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        System.out.println(s.toUpperCase());
    }
}
```

**Java 要点**：
- `Scanner` 是 Java 的输入工具类
- `sc.next()` 读入一个字符串（遇到空格停止）
- `toUpperCase()` 返回大写版本的字符串
- Java 的 `String` 也是不可变的

## 复杂度分析

- **时间复杂度**：$O(n)$，遍历一次字符串
- **空间复杂度**：$O(1)$，只用了常数额外空间
