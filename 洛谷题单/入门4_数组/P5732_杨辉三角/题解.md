# P5732 【深基5.习7】杨辉三角

## 题目描述

给出 $n(1\le n\le20)$，输出杨辉三角的前 $n$ 行。

如果你不知道什么是杨辉三角，可以观察样例找找规律。

## 输入格式

输入一个整数 $n$。

## 输出格式

输出杨辉三角的前 $n$ 行，每行数字用空格分隔。

## 输入输出样例 #1

### 输入 #1

```
6
```

### 输出 #1

```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
1 5 10 10 5 1
```

## 解题思路

### 1. 理解杨辉三角的性质

杨辉三角是一个数字三角形，具有以下重要性质：

1. **每行首尾都是1**：第 $i$ 行的第 $0$ 个和第 $i$ 个元素都是 $1$
2. **递推关系**：每个中间的数字等于它上方两个数字之和
   - $C(n, k) = C(n-1, k-1) + C(n-1, k)$
3. **对称性**：第 $i$ 行的第 $k$ 个数与第 $i-k$ 个数相等

### 2. 算法选择

对于本题，有几种常见的实现方法：

#### 方法一：二维数组递推（本题采用）

- 使用二维数组 `a[i][j]` 存储杨辉三角
- 初始化：`a[i][0] = a[i][i] = 1`
- 递推：`a[i][j] = a[i-1][j-1] + a[i-1][j]`（$1 \le j < i$）
- 时间复杂度：$O(n^2)$
- 空间复杂度：$O(n^2)$

#### 方法二：组合数公式

- 杨辉三角第 $i$ 行第 $j$ 个数是 $C(i, j)$
- 可以使用组合数公式 $C(n, k) = \frac{n!}{k!(n-k)!}$ 计算
- 需要处理阶乘计算，可能涉及大数问题

#### 方法三：滚动数组优化

- 只使用一维数组，从后往前更新
- 空间复杂度可优化到 $O(n)$

### 3. 本题实现细节

```cpp
#include <iostream>
using namespace std;

int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    int n;
    cin >> n;
    int a[25][25] = {0};  // 数组大小为25，满足n≤20的要求
    
    // 构建杨辉三角
    for(int i=0;i<n;++i){
        a[i][0] = 1;  // 每行第一个元素为1
        a[i][i] = 1;  // 每行最后一个元素为1
        
        // 计算中间元素
        for(int j = 1; j < i; ++j){
            a[i][j] = a[i-1][j-1] + a[i-1][j];  // 递推公式
        }
    }

    // 输出结果
    for(int i=0;i<n;++i){
        for(int j=0;j<=i;++j){
            if(j>0) cout << " ";  // 数字间空格分隔
            cout << a[i][j];
        }
        cout<<endl;  // 换行
    }
    return 0;
}
```

## 算法知识总结

### 1. 杨辉三角的数学性质

1. **组合数表示**：第 $n$ 行第 $k$ 个数是组合数 $C(n, k)$
2. **对称性**：$C(n, k) = C(n, n-k)$
3. **递推关系**：$C(n, k) = C(n-1, k-1) + C(n-1, k)$
4. **行和性质**：第 $n$ 行所有数之和为 $2^n$

### 2. 相关算法应用

1. **二项式定理**：$(a+b)^n = \sum_{k=0}^{n} C(n, k) a^{n-k} b^k$
2. **组合数学**：解决组合计数问题
3. **动态规划**：杨辉三角是动态规划的入门例子
4. **路径计数**：网格中从一点到另一点的路径数

### 3. 编程实现要点

1. **数组定义**：注意数组大小要足够，本题 $n \le 20$，可定义 $25 \times 25$
2. **边界处理**：首尾元素直接赋值为1
3. **输出格式**：注意空格分隔和换行
4. **输入优化**：使用 `ios::sync_with_stdio(0)` 加快输入输出

### 4. 复杂度分析

- **时间复杂度**：$O(n^2)$，需要填充整个三角形
- **空间复杂度**：$O(n^2)$，使用二维数组存储

### 5. 扩展思考

1. 如何用一维数组（滚动数组）优化空间复杂度？
2. 如何计算杨辉三角中某个特定位置的值？
3. 杨辉三角在组合数学中还有哪些应用？
4. 如何处理更大的 $n$ 值（如 $n > 30$）？

### 6. 测试用例

- $n=1$：输出 `1`
- $n=2$：输出 `1` 和 `1 1`
- $n=3$：输出 `1`、`1 1`、`1 2 1`
- $n=6$：题目样例

## 常见错误

1. **数组越界**：定义的数组太小，当 $n=20$ 时需要至少 $21 \times 21$ 的数组
2. **边界错误**：忘记处理每行的首尾元素
3. **输出格式**：数字间缺少空格或多余空格
4. **索引错误**：循环条件写错，导致访问不存在的元素

## 多语言版本对比分析

### 1. C++版本特点

```cpp
#include <iostream>
using namespace std;

int main(){
    ios::sync_with_stdio(0);  // 关闭同步，加速输入输出
    cin.tie(0);                // 解除cin和cout的绑定
    int n;
    cin >> n;
    int a[25][25] = {0};      // 静态数组，编译时确定大小
    
    for(int i = 0; i < n; ++i){
        a[i][0] = 1;
        a[i][i] = 1;
        for(int j = 1; j < i; ++j){
            a[i][j] = a[i-1][j-1] + a[i-1][j];
        }
    }
    
    for(int i = 0; i < n; ++i){
        for(int j = 0; j <= i; ++j){
            if(j > 0) cout << " ";
            cout << a[i][j];
        }
        cout << endl;
    }
    return 0;
}
```

**特点：**
- 使用 `ios::sync_with_stdio(0)` 加速I/O操作
- 静态数组，内存分配在栈上
- 执行效率高，适合竞赛环境
- 编译后直接运行，无需解释器

### 2. C语言版本特点

```c
#include <stdio.h>

int main(){
    int n;
    scanf("%d", &n);  // 使用scanf读取输入
    int a[25][25] = {0};  // C语言静态数组
    
    for(int i = 0; i < n; ++i){
        a[i][0] = 1;
        a[i][i] = 1;
        for(int j = 1; j < i; ++j){
            a[i][j] = a[i-1][j-1] + a[i-1][j];
        }
    }
    
    for(int i = 0; i < n; ++i){
        for(int j = 0; j <= i; ++j){
            if(j > 0) printf(" ");
            printf("%d", a[i][j]);
        }
        printf("\n");
    }
    return 0;
}
```

**特点：**
- 使用 `scanf/printf` 进行I/O，效率较高
- 语法简洁，接近底层
- 内存管理手动控制
- 编译后可执行文件较小

### 3. Python版本特点

```python
n = int(input())  # Python动态类型

# 使用列表推导式创建二维列表
a = [[0] * 25 for _ in range(25)]

for i in range(n):
    a[i][0] = 1
    a[i][i] = 1
    for j in range(1, i):
        a[i][j] = a[i-1][j-1] + a[i-1][j]

# 使用join方法格式化输出
for i in range(n):
    print(' '.join(str(a[i][j]) for j in range(i+1)))
```

**特点：**
- 动态类型，无需声明变量类型
- 列表推导式语法简洁
- 使用 `join()` 方法高效拼接字符串
- 代码量最少，可读性强
- 运行速度相对较慢（解释执行）

### 4. Java版本特点

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);  // 使用Scanner类
        int n = sc.nextInt();
        int[][] a = new int[25][25];  // Java二维数组
        
        for(int i = 0; i < n; ++i){
            a[i][0] = 1;
            a[i][i] = 1;
            for(int j = 1; j < i; ++j){
                a[i][j] = a[i-1][j-1] + a[i-1][j];
            }
        }
        
        for(int i = 0; i < n; ++i){
            for(int j = 0; j <= i; ++j){
                if(j > 0) System.out.print(" ");
                System.out.print(a[i][j]);
            }
            System.out.println();
        }
        sc.close();  // 关闭资源
    }
}
```

**特点：**
- 面向对象，需要类定义
- 使用 `Scanner` 类进行输入
- 数组声明需要指定类型
- 代码结构规范，适合大型项目
- 需要JVM运行，启动稍慢

## 语言选择建议

| 语言 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| C++ | 竞赛、算法题 | 执行效率高，STL丰富 | 语法相对复杂 |
| C | 底层开发、嵌入式 | 接近硬件，效率高 | 缺乏高级特性 |
| Python | 快速开发、数据处理 | 代码简洁，库丰富 | 运行速度慢 |

## 学习建议

1. **初学者**：建议从Python开始，语法简单，易于理解算法逻辑
2. **竞赛选手**：推荐C++，执行效率高，适合时间敏感的题目
3. **系统开发**：选择C/C++，性能好，贴近底层
4. **工程开发**：Java是不错的选择，结构清晰，易于维护

## 多语言实现要点总结

1. **核心算法相同**：所有语言都使用相同的递推逻辑
2. **I/O方式不同**：
   - C++: `cin/cout`
   - C: `scanf/printf`
   - Python: `input/print`
   - Java: `Scanner/System.out`
3. **数组定义不同**：
   - C/C++: 静态数组，编译时分配
   - Python: 动态列表
   - Java: 对象数组
4. **代码风格差异**：
   - C/C++: 简洁直接
   - Python: 优雅简洁
   - Java: 结构规范
