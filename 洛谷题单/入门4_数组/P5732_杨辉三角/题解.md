## 题目描述

输出杨辉三角的前 n 行。

## 输入格式

一个整数 n。

## 输出格式

n 行，每行若干个整数，空格分隔。

## 数据范围

$1 \le n \le 20$

## 样例

### 输入

```
6
```

### 输出

```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
1 5 10 10 5 1
```

## 解题思路

### 审题过程

1. **理解题意**：输出杨辉三角的前 n 行。
2. **关键观察**：杨辉三角有递推关系——每个数等于它上方两个数之和。
3. **建模**：二维数组递推。

### 方法一：二维数组递推

**递推公式**：`a[i][j] = a[i-1][j-1] + a[i-1][j]`

```
第0行：        1
第1行：      1   1
第2行：    1   2   1
第3行：  1   3   3   1
第4行：1   4   6   4   1
```

**性质**：
- 每行首尾都是 1
- 中间元素 = 上一行左上方 + 上一行正上方
- 第 i 行有 i+1 个元素

## 代码实现

```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    int a[25][25] = {0};

    for (int i = 0; i < n; ++i) {
        a[i][0] = 1;
        a[i][i] = 1;
        for (int j = 1; j < i; ++j) {
            a[i][j] = a[i-1][j-1] + a[i-1][j];
        }
    }

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j <= i; ++j) {
            if (j > 0) cout << " ";
            cout << a[i][j];
        }
        cout << endl;
    }

    return 0;
}
```

## 易错点

1. 每行有 i+1 个元素（从 0 开始）
2. 首尾都是 1，中间元素由上一行推导
3. 输出格式：数字间空格分隔

## 总结发散

### 核心模式：递推

杨辉三角是**动态规划的入门题**。递推的核心思想：从已知推出未知。

| 杨辉三角 | DP 应用 |
|----------|---------|
| `a[i][j] = a[i-1][j-1] + a[i-1][j]` | 01 背包：`dp[j] = max(dp[j], dp[j-w]+v)` |
| 每行只依赖上一行 | 空间优化：滚动数组 |

### 数学联系

- 杨辉三角第 n 行就是 $(a+b)^n$ 的展开系数
- 第 n 行第 k 个数 = $C(n, k)$（组合数）
- 每行数字之和 = $2^n$
