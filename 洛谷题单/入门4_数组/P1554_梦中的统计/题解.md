## 题目描述

统计区间 [M, N] 中所有整数中，数字 0~9 各出现了多少次。

## 输入格式

一行两个整数 M 和 N。

## 输出格式

一行 10 个整数，分别表示数字 0~9 出现的次数，空格分隔。

## 数据范围

$1 \le M \le N \le 10^6$

## 样例

### 输入

```
1 10
```

### 输出

```
1 2 2 1 1 1 1 1 1 1
```

---

## 解题思路

### 审题过程

1. **理解题意**：统计 [M, N] 区间内所有整数中，数字 0~9 各出现多少次。
2. **关键观察**：每个数可以拆分成若干位数字，逐位统计即可。
3. **建模**：用 `cnt[10]` 数组统计 0~9 的出现次数。

### 方法一：逐位拆分

**核心技巧**：`%10` 取最低位，`/10` 去掉最低位。

```
数字 123：
123 % 10 = 3 → cnt[3]++
123 / 10 = 12
12 % 10 = 2 → cnt[2]++
12 / 10 = 1
1 % 10 = 1 → cnt[1]++
1 / 10 = 0 → 结束
```

## 代码实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int M, N;
    cin >> M >> N;

    vector<int> cnt(10, 0);

    for (int i = M; i <= N; ++i) {
        int x = i;
        while (x > 0) {
            int d = x % 10;
            cnt[d]++;
            x /= 10;
        }
    }

    for (int i = 0; i < 10; ++i) {
        cout << cnt[i];
        if (i != 9) cout << ' ';
    }
    cout << endl;

    return 0;
}
```

## 易错点

1. 当 i == 0 时 while 循环不执行，需要单独处理（本题 M>=1 无此问题）
2. 输出格式：数字间空格分隔，最后一个后无空格
