## 题目描述

有 n 盏灯，每盏灯有一个实数参数 a 和操作次数 t。第 i 盏灯会对编号为 $(j \times a)$ 取整的灯进行开关操作（j 从 1 到 t）。求最后亮着的灯的最小编号。

## 输入格式

第一行：n。
接下来 n 行，每行一个实数 a 和一个整数 t。

## 输出格式

一个整数，亮着的灯的最小编号。

## 数据范围

$1 \le n \le 20$，$1 \le t \le 2000000$

## 样例

### 输入

```
2
0.500000 3
0.750000 4
```

### 输出

```
1
```

---

## 解题思路

### 审题过程

1. **理解题意**：n 盏灯，每盏灯有参数 a 和操作次数 t。第 i 盏灯对编号为 `floor(j × a)` 的灯进行开关操作（j=1..t）。求最后亮着的最小编号。
2. **关键观察**：每盏灯的操作是独立的，操作顺序不影响最终结果（因为两次开关等于没操作）。
3. **建模**：用布尔数组记录每盏灯的状态，模拟所有操作。

### 方法一：布尔数组模拟

**核心技巧**：浮点数乘法有精度问题，将 a 乘以 1000000 转为整数运算。

```
a = 0.5 → A = 500000
j = 1: idx = (1 × 500000) / 1000000 = 0
j = 2: idx = (2 × 500000) / 1000000 = 1
j = 3: idx = (3 × 500000) / 1000000 = 1
```

## 代码实现

```cpp
#include <iostream>
using namespace std;

const int MAXM = 2000005;
bool light[MAXM];

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    int n;
    cin >> n;
    for (int i = 0; i < n; ++i) {
        double a;
        int t;
        cin >> a >> t;
        long long A = (long long)(a * 1000000 + 0.5);
        for (int j = 1; j <= t; ++j) {
            long long idx = (j * A) / 1000000;
            light[idx] = !light[idx];
        }
    }

    for (int i = 1; ; ++i) {
        if (light[i]) {
            cout << i << '\n';
            break;
        }
    }
    return 0;
}
```

## 易错点

1. 浮点数乘法有精度问题，需要乘以 1000000 转为整数运算
2. 灯的编号从 1 开始
3. 数组要开到 2000005 以上

## 总结发散

### 核心模式：状态翻转

本题的核心是 **`light[idx] = !light[idx]`**——状态翻转。这是异或思想的体现：翻转两次等于没翻转。

### 精度处理技巧

| 问题 | 解决方案 |
|------|----------|
| 浮点数乘法不精确 | 乘以 10^6 转为整数运算 |
| 四舍五入 | `(long long)(a * 1000000 + 0.5)` |
| 整数除法截断 | `(j * A) / 1000000` |
