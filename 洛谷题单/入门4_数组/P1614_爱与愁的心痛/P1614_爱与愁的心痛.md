

# P1614 爱与愁的心痛 题解

## 题目理解

给定一个长度为 `n` 的整数序列（刺痛值），需要找出**所有长度为 `m` 的连续子段的和**，输出其中的**最小值**。

## 解题思路

### 暴力枚举

- 遍历所有可能的起始位置 `i`（从 0 到 `n-m`）
- 对每个起始位置，计算从 `i` 到 `i+m-1` 这 `m` 个数的和
- 记录最小值

由于题目保证 `n ≤ 3000`，最坏情况下需要计算约 `n*m ≤ 9×10^6` 次加法，完全可行。

### 滑动窗口（优化）

- 先计算第一个窗口 `[0, m-1]` 的和
- 然后每次窗口向右移动一位：`新窗口和 = 旧窗口和 - 离开元素 + 新进入元素`
- 每次更新最小值，时间复杂度 O(n)

## 边界情况

- 当 `m = 0` 时，没有连续的元素，和为 `0`（题目未明确，但根据常识输出 0）
- 当 `m = n` 时，只有一个窗口，即所有元素之和

## AC 代码

### 滑动窗口版本

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main() {
    int n, m;
    cin >> n >> m;

    vector<int> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }

    int sum = 0;
    for (int i = 0; i < m; ++i) {
        sum += a[i];
    }

    int min_sum = sum;

    for (int i = m; i < n; ++i) {
        sum = sum - a[i - m] + a[i];
        if (sum < min_sum) {
            min_sum = sum;
        }
    }

    cout << min_sum << endl;
    return 0;
}
```

### 暴力版本

```cpp
int min_sum = INT_MAX;
for (int i = 0; i <= n - m; ++i) {
    int sum = 0;
    for (int j = i; j < i + m; ++j) {
        sum += a[j];
    }
    if (sum < min_sum) min_sum = sum;
}
```

## 用户代码问题分析

### 1. vector 容器大小固定为 101

其实是因为没有看清楚题目上的边界条件

```cpp
vector<int> a(101);
```

题目中 `n` 最大可达 3000，而数组大小只有 101，当 `n > 101` 时会**越界访问**，导致程序崩溃或未定义行为。

正确做法：`vector<int> a(n);`

### 2. 核心求和逻辑错误且不完整

```cpp
for (int i = 0; i < n; ++i) {
    for(int j = 0; j < i; ++j){
        sum
    }
}
```

- 内层循环 `j < i` 没有求和操作，`sum` 后面没有运算
- 没有计算连续 `m` 个数的和
- 没有比较和的最小值，也没有输出结果

### 3. 循环边界错误

连续长度为 `m` 的子段，起始下标范围应为 `0` 到 `n-m`，而不是 `0` 到 `n-1`。

## 总结建议

1. **容器大小**：始终根据输入数据的大小动态分配，避免魔法数字
2. **逻辑设计**：先明确算法步骤（如滑动窗口或前缀和），再动手编码
3. **边界测试**：测试 `m=0`、`m=n`、`n=1` 等边界情况
4. **变量命名**：`sum` 和 `min_sum` 区分清楚，及时初始化
5. **调试方法**：添加输出中间结果（如每次窗口的和）来验证逻辑
