## 题目描述

一条马路长 L 米，路上有 M 段区间被占用。初始时每隔 1 米种一棵树，被占用的区间内的树要移走。求最后剩下多少棵树。

## 输入格式

第一行：L 和 M（马路长度和占用区间数）。
接下来 M 行，每行两个整数 start 和 end，表示被占用的区间。

## 输出格式

一个整数，剩余树的数量。

## 数据范围

$0 \le L \le 10000$，$1 \le M \le 100$

## 样例

### 输入

```
10 2
2 3
5 7
```

### 输出

```
6
```

---

## 解题思路

### 审题过程

1. **理解题意**：马路上每隔 1 米种一棵树，共 L+1 棵（从位置 0 到 L）。M 段区间被占用，这些区间内的树要移走。
2. **关键观察**：每个位置要么有树要么没有，这是一个二元状态问题。
3. **建模**：用布尔数组表示每个位置的状态——有树为 true，无树为 false。

### 方法一：布尔数组标记（推荐）

**第一步：初始化**
用 `tree[i]` 表示位置 i 是否有树。初始时所有位置都有树，全部设为 true。

**第二步：标记移除**
对每个占用区间 [start, end]，将 tree[start] 到 tree[end] 全部设为 false。

**第三步：统计结果**
遍历 0 到 L，统计 tree[i] 为 true 的个数。

```
初始：  T T T T T T T T T T T   (0~10，共11棵)
移除2~3：T T F F T T T T T T T
移除5~7：T T F F T F F F T T T
剩余：  1 1 0 0 1 0 0 0 1 1 1 = 6棵
```

**核心思路**：标记 + 统计。这是最直观的模拟方法。

## 代码实现

```cpp
#include <iostream>
using namespace std;

const int MAXN = 10010;
bool tree[MAXN] = {true};

int main() {
    int L, M;
    cin >> L >> M;

    for (int i = 0; i < M; ++i) {
        int start, end;
        cin >> start >> end;
        for (int j = start; j <= end; ++j) {
            tree[j] = false;
        }
    }

    int count = 0;
    for (int i = 0; i <= L; ++i) {
        if (tree[i]) count++;
    }

    cout << count << endl;
    return 0;
}
```

## 易错点

1. 树的下标从 0 到 L，共 L+1 棵
2. 区间是闭区间 [start, end]
3. `bool` 数组全局定义时默认为 false，需要手动初始化

## 总结发散

### 核心模式：标记数组

本题的核心是**用数组记录状态**。这个模式在很多题目中出现：

| 变体 | 题目 | 思路 |
|------|------|------|
| 一维标记 | P1047 校门外的树 | bool 数组标记位置 |
| 状态翻转 | P1161 开灯 | `light[idx] = !light[idx]` |
| 二维标记 | P5729 工艺品制作 | 二维数组标记区域 |
| 计数标记 | P2141 珠心算测验 | 标记两数之和 |

### 进阶方向

- **差分数组**：如果区间操作很多，可以用差分数组将 O(L) 的区间修改优化为 O(1)
- **线段树**：更高级的数据结构，支持区间修改和区间查询
- **容斥原理**：多个区间有重叠时，如何不重复计数
