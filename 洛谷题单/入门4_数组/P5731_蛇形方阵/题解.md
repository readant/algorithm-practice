## 题目描述

给出一个不大于 9 的正整数 $n$，输出 $n \times n$ 的蛇形方阵。

从左上角填上 1 开始，顺时针方向依次填入数字。每个数字占用 3 个字符宽度，不足用空格补齐。

### 输入输出样例

**输入：**

```
4
```

**输出：**

```
  1  2  3  4
 12 13 14  5
 11 16 15  6
 10  9  8  7
```

数据保证 $1 \leq n \leq 9$。

---

## 解题思路

### 核心思想：方向模拟（螺旋填充）

这道题的本质就是**按螺旋顺序填数字**。我们不需要真的去推导数学公式，只需要模拟"一条蛇"在方阵里爬的过程：

```
→
1  2  3  4
↓        ↓
12 13 14  5
↑        ↓
11 16 15  6
←        ↓
10 9  8  7
```

### 怎么模拟？用方向数组

**第一步：定义 4 个方向**

我们用两个数组来表示"右、下、左、上"四个方向的移动：

| 方向 | dx（行变化） | dy（列变化） |
| ---- | ------------ | ------------ |
| 右   | 0            | +1           |
| 下   | +1           | 0            |
| 左   | 0            | -1           |
| 上   | -1           | 0            |

```cpp
int dx[4] = {0, 1, 0, -1};  // 行的变化
int dy[4] = {1, 0, -1, 0};  // 列的变化
```

**第二步：模拟爬行过程**

从 `(0, 0)` 出发，每走一步就填一个数。关键问题：什么时候该转弯？

- 如果下一步**越界**了（超出方阵范围），转弯
- 如果下一步**已经有数字**了（被填过了），转弯

转弯就是把方向索引 `+1`，取模 4：

```cpp
dir = (dir + 1) % 4;
```

**第三步：输出**

每个数字占 3 个字符宽度，右对齐。

### 手动模拟一遍（n=4）

| 步骤 | 位置  | 数字 | 方向 | 下一步判断         |
| ---- | ----- | ---- | ---- | ------------------ |
| 1    | (0,0) | 1    | →    | (0,1) 可走         |
| 2    | (0,1) | 2    | →    | (0,2) 可走         |
| 3    | (0,2) | 3    | →    | (0,3) 可走         |
| 4    | (0,3) | 4    | →    | (0,4) 越界！转弯 ↓ |
| 5    | (1,3) | 5    | ↓    | (2,3) 可走         |
| ...  | ...   | ...  | ...  | ...                |

就这样一直填到 $n^2$ 为止。

## 代码实现

### C++ 版本

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int n;
    cin >> n;

    int a[10][10] = {0};  // n最大9，多开防越界

    // 方向：右、下、左、上
    int dx[4] = {0, 1, 0, -1};
    int dy[4] = {1, 0, -1, 0};

    int x = 0, y = 0, dir = 0;

    for (int num = 1; num <= n * n; ++num) {
        a[x][y] = num;
        int nx = x + dx[dir];
        int ny = y + dy[dir];
        // 越界或已填充则转向
        if (nx < 0 || nx >= n || ny < 0 || ny >= n || a[nx][ny] != 0) {
            dir = (dir + 1) % 4;
            nx = x + dx[dir];
            ny = y + dy[dir];
        }
        x = nx;
        y = ny;
    }

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < n; ++j) {
            cout << setw(3) << a[i][j];
        }
        cout << '\n';
    }
    return 0;
}
```

## 易错点

### 1. 输出宽度必须是 3 个字符

题目要求每个数字占 3 个字符宽度，不足补空格。如果直接输出数字，格式会错。

| 语言   | 正确写法                             |
| ------ | ------------------------------------ |
| C++    | `cout << setw(3) << num;`            |
| C      | `printf("%3d", num);`                |
| Python | `f"{num:3d}"` 或 `format(num, ">3")` |
| Java   | `String.format("%3d", num)`          |

### 2. 数组要多开一点

`n` 最大是 9，所以 `a[9][9]` 刚好够用，但访问 `a[n-1][n-1]` 时如果方向判断出错可能越界。建议开 `a[10][10]` 留余量，C++ 用 `{0}` 初始化，C 用 `memset`。

### 3. 转弯条件要同时判断两件事

转弯不光是"越界"，还包括"格子已经填过数字"。漏掉第二个条件会导致数字覆盖。

### 4. 先填数字，再移动

循环里应该是：**先填当前格 → 再算下一步 → 判断是否转弯 → 移动**。如果顺序搞反（先移动再填），起始位置会漏填。
