# P5731 蛇形方阵 - 算法模型与技巧

## 核心算法模型

### 1. 方向模拟法（螺旋矩阵生成）

**模型**：使用方向数组 + 碰撞检测

- 维护当前位置 `(x, y)` 和当前方向索引
- 方向数组：`dx[4] = {0, 1, 0, -1}`, `dy[4] = {1, 0, -1, 0}` 对应右、下、左、上
- 每步计算下一步位置，检测边界或已填充格子
- 碰撞时顺时针旋转90度（方向索引+1模4）

**关键技巧**：

- 方向转换使用模运算 `dir = (dir + 1) % 4`
- 使用额外一圈边界避免复杂边界检查（本题用10×10数组处理n≤9）
- 填充顺序：先填当前格，再计算下一步

### 2. 数字填充规律

**螺旋顺序**：

1. 从左上角开始，向右填充第一行
2. 向下填充最右列
3. 向左填充最下行
4. 向上填充最左列
5. 重复内层螺旋

**数学性质**：

- 每层螺旋填充的数字个数：外层 `4*(n-1)`，内层递减
- 第k层（从0开始）起始数字：可推导公式，但模拟更直观

### 方法2：纯 `<iostream>` 底层实现

**宽度控制**：

```cpp
// 手动填充空格
void printWithWidth(int num, int width) {
    int digits = (num == 0) ? 1 : 0;
    int temp = num;
    while (temp > 0) {
        digits++;
        temp /= 10;
    }
    // 输出前导空格
    for (int i = 0; i < width - digits; ++i) {
        cout << ' ';
    }
    cout << num;
}
```

**数字位数计算**：

- 特殊处理0的情况
- 循环除以10计算位数
- 注意：本题n≤9，最大数字81，2位数

## 算法优化思路

### 1. 空间优化

- 原地填充：如果不需要保留矩阵，可直接输出
- 使用一维数组模拟二维

### 2. 时间优化

- 预计算每层边界：减少重复检查
- 数学公式直接计算位置：复杂但高效

### 3. 代码简洁性

- 使用STL `pair` 和 `vector` 简化坐标管理
- 使用 `enum` 明确方向定义

## 实现模板

### 标准螺旋填充模板

```cpp
int a[N][N] = {0};
int dx[] = {0, 1, 0, -1};
int dy[] = {1, 0, -1, 0};
int x = 0, y = 0, dir = 0;

for (int num = 1; num <= n*n; ++num) {
    a[x][y] = num;
    int nx = x + dx[dir];
    int ny = y + dy[dir];
    if (nx < 0 || nx >= n || ny < 0 || ny >= n || a[nx][ny] != 0) {
        dir = (dir + 1) % 4;
        nx = x + dx[dir];
        ny = y + dy[dir];
    }
    x = nx;
    y = ny;
}
```

### 格式化输出模板（无iomanip）

```cpp
void printNum(int num, int width) {
    if (num == 0) {
        for (int i = 0; i < width-1; ++i) cout << ' ';
        cout << 0;
        return;
    }
    int temp = num, digits = 0;
    while (temp > 0) {
        digits++;
        temp /= 10;
    }
    for (int i = 0; i < width - digits; ++i) cout << ' ';
    cout << num;
}
```
