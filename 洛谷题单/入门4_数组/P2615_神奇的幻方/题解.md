## 题目描述

构造一个 N×N 的幻方（N 为奇数），使得每行、每列、两条对角线的和相等。

## 输入格式

一个奇数 N。

## 输出格式

N 行 N 列的幻方矩阵。

## 数据范围

$3 \le N \le 39$，N 为奇数

## 样例

### 输入

```
3
```

### 输出

```
8 1 6
3 5 7
4 9 2
```

## 解题思路

### 审题过程

1. **理解题意**：构造 N×N 幻方（N 为奇数），使每行、每列、对角线之和相等。
2. **关键观察**：奇数幻方有经典的构造方法（Siamese method）。
3. **建模**：按规则逐步填数。

### 方法一：Siamese Method

**构造规则**：
1. 数字 1 放在第一行中间
2. 每次向右上方移动一格
3. 超出边界 → 绕到对侧
4. 目标位置已有数字 → 向下移动一格

**为什么有效？** 这个规则保证了每个数字都被恰好填入一次，且满足幻方的行列对角线和相等的性质。

## 代码实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int N;
    cin >> N;

    vector<vector<int>> magic(N, vector<int>(N, 0));
    int x = 0, y = N / 2;
    magic[x][y] = 1;

    for (int k = 2; k <= N * N; ++k) {
        int nx, ny;
        if (x == 0 && y != N - 1) {
            nx = N - 1; ny = y + 1;
        } else if (y == N - 1 && x != 0) {
            nx = x - 1; ny = 0;
        } else if (x == 0 && y == N - 1) {
            nx = x + 1; ny = y;
        } else {
            if (magic[x - 1][y + 1] == 0) {
                nx = x - 1; ny = y + 1;
            } else {
                nx = x + 1; ny = y;
            }
        }
        magic[nx][ny] = k;
        x = nx; y = ny;
    }

    for (const auto& row : magic) {
        for (size_t j = 0; j < row.size(); ++j) {
            cout << row[j];
            if (j + 1 < row.size()) cout << ' ';
        }
        cout << '\n';
    }
    return 0;
}
```

## 易错点

1. N 必须是奇数
2. 超出边界时要绕到对侧
3. 目标位置已有数字时向下移
