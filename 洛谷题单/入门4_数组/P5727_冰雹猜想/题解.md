## 题目描述

给定一个正整数 n，按规则生成序列：若为偶数则除以 2，若为奇数则乘 3 加 1，直到变为 1。

## 输入格式

一个正整数 n。

## 输出格式

序列中的所有数，空格分隔。

## 数据范围

$1 \le n \le 10^6$

## 样例

### 输入

```
5
```

### 输出

```
5 16 8 4 2 1
```

---

## 解题思路

### 审题过程

1. **理解题意**：给定正整数 n，按规则生成序列直到变为 1。
2. **关键观察**：规则简单——偶数除 2，奇数乘 3 加 1。
3. **建模**：while 循环模拟。

### 方法一：直接模拟

**核心**：`while (n != 1)` 循环，每次按规则更新 n。

**注意**：先输出当前 n，再更新。最后单独输出 1。

## 代码实现

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    while (n != 1) {
        cout << n << " ";
        if (n % 2 == 0) {
            n /= 2;
        } else {
            n = n * 3 + 1;
        }
    }
    cout << 1 << endl;

    return 0;
}
```

## 易错点

1. 先输出当前 n，再更新
2. 最后要单独输出 1
3. n 可能很大，但 int 范围足够

## 总结发散

### 核心模式：规则模拟

本题是最简单的规则模拟——按给定规则不断变换，直到满足终止条件。

### 冰雹猜想的数学背景

冰雹猜想（Collatz Conjective）是著名的未解决问题：**是否所有正整数最终都会变为 1？** 目前计算机验证到了 $2^{68}$，但尚未证明。
