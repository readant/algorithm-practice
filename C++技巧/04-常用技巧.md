# C++ 常用技巧

## 一、万能头文件

```cpp
#include <bits/stdc++.h>
using namespace std;

// 包含所有常用头文件，适合竞赛
```

## 二、常用宏定义

```cpp
#define endl '\n'           // 换行符（比 endl 快）
#define ll long long        // 长整型
#define pb push_back        // vector添加元素
#define mp make_pair        // 创建pair
#define all(v) v.begin(), v.end()  // 整个范围

// 循环宏
#define FOR(i, a, b) for (int i = (a); i < (b); ++i)
#define ROF(i, a, b) for (int i = (a); i >= (b); --i)
```

## 三、typedef 和 using

```cpp
// typedef 方式
typedef long long ll;
typedef vector<int> vi;
typedef pair<int, int> pii;

// using 方式（C++11）
using ll = long long;
using vi = vector<int>;
using pii = pair<int, int>;
```

## 四、pair 的使用

```cpp
#include <utility>

pair<int, string> p = make_pair(1, "hello");
// 或
pair<int, string> p = {1, "hello"};

// 访问
cout << p.first << endl;   // 1
cout << p.second << endl;  // hello

// 比较：先比较 first，再比较 second
```

## 五、lambda 表达式

```cpp
// 排序
vector<int> v = {3, 1, 4, 1, 5};
sort(v.begin(), v.end(), [](int a, int b) {
    return a > b;  // 降序
});

// 自定义比较
sort(v.begin(), v.end(), [](int a, int b) {
    return abs(a) < abs(b);  // 按绝对值排序
});
```

## 六、随机数生成

```cpp
#include <random>

random_device rd;
mt19937 gen(rd());
uniform_int_distribution<> dis(1, 100);

int random_num = dis(gen);
```

## 七、时间测量

```cpp
#include <chrono>

auto start = chrono::high_resolution_clock::now();

// 你的代码

auto end = chrono::high_resolution_clock::now();
auto duration = chrono::duration_cast<chrono::milliseconds>(end - start);
cout << "耗时: " << duration.count() << "ms" << endl;
```
