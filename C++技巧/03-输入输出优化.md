# C++ 输入输出优化

## 一、快速输入输出

```cpp
#include <iostream>
using namespace std;

int main() {
    // 关闭同步，加速 cin/cout
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);

    int n;
    cin >> n;
    cout << n << endl;

    return 0;
}
```

## 二、格式化输出

```cpp
#include <iomanip>

// 控制精度
double pi = 3.1415926;
cout << fixed << setprecision(2) << pi << endl;  // 3.14

// 控制宽度
cout << setw(5) << 42 << endl;  // "   42"

// 填充字符
cout << setfill('0') << setw(5) << 42 << endl;  // "00042"

// 科学计数法
cout << scientific << pi << endl;  // 3.141593e+00
```

## 三、多组输入

```cpp
// 方式1：EOF 结束
int a, b;
while (cin >> a >> b) {
    cout << a + b << endl;
}

// 方式2：指定组数
int t;
cin >> t;
while (t--) {
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
}

// 方式3：特殊值结束
while (cin >> a >> b && a != 0 && b != 0) {
    cout << a + b << endl;
}
```

## 四、字符串输入

```cpp
#include <string>

string s;
cin >> s;           // 读一个单词
getline(cin, s);    // 读一行

// 混合使用时的注意事项
int n;
cin >> n;
cin.ignore();       // 清空缓冲区
getline(cin, s);
```

## 五、数组输入

```cpp
int n;
cin >> n;
vector<int> v(n);
for (int i = 0; i < n; ++i) {
    cin >> v[i];
}

// 或者
vector<int> v;
for (int i = 0; i < n; ++i) {
    int x;
    cin >> x;
    v.push_back(x);
}
```
